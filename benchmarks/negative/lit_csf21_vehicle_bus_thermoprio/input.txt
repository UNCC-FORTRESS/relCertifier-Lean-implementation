# lit_csf21_vehicle_bus_thermoprio: the internal-bus car of lit_csf21_vehicle_bus with the bus
# arbitration reversed (thermostat messages first), expected DECLINED (the temperature reading now
# reaches the velocity through the bus). NOT part of the certified suite: a negative exhibit.
# scenario: sensor-attack
#
# Same plant, constants, actions, settings, domain and claim as benchmarks/suite_v2/
# lit_csf21_vehicle_bus (source: Xiang, Fulton, Chong, CSF 2021, Sec. VI-C, Figs. 11-12). One
# change, ours and on BOTH sides: the source sends a thermostat message only in a cycle whose
# acceleration does not change (busV = a, acceleration priority); here a cycle whose thermostat
# reading asks for the other setting sends the thermostat message, and the drive keeps its current
# action for that cycle even where the action's choice guard fails (Acc held past psi within
# 0 <= v <= 39, Brk held from v >= 1, Coast held at v <= 1). Modes xtA (acceleration message, the
# action's choice guard) and xtT (thermostat message, entered from the same action with the other
# setting, the action's hold guard) on both sides; the genuine car adds its thermostat guard
# (temp >= 20 for Cool, temp <= 20 for Heat) to both, so an inconsistent setting forces the
# thermostat message; the attacked reading is free, so the attacked car may send one in any cycle.
# Four genuine modes BrkCoolE, BrkHeatE (v >= 39) and CoastCoolE, CoastHeatE (v < 1): the genuine
# drive overrides the thermostat at the speed limits, so the right model never blocks (Assumption 1).
#
# The leak, by hand (and exhaustively over the 3^4 x 2^4 genuine message and setting sequences by
# tmp/lit-r6/lit_csf21_vehicle_bus/handrun_check.py). From d = 3, v = 0 the attacked car runs
# AccHeatA (psi holds), AccCoolT (Acc held at v = 1 where psi fails: 5 > 7 is false), BrkCoolA
# (v = 2), CoastCoolA (v = 1). A genuine car can hold Acc in cycle 1 only through a forced or tied
# thermostat message, so its temperature is within 1 of 20 after it; cycles 2 and 3 change the
# action, so both need acceleration messages, which need the setting to stay consistent for two
# cycles while the temperature moves 1 per cycle away from 20: impossible. No genuine start
# temperature or mode matches, so the source's H-equivalence fails, not only the per-state form.
#
# Verdicts (RELCERT_IMPLIED_CUT=1, measured 2026-10-29 on branch benchmark-fixes, tip 131cb10):
# DECLINED (1.5 s). relcert --wellformed: 16 right modes, 2 ok (invariant), 14 ok (exit),
# 0 UNKNOWN, 0 BLOCKING. Without the four override modes 8 Acc and Brk right modes are UNKNOWN (by hand:
# a forced Acc hold at v > 39 or Brk hold at v < 1 leaves the domain).
