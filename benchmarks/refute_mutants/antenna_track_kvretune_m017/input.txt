# antenna_track_kvretune: the elevation axis of a 7.3 m X-band LEO ground-station antenna whose servo was
# retuned to a lower velocity error constant after a drive-gearbox replacement, against the axis as commissioned,
# over the end of a pass: program track down to loss of signal, then the slew to the zenith stow. The pointing
# requirement holds while tracking; after LOS only the slew lag is bounded.
# scenario: controller-change
# mechanisms: D (mode-dependent rows: while tracking the pointing row is held to a tenth of the beamwidth, during
#   the stow slew the row is the slew-lag envelope; every uniform row set declines at the pointing requirement;
#   matrix code M5)
#
# System (both sides). Pass clock t in s, commanded elevation c (the antenna control unit's program) and actual
# elevation x in deg; the ACU updates its program every 50 ms (epsilon 0.05 on both sides). Type-1 position loop
# with velocity error constant K (s^-1): x' = K (c - x), so a constant command rate w is followed with the lag
# w / K.
#   TRACK   t < 60         program track of the pass's descending leg, c' = -0.7 (c = 47 - 0.7 t, from 47 deg to
#                          the 5 deg mask at LOS; 0.7 deg/s is the maximum elevation rate of a near-zenith pass at
#                          about 600 km, orbital speed / altitude = 7.56 km/s / 600 km = 0.72 deg/s, taken for the
#                          whole leg, the worst case for the lag)
#   STOW    t >= 60, c < 90   after LOS the ACU slews to the zenith survival stow at the 5 deg/s axis limit, c' = 5
#   STOWED  c >= 90        hold at stow, c' = 0
# TRACK -> [TRACK, STOW, STOWED], STOW -> [STOW, STOWED], STOWED -> [STOWED]. Antenna numbers from a 7.3 m X-band
# full-motion antenna datasheet (Antesky): -3 dB beamwidth 0.36 deg at 8.0-8.5 GHz, travel speed 5 deg/s,
# tracking accuracy <= 0.05 deg RMS.
# Right (reference): the axis as commissioned, K = 30 /s (tracking lag 0.023 deg, slew lag 0.17 deg).
# Left (deployed): the same antenna, pass and program after the elevation gearbox was replaced: the softer drive
#   train lowers the locked-rotor resonance, and the position loop was retuned to K = 20 /s to keep its bandwidth
#   clear of it (servo practice: the loop bandwidth is held to a fraction of the locked-rotor resonance). Lags:
#   0.035 deg tracking, 0.25 deg slewing. The loop gain is the only difference.
#
# Property (mode-dependent).
#   TRACK:        t_L = t_R, c_L = c_R, |x_L - x_R| <= 0.035, and the validated axis's own lag envelope
#                 x_R - c_R <= 0.025, c_R - x_R <= 0 (descending: it lies at most 0.7 / 30 = 0.023 above its
#                 command, rounded up, and never below it).
#   STOW, STOWED: t_L = t_R, c_L = c_R, |x_L - x_R| <= 0.25, envelope x_R - c_R <= 0.025, c_R - x_R <= 0.17
#                 (5 / 30 = 0.167 below it while slewing up, rounded up).
# Requirement (TRACK): the retuned antenna points within a tenth of the 0.36 deg beamwidth of where the validated
# antenna points, 0.035 deg (Gaussian-beam pointing loss 12 (theta / theta_3dB)^2 dB: at most 0.12 dB more than
# the validated link budget). After LOS there is no signal and no pointing requirement; the STOW row is the
# slew-lag envelope 0.25 deg = 5 / 20, the retuned axis's own following error at the slew limit (a derived bound,
# not a requirement). The envelope rows are stated strengthening rows (without them the file DECLINES); the
# pointing row's residual is (K_R - K_L) / K_L times the validated lag. Tightest: TRACK 0.0125 (0.012 declines)
# = 10 / 20 x 0.025; STOW 0.085 (0.084 declines) = 10 / 20 x 0.17. Not implied by the domains (94 deg).
#
# Why the rows must differ (D). The following error grows with the command rate: at the 0.7 deg/s track rate the
# two lags differ by at most 0.0125 deg, inside the pointing requirement; at the 5 deg/s stow slew they differ by
# up to 0.085 deg, far outside it but harmless, since the link is down. Uniform rows with the slew envelope
# DECLINE at every band below 0.085 (measured 0.035, 0.05, 0.083, 0.084; 0.085 certifies): 2.4 times the
# pointing requirement. Uniform STOW rows (0.25) CERTIFY but do not state the requirement. So no uniform row set
# meets the requirement; the keyed rows do. The handoffs only relax (TRACK -> STOW, TRACK -> STOWED: 0.035 ->
# 0.25 and the envelope 0 -> 0.17; --handoff 6/6 unsat). This is neither molding_pack_checkring's gate-freeze
# drop nor hydro_rejection_gatecal's shared-grid equality: the same coordinates are bounded in every mode, the
# loop gain acts in every mode, and the bound changes because the command rate changes, together with the
# requirement that applies only while a signal is tracked.
# How the claim depends on the cause (measured): K_L = 30 (no retune): the exact uniform claim (all constants 0)
# CERTIFIES, also under RELCERT_SYNC=1, nothing mode-dependent; K_L = 25: tightest TRACK 0.005; 20 (this file):
# 0.0125; 15: 0.025 (STOW 0.17); 12.5: CERTIFIED; 12: DECLINED (the pointing requirement tolerates a velocity
# error constant down to about 12.5 /s). D window: at K_L = 24 a uniform 0.035 band DECLINES, at 26 it
# CERTIFIES, so D holds for K_L in [12.5, 24]. Law dependence: an arbitrary deployed schedule (every left guard
# the domain, each mode a successor of every other) DECLINES.
#
# Domains. t >= 0 s (the pass clock, forward invariant); c and x in [-2, 92] deg (the elevation travel between
# the limit switches). In TRACK the command follows the pass prediction (guard atom 46.95 <= c + 0.7 t <= 47.05,
# kept by the flow), so it stays above 4.9 deg; in STOW it rises to 90 (at most 0.25 past it in one update) and
# STOWED holds it; x follows c without overshoot and stays in the travel from every start in it. The right guards
# cover the domain except tracking states off the pass program (t < 60 with c + 0.7 t outside the 0.1 deg band):
# unreachable, the ACU commands the predicted pass; RELCERT_OPREGION=1: every admitted start lies in some right
# guard. Every left mode has a satisfiable start (equal states).
#
# Verdicts (RELCERT_IMPLIED_CUT=1 unless stated, measured 2026-10-27 at installation on branch benchmark-fixes): CERTIFIED (1.5 s);
# CERTIFIED under RELCERT_SYNC=1, RELCERT_NO_REPO=1, RELCERT_NO_PRUNE=1, RELCERT_NO_CHOICE=1, NO_PRUNE+NO_CHOICE,
# SYNC+NO_CHOICE, RELCERT_NO_CUT=1, RELCERT_NO_IMPLIED_CUT=1, RELCERT_NO_LINEAR_CUT=1, RELCERT_NO_PAIR_STRETCH=1,
# without RELCERT_IMPLIED_CUT, RELCERT_OPREGION=1 and RELCERT_WELLFORMED_STRICT=1. Cover: every left mode at
# lambda 1, budget 1, admissible start the same mode, joint segments only. Nothing pruned. relcert --wellformed:
# TRACK ok (exit->STOW), STOW ok (exit->STOWED), STOWED ok (invariant), 0 UNKNOWN. Letters: D.
#
# Suite status (domain audit, 2026-10-29): back from benchmarks/reserve/ (batch I11 had moved it
# there as a single-letter D design) in place of tunnel_jetfan_pairout, skipped by the audit (its
# velocity floor 2.6 m/s was the controller's minimum duty, not a limit of the tunnel, and the
# claim stood on it: at the physical floor 0 the reference's NORMAL mode is not well formed and
# no affine row set carries the CO requirement, see benchmarks/skipped/tunnel_jetfan_pairout/).
# Chosen as the best-scored reserve candidate (round-1 reserve scoring: P 4, R 4, C 5, overall 4)
# whose evolve domains are physical: t >= 0 and the elevation travel [-2, 92] deg between the
# limit switches, not load-bearing (every bound widened by 20 % of its range CERTIFIES; the file
# certifies with no evolve bound at all except t >= 0, measured on the reserve scan). The model,
# rows and the Assumption 1 proof (WellFormed/AntennaTrackKvretune.lean, commit fb55b6e) are the
# batch-I11 suite file's, unchanged.
# Re-measured 2026-10-29 (RELCERT_IMPLIED_CUT=1 unless stated): CERTIFIED (1.4 s); CERTIFIED
# under RELCERT_SYNC=1, RELCERT_NO_REPO=1, RELCERT_NO_PRUNE=1, RELCERT_NO_CHOICE=1,
# NO_PRUNE+NO_CHOICE, SYNC+NO_CHOICE, RELCERT_NO_CUT=1, RELCERT_NO_IMPLIED_CUT=1,
# RELCERT_NO_LINEAR_CUT=1, RELCERT_NO_PAIR_STRETCH=1, without RELCERT_IMPLIED_CUT,
# RELCERT_OPREGION=1 and RELCERT_WELLFORMED_STRICT=1; the tight values 0.0125 (TRACK) and 0.085
# (STOW) as above. Letters: D (uniform rows decline at the pointing requirement).
[problem]

max_depth = 8
lambda_min = 1.0
lambda_max = 1.0
bound_T = 200.0

[Lsys]
state_vars = [t, c, x]
epsilon = 0.05

[Lsys.mode.TRACK]
ode = t' = 1.0; c' = -0.7; x' = smt2:(* 20 (- c x));
guard = t < 60.0 and c + 0.7 * t >= 46.95 and c + 0.7 * t <= 47.05 and t >= 0.0 and c >= -2.0 and c <= 92.0 and x >= -2.0 and x <= 92.0
