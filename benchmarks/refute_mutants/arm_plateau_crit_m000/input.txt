# arm_plateau_crit: a critically damped PD arm against the planner's leading ramp-to-plateau
# reference.
# scenario: model-refinement
# mechanisms: M R B I (multi-step covers, matrix code M2; right-only repositioning up the ramp;
#   branching joint steps, M3; load-bearing cut chain, M6 M6+ M6L)
#
# System. Joint angle theta (rad), joint rate v (rad/s), time s.
# Left (deployed arm, epsilon 2 s): a PD-controlled joint tracking the step command 0.5 rad,
#   theta' = v, v' = -k_p (theta - 0.5) - k_d v, with k_p = 1, k_d = 2 (critically damped,
#   double eigenvalue -1: no oscillatory overshoot). Modes Accelerate (below the command,
#   rising: theta in [0, 0.5), v in [0, 0.355)) and Brake (past the command, v <= 0,
#   theta in [0.5, 0.855]); the two have the same flow, the mode records the phase.
# Right (the motion planner's reference, epsilon 1 s): a position-only leading profile that
#   ramps up in three rate steps, ApproachA 0.5 rad/s on [0, 0.35], ApproachB 0.35 rad/s on
#   [0.35, 0.5], ApproachC 0.2 rad/s on [0.5, 0.6], then Hold (theta' = 0) on [0.6, 1.15).
#   The planner samples every 1 s and holds the selected rate in between, so a held segment can
#   skip bands (ApproachA from 0.35 ends at 0.85, in Hold's band): each ramp mode names every
#   band one period can reach (ApproachA -> ApproachB, ApproachC, Hold; ApproachB -> ApproachC,
#   Hold).
# The relation is an abstraction: the right is the coarse profile the planner certifies, the left
# is the closed-loop arm that realises it; theta is shared (the right's variables are a sublist),
# the joint rate v exists only on the left.
#
# Property (both left modes): theta_L <= theta_R + 0.255, the arm never leads the reference by
# more than 0.255 rad. The constant is derived, the smallest the cut chain supports (below):
# the chain bounds the arm by 0.855 rad and the reference holds at least 0.6 rad once it reaches
# the plateau, 0.855 - 0.6 = 0.255. Tightest: 0.255 certifies, 0.2546 declines. The true peak
# from the engagement corner (theta = 0.5, v = 0.355) is 0.631 rad (theta = 0.5 + 0.355 t e^-t,
# t = 1 s); linear cuts cannot see the e^-t factor, so 0.855 is what is proved. Not implied by
# the domains (theta_L in [0, 1.2] and theta_R in [0, 1.2] allow a 1.2 rad lead).
#
# Why the cut chain is load-bearing (I). With k_p = 1, k_d = 2 the loop decouples along the
# linear form q = v + (theta - 0.5), q' = -q, so q <= K is forward invariant for K >= 0. The
# Accelerate guard box gives q <= 0.355 (kind linear-form, rational route), and on it
# theta' = v = q - (theta - 0.5) <= 0 wherever theta >= 0.855, so theta <= 0.855 (kind
# derived-bound, given the q-cut); Brake (guard theta <= 0.855, v <= 0) yields the same two
# cuts. The reference's Hold keeps its guard as a cut (theta >= 0.6; closure theta <= 1.15).
# RELCERT_NO_CUT=1, RELCERT_NO_IMPLIED_CUT=1, RELCERT_NO_LINEAR_CUT=1 and a run without
# RELCERT_IMPLIED_CUT all DECLINE.
# Why right-only segments are needed (R). In a Brake window the reference may still be low on
# the ramp (ApproachA); it advances alone up the ramp (a dynamic reposition into ApproachB,
# ApproachC or Hold) before the joint segment. RELCERT_SYNC=1, which forbids right-only
# segments, DECLINES; every cover runs at lambda = 1, so stretching is not what SYNC removes
# (no S).
# Multi-step and branching (M, B). Each 2 s left window is matched by 2 right cycles (budget 2);
# a joint step from ApproachA retains ApproachB, ApproachC and Hold, each covering.
#
# Domains (both sides): theta in [0, 1.2] rad, the joint's mechanical range; v in [-1, 1] rad/s
# on the left, the actuator's speed limit. Physical limits, not reachable-set estimates
# (scripts/domain_widening.py: every evolve bound widened by half its range still certifies).
# Coverage: the right guards cover [0, 1.15); theta_R in [1.15, 1.2] (between the joint's soft
# stop margin and its hard limit) is in no right guard and unreachable: the reference starts in
# a band, holds on the plateau, and no held segment ends above 0.85 rad. Every left mode has a
# satisfiable start (theta_R = theta_L). No fallback mode is declared.
#
# Verdicts (RELCERT_IMPLIED_CUT=1 unless stated): CERTIFIED; CERTIFIED under RELCERT_NO_CHOICE=1,
# RELCERT_NO_PRUNE=1 (also with RELCERT_NO_CHOICE=1) and RELCERT_OPREGION=1; DECLINED under
# RELCERT_SYNC=1 (also with RELCERT_NO_CHOICE=1), RELCERT_NO_CUT=1, RELCERT_NO_IMPLIED_CUT=1,
# RELCERT_NO_LINEAR_CUT=1 and without RELCERT_IMPLIED_CUT. Covers: both left modes at lambda 1,
# budget 2, every right mode an admissible start; branch 3 from Accelerate, 2 from Brake; right-only
# reposition out of ApproachA in the Brake cover; nothing pruned. Rows identical (--handoff 4/4
# vacuous). relcert --wellformed: ApproachA, ApproachB, ApproachC ok (exit), Hold ok (invariant).
[problem]
name = arm_plateau_crit
max_depth = 8
lambda_min = 1.0
lambda_max = 6.0
bound_T = 4.0

[Lsys]
state_vars = [theta, v]
epsilon = 2.0

[Lsys.mode.Accelerate]
ode = theta' = v; v' = smt2:(+ (* -1 (- theta 0.5)) (* -2.0 v));
guard = theta >= 0.0 and theta < 0.5 and v >= 0.0 and v < 0.355
evolve = theta >= 0.0 and theta <= 1.2 and v >= -1.0 and v <= 1.0
next = [Brake, Accelerate]

[Lsys.mode.Brake]
ode = theta' = v; v' = smt2:(+ (* -1 (- theta 0.5)) (* -2.0 v));
guard = theta >= 0.5 and theta <= 0.855 and v <= 0.0
evolve = theta >= 0.0 and theta <= 1.2 and v >= -1.0 and v <= 1.0
next = [Accelerate, Brake]

[Rsys]
state_vars = [theta]
epsilon = 1.0

[Rsys.mode.ApproachA]
ode = theta' = smt2:0.5;
guard = theta >= 0.0 and theta <= 0.35
evolve = theta >= 0.0 and theta <= 1.2
next = [ApproachB, ApproachA, ApproachC, Hold]

[Rsys.mode.ApproachB]
ode = theta' = smt2:0.35;
guard = theta >= 0.35 and theta <= 0.5
evolve = theta >= 0.0 and theta <= 1.2
next = [ApproachC, ApproachB, Hold]

[Rsys.mode.ApproachC]
ode = theta' = smt2:0.2;
guard = theta >= 0.5 and theta <= 0.6
evolve = theta >= 0.0 and theta <= 1.2
next = [Hold, ApproachC]

[Rsys.mode.Hold]
ode = theta' = smt2:0;
guard = theta >= 0.6 and theta < 1.15
evolve = theta >= 0.0 and theta <= 1.2
next = [Hold]

[relational_invariant]
# theta_L <= theta_R + 0.255: the chain bound 0.855 against the 0.6 plateau.
Accelerate = smt2:(>= L_theta (+ R_theta 0.255))
Brake = smt2:(>= L_theta (+ R_theta 0.255))
