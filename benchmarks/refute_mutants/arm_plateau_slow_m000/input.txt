# arm_plateau_slow: a worn PD arm (extra joint friction, over-damped) against the planner's
# leading ramp-to-plateau reference.
# scenario: model-refinement
# mechanisms: M R B I (multi-step covers, matrix code M2; right-only repositioning up the ramp;
#   branching joint steps, M3; load-bearing cut chain, M6 M6+ M6L)
#
# System. Joint angle theta (rad), joint rate v (rad/s), time s.
# Left (deployed arm, epsilon 2 s): a PD-controlled joint tracking the step command 0.5 rad,
#   theta' = v, v' = -k_p (theta - 0.5) - k_d v, on a worn joint whose viscous friction adds to
#   the controller's damping: k_p = 1, k_d = 2.5 (over-damped, eigenvalues -0.5 and -2; slow
#   mode time constant 2 s, never oscillates). Modes Accelerate (below the command, rising:
#   theta in [0, 0.5), v in [0, 0.355)) and Brake (past the command, v <= 0, theta in
#   [0.5, 0.6775]); the two have the same flow, the mode records the phase.
# Right (the motion planner's reference, epsilon 1 s), the same profile as arm_plateau_crit:
#   ApproachA 0.5 rad/s on [0, 0.35], ApproachB 0.35 rad/s on [0.35, 0.5], ApproachC 0.2 rad/s
#   on [0.5, 0.6], then Hold (theta' = 0) on [0.6, 1.15). The planner samples every 1 s and holds
#   the selected rate in between, so a held segment can skip bands (ApproachA from 0.35 ends at
#   0.85): each ramp mode names every band one period can reach.
# The relation is an abstraction: the right is the coarse profile the planner certifies, the left
# is the closed-loop (worn) arm that realises it; theta is shared (the right's variables are a
# sublist), the joint rate v exists only on the left.
#
# Property (both left modes): theta_L <= theta_R + 0.0775, the arm never leads the reference by
# more than 0.0775 rad. The constant is derived, the smallest the cut chain supports: the chain
# bounds the arm by 0.6775 rad against the 0.6 rad plateau. Tightest: 0.0775 certifies, 0.0774
# declines. The stiffer damping is what makes the bound small (0.6775 against 0.855 for the
# critically damped arm of arm_plateau_crit). Not implied by the domains (both allow theta in
# [0, 1.2]).
#
# Why the cut chain is load-bearing (I). With two real eigenvalues the loop has two decoupling
# linear forms, q_r = v + r (theta - 0.5) for r in {0.5, 2}, with q_r' = -(2.5 - r) q_r. The
# Accelerate guard box gives q_0.5 <= 0.355 and q_2 <= 0.355 (kind linear-form, rational
# route); the bound from the larger root is the tight one, theta <= 0.5 + 0.355 / 2 = 0.6775
# (kind derived-bound, given q_2 <= 0.355; the one from r = 0.5, theta <= 1.21, lies outside
# the domain). Brake (guard theta <= 0.6775, v <= 0) yields q_0.5 <= 0.08875, q_2 <= 0.355 and
# again theta <= 0.6775. The reference's Hold keeps its guard as a cut (closure theta <= 1.15).
# RELCERT_NO_CUT=1, RELCERT_NO_IMPLIED_CUT=1, RELCERT_NO_LINEAR_CUT=1 and a run without
# RELCERT_IMPLIED_CUT all DECLINE.
# Why right-only segments are needed (R). In an Accelerate window a reference in ApproachB
# advances alone (a dynamic reposition into ApproachC or Hold) before or after its joint
# segment. RELCERT_SYNC=1, which forbids right-only segments, DECLINES; every cover runs at
# lambda = 1, so stretching is not what SYNC removes (no S).
# Multi-step and branching (M, B). Each 2 s left window is matched by 2 right cycles (budget 2);
# a joint step from ApproachA retains ApproachB, ApproachC and Hold, each covering.
#
# Domains (both sides): theta in [0, 1.2] rad, the joint's mechanical range; v in [-1, 1] rad/s
# on the left, the actuator's speed limit. Physical limits, not reachable-set estimates.
# Coverage: the right guards cover [0, 1.15); theta_R in [1.15, 1.2] (between the joint's soft
# stop margin and its hard limit) is in no right guard and unreachable: the reference starts in
# a band, holds on the plateau, and no held segment ends above 0.85 rad. Every left mode has a
# satisfiable start (theta_R = theta_L). No fallback mode is declared.
#
# Verdicts (RELCERT_IMPLIED_CUT=1 unless stated): CERTIFIED; CERTIFIED under RELCERT_NO_CHOICE=1,
# RELCERT_NO_PRUNE=1 (also with RELCERT_NO_CHOICE=1) and RELCERT_OPREGION=1; DECLINED under
# RELCERT_SYNC=1 (also with RELCERT_NO_CHOICE=1), RELCERT_NO_CUT=1, RELCERT_NO_IMPLIED_CUT=1,
# RELCERT_NO_LINEAR_CUT=1 and without RELCERT_IMPLIED_CUT. Covers: both left modes at lambda 1,
# budget 2; admissible starts Accelerate: every right mode, Brake: ApproachB, ApproachC, Hold;
# branch 3 from Accelerate, 2 from Brake; right-only reposition out of ApproachB in the
# Accelerate cover; nothing pruned. Rows identical (--handoff 4/4 vacuous). relcert
# --wellformed: ApproachA, ApproachB, ApproachC ok (exit), Hold ok (invariant).
[problem]
name = arm_plateau_slow
max_depth = 8
lambda_min = 1.0
lambda_max = 6.0
bound_T = 4.0

[Lsys]
state_vars = [theta, v]
epsilon = 2.0

[Lsys.mode.Accelerate]
ode = theta' = v; v' = smt2:(+ (* -1 (- theta 0.5)) (* -2.5 v));
guard = theta >= 0.0 and theta < 0.5 and v >= 0.0 and v < 0.355
evolve = theta >= 0.0 and theta <= 1.2 and v >= -1.0 and v <= 1.0
next = [Brake, Accelerate]

[Lsys.mode.Brake]
ode = theta' = v; v' = smt2:(+ (* -1 (- theta 0.5)) (* -2.5 v));
guard = theta >= 0.5 and theta <= 0.6775 and v <= 0.0
evolve = theta >= 0.0 and theta <= 1.2 and v >= -1.0 and v <= 1.0
next = [Accelerate, Brake]

[Rsys]
state_vars = [theta]
epsilon = 1.0

[Rsys.mode.ApproachA]
ode = theta' = smt2:0.5;
guard = theta >= 0.0 and theta <= 0.35
evolve = theta >= 0.0 and theta <= 1.2
next = [ApproachB, ApproachA, ApproachC, Hold]

[Rsys.mode.ApproachB]
ode = theta' = smt2:0.35;
guard = theta >= 0.35 and theta <= 0.5
evolve = theta >= 0.0 and theta <= 1.2
next = [ApproachC, ApproachB, Hold]

[Rsys.mode.ApproachC]
ode = theta' = smt2:0.2;
guard = theta >= 0.5 and theta <= 0.6
evolve = theta >= 0.0 and theta <= 1.2
next = [Hold, ApproachC]

[Rsys.mode.Hold]
ode = theta' = smt2:0;
guard = theta >= 0.6 and theta < 1.15
evolve = theta >= 0.0 and theta <= 1.2
next = [Hold]

[relational_invariant]
# theta_L <= theta_R + 0.0775: the chain bound 0.6775 against the 0.6 plateau.
Accelerate = smt2:(>= L_theta (+ R_theta 0.0775))
Brake = smt2:(>= L_theta (+ R_theta 0.0775))
