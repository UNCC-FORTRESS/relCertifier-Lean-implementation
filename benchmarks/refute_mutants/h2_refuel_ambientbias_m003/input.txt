# h2_refuel_ambientbias: a 70 MPa hydrogen fill by a dispenser whose ambient-temperature sensor
# reads 10 K high, against the same fill with a correct reading.
# scenario: sensor-fault (degraded sensor feeding the end-pressure table)
# mechanisms: D I (mode-dependent rows: uniform p_L <= p_R declines on the top rows, uniform
#   p_L <= p_R + 2.9 and p_R >= 58 certifies but drops the stage requirement, see D; checked cuts,
#   RELCERT_NO_CUT=1 declines; matrix codes M5 M6+)
#
# System. Vehicle tank pressure p in MPa, time in s. Light-duty tank, nominal working pressure 70 MPa,
# maximum allowable 87.5 MPa (125 %). A staged pressure-ramp dispenser: in each stage the control
# valve feeds the tank toward the stage's set point, flow proportional to the pressure difference
# (gain 0.05 /s, about 45 s per 20 MPa stage, a fill of about 3 min); the dispenser re-decides every
# 1 s:
#   STAGE1        p < 18  toward 20 MPa      STAGE2  18 <= p < 38   toward 40 MPa
#   STAGE3   38 <= p < 58  toward 60 MPa      TOPOFF  58 <= p < end  toward end + 0.5 MPa
#   COMPLETE p >= end         nozzle valve closed, pressure held (p' = 0)
# The end pressure comes from the fueling protocol's table (SAE J2601, Fueling Protocols for Light
# Duty Gaseous Hydrogen Surface Vehicles: H70 tanks, nominal working pressure 70 MPa, maximum
# fueling pressure 87.5 MPa = 125 % NWP, and the end-of-fill target pressure read from a table
# indexed by the ambient temperature): the pressure at which the tank holds 100 % state of charge at
# the gas temperature the station infers from ambient. The staged pressure ramp with its gains and
# stage set points is a design value of this file (J2601 prescribes a pressure-ramp rate by table,
# not a stage structure). Not modeled: J2601's 0.5 MPa minimum vehicle tank pressure (the station
# declines to start such a fill; no fill reaches it, since every stage flow raises p), and the
# station aborts (gas temperature above 85 degC, pressure ramp outside its band, time-out): in this
# one-state model none is reachable by an ordinary fill, so STAGE1 fills from any p >= 0.
#
# Right (reference): correct ambient reading, end pressure 70.0 MPa. Left (deployed): the ambient
# sensor reads 10 K high, so the table returns 72.4 MPa (ideal-gas scaling 70 x (1 + 10/288)); the
# deployed tops off toward 72.9 and completes at 72.4. One cause: the sensor bias, which reaches the
# fill only through the end pressure (stages 1 to 3 are identical).
#
# Property (mode-dependent; real-time, lambda 1, no re-timing needed).
#   STAGE1, STAGE2, STAGE3: p_L <= p_R. Requirement: the ramp stages are identical, so the deployed
#     may not lead. Stage rows p_L <= p_R + c certify for c in [-10.00, 0.00] (-10.01 declines; 0.01
#     declines at the STAGE3 -> TOPOFF handoff, which must deliver the top rows' p_R >= 58; bisected
#     2026-10-30). A negative c only shrinks the admitted starts (the reference must start c ahead,
#     so the fill that starts with both tanks at the same pressure is excluded); 0 is the strongest
#     row that admits it.
#   TOPOFF, COMPLETE: p_L <= p_R + 2.9 and p_R >= 58. The conjunct p_R >= 58 is the reachable
#     relation the handoff delivers (at STAGE3 -> TOPOFF the stage row gives p_R >= p_L >= 58, and
#     the reference pressure never decreases): a deployed top-off faces a reference that has also
#     reached its top-off. Without it the relaxed top row admits starts that are no scenario of the
#     claim (a deployed already topping off at 58 MPa against a reference still in STAGE3 at 55.1:
#     the same fill does not start the two tanks at different pressures, and no handoff produces the
#     pair); from such a start the lock-step gap reaches 8.83 MPa, against 2.39 MPa from a normal
#     fill (simulated 2026-10-30). The bias shifts the end pressure by 2.4 MPa (the deployed
#     completes at 72.4 against 70.0); the further 0.5 MPa is what the certificate needs even at
#     zero bias (see the caveat below: the top-off's exit at the end pressure cannot be used, so the
#     tool bounds the deployed top-off by its set point end + 0.5). The deployed tank therefore ends
#     below 73.4 MPa in the certificate and at 72.4 MPa physically, both well inside the 87.5 MPa
#     limit. Tightest 2.90 (2.899 and 2.89 decline, bisected 2026-10-29); 2.4 declines; 5.0 and
#     20 MPa certify. No physically sound variant certifies 2.4: a top-off aimed at the end pressure
#     itself certifies 2.40 (2.399 declines) but never completes (--wellformed: TOPOFF invariant),
#     and a constant-rate top-off (0.3 MPa/s) has no contraction cut, so the tool bounds its segment
#     by the domain and the slack grows to 17.51 (17.50 declines) (measured 2026-10-29).
# Mode dependence (D). The rows differ because the requirements differ: the stages are identical
# (lead 0) and the end pressure is shifted (2.9 at the top). The uniform rows that keep every stated
# requirement DECLINE: p_L <= p_R (the top rows need 2.9) and the conjunction p_L <= p_R and
# p_R >= 58; uniform p_L <= p_R + 2.9 and p_R >= 58 CERTIFIES but drops the stage requirement. The
# handoffs only relax (exact to 2.9 at STAGE3 -> TOPOFF): --handoff 9/9 unsat. The bound moves
# with the cause: with an end-pressure shift s the top rows certify down to s + 0.5 (s = 0: 0.50,
# 0.49 declines; s = 1: 1.50, 1.49 declines; s = 2.4: 2.90; s = 5: 5.50, 5.49 declines; measured
# 2026-10-29, s = 0 and s = 5 re-measured with the p_R >= 58 conjunct 2026-10-30, unchanged).
# Caveat, stated: even without the bias (s = 0) the top rows need 0.50 MPa, because the one-sided
# claim lets a reference that has already completed at 70.0 face a deployed still topping off
# toward 70.5, and the certificate cannot use the top-off's exit at 70.0; so D is present at s = 0
# too, and the cause moves the top bound from 0.50 to 2.90.
#
# Letter windows. D and I are present at s = 0, 2.4 and 5 (uniform rows and RELCERT_NO_CUT=1
# DECLINE, RELCERT_SYNC=1 and RELCERT_NO_REPO=1 CERTIFY at each; measured 2026-10-30); the
# top rows certify for every tolerance in [s + 0.5, 20] MPa measured, here [2.90, 20]. The stated
# 2.9 is the end-pressure shift 2.4 plus the certificate's 0.5; a larger operational allowance
# (5 MPa, the deployed tank ending below 75 MPa) also certifies, with the same verdicts and letters
# (see Verdicts).
#
# No right-only repositioning (no R): with the reachable conjunct p_R >= 58 every cover is joint
# segments only, and RELCERT_SYNC=1 and RELCERT_NO_REPO=1 CERTIFY. Every cover is at lambda 1, so
# no S. No edge is pruned (no P).
# Review round 6 (2026-10-30): the top rows gained the conjunct p_R >= 58. Without it they admitted
# a reference starting in STAGE3 against a deployed TOPOFF window, which then ran alone into TOPOFF
# (RELCERT_SYNC=1 declined); no handoff reaches that pair, so R rested on start-only pairs. Letters
# R D I -> D I.
# Cuts (I). The implied contraction atoms (p <= set point of each stage) are load-bearing: DECLINED
# with RELCERT_NO_CUT=1 and without RELCERT_IMPLIED_CUT.
#
# Domains. 0 <= p <= 87.5 MPa on both sides (empty to the maximum allowable pressure), forward
# invariant in every mode (all set points <= 72.9, COMPLETE frozen); widened to 120 MPa the
# benchmark still CERTIFIES (and with the W20 widening). The right guards partition [0, 87.5] (no
# coverage gap); every left mode has a satisfiable start (p_R = p_L, for COMPLETE_L p_R = 70.5 in
# TOPOFF or COMPLETE).
#
# Stretch pinned (2026-10-29): lambda_max 6 -> 1. Every cover was already at lambda 1 and the
# requirement is a real-time one (RELCERT_SYNC=1 CERTIFIES with the p_R >= 58 conjunct), so the
# unused range [1, 6] is gone.
# ABORT removed (2026-10-29). Earlier versions carried an ABORT mode (p < 0.5, valve latched) that
# no fill reaches (every stage flow raises p) and that was entered only as a start; it made the
# stage rows exact and was the only cause of the pruned edges. Removed on both sides, STAGE1 now
# covers [0, 18); verdicts below re-measured.
# Verdicts (RELCERT_IMPLIED_CUT=1 unless stated, measured 2026-10-30 with the p_R >= 58 conjunct):
# CERTIFIED (0.8 s); CERTIFIED under RELCERT_SYNC=1, RELCERT_NO_REPO=1, SYNC+NO_CHOICE,
# RELCERT_NO_PRUNE=1, RELCERT_NO_CHOICE=1, RELCERT_NO_LINEAR_CUT=1, RELCERT_NO_PAIR_STRETCH=1,
# RELCERT_OPREGION=1 (every admitted start in some right guard) and RELCERT_WELLFORMED_STRICT=1
# (--wellformed: STAGE1, STAGE2, STAGE3, TOPOFF ok (exit to the next stage), COMPLETE ok
# (invariant), 0 UNKNOWN, 0 BLOCKING); DECLINED under RELCERT_NO_CUT=1, RELCERT_NO_IMPLIED_CUT=1
# and without RELCERT_IMPLIED_CUT.
# Cover: lambda 1, budget 1 in every left mode, joint segments only; TOPOFF_L and COMPLETE_L
# admissible [TOPOFF, COMPLETE]; STAGE3_L [STAGE3, TOPOFF, COMPLETE]; STAGE1_L every mode. Nothing
# pruned. Uniform rows: p_L <= p_R DECLINED; p_L <= p_R and p_R >= 58 DECLINED; p_L <= p_R + 2.9 and
# p_R >= 58 CERTIFIED (it drops the stage requirement). --handoff 9/9 checked, 9 passed (rows
# differ). Letters: D I (matrix M5 M6+).
# With the top rows at 5.0 MPa instead of 2.9 (the operational allowance above): CERTIFIED, the same
# letters D I.
#
[problem]
name = h2_refuel_ambientbias
max_depth = 8
lambda_min = 1.0
lambda_max = 1.0
bound_T = 600.0

[Lsys]
state_vars = [p]
epsilon = 1.0

[Lsys.mode.STAGE1]
ode = p' = smt2:(* 0.05 (- 20 p));
guard = p < 18.0
evolve = p >= 0.0 and p <= 87.5
next = [STAGE1, STAGE2]

[Lsys.mode.STAGE2]
ode = p' = smt2:(* 0.05 (- 40 p));
guard = p >= 18.0 and p < 38.0
evolve = p >= 0.0 and p <= 87.5
next = [STAGE2, STAGE3]

[Lsys.mode.STAGE3]
ode = p' = smt2:(* 0.05 (- 60 p));
guard = p >= 38.0 and p < 58.0
evolve = p >= 0.0 and p <= 87.5
next = [STAGE3, TOPOFF]

[Lsys.mode.TOPOFF]
ode = p' = smt2:(* 0.05 (- 72.9 p));
guard = p >= 58.0 and p < 72.4
evolve = p >= 0.0 and p <= 87.5
next = [TOPOFF, COMPLETE]

[Lsys.mode.COMPLETE]
ode = p' = smt2:0.0;
guard = p >= 72.4
evolve = p >= 0.0 and p <= 87.5
next = [COMPLETE]

[Rsys]
state_vars = [p]
epsilon = 1.0

[Rsys.mode.STAGE1]
ode = p' = smt2:(* 0.05 (- 20 p));
guard = p < 18.0
evolve = p >= 0.0 and p <= 87.5
next = [STAGE1, STAGE2]

[Rsys.mode.STAGE2]
ode = p' = smt2:(* 0.05 (- 40 p));
guard = p >= 18.0 and p < 38.0
evolve = p >= 0.0 and p <= 87.5
next = [STAGE2, STAGE3]

[Rsys.mode.STAGE3]
ode = p' = smt2:(* 0.05 (- 60 p));
guard = p >= 38.0 and p < 58.0
evolve = p >= 0.0 and p <= 87.5
next = [STAGE3, TOPOFF]

[Rsys.mode.TOPOFF]
ode = p' = smt2:(* 0.05 (- 70.5 p));
guard = p >= 58.0 and p < 70.0
evolve = p >= 0.0 and p <= 87.5
next = [TOPOFF, COMPLETE]

[Rsys.mode.COMPLETE]
ode = p' = smt2:0.0;
guard = p >= 70.0
evolve = p >= 0.0 and p <= 87.5
next = [COMPLETE]

[relational_invariant]
STAGE1 = smt2:(<= L_p (+ R_p 0.00))
STAGE2 = smt2:(<= L_p (+ R_p 0.00))
STAGE3 = smt2:(<= L_p (+ R_p 0.00))
TOPOFF = smt2:(and (>= L_p (+ R_p 2.9)) (>= R_p 58.0))
COMPLETE = smt2:(and (>= L_p (+ R_p 2.9)) (>= R_p 58.0))
