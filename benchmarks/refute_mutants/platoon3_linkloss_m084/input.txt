# platoon3_linkloss: a three-follower CACC string on a delayed V2V link, with a latched radar-only
# mode after the lead link is lost, against the design model.
# scenario: sensor-attack
# mechanisms: M P D I (multi-step covers, matrix code M2; pruned AEB edges, M4; mode-dependent rows
#   with a loosening handoff, M5; load-bearing guard cuts, M6)
#
# System. A lead vehicle cruising at constant speed and three automated followers; per link
# i = 1, 2, 3 (follower i behind its predecessor) the gap g_i (m) and the closing rate
# r_i = v_(i-1) - v_i (m/s), g_i' = r_i: state (g1, r1, g2, r2, g3, r3) per side (6-D, linear),
# time s. Follower i commands a_i = a_(i-1) + kp (g_i - c) + kd r_i (CACC: the predecessor's
# acceleration arrives over V2V as feed-forward; a_0 = 0), so r_i' = -kp (g_i - c) - kd r_i:
# every link is the same second-order loop. kp = 0.125 /s^2, kd = 0.75 /s, characteristic
# polynomial (s + 0.25)(s + 0.5): over-damped with rational roots rho_1 = 0.25, rho_2 = 0.5, so
# the linear forms p_j = r + rho_j (g - c) obey p_1' = -0.5 p_1, p_2' = -0.25 p_2.
# Right (design model, epsilon 1 s): set point c = 30 m (1.2 s at 25 m/s) on every link, mode
#   FOLLOW, and per follower k an AEB fallback BRAKEk (below).
# Left (deployed string, epsilon 2 s): acts on a gap fused with a 40 ms-old V2V position,
#   overstated by 1 m at 25 m/s, so its loops settle at 29 m true (FOLLOW). When the V2V link to
#   the LEADER is LOST (jamming or dropout), follower 1 latches a radar-only gap keeper with the
#   larger stand-off 35 m (radar-measured, no overstatement, same gains): LOST,
#   r1' = -kp (g1 - 35) - kd r1; links 2 and 3 keep V2V and the CACC law. No way back (the link is
#   re-established at the next platoon join, not modeled).
# One cause: the degraded V2V link (its delay, and the loss of the lead link under attack).
#
# Guards: the controller's OPERATING RANGE (it stays engaged throughout). Design FOLLOW: every
# gap above the AEB floor and within the radar's range, 20 <= g_i <= 60; every closing rate
# within the rated limit, |r_i| <= 10; and the AEB not imminent, the gap projected 2 s ahead
# stays 1 m above the floor and 1 m inside the range, 21 <= g_i + 2 r_i <= 59 (i.e.
# -4.5 <= p_2 <= 14.5 for link i: p_2 only decays under FOLLOW, so the guard is forward
# invariant; at g_i = 20 it forces r_i >= 0.5 > 0, at g_i = 60 r_i <= -0.5). Deployed FOLLOW:
# the same shifted by the 1 m overstatement, 19 <= g_i <= 59, |r_i| <= 10,
# 20 <= g_i + 2 r_i <= 58. LOST: links 2, 3 as FOLLOW; link 1 25 <= g1 <= 59, |r1| <= 10,
# 20 <= g1 + 2 r1 <= 58. The LOST floor 25 m is the AEB floor 20 m plus the 5 m by which the LOST
# row lets the reference's gap fall below the deployed's: it keeps every reference state related
# to a LOST start out of BRAKE1. It is placed for that purpose, with no separate physical
# requirement; 24.5 (and 24, 21, 19) DECLINES.
# The AEB fallback BRAKEk (design model, latched): engages below a 20 m gap whose projected gap
# is also below the floor, g_k < 20 and 0 <= g_k + 2 r_k < 20 (a projected gap below 0 is a
# collision the model does not represent), with the other two links in their operating range;
# follower k then matches its predecessor's speed, r_k' = -0.5 r_k (5 m/s^2 relative braking at
# the rated 10 m/s closing rate), the followers behind it keep the CACC law, and the AEB holds the
# gap it reaches (g_k + 2 r_k is conserved and g_k tends to it) until the driver resumes the
# CACC (not modeled): a sink whose guard is invariant.
#
# Property (MODE-DEPENDENT rows; Delta = L - R, e_i = Delta g_i + 1 the deviation from the
# deployed's 1 m offset).
#   FOLLOW: Delta r_i + rho_j e_i = 0 for every link i and j = 1, 2: exact refinement up to the
#     1 m offset (Delta g_i = -1, Delta r_i = 0).
#   LOST: links 2, 3 as FOLLOW; link 1 (the lost link) loosened: Delta r1 + rho_j (e1 - 6) in
#     [-6 rho_j, 0] (j = 1, 2) and 0 <= e1 <= 6, i.e. g1_R - 1 <= g1_L <= g1_R + 5: the
#     radar-only follower never closes in on the design gap beyond the 1 m offset and opens it by
#     at most the 6 m stand-off step (35 - 29).
# Derivation: on link 1 under LOST, e1'' = -kp (e1 - 6) - kd e1' (same gains, set points 6 m
# apart), so Q_j = e1' + rho_j (e1 - 6) obeys Q_j' = -rho_(3-j) Q_j; the FOLLOW row gives
# Q_j = -6 rho_j at the switch, so [-6 rho_j, 0] is the tightest box containing the handoff
# state, and the e1 bounds are stratified on the proven Q rows. Tightest: e1 <= 6 (5.994
# declines) and e1 >= 0 (0.008 declines); the constants are requirement values (the offset and
# the stand-off step), and they are tight.
#
# Why pruning is needed (P). FOLLOW -> BRAKE1, BRAKE2, BRAKE3 are pruned: the projected-gap
# guard conjunct is a kept cut (DI-strict, p_2' = -0.25 p_2 > 0 at p_2 = -4.5) and makes the flow
# repel at the AEB threshold (g_k = 20 forces r_k >= 0.5). RELCERT_NO_PRUNE=1 DECLINES (also with
# RELCERT_NO_CHOICE=1): the committed choice does not replace it.
# Why the guard cuts are load-bearing (I). The pruning certificate stands on the kept
# projected-gap conjunct: RELCERT_NO_CUT=1 DECLINES. The
# widened atoms (linear forms of the left FOLLOW guard) are kept but not needed:
# RELCERT_NO_IMPLIED_CUT=1, RELCERT_NO_LINEAR_CUT=1 and a run without RELCERT_IMPLIED_CUT
# certify.
# Why the rows differ (D). The handoff FOLLOW -> LOST loosens link 1 only (--handoff 3/3 unsat).
# Multi-step (M). Each 2 s left window is matched by 2 design cycles (budget 2) in both modes.
#
# Domains (both sides): 0 <= g_i <= 60 m (the radar's range), |r_i| <= 10 m/s (the closing-rate
# range); the certificate stands on no domain bound (every evolve bound widened at once still
# certifies). Coverage: design states outside FOLLOW's operating range and every BRAKEk guard
# (e.g. a gap below 20 m that reopens past 20 m within 2 s) are in no right guard; the design
# model never reaches them, since FOLLOW's guard is forward invariant and the sinks keep theirs.
# Every left mode has a satisfiable start (the row's offset state inside the guards).
#
# Verdicts (RELCERT_IMPLIED_CUT=1 unless stated): CERTIFIED; CERTIFIED under RELCERT_SYNC=1 (also
# with RELCERT_NO_CHOICE=1), RELCERT_NO_CHOICE=1, RELCERT_NO_IMPLIED_CUT=1,
