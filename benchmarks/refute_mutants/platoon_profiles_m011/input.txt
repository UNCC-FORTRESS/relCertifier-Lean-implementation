# platoon_profiles: a CACC follower driven in the SPORT profile (a shorter time gap) against the
# design follower verified in the NORMAL profile.
# scenario: controller-refinement
# mechanisms: D (mode-dependent rows with unsat handoffs, matrix code M5; a uniform claim
#   declines). No S, M: the claim is synchronous (lambda fixed to 1).
#
# Round A (2026-10-26): SPORT was defined as an exact 1.2 x time scaling of the CACC (kp x 1.44,
# kd x 1.2), so the stretch (S) and the two-cycle cover (M) were built into the definition. SPORT
# is now the physical profile parameter, a shorter CACC time gap with the same loop gains, and the
# claim is a spacing tolerance derived from it. Letters were S M D.
#
# Shared platoon model (identical in platoon_linkloss, platoon3_linkloss). A lead vehicle cruises
# at the platoon reference speed v_ref = 25 m/s (90 km/h). Per link (follower behind its
# predecessor): the gap g (m, bumper to bumper) and the range rate r = v_pred - v (m/s, positive
# = opening), g' = r. Units m, m/s, s.
# Spacing policy (constant time gap): standstill distance d0 = 5 m. CACC: time gap h_c = 0.6 s on
#   the V2V-broadcast reference speed, desired gap d0 + h_c v_ref = 20 m.
# CACC (V2V predecessor-acceleration feed-forward): a = a_pred + kp (g - d0 - h v_ref) + kd r, so
#   r' = -kp (g - d0 - h v_ref) - kd r with kp = 0.125 /s^2, kd = 0.75 /s: closed-loop poles 0.25
#   and 0.5 /s (over-damped).
# AEB (radar, the same function on every vehicle): triggers when the time to reach the standstill
#   distance at the current closing rate falls below T = 2 s, (g - d0) + T r < 0, i.e.
#   g + 2 r < 5; it then matches the predecessor's speed, r' = -0.5 r (relative deceleration
#   5 m/s^2 at the rated 10 m/s closing rate), which conserves the projected stop gap g + 2 r, and
#   stays latched until the driver resumes (not modeled). Trigger region as modeled:
#   0 <= g + 2 r < 5 (a projected stop gap below 0 is a collision the matching law cannot avoid).
# CACC operating range (the engagement spec, the same on both sides): |r| <= 10 (rated closing
#   rate) and 5 <= g + 2 r <= 60 (TTC to the standstill distance at least 2 s, and the gap
#   projected 2 s ahead inside the 60 m radar range gate). Forward invariant under both profiles:
#   d/dt (g + 2 r) = -0.25 (g + 2 r - (d0 + h v_ref)), so the TTC floor is a sublevel set of the
#   slow mode and the CACC never triggers the AEB.
# Control period 0.1 s on both sides (10 Hz V2V messages, the ETSI CAM / SAE BSM rate).
# Domain per link (both sides, every mode): 0 <= g <= 60 m (radar range gate), |r| <= 10 m/s
#   (rated closing rate); every mode's guard is forward invariant inside it.
#
# This file: one link (state g, r).
# Right (design follower): the CACC in its NORMAL profile, h = 0.6 s (desired gap 20 m), on the
#   operating range, next [CACC, AEB]; AEB latched.
# Left (deployed follower): the driver has selected SPORT, the CACC with time gap h_s = 0.5 s
#   (desired gap 5 + 0.5 x 25 = 17.5 m), the same gains, on the same operating range,
#   next [SPORT, AEB]; the same AEB, latched.
# One cause: the driver profile (the time gap it selects). Same plant, gains, AEB, operating
# range and control period on both sides.
#
# Property (Delta = L - R), lambda_min = lambda_max = 1 (equal times).
#   SPORT rows:
#     -2.5 <= g_L - g_R <= 0 (the requirement): the SPORT follower closes up on its predecessor by
#       at most the time-gap difference times the reference speed, (h_c - h_s) v_ref = 2.5 m, and
#       never runs a larger gap than the design; the design's spacing properties carry over up to
#       2.5 m.
#     -2.5 <= (g_L + 2 r_L) - (g_R + 2 r_R) <= 0: the same band for the projected 2-s gap (written
#       as the slow error form (r_L - r_R) + 0.5 ((g_L - g_R) + 2.5) in [0, 1.25]); strengthening,
#       needed: without it (and without the fast form) DECLINED. It also keeps the design's AEB out
#       of the admissible starts (the design's projected gap is at least the deployed's).
#     g_L >= 5 and g_L + 2 r_L >= 5: collision freedom of the deployed (gap at least d0 = 5 m) and
#       its TTC to d0 at least 2 s. The TTC floor is needed (without it the handoff SPORT -> AEB is
#       not unsat: DECLINED, 2/3 handoffs); the gap floor follows from it (at g = 5 the floor
#       forces r >= 0) and is kept as the requirement.
#     g_R + 2 r_R <= 60: the design inside its own operating range (radar range gate); keeps every
#       admitted design state in a right guard (RELCERT_OPREGION=1 clean; without it CERTIFIED but
#       the rows admit design states above the range gate).
#   AEB rows: exact, Delta r = 0 and Delta (g + 2 r) = 0 (the same AEB on both cars).
# Tightest (bisection to 0.01): lower 2.50 (2.49 declines), upper 0.00 (-0.01 declines): the band
# is exactly the time-gap difference. Not implied by the domains; every left mode has a
# satisfiable start (g = 20, r = 0 on both sides for SPORT; g = 3, r = 0 for AEB).
# Cause dependence (measured): SPORT time gap 0.4 s (desired 15 m): the band must widen to 5.00
# (4.99 declines; 2.5 declines); time gap 0.6 s (no cause): the exact claim (0) CERTIFIES. The
# bound is (h_c - h_s) v_ref.
#
# Why the rows differ (D). The SPORT rows carry the TTC floor, so the handoff SPORT -> AEB is unsat
# (a SPORT state never satisfies the AEB trigger: the deployed's AEB is reachable only as a start);
# the AEB rows are the exact matching rows. A uniform claim (the SPORT rows in AEB too, with or
# without the TTC floor) DECLINES. D rests on the start-only AEB mode, as in platoon_linkloss.
# Not load-bearing here: the design's CACC -> AEB edge is pruned (non-connection on the TTC floor),
# but RELCERT_NO_PRUNE=1 also certifies (P vacuous); the choice is not needed.
#
# Coverage of the right guards (domain 0 <= g <= 60, |r| <= 10): CACC and AEB together cover
# every domain state with 0 <= g + 2 r <= 60; the states with g + 2 r < 0 (collision
# unavoidable) or g + 2 r > 60 are in no right guard and no run reaches them (both guards are
# forward invariant).
#
# Verdicts (RELCERT_IMPLIED_CUT=1 unless stated, measured 2026-10-26 with the round-A binary):
# CERTIFIED (about 0.4 s); CERTIFIED under every switch: RELCERT_SYNC=1, RELCERT_NO_PRUNE=1,
# RELCERT_NO_CHOICE=1, NO_PRUNE+NO_CHOICE, SYNC+NO_CHOICE, without RELCERT_IMPLIED_CUT,
# RELCERT_NO_IMPLIED_CUT=1, RELCERT_NO_LINEAR_CUT=1, RELCERT_NO_CUT=1, RELCERT_NO_PAIR_STRETCH=1,
# RELCERT_WELLFORMED_STRICT=1 and RELCERT_OPREGION=1 (every admitted start in some right guard).
# Covers: SPORT_L at lambda 1, budget 1, admissible [CACC]; AEB_L at lambda 1, budget 1,
# admissible [AEB]; pruned CACC -> AEB. --handoff 3/3 pass (rows differ). relcert --wellformed:
# CACC ok (invariant), AEB ok (invariant), 0 UNKNOWN.
[problem]
name = platoon_profiles
max_depth = 8
lambda_min = 1.0
lambda_max = 1.0
bound_T = 4.0
[Lsys]
state_vars = [g, r]
epsilon = 0.1
[Lsys.mode.SPORT]
ode = g' = smt2:r; r' = smt2:(- (* -0.125 (- g 17.5)) (* 0.75 r));
guard = r >= -10.0 and r <= 10.0 and g + 2.0 * r >= 5.0 and g + 2.0 * r <= 60.0
evolve = g >= 0.0 and g <= 60.0 and r >= -10.0 and r <= 10.0
next = [SPORT, AEB]
[Lsys.mode.AEB]
ode = g' = smt2:r; r' = smt2:(* -0.5 r);
guard = g + 2.0 * r < 5.0 and g + 2.0 * r >= 0.0 and g >= 0.0
evolve = g >= 0.0 and g <= 60.0 and r >= -10.0 and r <= 10.0
next = [AEB]
[Rsys]
state_vars = [g, r]
epsilon = 0.1
[Rsys.mode.CACC]
ode = g' = smt2:r; r' = smt2:(- (* -0.125 (- g 20.0)) (* 0.75 r));
guard = r >= -10.0 and r <= 10.0 and g + 2.0 * r >= 5.0 and g + 2.0 * r <= 60.0
evolve = g >= 0.0 and g <= 60.0 and r >= -10.0 and r <= 10.0
next = [CACC, AEB]
[Rsys.mode.AEB]
ode = g' = smt2:r; r' = smt2:(* -0.5 r);
guard = g + 2.0 * r < 5.0 and g + 2.0 * r >= 0.0 and g >= 0.0
evolve = g >= 0.0 and g <= 60.0 and r >= -10.0 and r <= 10.0
next = [AEB]
[relational_invariant]
SPORT = smt2:(and (<= (- R_g L_g) 2.5) (<= (- L_g R_g) 0.0) (>= L_g 5.0) (<= (+ L_g (* 2.0 L_r)) 5.0) (<= (+ R_g (* 2.0 R_r)) 60.0) (>= (+ (- L_r R_r) (* 0.5 (+ (- L_g R_g) 2.5))) 0.0) (<= (+ (- L_r R_r) (* 0.5 (+ (- L_g R_g) 2.5))) 1.25))
AEB = smt2:(and (>= (- L_r R_r) 0.0) (<= (- L_r R_r) 0.0) (>= (+ (- L_g R_g) (* 2.0 (- L_r R_r))) 0.0) (<= (+ (- L_g R_g) (* 2.0 (- L_r R_r))) 0.0))
