# quad_light_lag: the 20 %-lighter quadrotor against the reference model, both with the same
# motor thrust lag; altitude conformance up to a time scaling.
# scenario: model-refinement
# mechanisms: S M (time stretch lambda = 6/5 needed, RELCERT_SYNC=1 declines; multi-step cover,
#   matrix codes M1 M2)
#
# System. The climb segment of quad_light_airframe_20 (same airframe numbers) with the motors'
# thrust lag: altitude h (m), climb rate w (m/s), net specific thrust a = T/m - g (m/s^2), time
# in s. The propellers realise the climb thrust through a first-order lag of time constant
# tau = 0.1 s (motor and ESC spin-up), T' = (T_cmd - T)/tau, so a' = 10 (a_cmd - a) on either
# airframe; w' = a - (k/m) w, h' = w.
#   Right (reference model): a_cmd = 2 g - g = 9.81, k/m_R = 4.905 /s (terminal 2.0 m/s).
#   Left (deployed): the same motors, command, lag and damping on the airframe 20 % lighter:
#     a_cmd = 1.25 (2 g) - g = 14.715, k/m_L = 6.13125 /s (terminal 2.4 m/s).
# One cause: the airframe mass (the lag is the same physical lag on both sides).
#
# Requirement: the altitude conformance of quad_light_airframe_20, |h_L - h_R| <= 0.8 m at times t
# and lambda t for one lambda in [1, 2]; 0.8 m is the altitude acceptance radius (PX4's default
# NAV_MC_ALT_RAD).
#   rows 1, 2 (the requirement): h_R - h_L <= 0.8 and h_L - h_R <= 0.8.
# Strengthening rows (each needed: dropping either, or both, DECLINES):
#   rows 3, 4: -0.16 <= Psi <= 0.16 with Psi = (h_L - h_R) + ((w_L - 2.4) + 0.1 (a_L - 14.715))
#     / 6.13125 - ((w_R - 2) + 0.1 (a_R - 9.81)) / 4.905 (written multiplied by 6.13125). Each
#     side's h + ((w - w_term) + tau (a - a_cmd)) / (k/m) is its extrapolated steady-climb
#     altitude and grows at exactly its terminal rate whatever the lag state, so at
#     lambda = 6/5 = 2.4 / 2 their difference Psi is conserved exactly.
#     Constant: the requirement 0.8 m less the largest transient term the climb envelopes allow
#     (0.63 m above, 0.61 m below), rounded down: with |Psi| <= 0.16 rows 1 and 2 follow from the
#     boxes.
# The lag breaks the lag-free climb-rate row 1.2 w_R <= w_L of quad_light_airframe_20: at the
# scaled time the reference's lag is 1.2 times shorter, so from hover its climb rate stays above
# the deployed's through the whole transient (simulated; adding that row DECLINES). The gap's
# sign flips against quad_light_airframe_20: from hover (h_L = h_R, w = a = 0 on both)
# Psi = -0.0237 m and the deployed falls behind the scaled reference by at most 2.4 cm
# (simulated: gap from 0 down to -0.0237 m, never positive); the lower row 1 is now the one the
# lag loads.
# Tightest (bisection to 0.01): with rows 3, 4 at 0.16, row 2 certifies down to 0.40 (0.39
# declines) and row 1 down to 0.38 (0.37 declines); with rows 1, 2 at 0.8, Psi's bounds certify
# up to 0.56 above (0.57 declines) and 0.58 below (0.59 declines); with Psi in [-0.03, 0.01]
# (hover still related) rows 1 and 2 certify down to 0.25 (0.24 declines). Psi is conserved, so
# its own bounds are only limited by the starts. Not implied by the domains.
#
# Guards and domains. CLIMB guard = evolve: h >= 0, 0 <= w <= terminal (2.4 left, 2.0 right),
# 0 <= a <= a_cmd (14.715 left, 9.81 right): from hover thrust to the climb thrust. Every box is
# forward invariant (a' >= 0 below the command, w' <= 0 at the terminal rate since a <= a_cmd,
# h' = w >= 0); altitude unbounded above (climb segments of any length). One right mode (no
# coverage gap); the left mode has a satisfiable start (hover). Climb-rate limiter (3 m/s) above
# both envelopes: not modeled. Control interval 1 s on both sides; budget ceil(6/5) = 2 (M).
#
# Verdicts (RELCERT_IMPLIED_CUT=1 unless stated): CERTIFIED; DECLINED under RELCERT_SYNC=1 and
# SYNC+NO_CHOICE; CERTIFIED under RELCERT_NO_PRUNE=1, RELCERT_NO_CHOICE=1, NO_PRUNE+NO_CHOICE,
# without RELCERT_IMPLIED_CUT, NO_IMPLIED_CUT, NO_LINEAR_CUT, RELCERT_NO_CUT=1, the operating
# region (every admitted start in some right guard) and RELCERT_WELLFORMED_STRICT=1. Cover: CLIMB
# at lambda = 6/5, budget 2, admissible start CLIMB, nothing pruned; --handoff 1/1 vacuous;
# relcert --wellformed: CLIMB ok (invariant). Units m, m/s, m/s^2, s.
[problem]
name = quad_light_lag
max_depth = 8
lambda_min = 1.0
lambda_max = 2.0
bound_T = 4.0
[Lsys]
state_vars = [h, w, a]
epsilon = 1.0
[Lsys.mode.CLIMB]
ode = h' = w; w' = smt2:(- a (* 6.13125 w)); a' = smt2:(* 10.0 (- 14.715 a));
guard = h >= 0.0 and w >= 0.0 and w <= 2.4 and a >= 0.0 and a <= 14.715
evolve = h >= 0.0 and w >= 0.0 and w <= 2.4 and a >= 0.0 and a <= 14.715
next = [CLIMB]
[Rsys]
state_vars = [h, w, a]
epsilon = 1.0
[Rsys.mode.CLIMB]
ode = h' = w; w' = smt2:(- a (* 4.905 w)); a' = smt2:(* 10.0 (- 9.81 a));
guard = h >= 0.0 and w >= 0.0 and w <= 2.0 and a >= 0.0 and a <= 9.81
evolve = h >= 0.0 and w >= 0.0 and w <= 2.0 and a >= 0.0 and a <= 9.81
next = [CLIMB]
[relational_invariant]
CLIMB = smt2:(and (<= (- R_h L_h) 0.8) (<= (- L_h R_h) 0.8) (<= (- (+ (* 6.13125 (- L_h R_h)) L_w (* 0.1 L_a)) (+ (* 1.25 R_w) (* 0.125 R_a) 0.14525)) (* 6.13125 0.16)) (<= (* (- 6.13125) 0.16) (- (+ (* 6.13125 (- L_h R_h)) L_w (* 0.1 L_a)) (+ (* 1.25 L_w) (* 0.125 R_a) 0.14525))))
