# rover_ladder_8to12: rover hierarchy, step 8 -> 12: heave and roll become second order and the tire
# slip moves (omega_z, omega_phi, y, omega_y move); the step carries the heading, roll, rollover and
# lane requirements.
# scenario: model-refinement
# mechanisms: S M I measured (time stretch 11/10 with two reference segments per window,
#   RELCERT_SYNC=1 declines; the zone facts s >= zone floor and v <= set point are load-bearing mode
#   facts, RELCERT_NO_CUT=1 declines; matrix codes M1 M2 M6). Cause test: S and I persist with the
#   left ODEs replaced by the right's, so they come from the re-timed claim form (the plan
#   tolerances), not only from the step's added dynamics; the file earns its place as a ladder rung.
#
# System (the canonical rover hierarchy, stated in full here and shared by rover_ladder_2to3,
# 3to6, 6to8 and 8to12; SI units, time in s, angles in rad): a four-wheel UGV (track 1.8 m, centre
# of gravity 0.9 m high, so the load-transfer ratio is LTR = a_b/g + phi_r and the static rollover
# threshold is 1 g; governed top speed 8 m/s) drives a route of three straight zones indexed by its
# odometer s [m]: STEEP s in [0, 60) (grade 0.15, cross-slope 0.10, speed set point c = 3.0 m/s),
# MODER [60, 140) (0.05, 0.05, 5.0 m/s), FLAT s >= 140 (level, 6.5 m/s). Speed loop v' = 0.5 (c - v)
# on every level (time constant 2 s); control interval 1 s on both sides. r = psi' is the yaw-rate
# error (r = -psi at L3 and L6, omega_psi - psi at L8 and L12), a = v r the lateral acceleration
# [m/s^2] of the heading corrections, g = 9.81 m/s^2. The levels:
#   L2 (v, s): s' = v.
#   L3 + heading error psi (steering loop 1 rad/s): psi' = -psi; s' = v (1 - psi^2/2) (along-track
#       component).
#   L6 + pitch theta_p, heave z [m], roll phi_r (terrain-following suspension, time constant 1 s):
#       theta_p' = -theta_p + grade + 0.5 z (bounce-pitch coupling), z' = -z, phi_r' = -phi_r +
#       xslope + 0.015 a (roll gradient 0.015 rad per m/s^2); s' = v (1 - psi^2/2 - 0.3 theta_p^2 -
#       0.2 phi_r^2) (wheel slip on the grade, crabbing on the cross-slope).
#   L8 + yaw and pitch inertia (critically damped at 1 rad/s, cascade chart w = x' + x; L6's heading
#       is L8's at omega_psi = 0): psi' = omega_psi - psi, omega_psi' = -omega_psi; theta_p' =
#       omega_theta - theta_p, omega_theta' = -omega_theta + grade + 0.5 z.
#   L12 + heave and roll inertia and tire slip: z' = omega_z - z, omega_z' = -omega_z; phi_r' =
#       omega_phi - phi_r, omega_phi' = -omega_phi + xslope + 0.015 a_b with the body lateral
#       acceleration a_b = a + y''; slip offset y [m]: y' = omega_y - y, omega_y' = -omega_y + 0.03
#       (a + g phi_r) (tire lateral compliance 0.03 m per m/s^2 of lateral load: centripetal plus
#       gravity on the rolled chassis), so y'' = y - 2 omega_y + 0.03 (a + g phi_r): slip moves the
#       rover sideways and drives roll.
# Requirements (one constant each): heading 0.35 rad = half field of view of the navigation camera
# (the path stays in view); pitch 0.25 rad = range of the mast camera's tilt stabilizer; roll 0.2
# rad = suspension roll stop; LTR 0.8 = 20 % margin to wheel lift (LTR = 1); lane 0.25 m = corridor
# half-width 1.25 m minus vehicle half-width 1.0 m. In the cascade chart the rate state carries its
# angle's tolerance (abs(x' + x) <= tol keeps the critically damped angle inside abs(x) <= tol).
# Each rung carries the requirements of the dynamics it adds: heading (2to3); pitch (3to6); heading,
# pitch, roll and rollover under yaw and pitch inertia (6to8); heading, roll, rollover and lane
# under roll inertia and tire slip (8to12).
#
# Left (L12: all twelve coordinates move). Right (L8, rover_ladder_6to8's left: omega_z, omega_phi,
# y, omega_y frozen at their start values, which the L8 dynamics and the rows do not read). The one
# difference is heave and roll inertia and the tire slip: the centripetal load and gravity on the
# rolled chassis push the rover sideways, and the slip acceleration y'' adds to the body lateral
# acceleration and drives roll.
#
# Property (the same rows in every left mode):
#   v_L <= v_R and s_L <= s_R (clearance, as in rover_ladder_2to3, against the re-timed reference: a
#     stop line the reference never passes is never passed by the rover, and with the timetable
#     tolerance the rover is never more than 25 % ahead of the reference's clock).
#   abs(psi_L), abs(omega_psi_L) <= 0.35 (heading; bounds r, so the centripetal part of the slip
#     load and of the LTR; any value down to 0.05 certifies; without the heading rows the file
#     DECLINES).
#   abs(phi_r_L), abs(omega_phi_L) <= 0.2 (roll requirement under the new roll inertia, driven by
#     the body lateral acceleration including the slip acceleration). Tightest certifying 0.15 (0.14
#     declines).
#   abs(a_b / g + phi_r)_L <= 0.8 with a_b = v r + y - 2 omega_y + 0.03 (v r + g phi_r) (rollover
#     requirement LTR <= 0.8 including the slip acceleration; folded in from rover_rollover_8to12,
#     same model pair; not implied by the other rows, which bound it by 0.87). Tightest certifying
#     0.35 (0.34 declines).
#   abs(y_L), abs(omega_y_L) <= 0.25 (lane requirement: the slip offset stays inside the lane
#     margin; folded in from rover_lateral_8to12, same model pair). Tightest certifying 0.20 (0.19
#     declines). The lane rows read the step's slip: with the tire compliance 5x (0.15 m per m/s^2)
#     the file DECLINES.
#   Plan tolerances abs(psi_R), abs(omega_psi_R) <= 0.35, abs(theta_p_R), abs(omega_theta_R) <=
#     0.25, abs(phi_r_R) <= 0.2: exactly rover_ladder_6to8's left requirement rows (its LTR row is
#     implied by them), so the 8-DOF reference is used inside what the previous rung certifies and
#     the chain composes. Without them the file DECLINES (the reference's loss is then bounded only
#     by its validity box, up to 0.338, which would need a re-timing of 1.51 > 1.25).
#
# Timetable tolerance (the stretch range). The dispatcher times the route from the 2-DOF plan
# (rover_ladder_2to3's right model): a waypoint's crossing slot opens at 80 % of the plan's arrival
# time, so the rover may run at most 25 % ahead of the plan's clock (a re-timing of at most 1/0.8 =
# 1.25 against the plan). A certificate's response runs the reference at a rate lambda in
# [lambda_min, lambda_max] (lambda_min = 1: never slower); with the clearance rows a rover at time t
# is no farther along than the reference at some time between t and lambda_max t. The rungs 2to3 and
# 3to6 need no re-timing and get none (lambda_max = 1); each re-timed rung (6to8, 8to12) may use the
# whole margin (lambda_max = 1.25). The certified covers use 11/10 in every pairing of both re-timed
# rungs, so the composed re-timing of the ladder's certificates is 1 x 1 x 1.1 x 1.1 = 1.21 <= 1.25
# (the analytic need, 1.0965 per rung, composes to 1.202). The forall-exists statement itself is
# untimed; the stretch is a property of the certificate's response, recorded in the emitted cover.
#
# Why the re-timing is needed (S, M) and where it comes from. The plan tolerance rows admit a
# reference at its worst admitted attitude (abs psi_R = 0.35, abs theta_p_R = 0.25, abs phi_r_R =

# Why the mode facts are needed (I). The re-timed reference's speed loop dominates the rover's only
