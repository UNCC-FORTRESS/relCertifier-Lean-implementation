# rover_lateral_6to8: lateral corridor keeping, the 8-state lateral rover refining the 6-DOF
#   plan (step 6 -> 8: the right moves 6 coordinates, the left 8).
# scenario: model-refinement
# mechanisms: none (CERTIFIED with RELCERT_SYNC=1, RELCERT_NO_PRUNE=1, RELCERT_NO_CHOICE=1, without
#   the widened cuts and with no cut at all; lambda = 1, one segment per window)
#
# Coordinates: v speed (m/s), s odometer (m), psi pitch and theta_p tilt (rad), z heave,
#   phi_r roll (rad), y lateral offset from the lane centreline (m, positive towards the right
#   edge), w = y' lateral velocity (m/s).
# Right (reasoning, the coarse plan): the 6-DOF rover, as in the other 6-DOF rover models (v
#   tracks the mode's set speed, s' = v (1 - psi^2/2 - 0.3 theta_p^2), psi, theta_p, z, phi_r
#   decay e^{-t}), lifted to 8 coordinates with the lateral pair frozen (y' = 0, w' = 0): the
#   plan holds whatever lateral offset it starts at.
# Left (deployed): the same 6-DOF rover plus the lateral regulator y' = w, w' = -y - 2w
#   (stiffness 1 s^-2, damping 2 s^-1: critically damped, natural frequency 1 rad/s, no
#   overshoot). The lead q = y + w (offset one time constant ahead) obeys q' = -q.
#   The two sides differ exactly in y' and w'; modes, guards, successors, domains are equal.
# Modes: STEEP (s in [0, 0.6), set speed 0.30), MODER (s in [0.6, 1.4), 0.50), FLAT
#   (s >= 1.4, 0.65, terminal, unbounded above); next = [MODER, STEEP], [FLAT, MODER], [FLAT].
#   Every s >= 0 lies in exactly one right guard.
# Property: the speed, odometer, pitch and tilt alignment rows of the ladder
#   (v_L <= v_R, s_L <= s_R, psi_L = psi_R, theta_p_L = theta_p_R) and corridor keeping
#   y_L <= y_R + d with the lead y_L + w_L <= y_R + d (the rate is part of the state: with the
#   offset row alone a deployed rover on the bound moving right breaks it at once).
# Requirement behind d = 0.5 m: the deployed rover may be at most one lane half-width further
#   right than the plan. For a plan on the left edge (y_R = -0.5) this says the regulator
#   recentres without crossing the centreline. Tightest certifiable d: 0.50 (0.49 DECLINES):
#   on the bound q_L = y_R + d the lead decays only if y_R + d >= 0, i.e. d >= 0.5 at the left
#   edge. An underdamped regulator would overshoot and break the row.
# Domains (both sides, every mode): physical limits. Lane: -0.5 <= y <= 0.5 (half-width 0.5 m);
#   lateral speed -1 <= w <= 1; lead -0.5 <= y + w <= 0.5 (forward-invariant under the
#   regulator: the lane box with this lead box is invariant, and it implies |w| <= 1); attitude
#   psi, theta_p, phi_r in [-0.5, 0.15], z in [-1, 0.15] (contractions, forward-invariant);
#   v in [0, 0.8]; s >= 0. Neither row follows from the domains (y_L - y_R and q_L - y_R range
#   up to 1.0 > d). Load-bearing bound (scripts/domain_widening.py): only the right's lane edge
#   y_R >= -0.5, which the frozen plan keeps.
# Pairs with rover_lateral_8to12, whose right model is this file's left model with the 12-DOF
#   coordinates pinned. (Redesigned 2026-10-26: before, the offsets lived in [0, 0.15] on both
#   sides, so the corridor row y_L <= y_R + 0.3 followed from the domains, phi_r was frozen on
#   both sides, and w entered no other equation.)
