# rover_rollover_6to7: rollover ladder, step 6 -> 7: the yaw channel becomes second order. With
# rover_rollover_7to12 it composes to rover_rollover_6to12.
# scenario: model-refinement
# mechanisms: M1 M2 M6
#
# System: the terrain-zone rover of rover_rollover_6to12 (zones STEEP / MODER / FLAT by odometer
# s, speed set points 0.30 / 0.50 / 0.65, s' = v (1 - psi^2/2 - 0.3 theta_p^2)).
#
# Left (the 7-DOF intermediate model IM, 7 coordinates move; the same model as
# rover_rollover_7to12's right): v, s, the first-order attitude psi' = -psi, theta_p' = -theta_p,
# roll phi_r' = -phi_r, and the second-order yaw loop in its cascade chart e' = r - 2 e, r' = -2 r.
# Here r is the yaw rate plus 2 e: in the original chart (yaw rate r - 2 e) this is the 12-DOF
# left's yaw loop e'' = -4 e - 4 e'; the chart makes the e, r box forward invariant (every face
# inflows). omega_psi, omega_theta, omega_phi, z, y are pinned.
# Right (the 6-DOF plan, 6 coordinates move; the same model as rover_rollover_6to12's right): yaw
# first order, e' = -e, with r pinned; guards with the zone entry condition v <= c.
#
# Property (the same rows in every left mode): rover_rollover_6to12's rows on this step.
#   v_L <= v_R and s_L <= s_R: IM is never faster than, and never ahead of, the plan.
#   |v_L (r_L - 2 e_L)| <= 1.0: lateral acceleration within a_max = 1.0 (r - 2 e is the yaw rate).
#   V(e_L, r_L - 2 e_L) <= 0.33: the yaw-loop Lyapunov function of 6to12 in the cascade chart;
#   0.33 is the largest two-decimal level giving |v r| < a_max at the top set point 0.65.
# Tightest certifying constants: s offset any value tried down to -1, energy any level down to 0
# (a Lyapunov sublevel set), |v r| 0.47 (0.46 declines); the claim keeps the requirement values.
# Not implied by the domains.
#
# Domains: every box is forward invariant (contractions toward 0, the cascade box, pinned
# coordinates, v toward its set point; s >= 0 unbounded above). The left guards have no speed
# condition; the right's v <= c with v_L <= v_R bounds the left speed at every admitted start.
#
# Operating region: as in rover_rollover_6to12, the invariant admits right speeds above their
# zone's set point, in no right guard; outside the plan's operating region, excluded as starts.
#
# Composition: this step gives v_IM <= v_R and s_IM <= s_R; rover_rollover_7to12 gives the
# 12-DOF left's v, s and rollover rows against IM; chained, rover_rollover_6to12's rows. This
# file's rollover rows are IM's own rollover property; the chain does not need them.
#
# Verdicts (RELCERT_IMPLIED_CUT=1): CERTIFIED (also NO_CHOICE, NO_PRUNE, NO_PRUNE+NO_CHOICE,
# NO_IMPLIED_CUT, NO_LINEAR_CUT, OPREGION); DECLINED under SYNC, SYNC+NO_CHOICE and NO_CUT.
# Covers: lambda 27/20 and budget 2 in every left mode (M1, M2); checked cut load-bearing (M6);
# nothing pruned; handoff vacuous (rows identical).
