# rover_rollover_payload: rollover margin of the canonical 12-DOF rover carrying a mast payload
# that raises its centre of gravity from 0.9 m to 1.2 m (deployed), against the same rover without
# the payload (nominal reference). Both sides 12-DOF; one cause (the CG height).
# scenario: degradation
# mechanisms: X I (hop of the reference into the deployed's zone inside its transition band,
#   RELCERT_NO_CHOICE=1 declines; checked cut v <= c (zone entry speed), RELCERT_NO_CUT=1 declines;
#   matrix code M6). Both letters come from the claim form (they persist at h_L = h_R), see below.
#
# System. The canonical rover of the round-A hierarchy (tmp/r2a/rover/gen.py, level L12: SI units,
# s in m, angles in rad; track T = 1.8 m; zones STEEP [0, 60) m, MODER [60, 140) m, FLAT >= 140 m with
# grade 0.15 / 0.05 / 0 rad, cross-slope 0.10 / 0.05 / 0 rad, speed set points 3.0 / 5.0 / 6.5 m/s;
# control interval 1 s on both sides). The equations are literally the generator's L12 equations on
# both sides; the right ODEs are byte-identical to the left ODEs of rover_ladder_8to12.
#   v' = 0.5 (c - v); s' = v (1 - psi^2/2 - 0.3 theta_p^2 - 0.2 phi_r^2); psi' = omega_psi - psi,
#   omega_psi' = -omega_psi; theta_p' = omega_theta - theta_p, omega_theta' = -omega_theta + grade +
#   0.5 z; z' = omega_z - z, omega_z' = -omega_z; phi_r' = omega_phi - phi_r, omega_phi' = -omega_phi
#   + xslope + KPHI a_b; y' = omega_y - y, omega_y' = -omega_y + 0.03 (a + 9.81 phi_r), with
#   a = v (omega_psi - psi) and the body lateral acceleration a_b = a + y - 2 omega_y + 0.03 (a + 9.81 phi_r).
#
# The cause. The CG height h enters the canonical model in two places: the roll gradient
# KPHI = 0.015 h / 0.9 rad per m/s^2 (roll moment arm = h for a roll axis at ground level, to first
# order in m g h / K_roll) and the load-transfer ratio LTR = (2 h / T)(a_b / 9.81 + phi_r). Nominal
# h_R = 0.9 m: KPHI_R = 0.015, 2h/T = 1 (static rollover threshold 1 g). Deployed h_L = 1.2 m (mast
# payload): KPHI_L = 0.02, 2h/T = 4/3 (threshold 0.75 g). Nothing else differs in the dynamics.
#
# Deployed guards: the canonical zone guards with the zone entry speed v <= c (as the ladder's L12
# left: a start condition every reachable state satisfies, set points rise along the route and
# v' = 0.5 (c - v) never overshoots). Reference guards: the nominal reads each zone joint as a
# transition band of +-2 m (STEEP s < 62, MODER 58 <= s < 142, FLAT s >= 138) and may switch back
# inside the band (declared MODER -> STEEP, FLAT -> MODER). This is the reference's abstraction, not
# a dynamic difference: the larger roll of the payload rover changes its crabbing loss
# (0.2 phi_r^2 in s'), so the two odometers drift and a nominal run with exact joints cannot follow
# the payload rover's zone schedule. Load-bearing: exact joints (no band, no back edges) DECLINE, a
# 1 m band DECLINES, the 2 m band without the back edges DECLINES. The width is the certified drift
# at the last joint (0.012 x 145 + 0.2 = 1.94 m).
#
# Property (rows identical in every zone).
#   shared channels equal: v, psi, omega_psi, theta_p, omega_theta, z, omega_z (the payload changes
#     none of their equations and the zones are matched);
#   heading |psi_L|, |omega_psi_L| <= 0.35 rad (the ladder's heading requirement; it bounds the
#     lateral acceleration a);
#   roll stop |phi_r|, |omega_phi| <= 0.2 rad and lane |y|, |omega_y| <= 0.25 m on BOTH sides (the
#     ladder's requirements; on the right they are the nominal's own envelope);
#   roll and slip differences |phi_rL - phi_rR|, |omega_phiL - omega_phiR| <= 0.06,
#     |y_L - y_R|, |omega_yL - omega_yR| <= 0.05 (certificate rows: the payload's extra roll);
#   odometer drift |s_L - s_R| <= 0.012 s_L + 0.2 m (certificate row; it keeps the zones matched);
#   REQUIREMENT |LTR_L| <= 0.8, LTR_L = (4/3)(a_bL / 9.81 + phi_rL): 20 % margin to wheel lift (LTR = 1);
#   RELATIONAL |LTR_L - (h_L/h_R) LTR_R| <= 0.1: the payload rover's load transfer is the nominal's
#     scaled by the CG ratio 4/3 (the static effect) up to a dynamic excess of 0.1 (half the 0.2
#     rollover margin). LTR_R is written with the shared channels v, psi, omega_psi read on the left
#     (equal by the rows above); a draft with the literal right-side form (excess 0.15) CERTIFIED in
#     84 s with a raised RELCERT_TIME_BUDGET_MS, over the 40 s default budget.
#
# Tightest constants (bisection, the other constants at their file values, 2026-10-26):
#   LTR_L 0.460 (0.457 declines); relational excess 0.084 (0.080 declines); drift slope 0.005
#   (0.004 declines, band 3 m); roll difference 0.056 (0.051 declines; drift slope 0.016, band 3 m).
#
# The claim depends on the cause (measured; support rows widened where noted so that they do not bind):
#   roll difference needed: 0.032 at h_L = 0.9 m (no payload; the floor of the stratified certificate,
#     which cannot prove the cyclic roll-slip loop equal), 0.056 at 1.2 m, 0.080 at 1.5 m;
#   tightest LTR_L: 0.347 (0.9 m, = the nominal's own), 0.385 (1.0), 0.422 (1.1), 0.461 (1.2),
#     0.499 (1.3), 0.537 (1.4), 0.575 (1.5): proportional to h;
#   relational excess with fixed support rows (difference rows 0.1, drift slope 0.016, band 3 m):
#     0.101, 0.117, 0.125, 0.141, 0.149, 0.157, 0.172 for h_L = 0.9 .. 1.5 m;
#   the file itself CERTIFIES up to h_L = 1.30 m and DECLINES from 1.31 m (the 0.06 roll-difference
#     row no longer holds); an arbitrary deployed zone schedule (zone guards without the odometer,
#     every zone a successor of every zone) DECLINES.
#
# Letters, honestly. X: from a deployed zone change the reference starts the next window in its old
# zone (still in the band) and hops into the deployed's zone; I: the zone entry speed v <= c is a
# checked cut that bounds a = v r in the roll and slip rows. Both persist at h_L = 0.9 m (NO_CHOICE
