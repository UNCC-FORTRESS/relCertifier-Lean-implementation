# rover_terrain_2to4: terrain chain, step 2 -> 4: wheel slip and soil sinkage. The right (the
# no-slip plan) moves 2 coordinates (v, s), the left 4 (v, s, w, zs). First step of the chain
# rover_terrain_2to4, rover_terrain_4to6, rover_terrain_6to12. (Renamed 2026-10-26 from
# rover_terrain_3to6, whose models were the rover ladder's attitude models; the terrain chain
# now refines terrain physics: soil, roughness, slope; the ladder refines attitude.)
# scenario: model-refinement
# mechanisms: I (the checked cuts w <= c_T and s >= zone floor are load-bearing mode facts,
#   RELCERT_NO_CUT=1 declines, matrix code M6), from the terrain structure: this is a refinement
#   step, a rung of the terrain chain.
# Review round 6 (2026-10-30): the claim is the real-time form (lambda 1, with the auxiliary row
#   w[l] <= v[r]). The re-timed form stated before (lambda in [1, 2.7]) needed its stretch only
#   for admitted starts with the wheel ahead of the plan (w_L > v_R), which no run from a start
#   with w_L <= v_R reaches (Property), so S and M were start-only; letters S M I -> I.
# One domain (2026-10-29): left w in [0.15, 0.8] (the controller's creep floor), right w in
#   [0, 0.8] -> w in [0, 0.8] on both sides; then (fix round 4, 2026-10-29) w in [0.05, 0.8],
#   the soil model's validity range (Domain, below), shared with rover_terrain_4to6; rows,
#   verdict, tight values and ablations unchanged.
#
# System (SI units: m, s, m/s; g = 9.81 m/s^2): a rover climbs out of a muddy bank onto a
# gravel track and then a paved road. The terrain is a mode, fixed by the odometer s along the
# route: MUD s in [0, 5), GRAVEL [5, 12), PAVED s >= 12; the route is traversed in that order.
# Per terrain T: wheel-speed set point c_T = 0.25 / 0.45 / 0.70 m/s (the controller slows on
# soft ground), traction stiffness mu_T = 2.5 / 4 / 8 1/s (tractive force per unit slip
# velocity: soft soil shears, pavement grips), terrain drag r_T = 0.4 / 0.15 / 0.05 1/s, and
# equilibrium sinkage Z_T = 0.10 / 0.03 / 0 (in wheel radii).
#
# Right (2-DOF, the no-slip plan): no slip, the ground speed IS the wheel speed, v' = 3 (c_T - v),
# s' = v: wheel odometry taken as ground truth, the wheel loop's own rate (3 /s, the rate the
# 4-DOF model's wheel loop runs at, so the plan is the 4-DOF model with slip and sinkage removed).
# w, zs pinned (w' = zs' = 0).
# Left (4-DOF): the speed loop closes on the wheel speed w, w' = 3 (c_T - w); the ground speed
# follows through the soil, v' = mu_T (w - v) - r_T v - zs (traction from the slip velocity
# w - v, viscous terrain drag, and compaction resistance proportional to sinkage, Bekker-style
# and speed independent, 1 m/s^2 per wheel radius); the wheels settle to the terrain's sinkage,
# zs' = 2 (Z_T - zs) (climbing out of the ruts on firmer ground). s' = v.
#
# Property (the same rows in every left mode):
#   v_L <= v_R and s_L <= s_R: the rover is never faster than, and never ahead of, the no-slip
#     plan at the same time (lambda 1). Offset 0 (structural).
#   w_L <= v_R (auxiliary row): the wheel never turns faster than the plan's speed. Inductive:
#     d/dt (w_L - v_R) = -3 (w_L - v_R) + 3 (c_L - c_R) and c_L <= c_R (s_L <= s_R, set points
#     increase along the route); a 4000-start lambda-1 simulation from admitted starts with
#     w_L <= v_R never exceeds 0 (2026-10-30). It excludes exactly the starts with the wheels
#     already slipping ahead of the plan.
#   v_L <= w_L and w_L <= v_L + sigma, sigma = 0.25 m/s: the slip velocity stays in
#     [0, sigma]: the wheels never skid (ground speed never exceeds wheel speed) and never spin
#     past the traction controller's slip-velocity threshold sigma (it would cut torque there;
#     requirement: it never has to on this route).
#   Not implied by the domain (w - v ranges over [-0.8, 0.8] on the box).
# Tightest (bisection 0.01, re-measured on the one domain): sigma certifies down to 0.21
# (declines at 0.20). Analytically: a
# launch from v = 0 at the start of GRAVEL with zs = 0.12 has d(w - v)/dt = 3 (0.45 - w)
# - 4 (w - v) + zs at w - v = sigma, <= 0 iff sigma >= 1.47 / 7 = 0.21. The slip row is the
# requirement itself.
#
# Domain (the same in every mode, both sides): v in [0, 0.8] m/s (standstill to the drive's top
# speed), s >= 0 (unbounded above), w in [0.05, 0.8] m/s, zs in [0, 0.12] (the sinkage range).
# The wheel floor 0.05 is the validity range of the linear soil model: its compaction resistance
# zs is speed independent, so with the wheel nearly still (mu_T w < zs) it would push a standing
# rover backward, which soil cannot do; the model holds where traction at standstill covers it,
# mu_MUD w >= Z_max, w >= 0.12 / 2.5 = 0.048, rounded up to 0.05 (then v' >= 2.5 x 0.05 - 0.12 > 0
# at v = 0 in every zone). Until 2026-10-29 the domain was w in [0, 0.8] and a launch with the wheel
# nearly still stalled at v = 0 (the run ended there); w in [0.15, 0.8] before that was the wheel
# controller's creep floor, a policy value. On the left, w' = 3 (c_T - w) points inward at 0.05
# and at 0.8, zs' = 2 (Z_T - zs) with Z_T <= 0.10, at v = 0.8, v' <= 0 since w <= 0.8, and at
# v = 0, v' > 0 (above): forward invariant. The plan's v in [0, 0.8] is forward invariant; its
# flow keeps w, zs fixed.
# Guards: right = the terrain zones only (every right state lies in exactly one right guard);
# left = the zone and entry wheel speed w <= c_T. A left state with w above its zone's set
# point is in no left guard: unreachable from a guarded entry (w' = 3 (c_T - w) keeps w <= c_T
# inside a zone; set points increase along the route). Starts are non-vacuous in every mode
# (e.g. MUD: s = 0, v = 0.1, w = 0.25, zs = 0.1 with any plan state v_R >= 0.1, s_R >= 0); the
# entry guard admits every wheel speed in [0.05, c_T], so starts with the wheel at its floor too.
#
# Composition: the left model is exactly the right model of rover_terrain_4to6 (u, zh pinned
# there; checked 2026-10-27, and the domain again 2026-10-29: same fields, guards, successor
# lists and wheel range [0.05, 0.8] on the shared coordinates),
# so the v and s rows chain by transitivity with that file's and with rover_terrain_6to12's:
# 12-DOF <= 6-DOF <= 4-DOF <= no-slip plan, all at lambda 1 (real time), from starts with the
# wheel at or below the plan's speed.
#
# Verdicts (RELCERT_IMPLIED_CUT=1, measured 2026-10-30, lambda_min = lambda_max = 1):
# CERTIFIED (about 0.6 s); also under SYNC, NO_PRUNE, NO_CHOICE, NO_REPO, OPREGION,
# NO_IMPLIED_CUT, NO_LINEAR_CUT, NO_PAIR_STRETCH and RELCERT_WELLFORMED_STRICT; DECLINED under
# NO_CUT. sigma tight 0.21 (0.20 declines). --handoff 5/5 (vacuous: rows identical).
# --wellformed: MUD ok (exit -> GRAVEL), GRAVEL ok (exit -> PAVED), PAVED ok (invariant),
# 0 UNKNOWN, 0 BLOCKING. Assumption 1 proof: WellFormed/RoverTerrain2to4.lean (the batch-I5
# plan, wheel range of 2026-10-29).
# Letters: I. Without the row w[l] <= v[r] the file at lambda 1 DECLINES.

[problem]
name = rover_terrain_2to4
max_depth = 8
lambda_min = 1.0
lambda_max = 1.0
bound_T = 4.0

[Lsys]
state_vars = [v, s, w, zs]
epsilon = 1.0

[Lsys.mode.MUD]
ode = v' = 2.5*(w - v) - 0.4*v - zs; s' = v; w' = 3*(0.25 - w); zs' = 2*(0.1 - zs);
guard = s >= 0.0 and s < 5.0 and w <= 0.25
evolve = v >= 0.0 and v <= 0.8 and s >= 0.0 and w >= 0.05 and w <= 0.8 and zs >= 0.0 and zs <= 0.12
next = [GRAVEL, MUD]

[Lsys.mode.GRAVEL]
ode = v' = 4.0*(w - v) - 0.15*v - zs; s' = v; w' = 3*(0.45 - w); zs' = 2*(0.03 - zs);
guard = s >= 5.0 and s < 12.0 and w <= 0.45
evolve = v >= 0.0 and v <= 0.8 and s >= 0.0 and w >= 0.05 and w <= 0.8 and zs >= 0.0 and zs <= 0.12
next = [PAVED, GRAVEL]

[Lsys.mode.PAVED]
ode = v' = 8.0*(w - v) - 0.05*v - zs; s' = v; w' = 3*(0.7 - w); zs' = 2*(0.0 - zs);
guard = s >= 12.0 and w <= 0.7
evolve = v >= 0.0 and v <= 0.8 and s >= 0.0 and w >= 0.05 and w <= 0.8 and zs >= 0.0 and zs <= 0.12
next = [PAVED]

[Rsys]
state_vars = [v, s, w, zs]
epsilon = 1.0

[Rsys.mode.MUD]
ode = v' = 3*(0.25 - v); s' = v; w' = 0; zs' = 0;
guard = s >= 0.0 and s < 5.0
evolve = v >= 0.0 and v <= 0.8 and s >= 0.0 and w >= 0.05 and w <= 0.8 and zs >= 0.0 and zs <= 0.12
next = [GRAVEL, MUD]

[Rsys.mode.GRAVEL]
ode = v' = 3*(0.45 - v); s' = v; w' = 0; zs' = 0;
guard = s >= 5.0 and s < 12.0
evolve = v >= 0.0 and v <= 0.8 and s >= 0.0 and w >= 0.05 and w <= 0.8 and zs >= 0.0 and zs <= 0.12
next = [PAVED, GRAVEL]

[Rsys.mode.PAVED]
ode = v' = 3*(0.7 - v); s' = v; w' = 0; zs' = 0;
guard = s >= 12.0
evolve = v >= 0.0 and v <= 0.8 and s >= 0.0 and w >= 0.05 and w <= 0.8 and zs >= 0.0 and zs <= 0.12
next = [PAVED]

[relational_invariant]
MUD = smt2:(and (<= L_v R_v) (<= L_s R_s) (<= L_v R_w) (<= L_w (+ L_v 0.25)) (<= L_w R_v))
GRAVEL = smt2:(and (<= L_v R_v) (<= L_s R_s) (<= L_v R_w) (<= L_w (+ L_v 0.25)) (<= L_w R_v))
PAVED = smt2:(and (<= L_v R_v) (<= L_s R_s) (<= L_v R_w) (<= L_w (+ L_v 0.25)) (<= L_w R_v))
