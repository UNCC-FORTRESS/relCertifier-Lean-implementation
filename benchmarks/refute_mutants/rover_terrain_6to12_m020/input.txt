# rover_terrain_6to12: terrain chain, step 6 -> 12: the bank's slope, the chassis pitch, the
# lagged body acceleration, the suspension's squat pitch and the damped heave. The right moves
# 6 coordinates (v, s, w, zs, u, zh), the left all 12 (+ vz, gamma, theta_p, ax, phs,
# omega_phs). Last step of the chain rover_terrain_2to4, rover_terrain_4to6,
# rover_terrain_6to12. (Redesigned 2026-10-26: it used to refine the rover ladder's 6-DOF attitude
# model with lagged ax, ay; the terrain chain has no lateral dynamics, so ay is gone and the
# 6-DOF base is now rover_terrain_4to6's terrain model.)
# scenario: model-refinement
# mechanisms: I (the checked cuts u <= c_T, the zone floors and the left MUD fact gamma >= 0.02
#   are load-bearing mode facts, RELCERT_NO_CUT=1 declines; lambda 1, one segment per window)
#
# System: the terrain rover of rover_terrain_4to6 (SI units; MUD s in [0, 5), GRAVEL [5, 12),
# PAVED s >= 12, traversed in order; c_T = 0.25 / 0.45 / 0.70 m/s, mu_T = 2.5 / 4 / 8 1/s,
# r_T = 0.4 / 0.15 / 0.05 1/s, Z_T = 0.10 / 0.03 / 0, roughness rho_T = 0.5 / 0.2 / 0.05). The
# muddy stretch is a bank of constant grade 0.02 rad; past its top the grade eases to level
# over a vertical curve of length 2 m.
#
# Right (6-DOF; exactly rover_terrain_4to6's left): u' = 4 (c_T - u), w' = 3 (u - w),
# v' = mu_T (w - v) - r_T v - zs, zs' = 2 (Z_T - zs), zh' = rho_T v - zh (first-order heave
# envelope), s' = v; the six new coordinates pinned. The right model has no slope.
# Left (12-DOF):
#   gamma: the terrain grade under the front axle: 0.02 rad on the bank (MUD, entered with
#     gamma >= 0.02 and theta_p >= 0.02, gamma' = 0), easing with distance past the top,
#     gamma' = -0.5 v gamma (GRAVEL, PAVED).
#   theta_p: the chassis pitch (the chord slope between the axles), lagging the grade by one
#     wheelbase (0.5 m) of travel, theta_p' = 2 v (gamma - theta_p).
#   slope load on the ground speed: v' = mu_T (w - v) - r_T v - zs - 9.81 theta_p (g sin of
#     the chassis slope, linearized).
#   vz: heave becomes second order, critically damped, in its cascade chart (vz := zh' + zh):
#     zh' = vz - zh, vz' = rho_T v - vz.
#   ax: the body's longitudinal acceleration as the accelerometer reports it (0.2 s lag),
#     ax' = 5 (v'_expr - ax), v'_expr the left's own v' field.
#   phs, omega_phs: the suspension's squat pitch (critically damped, cascade chart), driven by
#     the acceleration, phs' = omega_phs - phs, omega_phs' = 0.05 ax - omega_phs (0.05 rad
#     per m/s^2).
#   u, w, zs, s as on the right.
#
# Property (the same rows in every left mode):
#   requirements: v_L <= v_R and s_L <= s_R (the sloped, compliant rover never faster than,
#     never ahead of, the flat-ground model; offset 0, structural); slip window v_L <= w_L <=
#     v_L + sigma, sigma = 0.25 m/s; heave zh_L <= H, H = 0.15 wheel radii (bump stop);
#     body pitch theta_p_L + phs_L <= Theta, Theta = 0.15 rad (nose-up limit of the navigation
#     camera's pitch stabilization: chassis slope plus squat).
#   auxiliary rows (each needed; constants derived, not tuned): u_L <= u_R, w_L <= w_R,
#     zs_R <= zs_L, w_L <= u_L (orderings, as in rover_terrain_4to6); vz_L <= H (heave's
#     cascade coordinate, which bounds zh); ax_L <= 2.0 = mu_PAVED * sigma (the largest
#     tractive acceleration the slip limit allows); omega_phs_L <= 0.1 = 0.05 * 2.0 (the squat
#     the acceleration bound allows).
#   Not implied by the domains.
# Tightest (bisection 0.01): sigma 0.24 (declines at 0.23; the slope load needs more slip on
#   the bank than flat ground, 0.21); H 0.13 (declines at 0.12; analytic 0.125); Theta 0.13
#   (declines at 0.12; the analytic bound, bank grade 0.02 + squat bound 0.1, is 0.12); aux ax 2.00 (declines at 1.99: it
#   is exactly mu_PAVED * sigma); aux omega_phs 0.10 (declines at 0.09).
#
# Domains (left; all forward invariant): v in [0, 0.8] (at v = 0, v' >= 2.5 * 0.15 - 0.12
# - 9.81 * 0.02 > 0, so the creep floor keeps the rover climbing the bank), w, u in
# [0.15, 0.8], zs in [0, 0.12], zh, vz in [0, 0.5], gamma, theta_p in [0, 0.02] (the grade

# w = u = 0.25, zs = 0.1, gamma = theta_p = 0.02, the rest 0).
#
# Composition: the right model is rover_terrain_4to6's left (six coordinates pinned), so the v
