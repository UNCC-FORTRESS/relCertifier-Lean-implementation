# sat3w_detumble_weak: three-wheel microsatellite, weakened actuators, design model with profiles.
# scenario: degraded-actuator
# mechanisms: M B I (multi-step cover; branching joint steps over the ground-selectable profiles;
#   the engagement envelope as a load-bearing checked cut; matrix codes M2 M3 M6)
#
# Dimension lift of sat_detumble_weak: the single z-wheel gyrostat becomes a
# full three-wheel gyrostat, state (w1, w2, w3, h1, h2, h3) per side (6 D).
#
# THE PLANT (both sides; a ~60 kg microsatellite, SI units). Body rates w = (w1, w2, w3)
# (rad/s) about the principal axes, inertia J = diag(2, 4, 5) kg m^2, and the momenta
# h = (h1, h2, h3) (N m s) of three reaction wheels aligned with the principal axes.
# Euler's equations of a gyrostat (body frame, no external torque):
#   J w' = -w x (J w + h) - h',
# and each wheel absorbs its axis rate (rate-damping law of gain k): h_i' = k J_i w_i, so
#   J w' = -w x (J w + h) - k J w.
# Componentwise, with (w x H)_1 = w2 H3 - w3 H2 etc. and H = J w + h:
#   J1 w1' = (J2 - J3) w2 w3 + w3 h2 - w2 h3 - k J1 w1,
#   J2 w2' = (J3 - J1) w3 w1 + w1 h3 - w3 h1 - k J2 w2,
#   J3 w3' = (J1 - J2) w1 w2 + w2 h1 - w1 h2 - k J3 w3,
# i.e. w1' = -0.5 w2 w3 + 0.5 (w3 h2 - w2 h3) - k w1,
#      w2' = 0.75 w3 w1 + 0.25 (w1 h3 - w3 h1) - k w2,
#      w3' = -0.4 w1 w2 + 0.2 (w2 h1 - w1 h2) - k w3,
#      h1' = 2 k w1, h2' = 4 k w2, h3' = 5 k w3.
# ENERGY: E = 2 w1^2 + 4 w2^2 + 5 w3^2 = w . J w (twice the body's rotational kinetic
# energy). E' = 2 w . J w' = -2 w . (w x H) - 2 k w . J w = -2 k E, because w . (w x H) = 0
# for EVERY H: the gyroscopic cubic terms (coefficients -2 + 6 - 4 = 0 on w1 w2 w3) and the
# six wheel-coupling cubic terms (w1 w3 h2, w1 w2 h3, w2 w3 h1, each +2 and -2) cancel
# exactly. E' = -2 k E holds only through that cancellation, which every flow query on the
# energy rows has to establish in nonlinear real arithmetic (12 real variables per query).
# The wheels do not dissipate the TOTAL momentum: |J w + h| is conserved (H . H' = 0);
# a later momentum dump by magnetorquers is not modeled.
# The DESIGN MODEL (right) neglects the gyroscopic and wheel couplings: w_i' = -k w_i,
# h_i' = k J_i w_i.
# PHYSICAL DOMAIN (both sides): |w_i| <= 1 rad/s (the gyro's measurement range) and
# |h_i| <= 2 N m s (each wheel's momentum capacity); no certificate stands on them
# (widening test: CERTIFIED with every bound widened at once, no load-bearing group).
# Guards (entry conditions): the detumble controller engages with the body energy inside
# its authority envelope, E <= 1 (a controller-design constant: e.g. |w1| <= 0.71 rad/s
# about x alone). The design model declares the FDIR SAFE mode on the ENERGY threshold
# E > 1 (actuators inhibited, a sink; modeled frozen) -- a quadratic threshold. The right
# guards cover the domain (the three profiles share E <= 1, SAFE is E > 1): no coverage gap.
#
# Degraded deployed: a bus under-voltage limits the wheel torque to 80 %: k_L = 0.4 /s.
# The design model (right) offers three ground-selectable detumble power profiles,
# NOMINAL k = 0.5, ECONOMY 0.45 and SURVIVAL 0.42 (battery states), switchable
# NOMINAL <-> ECONOMY / SURVIVAL; each declares SAFE.
#
# One cause between the sides: the actuator degradation (k_L = 0.4 against the profiles'
# 0.5 / 0.45 / 0.42). The left also carries the gyroscopic and wheel couplings the design
# model neglects, but they do no work, so they do not move the energy the claim reads.
#
# CLAIM: E_R <= E_L (the weakened spacecraft never detumbles faster than the design model)
# and E_L <= E_R + 0.2. On the boundary E_L = E_R + d the gap grows at
# 2 k_R E_R - 2 k_L (E_R + d), which is <= 0 iff E_R <= d k_L / (k_R - k_L); with
# E_R <= E_L <= 1 (the engagement envelope, a checked cut) the tangent tolerance is
# d* = 1 - k_L / k_R: 0.2 against NOMINAL, 0.111 against ECONOMY, 0.048 against SURVIVAL.
# The file states the NOMINAL bound, the largest of the three, as a profile-independent
# tolerance; the certificate is existential in the reference profile, so it certifies
# tighter. Tightest certifying (measured 2026-10-26, default recipe): 0.1114 CERTIFIED,
# 0.1099 DECLINED, i.e. the ECONOMY bound 1/9: the existential reference may run a slower
# profile than NOMINAL. Below the NOMINAL bound the committed successor subsets are needed
# (at 0.12, RELCERT_NO_CHOICE=1 DECLINES); at the file's 0.2 they are not. Not implied by the
# domains; the left mode has a satisfiable start (E_L = E_R <= 1).
# Covers (measured): lambda in [1, 1] (synchronous, as sat_detumble_nominal; a weaker
# deployed gains nothing from a stretch), budget 2; admissible starts NOMINAL, ECONOMY,
# SURVIVAL. From NOMINAL a joint step retains NOMINAL, ECONOMY and SURVIVAL, from ECONOMY
# and SURVIVAL their own profile and NOMINAL; every retained successor covers (M, B). The
# engagement envelope E <= 1 is a checked cut (a quadratic guard conjunct whose
# invariance is a DI-boundary query with the cubic cancellation): RELCERT_NO_CUT=1
# DECLINES (I).
# Fallback: NOMINAL/ECONOMY/SURVIVAL -> SAFE pruned (no entry state has E > 1; on
# E = 1 the field gives E' = -2 k E < 0); the committed successor subsets close the same
# fallback, so RELCERT_NO_PRUNE=1 alone CERTIFIES and only RELCERT_NO_PRUNE=1
# RELCERT_NO_CHOICE=1 DECLINES (no P, no X).
#
# Verdicts (RELCERT_IMPLIED_CUT=1 unless stated, measured 2026-10-26): CERTIFIED (about 2 s);
# CERTIFIED under RELCERT_SYNC=1, RELCERT_NO_CHOICE=1, SYNC+NO_CHOICE, RELCERT_NO_PRUNE=1,
# NO_IMPLIED_CUT, NO_LINEAR_CUT, RELCERT_OPREGION=1 and without RELCERT_IMPLIED_CUT; DECLINED
# under RELCERT_NO_CUT=1 and RELCERT_NO_PRUNE=1 RELCERT_NO_CHOICE=1. One row (--handoff
# vacuous, 1/1).
#
# MOMENTUM BAND (right evolve domains): |h_i + J_i w_i| <= 2 N m s, the total angular momentum of
# each axis within one wheel's capacity. It is conserved by every design-model mode
# (h_i' = k J_i w_i, w_i' = -k w_i), so it is a constraint on the initial state: the wheels can
# absorb the body's momentum. Off the band a wheel saturates before the body is stopped and the
# design model has no run of a full period (its Assumption 1 fails); the momentum dump that
# would handle that case is not modeled.
