# sat_detumble_weak: detumbling on weakened actuators: the real body (the gyrostat of
# sat_detumble_phases) on derated actuators against the design model's power profiles; the
# weakened spacecraft's body energy equals the NOMINAL profile's at 4/5 of its speed, exactly, and
# the ADCS in its power-saving duty cycle decides every 2 s.
# scenario: degraded-actuator
# mechanisms: S M B X (time stretch lambda = 4/5, the actuator derating, RELCERT_SYNC=1 declines,
#   matrix code M1; multi-cycle matching, one 2 s flight decision against two 1 s design cycles
#   (budget ceil(0.8 * 2 / 1) = 2), matrix code M2; branching joint steps, the NOMINAL segment
#   retaining ECONOMY and SURVIVAL, matrix code M3; committed existential choice of the reference's
#   profile, RELCERT_NO_CHOICE=1 declines). S and X come from the derating (the exact scaling and
#   the profile it selects), M and B from the 2 s decision period of the power-saving duty cycle.
#   Batch I9 (2026-10-27): the claim is the exact re-timed one (the batch-I4 file stated a 0.125
#   tolerance band at lambda 1 with equal periods, letters I X; the engagement-envelope cut that
#   band needed is no longer load-bearing, so no I). Round 1 (2026-10-29): the left is the real
#   body (the gyrostat), no longer the design model, so the witness is not a re-timed copy.
#   One domain (2026-10-29): |w_i| <= 1, |h| <= 2 on both sides plus |h + 5 w3| <= 2 on the right
#   -> |w_i| <= 1 on every mode of both sides; CERTIFIED with the row unchanged, same ablations.
#
# THE SPACECRAFT (a ~60 kg microsatellite, SI units; the plant of sat_detumble_nominal, in
# benchmarks/reserve/). Body rates w1, w2, w3 (rad/s) about the principal axes, inertia
# J = diag(2, 4, 5) kg m^2, and the momentum h (N m s) of a reaction wheel on the z-axis;
# rate-damping actuators on x, y and the wheel absorbing the z-rate, gain k.
# Left (the real body): the gyrostat of sat_detumble_phases, Euler's equations with the z-wheel
# and the bilinear couplings as in that file, w1' = -0.5 w2 w3 - 0.5 w2 h - k w1,
# w2' = 0.75 w3 w1 + 0.25 w1 h - k w2, w3' = -0.4 w1 w2 - k w3, h' = 5 k w3, at the derated gain
# k_L = 0.4. Right: the decoupled design model, w_i' = -k w_i, h' = 5 k w3, at each profile's gain.
# The couplings do no work and the damping is isotropic (the same k on every axis), so the body
# energy E = 2 w1^2 + 4 w2^2 + 5 w3^2 (twice the rotational kinetic energy) obeys E' = -0.8 E on
# the left and E' = -2 k E on the right at every profile. The couplings are the model refinement
# that sat_detumble_phases certifies; here they are carried on the left only.
# PHYSICAL DOMAIN (every mode, both sides): |w_i| <= 1 rad/s (the gyro's measurement range);
# the wheel momentum h is not bounded (see WHEEL MOMENTUM); no certificate stands on the domain.
# Control periods. Right (design model): 1 s (epsilon = 1.0), the attitude mode manager's cycle on
# a 1 Hz ADCS (the attitude solution of a CubeSpace CubeStar star tracker is updated at 1 Hz,
# CubeSpace sensor data sheet), as in sat_detumble_nominal. Left (deployed, under-voltage): 2 s
# (epsilon = 2.0): with the bus under-voltage the ADCS runs its power-saving duty cycle and
# evaluates the mode decision every other sensor cycle (a design value of this file, the same 2 s
# the round-2 file used). Every decision interval is at most the period; the damping law is
# continuous in the ODEs. The M window: any left decision period strictly above the right's gives M,
# with budget ceil(lambda x left period / right period) (2 at the stated 2:1 and lambda 4/5); the
# stated periods are not at an edge.
# Guards (entry conditions): the detumble controller engages with the body energy inside its
# authority envelope, E <= 1 (e.g. |w1| <= 0.71 rad/s about x alone). The design model declares the
# FDIR SAFE mode on an ENERGY threshold, E > 1 (actuators inhibited, a sink; modeled frozen), a
# quadratic threshold, not a speed floor. The right guards cover the domain (the three profiles
# share E <= 1, SAFE is E > 1): no coverage gap.
#
# Degraded deployed (left): a bus under-voltage scales the proportional driver's authority (the
# torquer dipole and the wheel torque per unit rate) to 80 %: k_L = 0.4 /s (damping -0.4 w_i,
# h' = 2 w3, the couplings unchanged). The design model (right) offers three ground-selectable
# detumble power profiles, NOMINAL k = 0.5, ECONOMY 0.45 and SURVIVAL 0.42 (battery states),
# switchable NOMINAL <-> ECONOMY / SURVIVAL; each declares SAFE.
# One cause between the sides: the derating of the real body's actuators (k_L = 0.4 against the
# profiles' 0.5 / 0.45 / 0.42) and the duty cycle it brings (the 2 s decision period); the
# couplings are the model refinement that sat_detumble_phases certifies and are carried here on
# the left only.
#
# CLAIM (the exact re-timed one): E_L = E_R (two rows, E_L <= E_R and E_R <= E_L) against the
# design model re-timed by lambda = 4/5 (lambda_min = lambda_max = 0.8). The weakened spacecraft's
# ENERGY at time t is the NOMINAL design model's at time 0.8 t exactly (E_L(t) = E(0) e^{-0.8 t}
# = E_R^NOM(0.8 t)); the states differ (the couplings redistribute rate between the axes), so the
# witness is not a re-timed copy (RK4 check, 2026-10-29, from w = (0.5, 0.3, 0.2), h = 1:
# E_L(2) = E_R^NOM(1.6) = 0.214010 while w_L(2) = (-0.046, 0.218, 0.064) against
# w_R(1.6) = (0.225, 0.135, 0.090)). Requirement: the design model's detumble-time prediction
# holds for the weakened spacecraft after re-timing by the derating, so a detumble budget of T s
# on the design model is a budget of T / 0.8 = 1.25 T s on the degraded spacecraft (the time the
# mission planning must allow before the sun-acquisition mode can take over). Exact, no tolerance
# constant.
# The stretch follows the cause: lambda = k_L / k_NOM = 0.4 / 0.5 = 4/5 (the ratio of the
# derated gain to the NOMINAL gain). It is stated, not searched; as every exact rate ratio of this
# suite (quad_light_lag's 6/5, acc_tune_lag's 2) it certifies at its exact value only: pinned to
# 0.79 or 0.81 the file DECLINES (measured 2026-10-29, again on the one domain), and so does
# RELCERT_SYNC=1 (lambda 1).
# Why the choice (X). At lambda = 4/5 only the NOMINAL profile matches the weakened spacecraft
# exactly (ECONOMY re-timed by 4/5 decays at 0.9 k_L, SURVIVAL at 0.84 k_L). A design run that
# starts in ECONOMY or SURVIVAL must be committed to NOMINAL: the cover hops ECONOMY -> NOMINAL and
# SURVIVAL -> NOMINAL (committed successor subsets), then runs the joint segment from NOMINAL;
# RELCERT_NO_CHOICE=1 DECLINES. The hop target is the profile the derated spacecraft behaves like,
# not a copy of the deployed's mode (the deployed has one mode).
# Multi-cycle matching (M) and branching (B): a 2 s deployed window is matched by two 1 s design
# cycles (budget 2); at the joint step the NOMINAL segment's declared successors ECONOMY and
# SURVIVAL are retained (branch 2) and covered through the committed hop back into NOMINAL.
# Fallback: NOMINAL/ECONOMY/SURVIVAL -> SAFE pruned as in sat_detumble_nominal (source: no entry
# state has E > 1; barrier: on E = 1 every profile's field gives E' < 0); the committed successor
# subsets close the same fallback, so RELCERT_NO_PRUNE=1 alone CERTIFIES (no P). The engagement
# envelope E <= 1 is kept as a checked cut but is not load-bearing for the exact rows
# (RELCERT_NO_CUT=1 CERTIFIES: no I).
# Letter window: S, M, B and X hold for every derating k_L / k_NOM on the stretch grid (the file
# pins lambda to it; measured 2026-10-27 on the design-model left, before the one-domain change; at
# k_L = 0.4 re-measured on the gyrostat left and the one domain, see Verdicts); at k_L = 0.5 (no
# degradation) the pair is the DETUMBLE pair of sat_detumble_phases, energy-equal at lambda 1:
# CERTIFIED and RELCERT_SYNC=1 CERTIFIES (no S), RELCERT_NO_CHOICE=1 DECLINES (X persists, from the
# profile choice; the commitment then goes into NOMINAL), measured 2026-10-29, again on the one
# domain.
# Not implied by the domains; the left mode has a satisfiable start (E_L = E_R <= 1, any profile).
#
# Verdicts (RELCERT_IMPLIED_CUT=1 unless stated, measured 2026-10-29, gyrostat left, one domain):
# CERTIFIED (about 4 s on a shared machine); CERTIFIED under RELCERT_NO_PRUNE=1, RELCERT_NO_CUT=1,
# RELCERT_NO_IMPLIED_CUT=1, RELCERT_NO_LINEAR_CUT=1, RELCERT_NO_REPO=1, RELCERT_OPREGION=1,
# RELCERT_WELLFORMED_STRICT=1, without RELCERT_IMPLIED_CUT and with every evolve bound widened by
# 20 %; DECLINED under RELCERT_SYNC=1, RELCERT_NO_CHOICE=1,
# NO_PRUNE+NO_CHOICE and SYNC+NO_CHOICE. Cover: DETUMBLE at lambda = 4/5, budget 2, admissible
# starts NOMINAL, ECONOMY, SURVIVAL, hops into NOMINAL, joint steps from NOMINAL retaining ECONOMY
# and SURVIVAL (branch 2), no right-only segment; pruned NOMINAL, ECONOMY, SURVIVAL -> SAFE. One
# row (--handoff vacuous, 1/1). relcert --wellformed: NOMINAL, ECONOMY, SURVIVAL, SAFE ok
# (invariant), 0 UNKNOWN, 0 BLOCKING. The right fields and guards are unchanged since batch I4;
# the right domain changed on 2026-10-29 (one domain: the band and the h box dropped), so the Lean
# Assumption 1 proof is redone on the w box (2026-10-29, Z3-free). The left changed in
# its period (1 -> 2 s, batch I9), in the claim's form (exact re-timed rows, lambda 4/5, batch I9),
# in its field (the design model -> the gyrostat, round 1, 2026-10-29) and in its domain (one
# domain, 2026-10-29); the cover and every verdict above are the same across the last two changes.
# Letters: S M B X.
#
# WHEEL MOMENTUM (not in the domain). Neither model has wheel-saturation dynamics, so the wheel's
# capacity (2 N m s) and the momentum dump that would handle it are coverage gaps of the models,
# not domain bounds: with |h| <= 2 in the domain the design model's own flow (h' = 5 k w3) crosses
# it, and relcert --wellformed reports NOMINAL, ECONOMY and SURVIVAL BLOCKING (leaves h >= -2.0;
# Assumption 1 fails, measured 2026-10-29). The band |h + 5 w3| <= 2 (the z-axis total momentum
# within the wheel's capacity) is a first integral of every design-model mode but not of the
# gyrostat, where (h + 5 w3)' = -2 w1 w2, so on the left it would be a reachable-set band. The
# claim needs neither: E' = -0.8 E on the left and E' = -2 k E on the right whatever h is.
[problem]
name = sat_detumble_weak
max_depth = 8
lambda_min = 0.8
lambda_max = 0.8
bound_T = 4.0
[Lsys]
state_vars = [w1, w2, w3, h]
epsilon = 2.0
[Lsys.mode.DETUMBLE]
ode = w1' = smt2:(- (- (* -0.5 (* w2 w3)) (* 0.5 (* w2 h))) (* 0.4 w1)); w2' = smt2:(- (+ (* 0.75 (* w3 w1)) (* 0.25 (* w1 h))) (* 0.4 w2)); w3' = smt2:(- (* -0.4 (* w1 w2)) (* 0.4 w3)); h' = smt2:(* 2.0 w3);
guard = w1*w1*2 + w2*w2*4 + w3*w3*5 <= 1.0
evolve = w1 >= -1.0 and w1 <= 1.0 and w2 >= -1.0 and w2 <= 1.0 and w3 >= -1.0 and w3 <= 1.0
next = [DETUMBLE]
[Rsys]
state_vars = [w1, w2, w3, h]
epsilon = 1.0
[Rsys.mode.NOMINAL]
ode = w1' = smt2:(* -0.5 w1); w2' = smt2:(* -0.5 w2); w3' = smt2:(* -0.5 w3); h' = smt2:(* 2.5 w3);
guard = w1*w1*2 + w2*w2*4 + w3*w3*5 <= 1.0
evolve = w1 >= -1.0 and w1 <= 1.0 and w2 >= -1.0 and w2 <= 1.0 and w3 >= -1.0 and w3 <= 1.0
next = [NOMINAL, ECONOMY, SURVIVAL, SAFE]
[Rsys.mode.ECONOMY]
ode = w1' = smt2:(* -0.45 w1); w2' = smt2:(* -0.45 w2); w3' = smt2:(* -0.45 w3); h' = smt2:(* 2.25 w3);
guard = w1*w1*2 + w2*w2*4 + w3*w3*5 <= 1.0
evolve = w1 >= -1.0 and w1 <= 1.0 and w2 >= -1.0 and w2 <= 1.0 and w3 >= -1.0 and w3 <= 1.0
next = [ECONOMY, NOMINAL, SAFE]
[Rsys.mode.SURVIVAL]
ode = w1' = smt2:(* -0.42 w1); w2' = smt2:(* -0.42 w2); w3' = smt2:(* -0.42 w3); h' = smt2:(* 2.1 w3);
guard = w1*w1*2 + w2*w2*4 + w3*w3*5 <= 1.0
evolve = w1 >= -1.0 and w1 <= 1.0 and w2 >= -1.0 and w2 <= 1.0 and w3 >= -1.0 and w3 <= 1.0
next = [SURVIVAL, NOMINAL, SAFE]
[Rsys.mode.SAFE]
ode = w1' = smt2:0; w2' = smt2:0; w3' = smt2:0; h' = smt2:0;
guard = w1*w1*2 + w2*w2*4 + w3*w3*5 > 1.0
evolve = w1 >= -1.0 and w1 <= 1.0 and w2 >= -1.0 and w2 <= 1.0 and w3 >= -1.0 and w3 <= 1.0
next = [SAFE]
[relational_invariant]
DETUMBLE = smt2:(and (<= (+ (+ (* (* L_w1 L_w1) 2.0) (* (* L_w2 L_w2) 4.0)) (* (* L_w3 L_w3) 5.0)) (+ (+ (* (* L_w1 L_w1) 2.0) (* (* R_w2 R_w2) 4.0)) (* (* R_w3 R_w3) 5.0))) (<= (+ (+ (* (* R_w1 R_w1) 2.0) (* (* R_w2 R_w2) 4.0)) (* (* R_w3 R_w3) 5.0)) (+ (+ (* (* L_w1 L_w1) 2.0) (* (* L_w2 L_w2) 4.0)) (* (* L_w3 L_w3) 5.0))))
