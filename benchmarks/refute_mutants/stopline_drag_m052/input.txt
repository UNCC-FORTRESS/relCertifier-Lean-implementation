# a level, straight corridor (grade 0, cross-slope 0). Both sides decide every 0.1 s (the brake ECU's
# cycle) from the wheel odometer p [m] and the speed v [m/s]. Modes on every level: CRUISE (p < 100,
# v >= 0.35, speed held: p' = v, v' = 0), BRAKE (p >= 100, v >= 0.35: the planner's brake point),
# STOP (p >= 100, v <= 0.35 m/s = 1.3 km/h, every state frozen). Along-track position s [m] (the
# distance to the line is measured along the corridor): s' = v (1 - psi^2/2 - 0.2 phi_r^2), the
# heading and crabbing losses of the rover hierarchy; the planner identifies s with p.
# The levels are models of the same rover at increasing fidelity. Each rung adds one longitudinal

#       v' = -b; CRUISE b' = -b/0.3, released); the heading error psi with the steering loop psi' =

#   L8  + theta_p, z, phi_r (stopline_friction, 5 -> 8): the tyre-road friction limit of the gravel
