# stopline_friction: stop-line ladder, rung 2 (P3f / P3): friction-limited deceleration.
# scenario: model-refinement
# mechanisms: S D (a time-to-stop requirement re-times the braking; mode-dependent rows); used S D I
#
# System (the stop-line ladder, shared by stopline_lag, _friction, _tyre and _drag; SI units, time
# in s). A rover approaches a stop line on a level, straight corridor at up to V = 8 m/s; both sides
# decide every 0.1 s from the wheel odometer p [m] (the along-track position: no heading or grade
# on this corridor) and the speed v [m/s]. Modes on every level: CRUISE (p < 100, v >= 0.35, speed
# held), BRAKE (p >= 100, v >= 0.35), STOP (p >= 100, v <= 0.35, every state frozen). One physical
# domain on every rung and both sides: p >= 0, 0 <= v <= 8, and the actuator states b, c in [0, 3]
# (the right declares the left's extra states, frozen). The levels (each rung's right model is the
# previous rung's left verbatim, up to the frozen extra states):
#   P2  (p, v)        the planner's point model: BRAKE v' = -3.
#   P3  (p, v, b)     + brake actuator lag: the realised deceleration b follows the command
#                     (3 m/s^2 braking, 0 released) with time constant tau = 0.3 s; v' = -b.
#   P3f (p, v, b)     + friction-limited deceleration on gravel: b relaxes to aL = 2.7 m/s^2.
#   P4  (p, v, b, c)  + tyre relaxation lag: the hub command c lags as b did (tau, target 2.7),
#                     and b follows c with T = 0.05 s (b' = 20 (c - b)).
#   P4d (p, v, b, c)  + aerodynamic and rolling drag: v' = -b - 0.003 v^2 - 0.2.
# Constants are representative values, not taken from a cited source: brake actuator lag 0.3 s
# (a hydraulic/electromechanical brake build-up time of a few tenths of a second); gravel friction
# limit 2.7 m/s^2 (mu about 0.275); tyre relaxation length 0.4 m, i.e. 0.05 s at 8 m/s;
# aerodynamic term 0.003 v^2 (rho C_dA / 2m for C_dA 1.5 m^2 and a 300 kg rover) and rolling
# resistance 0.2 m/s^2 (about 0.02 g).
# Stop point. On each level the braking flow conserves (P4d: does not increase) the stop-point
# functional Z: Z_P2 = p + v^2/6; Z_P3 = p + tau v + (v - tau b)^2/6; Z_P3f = p + tau v +
# (v - tau b)^2/5.4; Z_P4 = p + (T + tau) v - tau T b + (v - T b - tau c)^2/5.4. The planner's
# margin: its stop point P* = Z_P2 at the brake point stays 5 m short of the line (110.67 m
# against 115.67 m at 8 m/s).
# Rows. CRUISE: p_L = p_R, v_L = v_R and every brake state 0 on both sides (both trigger at the
# same decision; the two-sided form keeps the brake states at 0 while cruising). BRAKE and STOP:
# R_p >= 100 and the loss row Z(left) <= Z(right) + delta, scaled to integer-friendly
# coefficients. The CRUISE brake rows are not needed for the loss (a pre-charged brake only
# shortens the stop; the mutants that drop them certify, true claims).
#
# This rung: left P3f (gravel: b relaxes to 2.7 m/s^2), right P3 (asphalt: b relaxes to 3).
# Loss row (BRAKE, STOP): 27 Z_P3f(L) <= 27 Z_P3(R) + 32, i.e. Z_P3f(L) <= Z_P3(R) + 32/27.
# Closed form: (V^2/2)(1/2.7 - 1/3) = 32/27 = 1.185 m at the top speed. 32/27 is the TIGHTEST
# constant (32/27 - 0.01 DECLINED). Cause test (without the stretch rows): with the left braking
# to 3 as the right, delta 0 CERTIFIES and -0.01 DECLINES; with aL = 2.85 the tight delta is
# 0.5614, the closed form.
# Time to stop (the stretch): while braking, the refined rover's speed stays at or below the
# plan's re-timed by lambda in [0.9, 1.0] (time-to-stop within 1/0.9 of the plan's): BRAKE rows
# v_L <= v_R and b_L >= 0.9 b_R (the second the inductive helper: the derated brake reaches 2.7
# faster than the re-timed plan's brake reaches 0.9 of 3). The cover runs BRAKE_L at lambda 9/10,
# CRUISE_L and STOP_L at 1. 0.9 = 2.7/3, the friction ratio, is the TIGHTEST lower end (the range
# [0.905, 1] DECLINES; a single pinned lambda declines at every value, CRUISE and STOP need 1).
# S is genuine: under RELCERT_SYNC=1 the file DECLINES.
# The right's braking nodes when the left has stopped first are pre-landing right-only nodes;
# their progress certificate has two stages in mixed directions (b >= 2 up, then v <= 0.35 down),
# covered by Progress.lean's repoProgress_two_ud_reg since 2026-11-01 (docs/PRELANDING.md).
# Composition: the right is stopline_lag's left; the next rung's right (stopline_tyre) is this
# left.
# Letters: needed S D; used S D I.
# Chained claim (the four rungs): Z_P4d(L) <= Z_P4 + 0 <= Z_P3f + 0.4 <= Z_P3 + 1.585 <= P* +
