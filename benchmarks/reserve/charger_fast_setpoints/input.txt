# RESERVE (benchmarks/reserve/, 2026-10-27): not in suite_v2, not in the paper, no Lean integration.
# Reason: the same cause-blind claim as charger_fast_tapers (any faster or higher-target charger
# with the same thresholds passes x_L <= x_R + 2), and the name is stale (both sides target 90 %).
# The header below is the design's.
#
# charger_fast_setpoints: the fast charger against the certified profile whose bulk phase targets
# 90 %, same control period on both sides.
# scenario: degraded-controller
# mechanisms: R D I (right-only repositioning; mode-dependent rows; checked cuts, matrix codes M5
#   M6 M6+). RELCERT_SYNC=1 declines because the covers need right-only repositioning; every cover
#   is at lambda = 1, so no S. R, D and I come from the claim form (a one-sided bound against an
#   existential reference) and persist with the cause removed (below). The round-2 file's M came
#   only from a 2 h left period against a 1 h right period and is gone with equal periods.
#
# System. State of charge x (%), time in h. The certified charging profile (right):
#   PRECHARGE (10 <= x < 15): x' = 0.2 (20 - x)    recovery charge of a deeply discharged cell at
#                                                   the pre-charge voltage (2 %/h at 10 %, 1 %/h
#                                                   at 15 %), until the 15 % bulk threshold
#   BULK      (15 <= x < 80): x' = 0.1 (90 - x)    fast phase toward a 90 % bulk target
#   ABSORB    (80 <= x < 99): x' = 0.05 (100 - x)  taper toward 100 %
#   FULL      (x >= 99):      x' = 0               hold
#   FAULT     (x < 10):       x' = -0.01 x         cell fault: a cell below 10 % is not charged,
#                                                   latched (self-discharge only)
# PRECHARGE and BULK may latch FAULT (declared edges). The deployed unit (left) runs the same
# firmware with its current limit raised 25 % (every rate constant x 1.25: PRECHARGE 0.25,
# BULK 0.125, ABSORB 0.0625) and the same FAULT latch. One cause: the current limit.
# The guards partition [0, 100] on both sides (no coverage gap): [10, 15) is the pre-charge phase
# every Li-ion charger runs below its bulk threshold.
# Control period: 0.0001 h = 0.36 s on BOTH sides (epsilon = 0.0001; every decision interval is at
# most 0.36 s). The phase decision follows the vehicle's charge-current request, sent on the
# CHAdeMO CAN cycle of 100 ms +- 10 % (CHAdeMO protocol), so 0.36 s bounds it with margin; the file's
# time unit is the hour, so the bound is a decimal number of hours. Both sides use the same period.
#
# Property. Requirement (SoC overshoot): the deployed unit's state of charge never exceeds the
# certified profile's by more than 2 % SoC, the state-of-charge accuracy of the battery
# management system (a smaller lead is not observable as non-conformance):
#   BULK, ABSORB, FULL, FAULT: x_L <= x_R + 2;   PRECHARGE: x_L <= x_R.
# The pre-charge row is stricter by necessity (mode-dependent, D): with any lead allowed there, a
# deployed cell in pre-charge at 10 % could pair with a certified cell below 10 %, latched in
# FAULT, which no cover can follow; with x_L <= x_R the reference is at or above 10 %.
# The bulk floor separates the fault: a deployed BULK start (x_L >= 15) with a lead below 5 %
# keeps the reference at or above 10 %, so FAULT is no admissible start for BULK.
# Tightest (measured 2026-10-26): the charging rows certify down to 1.00 (0.99 declines); uniform
# rows x_L <= x_R + c DECLINE (c = 1, 2, 3, 4.9), and uniform x_L <= x_R declines.
# Cause dependence (measured 2026-10-26, the deployed's rate constants set to the profile's, same
# rows): CERTIFIED; RELCERT_SYNC=1 and RELCERT_NO_CUT=1 still DECLINE and a uniform x_L <= x_R + 2
# still DECLINES, so R, I and D do not witness the current limit; with the cause removed also
# NO_PRUNE+NO_CHOICE certifies (with it, it declines).
#
# Domain 0 <= x <= 100 both sides (physical); every left mode has a satisfiable start
# (x_L = x_R). The implied contraction atoms x <= 20 (PRECHARGE), x <= 90 (BULK) are load-bearing
# (without RELCERT_IMPLIED_CUT and under RELCERT_NO_IMPLIED_CUT=1: DECLINED).
#
# Verdicts (RELCERT_IMPLIED_CUT=1 unless stated, measured 2026-10-26 with the copied tool):
# CERTIFIED (0.46 s); CERTIFIED under RELCERT_NO_PRUNE=1, RELCERT_NO_CHOICE=1,
# RELCERT_NO_LINEAR_CUT=1, RELCERT_OPREGION=1, RELCERT_WELLFORMED_STRICT=1; DECLINED under
# RELCERT_SYNC=1, NO_PRUNE+NO_CHOICE (pruning of PRECHARGE->FAULT, BULK->FAULT or the committed
# choice, either one suffices), without RELCERT_IMPLIED_CUT, RELCERT_NO_IMPLIED_CUT=1 and
# RELCERT_NO_CUT=1. Covers: lambda = 1 in every left mode, budget 1; right-only repositioning on
# the replayed path. Pruned: PRECHARGE -> FAULT, BULK -> FAULT. --handoff 10/10 unsat,
# non-vacuous. relcert --wellformed: PRECHARGE ok (exit->BULK), BULK ok (exit->ABSORB), ABSORB ok
# (exit->FULL), FULL and FAULT ok (invariant), 0 UNKNOWN. The right model changed only in its
# period (epsilon 1.0 -> 0.0001 h): its Assumption 1 proof needs the new interval.
[problem]
name = charger_fast_setpoints
max_depth = 8
lambda_min = 1.0
lambda_max = 6.0
bound_T = 4.0
[Lsys]
state_vars = [x]
epsilon = 0.0001
[Lsys.mode.PRECHARGE]
ode = x' = smt2:(* 0.25 (- 20.0 x));
guard = x >= 10.0 and x < 15.0
evolve = x >= 0.0 and x <= 100.0
next = [BULK, PRECHARGE, FAULT]
[Lsys.mode.BULK]
ode = x' = smt2:(* 0.125 (- 90.0 x));
guard = x >= 15.0 and x < 80.0
evolve = x >= 0.0 and x <= 100.0
next = [ABSORB, BULK, FAULT]
[Lsys.mode.ABSORB]
ode = x' = smt2:(* 0.0625 (- 100.0 x));
guard = x >= 80.0 and x < 99.0
evolve = x >= 0.0 and x <= 100.0
next = [FULL, ABSORB]
[Lsys.mode.FULL]
ode = x' = smt2:0;
guard = x >= 99.0
evolve = x >= 0.0 and x <= 100.0
next = [FULL]
[Lsys.mode.FAULT]
ode = x' = smt2:(* -0.01 x);
guard = x < 10.0
evolve = x >= 0.0 and x <= 100.0
next = [FAULT]
[Rsys]
state_vars = [x]
epsilon = 0.0001
[Rsys.mode.PRECHARGE]
ode = x' = smt2:(* 0.2 (- 20.0 x));
guard = x >= 10.0 and x < 15.0
evolve = x >= 0.0 and x <= 100.0
next = [BULK, PRECHARGE, FAULT]
[Rsys.mode.BULK]
ode = x' = smt2:(* 0.1 (- 90.0 x));
guard = x >= 15.0 and x < 80.0
evolve = x >= 0.0 and x <= 100.0
next = [ABSORB, BULK, FAULT]
[Rsys.mode.ABSORB]
ode = x' = smt2:(* 0.05 (- 100.0 x));
guard = x >= 80.0 and x < 99.0
evolve = x >= 0.0 and x <= 100.0
next = [FULL, ABSORB]
[Rsys.mode.FULL]
ode = x' = smt2:0;
guard = x >= 99.0
evolve = x >= 0.0 and x <= 100.0
next = [FULL]
[Rsys.mode.FAULT]
ode = x' = smt2:(* -0.01 x);
guard = x < 10.0
evolve = x >= 0.0 and x <= 100.0
next = [FAULT]
[relational_invariant]
