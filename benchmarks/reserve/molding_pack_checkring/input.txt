#
# molding_pack_checkring: an injection-molding cycle's packing (hold) and cooling phases on a machine
# whose screw-tip check ring is worn (melt leaks back during hold), against the same cycle with a new
# check ring; the requirement changes with the phase because the gate freezes at the end of hold.
# scenario: degraded-actuator
# mechanisms: D (mode-dependent rows: the hold row bounds the nozzle and the cavity pressure, the
#   cooling row only the cavity pressure; every uniform row declines at the requirement; matrix code M5)
#
# System (both sides). Phase clock t in s since the velocity/pressure switchover (the sequencer's
# timer), nozzle melt pressure x and cavity pressure y in bar; the machine controller re-decides every
# 0.05 s (epsilon 0.05 on both sides). Two timed phases, the hold time set to the gate-freeze time
# (5 s, from the gate-freeze study):
#   HOLD  t < 5   pressure control toward the 500 bar hold pressure through a proportional valve,
#                 x' = 10 (500 - x) - l x (0.1 s loop); the cavity follows the nozzle through the
#                 open gate, y' = 3 (x - y)
#   COOL  t >= 5  the gate has frozen: the sealed cavity's pressure decays as the part cools and
#                 shrinks, y' = -0.3 y; the screw decompresses, x' = -(2 + l) x
# with t' = 1 in both. HOLD -> [HOLD, COOL], COOL -> [COOL].
# Right (reference): new check ring, l = 0. Left (deployed): worn check ring, melt flows back past
# the screw tip at a rate proportional to the melt pressure, l = 0.4 /s. The leak is the only
# difference (same machine settings, mold, material, phase timing).
#
# Property (mode-dependent).
#   HOLD: t_L = t_R, |x_L - x_R| <= 25, |y_L - y_R| <= 25.
#   COOL: t_L = t_R, |y_L - y_R| <= 25.
# Requirement: the cavity-pressure process-monitoring envelope, +-5 % of the 500 bar hold level =
# +-25 bar around the reference cavity curve (the part-quality signature). While the gate is open
# the cavity follows the nozzle, so the nozzle pressure must stay in the same envelope (the HOLD
# row); after gate freeze the nozzle no longer reaches the part and only the cavity is bounded. The
# phase clocks are equal (same sequencer timing). Tightest: 19.24 bar for both HOLD rows together
# (19.23 declines) = the hold droop 500 x 0.4 / 10.4 = 19.23 bar; the cavity row needs at least the
# nozzle bound (cavity 25 needs nozzle <= 25: nozzle window [19.24, 25] at the 25 bar requirement).
# Not implied by the domains (they allow 500 bar).
#
# Why the rows must differ (D). Uniform rows with the nozzle bound DECLINE unless the bound is at
# least 83.34 bar (measured): after hold the worn ring bleeds the decompressing nozzle faster, the
# nozzle gap grows to 0.4 x 500 / 2.4 = 83.3 bar, far outside the envelope although the frozen gate
# keeps it away from the part. Uniform rows without the nozzle bound DECLINE: during hold the cavity
# row is inductive only together with the nozzle row (the cavity is driven by the nozzle). So no
# uniform row meets the +-25 bar requirement, while the phase-specific rows do. The handoffs only
# drop the nozzle conjunct (HOLD -> COOL; --handoff 3/3 unsat). This is not the staged
# exact-then-shifted pattern: the same envelope holds in both phases, the variable set changes with
# the coupling (open gate vs frozen gate), the cause acts in both phases, and there is no fallback
# sink.
# How the bound depends on the cause (measured, tightest common tolerance against the leak l):
# l = 0 (new ring): exact uniform claim (all constants 0) CERTIFIES, nothing mode-dependent; l = 0.2:
# 9.81; l = 0.4 (this file): 19.24; l = 0.6: 28.31, beyond the 25 bar envelope (the claim fails:
# the envelope tolerates a leak up to about 0.53 /s). Law dependence: an arbitrary deployed phase
# schedule (the left may enter COOL at any time) DECLINES.
#
# Domains. t >= 0 s (the phase clock, forward invariant), x and y in [0, 500] bar (500 = the hold
# set point, which no flow exceeds; forward invariant in both phases on both sides). The right guards
# partition t (no coverage gap); every left mode has a satisfiable start (equal states).
#
# Verdicts (RELCERT_IMPLIED_CUT=1 unless stated, measured 2026-10-27 on branch benchmark-fixes): CERTIFIED;
# CERTIFIED under RELCERT_SYNC=1, RELCERT_NO_PRUNE=1, RELCERT_NO_CHOICE=1, NO_PRUNE+NO_CHOICE,
# SYNC+NO_CHOICE, RELCERT_NO_CUT=1, RELCERT_NO_IMPLIED_CUT=1, RELCERT_NO_LINEAR_CUT=1, without
# RELCERT_IMPLIED_CUT, RELCERT_OPREGION=1 (every admitted start in some right guard) and
# RELCERT_WELLFORMED_STRICT=1. Cover: both left modes at lambda 1, budget 1, admissible start the
# same phase, joint segments only. Nothing pruned. relcert --wellformed: HOLD ok (exit->COOL), COOL
# ok (invariant), 0 UNKNOWN, 0 BLOCKING. Letters: D.
[problem]
name = molding_pack_checkring
max_depth = 8
lambda_min = 1.0
lambda_max = 1.0
bound_T = 30.0

[Lsys]
state_vars = [t, x, y]
epsilon = 0.05

[Lsys.mode.HOLD]
ode = t' = 1.0; x' = smt2:(- (* 10.0 (- 500.0 x)) (* 0.4 x)); y' = smt2:(* 3.0 (- x y));
guard = t < 5.0 and t >= 0.0 and x >= 0.0 and x <= 500.0 and y >= 0.0 and y <= 500.0
evolve = t >= 0.0 and x >= 0.0 and x <= 500.0 and y >= 0.0 and y <= 500.0
next = [HOLD, COOL]

[Lsys.mode.COOL]
ode = t' = 1.0; x' = smt2:(* (- (+ 2.0 0.4)) x); y' = smt2:(* (- 0.3) y);
guard = t >= 5.0 and t >= 0.0 and x >= 0.0 and x <= 500.0 and y >= 0.0 and y <= 500.0
evolve = t >= 0.0 and x >= 0.0 and x <= 500.0 and y >= 0.0 and y <= 500.0
next = [COOL]

[Rsys]
state_vars = [t, x, y]
epsilon = 0.05

[Rsys.mode.HOLD]
ode = t' = 1.0; x' = smt2:(- (* 10.0 (- 500.0 x)) (* 0.0 x)); y' = smt2:(* 3.0 (- x y));
guard = t < 5.0 and t >= 0.0 and x >= 0.0 and x <= 500.0 and y >= 0.0 and y <= 500.0
evolve = t >= 0.0 and x >= 0.0 and x <= 500.0 and y >= 0.0 and y <= 500.0
next = [HOLD, COOL]

[Rsys.mode.COOL]
ode = t' = 1.0; x' = smt2:(* (- (+ 2.0 0.0)) x); y' = smt2:(* (- 0.3) y);
guard = t >= 5.0 and t >= 0.0 and x >= 0.0 and x <= 500.0 and y >= 0.0 and y <= 500.0
evolve = t >= 0.0 and x >= 0.0 and x <= 500.0 and y >= 0.0 and y <= 500.0
next = [COOL]

[relational_invariant]
HOLD = t[l] <= t[r] and t[r] <= t[l] and x[l] <= x[r] + 25 and x[r] <= x[l] + 25 and y[l] <= y[r] + 25 and y[r] <= y[l] + 25
COOL = t[l] <= t[r] and t[r] <= t[l] and y[l] <= y[r] + 25 and y[r] <= y[l] + 25
