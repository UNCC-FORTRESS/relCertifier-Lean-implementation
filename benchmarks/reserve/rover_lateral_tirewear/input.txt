# Reason: twin of rover_rollover_payload (the same right model, band guards and claim-form
# X I; the wear is one more gain in the same roll-slip loop), and it sits at three decline edges at
# once (wear 0.0345 against 0.035, the relational row, the nominal envelope).
# The header below is the design's.
#
# rover_lateral_tirewear: lane keeping of the canonical 12-DOF rover on worn tires (deployed),
# relative to the same rover on new tires (nominal reference). Both sides 12-DOF; one cause (the
# lateral compliance of the worn tread).
# scenario: degradation
# mechanisms: X I (hop of the reference into the deployed's zone inside its transition band,
#   RELCERT_NO_CHOICE=1 declines; checked cut v <= c (zone entry speed), RELCERT_NO_CUT=1 declines;
#   matrix code M6). Both letters come from the claim form (they persist without the wear), see below.
#
# System. The canonical rover of the round-A hierarchy (tmp/r2a/rover/gen.py, level L12; units,
# zones, set points, control interval 1 s and equations as in rover_rollover_payload's header). The
# right model (nominal, its ODEs byte-identical to the left ODEs of rover_ladder_8to12) and its
# guards are byte-identical to rover_rollover_payload's right model.
#
# The cause. The lateral slip compliance KS (slip offset per m/s^2 of lateral load) enters
# omega_y' = -omega_y + KS (a + 9.81 phi_r) and, through y'' = y - 2 omega_y + KS (a + 9.81 phi_r),
# the body lateral acceleration a_b that drives the roll. New tires KS_R = 0.03 m per m/s^2; worn lugs
# KS_L = 0.0345 (lateral stiffness of the lugged tread on soil down by 13 %, compliance up 15 %).
# Nothing else differs; in particular the CG height (KPHI = 0.015, 2h/T = 1) is the nominal one.
#
# Guards: as rover_rollover_payload (deployed: canonical zone guards with the zone entry speed
# v <= c; reference: each zone joint read as a +-2 m transition band, back-switch inside the band
# declared). Here the odometers drift because the worn tires change a_b, hence the roll and the
# crabbing loss. Load-bearing: exact reference joints (no band, no back edges) DECLINE, the band
# without the back edges DECLINES.
#
# Property (rows identical in every zone).
#   shared channels equal: v, psi, omega_psi, theta_p, omega_theta, z, omega_z;
#   heading |psi_L|, |omega_psi_L| <= 0.35 rad; roll stop |phi_r|, |omega_phi| <= 0.2 rad both sides;
#   roll differences |phi_rL - phi_rR|, |omega_phiL - omega_phiR| <= 0.06 (certificate rows);
#   odometer drift |s_L - s_R| <= 0.012 s_L + 0.2 m (certificate row; keeps the zones matched);
#   REQUIREMENT lane |y_L|, |omega_y_L| <= 0.25 m: corridor half-width 1.25 m minus vehicle
#     half-width 1.0 m (the ladder's lane requirement);
#   NOMINAL envelope |y_R|, |omega_y_R| <= 0.20 m (the nominal rover's certified lateral offset;
#     its tightest value is 0.199 with the other rows);
#   RELATIONAL |y_L - y_R|, |omega_yL - omega_yR| <= 0.05 m = 0.25 - 0.20: the worn rover may deviate
#     from the nominal's lateral position by at most the margin left between the nominal's certified
#     offset and the lane margin (with the nominal envelope it implies the lane requirement).
#
# Tightest constants (bisection, other constants at their file values unless noted, 2026-10-26):
#   relational lane 0.047 (0.045 declines); nominal envelope 0.199 (KS_L = 0.03); deployed lane 0.227
#   (relational row 0.1, nominal envelope 0.25); roll difference 0.037 (relational row 0.1, lane row
#   0.5, nominal envelope 0.25; the same 0.037 at KS_L = 0.03: the wear barely changes the roll).
#
# The claim depends on the cause (measured):
#   relational lane bound needed (lane row 0.5, nominal envelope 0.25 so that they do not bind):
#     0.018 at KS_L = 0.03 (no wear; the floor of the stratified certificate, which cannot prove the
#     cyclic roll-slip loop equal), 0.051 at 0.0345, 0.084 at 0.04, 0.116 at 0.045;
#   the deployed's own lane bound: 0.227 at KS_L = 0.0345, 0.265 at 0.04 (the 0.25 m lane fails);
#   the file itself CERTIFIES at KS_L = 0.03 and 0.0345 and DECLINES at 0.035, 0.0355, 0.036 and 0.04
#     (from 17 % more compliance the 0.05 m relational row no longer holds; the file sits close to its
#     edge: tightest relational lane 0.047 at 0.0345); an arbitrary deployed zone schedule
#     (zone guards without the odometer, every zone a successor of every zone) DECLINES.
#
# Letters, honestly: X and I as in rover_rollover_payload (hop inside the band; the v <= c cut bounds
# a = v r). Both persist at KS_L = 0.03 (NO_CHOICE and NO_CUT still DECLINE): claim form, not the
# wear. What the wear moves is the bounds above. No S M R B P D (lambda 1, one segment per window,
# nothing pruned, rows identical).
