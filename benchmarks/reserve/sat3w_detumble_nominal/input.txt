# scenario: model-refinement

# Dimension lift of sat_detumble_nominal: the single z-wheel gyrostat becomes a
# full three-wheel gyrostat, state (w1, w2, w3, h1, h2, h3) per side (6 D).
#
# THE PLANT (both sides; a ~60 kg microsatellite, SI units). Body rates w = (w1, w2, w3)
# (rad/s) about the principal axes, inertia J = diag(2, 4, 5) kg m^2, and the momenta
# h = (h1, h2, h3) (N m s) of three reaction wheels aligned with the principal axes.
# Euler's equations of a gyrostat (body frame, no external torque):
#   J w' = -w x (J w + h) - h',
# and each wheel absorbs its axis rate (rate-damping law of gain k): h_i' = k J_i w_i, so
#   J w' = -w x (J w + h) - k J w.
# Componentwise, with (w x H)_1 = w2 H3 - w3 H2 etc. and H = J w + h:
#   J1 w1' = (J2 - J3) w2 w3 + w3 h2 - w2 h3 - k J1 w1,
#   J2 w2' = (J3 - J1) w3 w1 + w1 h3 - w3 h1 - k J2 w2,
#   J3 w3' = (J1 - J2) w1 w2 + w2 h1 - w1 h2 - k J3 w3,
# i.e. w1' = -0.5 w2 w3 + 0.5 (w3 h2 - w2 h3) - k w1,
#      w2' = 0.75 w3 w1 + 0.25 (w1 h3 - w3 h1) - k w2,
#      w3' = -0.4 w1 w2 + 0.2 (w2 h1 - w1 h2) - k w3,
#      h1' = 2 k w1, h2' = 4 k w2, h3' = 5 k w3.
# ENERGY: E = 2 w1^2 + 4 w2^2 + 5 w3^2 = w . J w (twice the body's rotational kinetic
# energy). E' = 2 w . J w' = -2 w . (w x H) - 2 k w . J w = -2 k E, because w . (w x H) = 0
# for EVERY H: the gyroscopic cubic terms (coefficients -2 + 6 - 4 = 0 on w1 w2 w3) and the
# six wheel-coupling cubic terms (w1 w3 h2, w1 w2 h3, w2 w3 h1, each +2 and -2) cancel
# exactly. E' = -2 k E holds only through that cancellation, which every flow query on the
# energy rows has to establish in nonlinear real arithmetic (12 real variables per query).
# The wheels do not dissipate the TOTAL momentum: |J w + h| is conserved (H . H' = 0);
# a later momentum dump by magnetorquers is not modeled.
# The DESIGN MODEL (right) neglects the gyroscopic and wheel couplings: w_i' = -k w_i,
# h_i' = k J_i w_i.
# PHYSICAL DOMAIN (both sides): |w_i| <= 1 rad/s (the gyro's measurement range) and
# |h_i| <= 2 N m s (each wheel's momentum capacity); no certificate stands on them
# (widening test: CERTIFIED with every bound widened at once, no load-bearing group).
# Control period: 1 s on BOTH sides (epsilon = 1.0; every decision interval is at most 1 s), the
# attitude mode manager's cycle on a 1 Hz ADCS (the attitude solution of a CubeSpace CubeStar star
# tracker is updated at 1 Hz, CubeSpace sensor data sheet), as in sat_detumble_nominal. The
# rate-damping laws are continuous in the ODEs.
# Guards (entry conditions): the detumble controller engages with the body energy inside
# its authority envelope, E <= 1 (a controller-design constant). The design model
# declares the FDIR SAFE mode on the ENERGY threshold E > 1 (actuators inhibited, a sink;
# modeled frozen) -- a quadratic threshold. The right guards partition the domain (E <= 1,
# E > 1): no coverage gap.
#
# One cause between the sides: the right is the design model of the same spacecraft, the
# left adds the gyroscopic and wheel couplings (a model refinement; same gain, same guards, same
# period). Nominal: k = 0.5 /s on both sides. CLAIM: E_L <= E_R and E_R <= E_L -- the full
# rigid body's energy EQUALS the design model's at every instant (tolerance 0 in both
# directions; the exact equality is what the cubic cancellation gives, so no tighter
# claim exists). Requirement: the design model's energy prediction is exact for the real
# body, so detumble-time budgets computed on it hold. Not implied by the domains; every left
# start with E_L = E_R <= 1 is admissible (DETUMBLE).
# The claim depends on the cause (measured 2026-10-26): with the wheel term +0.5 w3 h2 of w1'
# removed on the left (that coupling then does work) the same claim DECLINES.
# Covers (measured): stretch range lambda in [1, 6]; the cover is found at lambda = 1
# (no S), budget 1; admissible start DETUMBLE. The envelope cut is kept but not needed
# (RELCERT_NO_CUT=1 CERTIFIES: no I).
#
# Fallback (energy threshold): DETUMBLE -> SAFE is pruned by the non-connection
# certificate -- source: no DETUMBLE entry state has E > 1; barrier: on E = 1 the
# design model's field gives E' = -E < 0. SAFE is not an admissible start
# (E_R <= E_L <= 1). With one right cycle per left window neither the pruning nor the committed
# successor subset is needed: RELCERT_NO_PRUNE=1, RELCERT_NO_CHOICE=1 and both together CERTIFY
# (no P, no X).
#
# Verdicts (RELCERT_IMPLIED_CUT=1 unless stated, measured 2026-10-26 with the copied tool):
# CERTIFIED (about 1 s); CERTIFIED under RELCERT_SYNC=1, RELCERT_NO_CHOICE=1, RELCERT_NO_PRUNE=1,
# NO_PRUNE+NO_CHOICE, RELCERT_NO_CUT=1, RELCERT_NO_IMPLIED_CUT=1, RELCERT_NO_LINEAR_CUT=1,
# RELCERT_OPREGION=1, RELCERT_WELLFORMED_STRICT=1 and without RELCERT_IMPLIED_CUT. Pruned:
# DETUMBLE -> SAFE. One row (--handoff vacuous, 1/1). relcert --wellformed: DETUMBLE, SAFE ok
# (invariant), 0 UNKNOWN. The right model is unchanged from the repo
# file (epsilon 1.0; its Assumption 1 proof stands); the left changed only in its period.
#
# MOMENTUM BAND (right evolve domains): |h_i + J_i w_i| <= 2 N m s, the total angular momentum of
# each axis within one wheel's capacity. It is conserved by every design-model mode
# (h_i' = k J_i w_i, w_i' = -k w_i), so it is a constraint on the initial state: the wheels can
# absorb the body's momentum. Off the band a wheel saturates before the body is stopped and the
# design model has no run of a full period (its Assumption 1 fails); the momentum dump that
