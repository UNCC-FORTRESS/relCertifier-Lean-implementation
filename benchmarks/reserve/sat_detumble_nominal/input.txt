# sat_detumble_nominal: microsatellite detumbling, full gyrostat model against its design model,
# same control period on both sides.
# scenario: model-refinement
# mechanisms: none (the base rung of the satellite family: an exact nonlinear energy claim whose
#   flow queries must establish the cubic cancellation; single-step cover, lambda = 1). The round-2
#   file's M came only from a 2 s left period against a 1 s right period and is gone with equal
#   periods.
#
# THE PLANT (both sides; a ~60 kg microsatellite, SI units). Body rates w1, w2, w3 (rad/s)
# about the principal axes, inertia J = diag(2, 4, 5) kg m^2, and the momentum h (N m s)
# of a reaction wheel on the z-axis. Euler's equations with the wheel (a gyrostat):
#   J1 w1' = (J2 - J3) w2 w3 - w2 h + tau1,   J2 w2' = (J3 - J1) w3 w1 + w1 h + tau2,
#   J3 w3' = (J1 - J2) w1 w2 - h',            h' = k J3 w3,
# with rate-damping magnetorquers tau_i = -k J_i w_i on x, y and the wheel absorbing the
# z-rate: w1' = -0.5 w2 w3 - 0.5 w2 h - k w1, w2' = 0.75 w3 w1 + 0.25 w1 h - k w2,
# w3' = -0.4 w1 w2 - k w3, h' = 5 k w3. The gyroscopic and wheel-coupling terms are
# genuine BILINEAR couplings (products w2 w3, w3 w1, w1 w2, w2 h, w1 h); they do no work,
# so the body energy E = 2 w1^2 + 4 w2^2 + 5 w3^2 (twice the rotational kinetic energy)
# obeys E' = -2 k E exactly -- but only through the cancellation of the cubic terms,
# which every flow query has to establish (Z3, nonlinear real arithmetic).
# The DESIGN MODEL (right) neglects the couplings: w_i' = -k w_i, h' = 5 k w3.
# PHYSICAL DOMAIN (both sides): |w_i| <= 1 rad/s (the gyro's measurement range) and
# |h| <= 2 N m s (the wheel's momentum capacity); no certificate stands on them
# (widening test).
# Control period: 1 s on BOTH sides (epsilon = 1.0; every decision interval is at most 1 s), the
# attitude mode manager's cycle on a 1 Hz ADCS (the attitude solution of a CubeSpace CubeStar star
# tracker is updated at 1 Hz, CubeSpace sensor data sheet). The rate-damping laws are continuous in
# the ODEs; the period is that of the mode decision (engagement, FDIR).
# Guards (entry conditions): the detumble controller engages with the body energy inside
# its authority envelope, E <= 1 (e.g. |w1| <= 0.71 rad/s about x alone). The design
# model declares the FDIR SAFE mode on an ENERGY threshold, E > 1 (actuators inhibited,
# a sink; modeled frozen: in the design model a free tumble keeps its rates) -- a quadratic
# threshold, not a speed floor. The right guards partition the domain (E <= 1, E > 1): no
# coverage gap.
#
# One cause between the sides: the right is the design model of the same spacecraft, the
# left adds the gyroscopic and wheel couplings (a model refinement; same gain, same guards, same
# period). Nominal: k = 0.5 /s on both sides. CLAIM: E_L <= E_R and E_R <= E_L -- the full
# rigid body's energy EQUALS the design model's at every instant (tolerance 0 in both
# directions; the exact equality is what the cubic cancellation gives, so no tighter claim
# exists). Requirement: the design model's energy prediction is exact for the real body, so
# detumble-time budgets computed on it hold. Not implied by the domains. Every left start
# with E_L = E_R <= 1 is admissible (DETUMBLE). The claim is synchronous: lambda in [1, 1]
# (the design model must match in real time).
# The claim depends on the cause (measured 2026-10-26): with the wheel back-reaction on w1
# removed on the left (the term -0.5 w2 h of w1' set to 0, so the w1-h coupling does work) the
# same claim DECLINES.
#
# Fallback (energy threshold): DETUMBLE -> SAFE is pruned by the non-connection
# certificate -- source: no DETUMBLE entry state has E > 1; barrier: on E = 1 the
# design model's field gives E' = -E < 0. SAFE is not an admissible start
# (E_R <= E_L <= 1). With one right cycle per left window neither the pruning nor the committed
# successor subset is needed: RELCERT_NO_PRUNE=1, RELCERT_NO_CHOICE=1 and both together CERTIFY
# (no P, no X).
#
# Verdicts (RELCERT_IMPLIED_CUT=1 unless stated, measured 2026-10-26 with the copied tool):
# CERTIFIED (about 1 s); CERTIFIED under RELCERT_SYNC=1, RELCERT_NO_CHOICE=1, RELCERT_NO_PRUNE=1,
# NO_PRUNE+NO_CHOICE, RELCERT_NO_CUT=1, RELCERT_NO_IMPLIED_CUT=1, RELCERT_NO_LINEAR_CUT=1,
# RELCERT_OPREGION=1, RELCERT_WELLFORMED_STRICT=1 and without RELCERT_IMPLIED_CUT. Cover: lambda 1,
# budget 1, admissible start DETUMBLE. Pruned: DETUMBLE -> SAFE. One row (--handoff vacuous, 1/1).
# relcert --wellformed: DETUMBLE, SAFE ok (invariant), 0 UNKNOWN. The right model is unchanged
# from the repo file (epsilon 1.0; its Assumption 1 proof stands); the left changed only in its
# period.
#
# MOMENTUM BAND (right evolve domains): |h + 5 w3| <= 2 N m s, the z-axis total angular momentum
# within the wheel's capacity. It is conserved by every design-model mode (h' = 5 k w3,
# w3' = -k w3), so it is a constraint on the initial state: the wheel can absorb the body's
# momentum. Off the band the wheel saturates before the body is stopped and the design model
# has no run of a full period (its Assumption 1 fails); the momentum dump that would handle
# that case is not modeled.
