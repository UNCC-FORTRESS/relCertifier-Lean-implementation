# Ladder rung 3->6: 6-DOF refines 3-DOF (NON-DEGENERATE)
#
# L (deployed, 6-DOF): s'=v(1-0.5*psi^2-0.3*theta^2), psi'=-psi, theta'=-theta, z'=-z, phi'=-phi
#   Carries BOTH heading and pitch penalty. Pitch reduces progress.
#
# R (reasoning, 3-DOF lifted): s'=v(1-0.5*psi^2), psi'=-psi  [HEADING ONLY]
#   theta'=-theta (carried but absent from s'), z'=0, phi'=0 (pinned).
#   R is the genuine 3-DOF model: ignores pitch, so R progresses MORE than L.
#
# This is a REAL simulation relation (not bisimulation): L and R have DIFFERENT
# progress dynamics. L falls behind R because L loses progress to pitch.
# The relation s_L <= s_R holds because R (ignoring pitch) always progresses >= L.
#
# Invariant: v_L<=v_R AND s_L<=s_R AND psi_L=psi_R
#   - psi equality: both share psi'=-psi, inductive at lambda=1.
#   - s_L<=s_R: dg/dt = (vL-vR)(1-0.5psi^2) - 0.3*vL*thetaL^2 <= 0. R stays ahead.
#   - v_L<=v_R: same v* per terrain, inductive at lambda=1.
#   d=0 is the TIGHT bound (R weakly ahead), not a degenerate slack.
#
# Backward pairs (L ahead of R) are vacuous under s_L<=s_R: R always leads.
# Only forward + same-terrain pairs apply.
#
# Composition: 6-DOF L = rung3 R exactly.
# Chain: 3-DOF(R) -> 6-DOF(L=rung3 R) -> 8-DOF(rung3 L) -> 12-DOF(pos).
