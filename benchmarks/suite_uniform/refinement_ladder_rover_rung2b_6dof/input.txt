# Ladder rung 2b: 6-DOF refines 4-DOF  (4→6 composition step)
#
# L (deployed, 6-DOF): adds heave (z) and roll (phi_r) to the 4-DOF model.
#   s'=v(1-0.5*psi^2-0.3*theta^2), psi'=-psi, theta'=-theta, z'=-z, phi'=-phi
#   z and phi_r are off-H filler states: they do NOT appear in s'.
#
# R (reasoning, 4-DOF lifted to 6-DOF): rung2 L lifted, z and phi pinned.
#   s'=v, psi'=0, theta'=0, z'=0, phi'=0
#   Same 2-DOF kinematic baseline, lifted into 6-DOF state space.
#
# Invariant: g = s_L - s_R - 0.2 + (v_L-v_R)/3 <= 0
#   z and phi_r are irrelevant to dg/dt (don't appear in s' or v').
#   Identical cert to rung2: dg/dt = v*_L - lambda*v*_R at boundary.
#   9/9 pairs certified at same lambdas as rung2.
#
# Composition: R = rung2 L lifted (s'=v, psi/theta/z/phi all pinned).
#   rung2b L = rung3 R restricted to {omega_psi=omega_theta=0}:
#   rung3 R has psi'=-psi, theta'=-theta, omega'=0 -- matches rung2b L.
# Chain: 2-DOF → 4-DOF (rung2) → 6-DOF (this) → 8-DOF (rung3) → 12-DOF (pos_ladder).
