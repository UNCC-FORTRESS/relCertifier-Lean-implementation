# scenario: sensor-attack
# mechanisms: M1 M2 M4

# Same controller, floor logic and reference as acc_spoof_cruise; the deployed
# vehicle's fused speed reads 1.5 v, so its loop is v' = 0.5 (30 - 1.5 v) = 0.75 (20 - v):
# it settles 10 m/s low and reacts 50 % faster. Rows: v_L <= v_R and v_R <= v_L + 10.5.

# 5/4 fail the slowdown bound at high speeds), budget ceil(3/2 * 2 / 1) = 3 right cycles
# per left window (M1, M2). DISENGAGE (wheel speed < 20 m/s) is pruned from CRUISE and
# excluded as a start (v_L >= 20, v_L <= v_R); RELCERT_NO_PRUNE=1 DECLINES (M4).
# Units m/s, s; envelope 0 <= v <= 40 both sides.
