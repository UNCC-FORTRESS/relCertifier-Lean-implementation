# acc_spoof_lag: the cruise loop under a speed-sensor spoof against the unspoofed loop, both with
# the same powertrain lag and the same control period; the spoofed loop is the stock loop run 3/2
# times faster toward a set speed 6 m/s lower.
# scenario: sensor-attack
# mechanisms: S (time stretch lambda = 3/2, the ratio of the two dominant time constants,
#   RELCERT_SYNC=1 declines, matrix code M1). The stretch comes from the attack: the spoof scales
#   the loop gain by 1.25 and so the dominant rate by 3/2. The cover is multi-step, each 0.1 s left
#   window matched by two right cycles (budget ceil(3/2 * 0.1 / 0.1) = 2, matrix code M2), but M is
#   not credited: the right has one mode, so its cycle boundaries are invisible and the two cycles
#   are one continuous right run cut at epsilon_R (letter rule M, 2026-10-30). Batch I9
#   (2026-10-27): the exact dominant-mode claim of the round-2 file is restored on the batch-I4
#   models (0.1 s periods, the engaged envelopes as guards); the batch-I4 real-time claim with the
#   8 m/s shortfall envelope (letters I) still certifies and is quoted below as a consequence.
#
# System. Speed v (m/s) and realised acceleration a (m/s^2) of one car whose cruise loop commands
# a_cmd = 0.5 (30 - v_meas) toward the set speed 30 m/s; the powertrain realises the command through
# a first-order lag of time constant tau = 0.375 s: v' = a, a' = (8/3) (a_cmd - a).
#   Left (attacked): the speed sensor is spoofed to read 25 % high, v_meas = 1.25 v, so
#     a_cmd = 0.5 (30 - 1.25 v) = 0.625 (24 - v): the car settles at 24 m/s.
#   Right (reference): the same car and lag, unspoofed, v_meas = v.
# The attack is the only difference (same plant, lag, period, engagement). Lag choice:
# tau = 0.375 s (1/tau = 8/3) is the lag at which both closed loops have rational real roots
# (left (s + 1)(s + 5/3), right (s + 2/3)(s + 2)), so both are non-oscillatory and decouple into
# exponential modes.
# Control period: 0.1 s on BOTH sides (epsilon = 0.1; every decision interval is at most 0.1 s):
# the engagement check runs on the ACC's update cycle, bounded by an automotive long-range radar's
# cycle (the Continental ARS 408-21 data sheet gives about 72 ms). The speed loop is continuous in
# the ODEs; the period is that of the mode decision.
#
# Property (requirement and the attack's exact signature). Let u = v + a / r_f be the dominant-mode
# speed (r_f the fast root: u_L = v_L + 0.6 a_L, u_R = v_R + 0.5 a_R); u_L - 24 decays at 1 /s and
# u_R - 30 at 2/3 /s. Rows:
#   v_L <= v_R (row 1, the requirement re-timed, constant 0): the spoofed car at time t is never
#     faster than the unspoofed reference at time 3/2 t. The row certifies down to
#     v_L <= v_R - 3.33 (-3.34 declines) along the cover. The real-time overspeed bound (v_L <= v_R
#     at equal times) is not a row of this file: it certifies at lambda 1 as a separate claim with
#     the strengthening v_L + a_L/2 <= v_R + a_R/2 (both sides, 1/2 = the reference's fast-root
#     time; the batch-I4 rows), down to -3.95 (-3.96 declines; letters I, RELCERT_NO_CUT=1
#     declines; measured 2026-10-29), and adding it to the lambda-3/2 rows DECLINES.
#   u_L <= u_R - 6 (row 2, exact): at lambda = 3/2 the two dominant modes decay alike, so the
#     spoofed car's dominant-mode speed equals the reference's at 3/2 the elapsed time minus the
#     6 m/s set-speed shift (30 - 24), and the row is kept exactly. Row 2 holds with equality
#     (u_L - 24 and u_R - 30 are the same exponential after re-timing); stated one-sided, tight
#     at -6 (-6.01 declines).
#     Row 2 is also the inductive strengthening row 1 needs (row 1 alone has no inductive
#     certificate: its derivative compares the two accelerations).
# Reading: the spoof turns the stock loop into the same loop 3/2 times faster aiming 6 m/s lower,
# so every speed profile of the attacked car is a sped-up, lowered profile of the reference. Exact:
# no tolerance constant. Not implied by the domains.
# The stretch follows the cause: lambda = 1 / (2/3) = 3/2 is the ratio of the dominant rates, i.e.
# the loop-gain factor the spoof introduces (0.625 / 0.5 = 1.25 on the gain, 3/2 on the dominant
# root at this lag). Stated, not searched (lambda_min = lambda_max = 1.5); as every exact rate
# ratio of this suite it certifies at its exact value only (1.45 DECLINES, measured 2026-10-27;
# and RELCERT_SYNC=1 DECLINES). Cause dependence: at a 20 % spoof (v_meas = 1.2 v, set point 25,
# dominant ratio 1.4 at a lag with rational roots) the rows would read u_L <= u_R - 5 at lambda
# 7/5; the stated spoof fixes both constants.
# Consequence (measured 2026-10-27, re-checked 2026-10-29, not part of the claim): the batch-I4
# real-time rows v_R <= v_L + 8 and w_R <= w_L + 8 with w = v + 0.5 a on BOTH sides (the batch-I4
# strengthening, not the u of this file: with u_L = v_L + 0.6 a_L the pair DECLINES at lambda 1)
# (the shortfall envelope, 8 m/s = the 6 m/s set-speed shift plus the lag transient; its
# requirement: the spoof may slow the car at most 8 m/s below the reference, which at the 30 m/s
# set speed keeps the spoofed car above 22 m/s (80 km/h), the minimum speed the scenario's
# motorway lane requires) certify at lambda 1 on this file's models; adding them to the exact
# rows at lambda 3/2 DECLINES (they are real-time statements, not re-timed ones), so the file
# states the exact claim alone.
#
# Guards. Left: the spoofed loop's ENGAGED ENVELOPE, the forward-invariant hull under the spoofed
# loop of its engagement box (the controller engages, or resumes, between 23 m/s and the set speed
# with |a| <= 2 m/s^2, no hard pedal input): a + (v - 24) in [-3, 8] and a + (5/3)(v - 24) in
# [-11/3, 12] (the left modal coordinates, decaying at 5/3 /s and 1 /s; the box's corners are
# envelope corners). The guard is re-checked at every decision; every left run from the box
# continues (with the box itself as the guard a run from (23, -2) dipped to 22.6 m/s and ended).
# Right: the reference's ENGAGED ENVELOPE, the forward-invariant hull of the same engagement box
# under the unspoofed loop: 3 a + 2 v in [40, 66] and a + 2 v in [44, 62] (modal coordinates of
# the box, each decaying toward 0; relcert --wellformed CRUISE ok (invariant)). It bounds the
# reference's lag state, which a speed band alone does not. It spans v in [16.5, 36.5]; simulated
# runs from the engagement box stay in v in [22.8, 30.6].
# Coverage. Right-domain states outside the envelope are in no right guard: the reference never
# reaches them after engaging. The stock controller's disengage branch below 20 m/s is not
# modeled: neither loop comes near 20 m/s from engagement.
# Domains (both sides): v in [0, 40] m/s, a in [-10, 10] m/s^2 (1 g, the tyre-road limit);
# physical limits, not load-bearing.
#
# Verdicts (RELCERT_IMPLIED_CUT=1 unless stated, measured 2026-10-27, batch I9; re-measured
# 2026-10-29): CERTIFIED (0.07 s); DECLINED under RELCERT_SYNC=1 and SYNC+NO_CHOICE; CERTIFIED
# under RELCERT_NO_PRUNE=1,
# RELCERT_NO_CHOICE=1, NO_PRUNE+NO_CHOICE, without RELCERT_IMPLIED_CUT, RELCERT_NO_IMPLIED_CUT=1,
# RELCERT_NO_LINEAR_CUT=1, RELCERT_NO_CUT=1, RELCERT_NO_REPO=1, RELCERT_OPREGION=1 and
# RELCERT_WELLFORMED_STRICT=1. Cover: lambda = 3/2, budget 2 right cycles per left window,
# admissible start CRUISE, nothing pruned (the cuts are kept but not load-bearing). --handoff 1/1
# vacuous (one left mode). relcert --wellformed: CRUISE ok (invariant), 0 UNKNOWN, 0 BLOCKING.
# The right model is unchanged since batch I4 (Assumption 1 proof unchanged); the rows and the
# stretch changed (batch I9). Units m/s, m/s^2, s.
[problem]
name = acc_spoof_lag
max_depth = 8
lambda_min = 1.5
lambda_max = 1.5
bound_T = 4.0
[Lsys]
state_vars = [v, a]
epsilon = 0.1
[Lsys.mode.CRUISE]
ode = v' = a; a' = smt2:(* (/ 8.0 3.0) (- (* 0.5 (- 30.0 (* 1.25 v))) a));
guard = smt2:(and (>= (+ a (- v 24.0)) (- 3.0)) (<= (+ a (- v 24.0)) 8.0) (>= (+ a (* (/ 5.0 3.0) (- v 24.0))) (- (/ 11.0 3.0))) (<= (+ a (* (/ 5.0 3.0) (- v 24.0))) 12.0))
evolve = v >= 0.0 and v <= 40.0 and a >= -10.0 and a <= 10.0
next = [CRUISE]
[Rsys]
state_vars = [v, a]
epsilon = 0.1
[Rsys.mode.CRUISE]
ode = v' = a; a' = smt2:(* (/ 8.0 3.0) (- (* 0.5 (- 30.0 v)) a));
guard = smt2:(and (>= (+ (* 3.0 a) (* 2.0 v)) 40.0) (<= (+ (* 3.0 a) (* 2.0 v)) 66.0) (>= (+ a (* 2.0 v)) 44.0) (<= (+ a (* 2.0 v)) 62.0))
evolve = v >= 0.0 and v <= 40.0 and a >= -10.0 and a <= 10.0
next = [CRUISE]
[relational_invariant]
CRUISE = smt2:(and (<= L_v R_v) (<= (+ L_v (* 0.6 L_a)) (- (+ R_v (* 0.5 R_a)) 6.0)))
