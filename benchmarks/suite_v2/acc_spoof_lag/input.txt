# acc_spoof_lag: the cruise loop under a speed-sensor spoof against the unspoofed loop, both with
# the same powertrain lag.
# scenario: sensor-attack
# mechanisms: S M (time stretch lambda = 3/2 needed, RELCERT_SYNC=1 declines; multi-step cover,
#   matrix codes M1 M2)
#
# System. Speed v (m/s), realised acceleration a (m/s^2); the cruise loop commands
# a_cmd = 0.5 (30 - v_meas) toward the set speed 30 m/s and the powertrain realises it through a
# first-order lag of time constant tau = 0.375 s: v' = a, a' = (8/3) (a_cmd - a).
#   Left (attacked): the speed sensor is spoofed to read 25 % high, v_meas = 1.25 v, so
#     a_cmd = 0.5 (30 - 1.25 v) = 0.625 (24 - v): the car settles at 24 m/s.
#   Right (reference): the same car and lag, unspoofed, v_meas = v.
# The attack is the only difference. Lag choice: tau = 0.375 s (1/tau = 8/3) is the lag at which
# both closed loops have rational real roots (left (s + 1)(s + 5/3), right (s + 2/3)(s + 2)), so
# both are non-oscillatory; the previous 0.4 s lag made the attacked loop critically damped and
# the reference had no lag at all.
#
# Property. Requirement: a spoofed speed sensor must not make the car faster than the unspoofed
# reference: v_L <= v_R (row 1, constant 0 from the requirement). Row 2 is the attack's exact
# impact on the dominant mode: with u = v + a / r_f (r_f the fast root, u_L = v_L + 0.6 a_L,
# u_R = v_R + 0.5 a_R), u_L - 24 and u_R - 30 decay at the slow rates 1 /s and 2/3 /s, so at
# lambda = 3/2 they decay alike and u_L <= u_R - 6 (the 6 m/s set-speed shift 30 - 24) is kept
# exactly. Row 2 is the inductive strengthening row 1 needs (row 1 alone has no inductive
# certificate: its derivative compares the two accelerations).
# Tightest: row 1 certifies down to v_L <= v_R - 3.33 (-3.34 declines): the attack slows the
# car by at least 3.33 m/s; row 2 is tight at -6 (-6.01 declines). Not implied by the domains.
#
# Guards. Left: the controller engages between 23 m/s and the set speed with |a| <= 2 m/s^2 (no
# hard pedal input), the engagement condition at every sample, as before. Right: the reference's
# ENGAGED ENVELOPE, the forward-invariant hull of the same engagement box under the unspoofed
# loop: 3 a + 2 v in [40, 66] and a + 2 v in [44, 62] (modal coordinates of the box, each
# decaying toward 0; relcert --wellformed CRUISE ok (invariant)). It bounds the reference's lag
# state, which a speed band alone does not. It spans v in [16.5, 36.5]; simulated runs from the
# engagement box stay in v in [22.8, 30.6].
# Coverage. Right-domain states outside the envelope are in no right guard: the reference never
# reaches them after engaging. The stock controller's disengage branch below 20 m/s (declared in
# earlier versions) is not modeled: neither loop comes near 20 m/s from engagement.
# Domains (both sides): v in [0, 40] m/s, a in [-10, 10] m/s^2 (1 g); physical, not load-bearing.
#
# Verdicts (RELCERT_IMPLIED_CUT=1 unless stated): CERTIFIED; DECLINED under RELCERT_SYNC=1 (and
# SYNC+NO_CHOICE); CERTIFIED under NO_PRUNE, NO_CHOICE, NO_PRUNE+NO_CHOICE, without
# RELCERT_IMPLIED_CUT, NO_IMPLIED_CUT, NO_LINEAR_CUT, NO_CUT and RELCERT_WELLFORMED_STRICT=1.
# Cover: lambda = 3/2, budget ceil(3/2 * 2 / 1) = 3, nothing pruned; --handoff 1/1 vacuous.
# Units m/s, m/s^2, s.
[problem]
name = acc_spoof_lag
max_depth = 8
lambda_min = 1.0
lambda_max = 6.0
bound_T = 4.0
[Lsys]
state_vars = [v, a]
epsilon = 2.0
[Lsys.mode.CRUISE]
ode = v' = a; a' = smt2:(* (/ 8.0 3.0) (- (* 0.5 (- 30.0 (* 1.25 v))) a));
guard = v >= 23.0 and v <= 30.0 and a >= -2.0 and a <= 2.0
evolve = v >= 0.0 and v <= 40.0 and a >= -10.0 and a <= 10.0
next = [CRUISE]
[Rsys]
state_vars = [v, a]
epsilon = 1.0
[Rsys.mode.CRUISE]
ode = v' = a; a' = smt2:(* (/ 8.0 3.0) (- (* 0.5 (- 30.0 v)) a));
guard = smt2:(and (>= (+ (* 3.0 a) (* 2.0 v)) 40.0) (<= (+ (* 3.0 a) (* 2.0 v)) 66.0) (>= (+ a (* 2.0 v)) 44.0) (<= (+ a (* 2.0 v)) 62.0))
evolve = v >= 0.0 and v <= 40.0 and a >= -10.0 and a <= 10.0
next = [CRUISE]
[relational_invariant]
CRUISE = smt2:(and (<= L_v R_v) (<= (+ L_v (* 0.6 L_a)) (- (+ R_v (* 0.5 R_a)) 6.0)))
