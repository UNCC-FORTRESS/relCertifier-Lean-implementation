# acc_tune_lag: the retuned cruise controller refined with the powertrain lag.
# scenario: model-refinement
# mechanisms: M1 M2 M4
#
# Refinement of acc_tune_gain. The deployed vehicle (left) is modeled with its
# powertrain lag: the retuned speed loop commands a_cmd = 0.75 (30 - v) and the
# powertrain realises it through a first-order lag of 0.5 s: v' = a, a' = 2 (a_cmd - a),
# with the acceleration envelope -3 <= a <= 6 m/s^2. The reference (right) is the stock
# first-order cruise model v' = 0.5 (30 - v) (lag abstracted away).
#
# Claim: the lifted functional a_L + 2 v_L <= 2 v_R + 6. Along the deployed model
# (a + 2v)' = 2 a_cmd = 1.5 (30 - v), so the functional plays the role the speed plays
# in acc_tune_gain; with the envelope the row implies v_L <= v_R + 4.5 (the lag costs
# 3.5 m/s of tolerance against the lag-free 1 m/s of acc_tune_gain). The right certifies
# at lambda = 3/2 (at lambda = 1 the boundary derivative 12 - 0.5 v_L + 0.5 a_L is
# positive throughout the band), budget ceil(3/2 * 2 / 1) = 3 right cycles per left
# window (M1, M2).
#
# Fallback (M4): the reference's DISENGAGE branch below the 20 m/s wheel-speed floor
# (v' = -0.5 v, sink) is pruned (CRUISE accelerates at the floor, entered above it);
# the deployed CRUISE window starts at v_L >= 25 with a_L >= -3, so the row gives
# v_R >= v_L + (a_L - 6) / 2 >= 20.5 and DISENGAGE is not an admissible start.
# RELCERT_NO_PRUNE=1 DECLINES. Units m/s, m/s^2, s; envelope v in [0, 40], a in [-3, 6].
[problem]
name = acc_tune_lag
max_depth = 8
lambda_min = 1.0
lambda_max = 6.0
bound_T = 4.0
[Lsys]
state_vars = [v, a]
epsilon = 2.0
[Lsys.mode.CRUISE]
ode = v' = a; a' = smt2:(* 2.0 (- (* 0.75 (- 30.0 v)) a));
guard = v >= 25.0 and v < 40.0 and a >= -3.0 and a <= 6.0
evolve = v >= 0.0 and v <= 40.0 and a >= -3.0 and a <= 6.0
next = [CRUISE]
[Rsys]
state_vars = [v, a]
epsilon = 1.0
[Rsys.mode.CRUISE]
ode = v' = smt2:(* 0.5 (- 30.0 v)); a' = smt2:0;
guard = v >= 20.0 and v < 40.0
evolve = v >= 0.0 and v <= 40.0 and a >= -3.0 and a <= 6.0
next = [CRUISE, DISENGAGE]
[Rsys.mode.DISENGAGE]
ode = v' = smt2:(* -0.5 v); a' = smt2:0;
guard = v < 20.0
evolve = v >= 0.0 and v <= 40.0 and a >= -3.0 and a <= 6.0
next = [DISENGAGE]
[relational_invariant]
CRUISE = smt2:(<= (+ L_a (* 2.0 L_v)) (+ (* 2.0 R_v) 6.0))
