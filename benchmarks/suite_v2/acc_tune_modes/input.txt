# acc_tune_modes: retuned cruise control against a reference with driver-selectable response modes.
# scenario: degraded-controller
# mechanisms: M1 M2 M3 M4 M6
#
# Same vehicle as acc_tune_limp's CRUISE mode: the deployed cruise controller (left) runs an
# aftermarket tune with speed-loop gain 0.75 /s toward the set speed 30 m/s
# (v' = 0.75 (30 - v)). The reference controller (right) is the stock unit, which lets the
# driver select a response mode at any time: COMFORT (gain 0.4), NORMAL (0.5) or SPORT
# (0.6), all toward 30 m/s; the mode can be changed from NORMAL to either neighbour and
# back (nondeterministic switching within the same band).
#
# Claim: |v_L - v_R| <= 2 m/s whichever response mode the reference is in (rows
# v_L <= v_R + 2 and v_R <= v_L + 2). The right certifies at lambda = 3/2 (NORMAL is the
# retuned loop slowed by 1.5; COMFORT and SPORT are absorbed by the 2 m/s slack inside
# the 20..36 m/s band); at lambda = 1 the first conjunct fails below 27 m/s. Budget
# ceil(3/2 * 2 / 1) = 3 right cycles per left window; the cover from NORMAL takes a joint
# step whose retained successors COMFORT and SPORT both cover (M1, M2, M3). The band
# bounds 20 <= v <= 36 are flow-invariant guard conjuncts (every loop contracts toward
# 30) kept as checked cuts, and the COMFORT and SPORT segments need them: with
# RELCERT_NO_CUT=1 no lambda certifies all three modes and the benchmark is DECLINED (M6).
#
# Fallback (M4): every reference mode declares the DISENGAGE branch below the 20 m/s
# wheel-speed floor (coast down v' = -0.5 v, sink); each loop accelerates at the floor
# (v' >= 4 > 0) and is entered above it, so all three edges are pruned; v_L >= 22 and
# v_L <= v_R + 2 exclude DISENGAGE as a start. RELCERT_NO_PRUNE=1 DECLINES.
# Units m/s, s; envelope 0 <= v <= 40 both sides; bands 20..36 m/s (deployed 22..36).
[problem]
name = acc_tune_modes
max_depth = 8
lambda_min = 1.0
lambda_max = 6.0
bound_T = 4.0
[Lsys]
state_vars = [v]
epsilon = 2.0
[Lsys.mode.CRUISE]
ode = v' = smt2:(* 0.75 (- 30.0 v));
guard = v >= 22.0 and v <= 36.0
evolve = v >= 0.0 and v <= 40.0
next = [CRUISE]
[Rsys]
state_vars = [v]
epsilon = 1.0
[Rsys.mode.NORMAL]
ode = v' = smt2:(* 0.5 (- 30.0 v));
guard = v >= 20.0 and v <= 36.0
evolve = v >= 0.0 and v <= 40.0
next = [NORMAL, COMFORT, SPORT, DISENGAGE]
[Rsys.mode.COMFORT]
ode = v' = smt2:(* 0.4 (- 30.0 v));
guard = v >= 20.0 and v <= 36.0
evolve = v >= 0.0 and v <= 40.0
next = [COMFORT, NORMAL, DISENGAGE]
[Rsys.mode.SPORT]
ode = v' = smt2:(* 0.6 (- 30.0 v));
guard = v >= 20.0 and v <= 36.0
evolve = v >= 0.0 and v <= 40.0
next = [SPORT, NORMAL, DISENGAGE]
[Rsys.mode.DISENGAGE]
ode = v' = smt2:(* -0.5 v);
guard = v < 20.0
evolve = v >= 0.0 and v <= 40.0
next = [DISENGAGE]
[relational_invariant]
CRUISE = smt2:(and (<= L_v (+ R_v 2.0)) (<= R_v (+ L_v 2.0)))
