# arm_plateau_lowgain: detuned PD arm (half the gains, still over-damped) tracking the leading reference.
# scenario: degraded-controller
# mechanisms: M2 M6 M6L
#
# The reference-tracking arm (redesign of the arm tower; repaired in the domain audit,
# docs/SUITE-REDESIGN.md section 13). Deployed (left): a PD-controlled joint tracking
# the step command theta = 0.5 rad from rest, state (theta, v): theta' = v,
# v' = -k_p (theta - 0.5) - k_d v, with the modes Accelerate (rising toward the
# command, v >= 0) and Brake (past the command, v <= 0). Reference (right): a coarse
# leading reference that ramps up in three rate steps, ApproachA (0.5 rad/s) ->
# ApproachB (0.35) -> ApproachC (0.2), to a plateau of 0.6 rad and then HOLDS there
# (Hold: theta' = 0, guard theta >= 0.6), a sound envelope the arm tracks from below.
# This rung: a detuned controller, k_p = 0.5, k_d = 1.5 (half the proportional gain,
# over-damped, eigenvalues -0.5 and -1): slower than the nominal loop, no overshoot.
# (The family's earlier half-torque member, k_p = k_d = 0.5, is UNDER-damped, damping
# ratio 0.35, and so is the earlier nominal member k_p = k_d = 1: an oscillatory loop
# has no real decoupling form, its overshoot is not bounded by any linear or quadratic
# cut the certifier can check, and both certified only through the reachable-set
# domain cap theta <= 0.65. They are replaced, not kept.)
#
# PHYSICAL DOMAINS. As in arm_plateau_crit: theta in [0, 1.2] rad, v in [-1, 1] rad/s;
# no reachable-set estimate. Guards are entry conditions: Accelerate with the
# engagement velocity v < 0.355 rad/s; Brake past the command with v <= 0 and the
# entry cap theta <= 0.855, the bound the cut chain proves for Accelerate.
#
# THE CUT CHAIN (RELCERT_IMPLIED_CUT=1, L7). The decoupling forms are
# q_r = v + r (theta - 0.5) for r in {0.5, 1}, q_r' = -(1.5 - r) q_r. Round 1 from the
# Accelerate guard box: q_0.5 <= 0.355 and q_1 <= 0.355 (linear-form, O1 rational,
# O2 linear-shape). Round 2: the derived bound from the larger root, theta <= 0.5 +
# 0.355 / 1 = 0.855 (derived-bound, given q_1 <= 0.355); the same bound as the
# critically damped loop, whose larger root is also 1. Brake yields the same.
#
# CLAIM, derived: theta_L <= theta_R + 0.255 in both deployed modes (0.855 against
# the 0.6 plateau; the tangent point (0.855, 0.6) is decided by the superlevel route).
#
# Covers (measured): lambda = 1 with budget 2 right cycles per left window
# (epsilon_L = 2 s, epsilon_R = 1 s), right-only repositioning up the ramp to Hold and
# a joint window against the plateau (M2 with right-only segments). Counter-runs:
# RELCERT_NO_CUT=1 DECLINED (M6); RELCERT_NO_LINEAR_CUT=1 DECLINED (M6L). No fallback
# is declared: the arm starts at theta = 0 and the row is one-sided. Units rad, rad/s, s.
[problem]
name = arm_plateau_lowgain
max_depth = 8
lambda_min = 1.0
lambda_max = 6.0
bound_T = 4.0

[Lsys]
state_vars = [theta, v]
epsilon = 2.0

[Lsys.mode.Accelerate]
ode = theta' = v; v' = smt2:(+ (* -0.5 (- theta 0.5)) (* -1.5 v));
guard = theta >= 0.0 and theta < 0.5 and v >= 0.0 and v < 0.355
evolve = theta >= 0.0 and theta <= 1.2 and v >= -1.0 and v <= 1.0
next = [Brake, Accelerate]

[Lsys.mode.Brake]
ode = theta' = v; v' = smt2:(+ (* -0.5 (- theta 0.5)) (* -1.5 v));
guard = theta >= 0.5 and theta <= 0.855 and v <= 0.0
evolve = theta >= 0.0 and theta <= 1.2 and v >= -1.0 and v <= 1.0
next = [Accelerate, Brake]

[Rsys]
state_vars = [theta]
epsilon = 1.0

[Rsys.mode.ApproachA]
ode = theta' = smt2:0.5;
guard = theta >= 0.0 and theta <= 0.35
evolve = theta >= 0.0 and theta <= 1.2
next = [ApproachB, ApproachA]

[Rsys.mode.ApproachB]
ode = theta' = smt2:0.35;
guard = theta >= 0.35 and theta <= 0.5
evolve = theta >= 0.0 and theta <= 1.2
next = [ApproachC, ApproachB]

[Rsys.mode.ApproachC]
ode = theta' = smt2:0.2;
guard = theta >= 0.5 and theta <= 0.6
evolve = theta >= 0.0 and theta <= 1.2
next = [Hold, ApproachC]

[Rsys.mode.Hold]
ode = theta' = smt2:0;
guard = theta >= 0.6 and theta < 1.15
evolve = theta >= 0.0 and theta <= 1.2
next = [Hold]

[relational_invariant]
# theta_L <= theta_R + 0.255: the chain bound 0.855 against the 0.6 plateau.
Accelerate = theta[l] <= theta[r] + 0.255
Brake      = theta[l] <= theta[r] + 0.255
