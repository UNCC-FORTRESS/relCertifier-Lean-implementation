# charger_bias_estimator: the certified charger with a +5 % state-of-charge estimator bias.
# scenario: sensor-attack
# mechanisms: M2 M4
#
# State of charge x (%). The certified charging profile (right) is the two-rate charger
# of charger_fast_bulk: BULK x' = 0.1 (100 - x) for 15 <= x < 80, ABSORB
# x' = 0.05 (100 - x) for 80 <= x < 99, FULL hold at x >= 99, CELL FAULT below 10 %
# (x' = -0.01 x, sink). The deployed charger (left) runs the SAME current profile but its
# SoC estimator reads 5 % high (a spoofed coulomb counter), so it switches phases 5 %
# early in true SoC: BULK for 10 <= x < 75, ABSORB for 75 <= x < 94, FULL at x >= 94.
# Claim (every phase): x_L <= x_R and x_R <= x_L + 6 -- the deployed charger is never
# ahead of the certified profile and never more than 6 % SoC behind it.
#
# PER-MODE EVOLVE DOMAINS (the paper's model, Eq. 2): each phase's domain is its own
# SoC band (BULK 15..80 / 10..75, ABSORB 80..99 / 75..94, FULL 99..100 / 94..100,
# FAULT 0..10): the charger cannot persist in a phase beyond its switching threshold, so
# the switches are forced by the domains. This is what makes the cross-phase pairings
# certify: a deployed BULK window (x_L <= 75) against a reference in ABSORB (x_R >= 80)
# never reaches the boundary x_L = x_R, and a reference still in BULK (x_R <= 80) never
# gets more than 6 % ahead of a deployed taper (x_L >= 75). The same model with one
# uniform envelope 0..100 for every mode is DECLINED (the BULK_L/ABSORB_R pairing then
# needs lambda > 2 while BULK_L/BULK_R needs lambda <= 1.08). lambda = 1, budget 2
# (epsilon_L = 2 h, epsilon_R = 1 h), crossing BULK -> ABSORB -> FULL (M2). The phase
# floors are guard conjuncts the certifier keeps as checked cuts, but the per-mode
# domains already carry them, so the cuts are not load-bearing (RELCERT_NO_CUT=1 still
# CERTIFIES). BULK -> FAULT is pruned and FAULT is not an admissible start (x_L >= 10
# and x_L <= x_R; M4, NO_PRUNE DECLINES). Units %, h.
[problem]
name = charger_bias_estimator
max_depth = 8
lambda_min = 1.0
lambda_max = 6.0
bound_T = 4.0
[Lsys]
state_vars = [x]
epsilon = 2.0
[Lsys.mode.BULK]
ode = x' = smt2:(* 0.1 (- 100.0 x));
guard = x >= 10.0 and x < 75.0
evolve = x >= 10.0 and x <= 75.0
next = [ABSORB, BULK]
[Lsys.mode.ABSORB]
ode = x' = smt2:(* 0.05 (- 100.0 x));
guard = x >= 75.0 and x < 94.0
evolve = x >= 75.0 and x <= 94.0
next = [FULL, ABSORB]
[Lsys.mode.FULL]
ode = x' = smt2:0;
guard = x >= 94.0
evolve = x >= 94.0 and x <= 100.0
next = [FULL]
[Rsys]
state_vars = [x]
epsilon = 1.0
[Rsys.mode.BULK]
ode = x' = smt2:(* 0.1 (- 100.0 x));
guard = x >= 15.0 and x < 80.0
evolve = x >= 15.0 and x <= 80.0
next = [ABSORB, BULK, FAULT]
[Rsys.mode.ABSORB]
ode = x' = smt2:(* 0.05 (- 100.0 x));
guard = x >= 80.0 and x < 99.0
evolve = x >= 80.0 and x <= 99.0
next = [FULL, ABSORB]
[Rsys.mode.FULL]
ode = x' = smt2:0;
guard = x >= 99.0
evolve = x >= 99.0 and x <= 100.0
next = [FULL]
[Rsys.mode.FAULT]
ode = x' = smt2:(* -0.01 x);
guard = x < 10.0
evolve = x >= 0.0 and x <= 10.0
next = [FAULT]
[relational_invariant]
BULK   = x[l] <= x[r] and x[r] <= x[l] + 6
ABSORB = x[l] <= x[r] and x[r] <= x[l] + 6
FULL   = x[l] <= x[r] and x[r] <= x[l] + 6
