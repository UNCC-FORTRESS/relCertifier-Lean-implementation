# charger_fast_setpoints: the fast charger against the certified profile whose bulk phase targets 90 %.
# scenario: degraded-controller
# mechanisms: S M R D I (RELCERT_SYNC=1 declines; multi-step covers with right-only
#   repositioning; mode-dependent rows; implied cuts, matrix codes M2 M5 M6 M6+)
#
# System. State of charge x (%), time in h. The certified charging profile (right):
#   PRECHARGE (10 <= x < 15): x' = 0.2 (20 - x)    recovery charge of a deeply discharged cell at
#                                                   the pre-charge voltage (2 %/h at 10 %, 1 %/h
#                                                   at 15 %), until the 15 % bulk threshold
#   BULK      (15 <= x < 80): x' = 0.1 (90 - x)    fast phase toward a 90 % bulk target
#   ABSORB    (80 <= x < 99): x' = 0.05 (100 - x)  taper toward 100 %
#   FULL      (x >= 99):      x' = 0               hold
#   FAULT     (x < 10):       x' = -0.01 x         cell fault: a cell below 10 % is not charged,
#                                                   latched (self-discharge only)
# PRECHARGE and BULK may latch FAULT (declared edges). The deployed unit (left) runs the same
# firmware with its current limit raised 25 % (every rate constant x 1.25: PRECHARGE 0.25,
# BULK 0.125, ABSORB 0.0625) and the same FAULT latch. One cause: the current limit.
# The guards partition [0, 100] on both sides: the old gap [10, 15) (no right mode) is closed by
# the pre-charge phase every Li-ion charger runs below its bulk threshold.
#
# Property. Requirement (SoC overshoot): the deployed unit's state of charge never exceeds the
# certified profile's by more than 2 % SoC, the state-of-charge accuracy of the battery
# management system (a smaller lead is not observable as non-conformance):
#   BULK, ABSORB, FULL, FAULT: x_L <= x_R + 2;   PRECHARGE: x_L <= x_R.
# The pre-charge row is stricter by necessity (mode-dependent, D): with any lead allowed there, a
# deployed cell in pre-charge at 10 % could pair with a certified cell below 10 %, latched in
# FAULT, which no cover can follow; with x_L <= x_R the reference is at or above 10 %.
# The bulk floor separates the fault: a deployed BULK start (x_L >= 15) with a lead below 5 %
# keeps the reference at or above 10 %, so FAULT is no admissible start for BULK.
# Tightest: the charging rows certify down to 1.00 (0.99 declines); uniform rows x_L <= x_R + c
# DECLINE (c = 1, 2, 3, 4.9), and uniform x_L <= x_R declines.
#
# Domain 0 <= x <= 100 both sides (physical). The implied contraction atoms x <= 20 (PRECHARGE),
# x <= 90 (BULK) are load-bearing (without RELCERT_IMPLIED_CUT: DECLINED).
#
# Verdicts (RELCERT_IMPLIED_CUT=1 unless stated): CERTIFIED; CERTIFIED under NO_PRUNE, NO_CHOICE,
# NO_LINEAR_CUT, RELCERT_WELLFORMED_STRICT=1; DECLINED under RELCERT_SYNC=1, SYNC+NO_CHOICE,
# NO_PRUNE+NO_CHOICE (pruning of PRECHARGE->FAULT, BULK->FAULT or the committed choice, either one
# suffices), without RELCERT_IMPLIED_CUT, NO_IMPLIED_CUT and NO_CUT. Covers: lambda = 1 in every
# left mode, budget 2; right-only repositioning (with progress certificates) out of PRECHARGE,
# BULK and ABSORB. --handoff 10/10 unsat, non-vacuous. relcert --wellformed: PRECHARGE ok
# (exit->BULK), BULK ok (exit->ABSORB), ABSORB ok (exit->FULL), FULL and FAULT ok (invariant).
[problem]
name = charger_fast_setpoints
max_depth = 8
lambda_min = 1.0
lambda_max = 6.0
bound_T = 4.0
[Lsys]
state_vars = [x]
epsilon = 2.0
[Lsys.mode.PRECHARGE]
ode = x' = smt2:(* 0.25 (- 20.0 x));
guard = x >= 10.0 and x < 15.0
evolve = x >= 0.0 and x <= 100.0
next = [BULK, PRECHARGE, FAULT]
[Lsys.mode.BULK]
ode = x' = smt2:(* 0.125 (- 90.0 x));
guard = x >= 15.0 and x < 80.0
evolve = x >= 0.0 and x <= 100.0
next = [ABSORB, BULK, FAULT]
[Lsys.mode.ABSORB]
ode = x' = smt2:(* 0.0625 (- 100.0 x));
guard = x >= 80.0 and x < 99.0
evolve = x >= 0.0 and x <= 100.0
next = [FULL, ABSORB]
[Lsys.mode.FULL]
ode = x' = smt2:0;
guard = x >= 99.0
evolve = x >= 0.0 and x <= 100.0
next = [FULL]
[Lsys.mode.FAULT]
ode = x' = smt2:(* -0.01 x);
guard = x < 10.0
evolve = x >= 0.0 and x <= 100.0
next = [FAULT]
[Rsys]
state_vars = [x]
epsilon = 1.0
[Rsys.mode.PRECHARGE]
ode = x' = smt2:(* 0.2 (- 20.0 x));
guard = x >= 10.0 and x < 15.0
evolve = x >= 0.0 and x <= 100.0
next = [BULK, PRECHARGE, FAULT]
[Rsys.mode.BULK]
ode = x' = smt2:(* 0.1 (- 90.0 x));
guard = x >= 15.0 and x < 80.0
evolve = x >= 0.0 and x <= 100.0
next = [ABSORB, BULK, FAULT]
[Rsys.mode.ABSORB]
ode = x' = smt2:(* 0.05 (- 100.0 x));
guard = x >= 80.0 and x < 99.0
evolve = x >= 0.0 and x <= 100.0
next = [FULL, ABSORB]
[Rsys.mode.FULL]
ode = x' = smt2:0;
guard = x >= 99.0
evolve = x >= 0.0 and x <= 100.0
next = [FULL]
[Rsys.mode.FAULT]
ode = x' = smt2:(* -0.01 x);
guard = x < 10.0
evolve = x >= 0.0 and x <= 100.0
next = [FAULT]
[relational_invariant]
PRECHARGE = x[l] <= x[r]
BULK = x[l] <= x[r] + 2
ABSORB = x[l] <= x[r] + 2
FULL = x[l] <= x[r] + 2
FAULT = x[l] <= x[r] + 2
