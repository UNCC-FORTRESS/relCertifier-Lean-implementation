# charger_fast_tapers: a DC fast charger whose current limit is raised 25 %, against the certified
# charging profile with two taper options, same control period on both sides.
# scenario: degraded-controller
# mechanisms: R P D I (right-only repositioning; pruned fault edges; mode-dependent rows; checked
#   cuts, matrix codes M4 M5 M6 M6+). RELCERT_SYNC=1 and RELCERT_NO_REPO=1 decline because the
#   covers need right-only repositioning; every cover is at lambda = 1, so no S. R, D and I come from
#   the claim form (a one-sided bound against an existential reference), P from the raised limit
#   (below).
#
# System. State of charge x (%), time in min. The certified charging profile (right):
#   PRECHARGE   (10 <= x < 15): x' = 0.2 (20 - x)    recovery charge of a deeply discharged cell
#                                                     (2 %/min at 10 %, 1 %/min at 15 %)
#   BULK        (15 <= x < 80): x' = 0.1 (100 - x)   constant-current phase (15 -> 80 % in about
#                                                     14.5 min, the DC fast-charging range)
#   ABSORB_SLOW (80 <= x < 99): x' = 0.05 (100 - x)  slow taper (80 -> 99 % in about 60 min)  } the
#   ABSORB_FAST (80 <= x < 99): x' = 0.07 (100 - x)  fast taper (80 -> 99 % in about 43 min)  } firmware
#                                                     selects one when it leaves BULK
#   FULL        (x >= 99):      x' = 0               hold
#   FAULT       (x < 10):       x' = -0.01 x         cell fault, latched (self-discharge only)
# PRECHARGE and BULK may latch FAULT (declared edges). The deployed unit (left) runs the profile
# with its current limit raised 25 % and the slow taper (PRECHARGE 0.25, BULK 0.125, ABSORB
# 0.0625; 15 -> 80 % in about 11.6 min) and the same FAULT latch. One cause: the current limit. The
# guards partition [0, 100] on both sides (no coverage gap: the pre-charge phase covers [10, 15)).
# Control period: 0.006 min = 0.36 s on BOTH sides (epsilon = 0.006; every decision interval is at
# most 0.36 s). The phase decision follows the vehicle's charge-current request, sent on the
# CHAdeMO CAN cycle of 100 ms +- 10 % (CHAdeMO protocol), so 0.36 s bounds it with margin. Time
# scale (2026-10-27, batch I7): the time unit is the minute (the earlier design used the hour with
# epsilon 0.0001 h, a 20 h bulk phase against a fast-charging period); the rate constants are per
# minute, so the phases take the minutes of DC fast charging. Same letters at both scales.
#
# Property. Requirement (SoC overshoot): the deployed state of charge never exceeds the certified
# profile's by more than 2 % SoC, the state-of-charge accuracy of the battery management system
# (a larger lead would put the deployed cell outside the profile's validated SoC trajectory by more
# than the BMS can resolve):
#   BULK, ABSORB, FULL, FAULT: x_L <= x_R + 2;   PRECHARGE: x_L <= x_R.
# The pre-charge row is stricter by necessity (D): with a lead allowed there a deployed cell at
# 10 % could pair with a certified cell latched in FAULT. Tightest (measured 2026-10-27): the
# charging rows certify down to 1.00 (0.99 declines); uniform rows x_L <= x_R + c decline
# (c = 1, 2, 3, 4.9), and so does a uniform x_L <= x_R.
# Why pruning is needed (P). The reference's PRECHARGE and BULK declare FAULT edges; their
# non-connection certificates (the charging flow rises at the 10 % threshold) prune them. Under
# RELCERT_NO_PRUNE=1 the deployed PRECHARGE window has no cover (the reference's PRECHARGE
# segment keeps FAULT in its all-successors obligation and the existential choice does not
# replace it): DECLINED.
# The bound also holds for other deployed behaviour (measured 2026-10-27): with the deployed rates
# at twice or three times the profile's (the current limit doubled or tripled) the 2 % rows
# CERTIFY, and RELCERT_NO_PRUNE=1 still DECLINES; with no raised limit (the deployed's rates set to
# the profile's slow taper) they CERTIFY and RELCERT_NO_PRUNE=1 then also CERTIFIES (P is the
# raised limit's: the faster deployed charge is what makes the FAULT obligation bite), while
# RELCERT_SYNC=1 and RELCERT_NO_CUT=1 still DECLINE (R and I are the claim form's).
#
# Domain 0 <= x <= 100 both sides (physical); every left mode has a satisfiable start
# (x_L = x_R). The implied contraction atoms x <= 20 (PRECHARGE) and x <= 100 (BULK, tapers) are
# load-bearing (without RELCERT_IMPLIED_CUT and under RELCERT_NO_IMPLIED_CUT=1: DECLINED).
#
# Verdicts (RELCERT_IMPLIED_CUT=1 unless stated, measured 2026-10-27 on branch benchmark-fixes):
# CERTIFIED; CERTIFIED under RELCERT_NO_CHOICE=1, RELCERT_NO_LINEAR_CUT=1, RELCERT_NO_PAIR_STRETCH=1,
# RELCERT_OPREGION=1 (every admitted start in some right guard), RELCERT_WELLFORMED_STRICT=1;
# DECLINED under RELCERT_SYNC=1, RELCERT_NO_PRUNE=1, NO_PRUNE+NO_CHOICE, SYNC+NO_CHOICE,
# RELCERT_NO_REPO=1, without RELCERT_IMPLIED_CUT, RELCERT_NO_IMPLIED_CUT=1 and RELCERT_NO_CUT=1.
# Covers: lambda = 1 in every left mode, budget 1, right-only repositioning on the replayed path
# (PRECHARGE_L, BULK_L, ABSORB_L), no branching joint step. Pruned: PRECHARGE -> FAULT,
# BULK -> FAULT. --handoff 10/10 unsat, non-vacuous. relcert --wellformed (both clauses):
# PRECHARGE ok (exit->BULK), BULK ok (exit->ABSORB_FAST), ABSORB_SLOW and ABSORB_FAST ok
# (exit->FULL), FULL and FAULT ok (invariant), 0 UNKNOWN, 0 BLOCKING. Letters: R P D I.
[problem]
name = charger_fast_tapers
max_depth = 8
lambda_min = 1.0
lambda_max = 6.0
bound_T = 4.0
[Lsys]
state_vars = [x]
epsilon = 0.006
[Lsys.mode.PRECHARGE]
ode = x' = smt2:(* 0.25 (- 20.0 x));
guard = x >= 10.0 and x < 15.0
evolve = x >= 0.0 and x <= 100.0
next = [BULK, PRECHARGE, FAULT]
[Lsys.mode.BULK]
ode = x' = smt2:(* 0.125 (- 100.0 x));
guard = x >= 15.0 and x < 80.0
evolve = x >= 0.0 and x <= 100.0
next = [ABSORB, BULK, FAULT]
[Lsys.mode.ABSORB]
ode = x' = smt2:(* 0.0625 (- 100.0 x));
guard = x >= 80.0 and x < 99.0
evolve = x >= 0.0 and x <= 100.0
next = [FULL, ABSORB]
[Lsys.mode.FULL]
ode = x' = smt2:0;
guard = x >= 99.0
evolve = x >= 0.0 and x <= 100.0
next = [FULL]
[Lsys.mode.FAULT]
ode = x' = smt2:(* -0.01 x);
guard = x < 10.0
evolve = x >= 0.0 and x <= 100.0
next = [FAULT]
[Rsys]
state_vars = [x]
epsilon = 0.006
[Rsys.mode.PRECHARGE]
ode = x' = smt2:(* 0.2 (- 20.0 x));
guard = x >= 10.0 and x < 15.0
evolve = x >= 0.0 and x <= 100.0
next = [BULK, PRECHARGE, FAULT]
[Rsys.mode.BULK]
ode = x' = smt2:(* 0.1 (- 100.0 x));
guard = x >= 15.0 and x < 80.0
evolve = x >= 0.0 and x <= 100.0
next = [ABSORB_SLOW, ABSORB_FAST, BULK, FAULT]
[Rsys.mode.ABSORB_SLOW]
ode = x' = smt2:(* 0.05 (- 100.0 x));
guard = x >= 80.0 and x < 99.0
evolve = x >= 0.0 and x <= 100.0
next = [FULL, ABSORB_SLOW]
[Rsys.mode.ABSORB_FAST]
ode = x' = smt2:(* 0.07 (- 100.0 x));
guard = x >= 80.0 and x < 99.0
evolve = x >= 0.0 and x <= 100.0
next = [FULL, ABSORB_FAST]
[Rsys.mode.FULL]
ode = x' = smt2:0;
guard = x >= 99.0
evolve = x >= 0.0 and x <= 100.0
next = [FULL]
[Rsys.mode.FAULT]
