# drl_lane_control: time-triggered local lane control refines the permissive controller
# (sampled form of the case study of differential refinement logic).
# scenario: controller-refinement
# mechanisms: X (committed successor subsets: the reference hops into the deployed's
#   follower/leader action pair at the start of every window)
#
# SOURCE. Loos and Platzer, "Differential refinement logic" (LICS 2016), Section 6.4: the
# local lane control of Loos, Platzer and Nistor (FM 2011), a follower behind a leader on a
# straight lane, x_f' = v_f, v_f' = a_f, x_l' = v_l, v_l' = a_l: the leader's acceleration is
# any value in [-B, A]; the follower's is any value in [-B, A] under the safety condition
# Safe_eps (eq. (7) of FM 2011, the time-triggered form), exactly -B when braking (dRL fixes
# the braking power, FM 2011 allows [-B, -b]), and 0 when stopped; dRL shows the
# time-triggered follower (period eps, guard Safe_eps) to refine the event-triggered one
# (guard Safe, the safe-distance invariant of FM 2011), with b = B. Refinement in dRL is
# reachability inclusion, i.e. the forall-exists relational invariance of this suite at the
# identity relation, stretch 1.
#
# STATE. The gap d = x_l - x_f and the two speeds: d' = v_l - v_f, v_f' = a_f, v_l' = a_l
# (three variables per side; the absolute positions do not enter the guards).
#
# THE SAMPLED FORM (the deviations from the source). (1) The right system is sampled at the
# same period as the left with the event guard Safe tested at each switch; the source's
# event-triggered right, whose runs may stop anywhere inside the event domain, is outside this
# suite's models (fixed control interval on both sides, Assumption 1). What is certified is
# dRL's refinement pattern between two sampled controllers: the conservative follower
# (Safe_eps) refines the permissive one (Safe), since Safe_eps implies Safe. (2) The leader's
# acceleration, an arbitrary value in [-B, A] in the source, is here one of {A, -B} per
# cycle (a mode choice on both sides); the witness copies the left's leader. (3) The
# follower's actions are the extremes: accelerate at A under Safe_eps (the source allows any
# value in [-B, A] there), brake at -B from a speed >= 1 (the source's braking run stops at
# v_f = 0), and coast (a = 0) unconditionally, which stands in for the source's stopped-car
# branch and keeps the right model complete; guards are closed where the source's are strict.
# All deviations are stated once here and in the suite table.
#
# PARAMETERS. A = 1, B = 1, eps = 1; speeds in [0, 10]; braking only from a speed >= 1 (a
# full period of braking stays in v >= 0); a Coast action (a = 0) of the follower keeps the
# right model complete (Assumption 1; the leader is complete with its two actions). Modes are
# pairs (follower action, leader action), six per side.
#   Safe_eps (left, follower Accel): d >= v_f^2/(2B) - v_l^2/(2B) + (A/B + 1)(A eps^2/2 + eps v_f),
#                                    i.e. d >= v_f^2/2 - v_l^2/2 + 2 v_f + 1;
#   Safe     (right, follower Accel): d >= v_f^2/2 - v_l^2/2.
# Claim (every left mode): d_L = d_R, v_f_L = v_f_R, v_l_L = v_l_R (two inequalities each).
# Why committed choice is needed (X). The existential mode choice is the tool's default: the
# right hops into the left's mode (follower and leader action) at the start of each window,
# legal because Safe_eps implies Safe under the identity relation, then runs the certified
# joint segment. Without it (RELCERT_NO_CHOICE=1) the right must flow on in whatever admissible
# action pair it holds and the gap or the speeds separate: DECLINED.
# Verdicts (RELCERT_IMPLIED_CUT=1 unless stated, measured 2026-10-26): CERTIFIED; CERTIFIED
# under RELCERT_SYNC=1, RELCERT_NO_PRUNE=1, RELCERT_NO_CUT=1, RELCERT_OPREGION=1 and without
# RELCERT_IMPLIED_CUT; DECLINED under RELCERT_NO_CHOICE=1, RELCERT_SYNC=1 RELCERT_NO_CHOICE=1
# and RELCERT_NO_PRUNE=1 RELCERT_NO_CHOICE=1. Cover: every left mode at lambda 1, budget 1,
# every right mode an admissible start, closed by a hop into the left's action pair. Rows
# identical (--handoff vacuous, 36/36). relcert --wellformed: all six right modes ok (exit).
[problem]
name = drl_lane_control
max_depth = 8
lambda_min = 1.0
