# engine_start_highidle: a turbofan ground start with the FADEC's high-idle schedule selected
# (anti-ice / bleed demand), against the same start with ground idle.
# scenario: controller-change
# mechanisms: R D I (right-only repositioning; mode-dependent rows, uniform rows decline; checked
#   cuts, RELCERT_NO_CUT=1 declines; matrix codes M5 M6 M6+)
#
# System. Core speed N2 in % of maximum, light-off timer t in s. A two-spool turbofan ground start
# (numbers typical of a CFM56-class engine: light-off near 25 % N2, starter cut-out at 50 %, ground
# idle about 62 %), each phase a first-order spool response, the start sequencer re-deciding every
# 1 s. The sequencer's light-off timer t runs in STARTER (t' = 1) and is frozen in every other
# phase; the start is aborted when no light-off has occurred within the 30 s time-out:
#   STARTER   5 <= N2 < 25, t < 30  air starter motoring, toward 30 % (torque limit): 0.1 (30 - N2)
#   LIGHTOFF 25 <= N2 < 50          fuel on and starter assist, toward 55 %:         0.08 (55 - N2)
#   SELF     50 <= N2 < 60          starter cut out, engine accelerates to idle:     0.15 (idle - N2)
#   IDLE     N2 >= 60               idle governor:                                   0.5 (idle - N2)
#   ABORT    N2 < 25, t >= 30       start aborted (starter and fuel off), frozen:    N2' = 0
# Only STARTER declares ABORT, and ABORT is reachable: from every STARTER start whose timer is within
# 1 s of the time-out, the next decision finds t >= 30 below 25 % (installed 2026-10-29; until then
# the model aborted on "N2 falls below 5 %", which no run of the rising starter phases reached, so
# ABORT was a start only).
#
# Right (reference): ground idle, idle = 62 %. Left (deployed): high idle selected, idle = 66 %
# (SELF and IDLE aim at 66). One cause: the idle set point (+4 % N2); the start phases below
# starter cut-out are untouched, as the FADEC schedules them independently of the idle selection.
#
# Property (mode-dependent).
#   STARTER: N2_L <= N2_R and t_R <= t_L. LIGHTOFF: N2_L <= N2_R. The start phases are certified on
#     the ground-idle schedule (starter duty, light-off and EGT limits); the requirement is that
#     high idle leaves them unchanged and that the reference's light-off timer is no later than
#     the deployed's (the reference times out only after the deployed has). Forced by the reachable
#     abort (measured 2026-10-29): a lead of 0.01 % declines in the low rows, a timer slack of
#     0.01 s declines, and the timer row removed declines (a reference timed out at under 25 %
#     against a deployed still motoring, or in LIGHTOFF, would be behind by more than any c).
#   SELF, IDLE, ABORT: N2_L <= N2_R + 4. Requirement: above starter cut-out the deployed may exceed
#     the reference start profile by at most the 4 % idle increment. Tightest 4.00 (3.99 declines).
# Both relations hold up to the reference's re-timing (it may run ahead alone, see R).
# Mode dependence is load-bearing (D): uniform N2_L <= N2_R + 4 declines (the reachable abort) and
# uniform N2_L <= N2_R declines (the idle increment, physical: equilibria 66 against 62, tight at
# 4.00). The handoffs only relax (exact to +4 at LIGHTOFF -> SELF and at STARTER -> ABORT):
# --handoff 9/9 unsat.
#
# Why right-only repositioning (R). From a deployed SELF window (aiming at 66 %) the reference may
# start in LIGHTOFF (aiming at 55 %): the joint segment fails, so the reference runs alone into
# SELF (left frozen); likewise SELF -> IDLE for a deployed IDLE window. RELCERT_SYNC=1 (no right-only
# steps) DECLINES and RELCERT_NO_REPO=1 DECLINES; every cover is at lambda 1, so no S.
# Nothing is pruned (ABORT is entered by a guard, not excluded by a flow): RELCERT_NO_PRUNE=1 and
# RELCERT_NO_CHOICE=1 CERTIFY.
# Cuts (I). The implied contraction atoms (N2 <= 30 in STARTER, N2 <= 55 in LIGHTOFF, N2 <= idle) are
# load-bearing: DECLINED with RELCERT_NO_CUT=1, with RELCERT_NO_IMPLIED_CUT=1 and without
# RELCERT_IMPLIED_CUT.
#
# Domains. 0 <= N2 <= 110 % and t >= 0 s on both sides: the physical range of the core speed (rest
# to the 110 % overspeed limit of the N2 red line) and the sequencer's timer, which only counts up.
# Forward invariant in every phase (every aim in [30, 66], so N2 never leaves [0, 110]; t is frozen
# outside STARTER and runs at 1 /s inside it). Not load-bearing: the domain audit of 2026-10-29
# reverted the earlier 5 <= N2 and t <= 40 (the STARTER floor and a reachable time-out bound) to
# these limits with every verdict and letter unchanged; every bound widened by 20 % of its range
# CERTIFIES. The right guards partition {N2 >= 5} (STARTER and ABORT split N2 < 25 at t = 30; no
# coverage gap); states with N2 < 5 are in no right guard (the start sequence is engaged from the
# starter's minimum motoring speed; RELCERT_OPREGION=1 CERTIFIES, every admitted start lies in some
# right guard); every left mode has a satisfiable start (N2_R = N2_L, t_R = t_L).
#
# Stretch pinned (2026-10-27): lambda_max 1; every cover is at lambda 1 and the requirement is a
# real-time one.
# Verdicts (RELCERT_IMPLIED_CUT=1 unless stated, measured 2026-10-29 on the installed model):
# CERTIFIED (0.4 to 0.6 s); CERTIFIED under RELCERT_NO_PRUNE=1, RELCERT_NO_CHOICE=1,
# RELCERT_NO_PRUNE=1 RELCERT_NO_CHOICE=1, RELCERT_NO_LINEAR_CUT=1, RELCERT_WELLFORMED_STRICT=1,
# RELCERT_OPREGION=1 (every admitted start in some right guard); DECLINED under RELCERT_SYNC=1,
# RELCERT_NO_REPO=1, RELCERT_NO_CUT=1, RELCERT_NO_IMPLIED_CUT=1 and without RELCERT_IMPLIED_CUT.
# Cover: lambda 1, budget 1 in every left mode; admissible STARTER_L [STARTER, LIGHTOFF, SELF, IDLE],
# LIGHTOFF_L [LIGHTOFF, SELF, IDLE], SELF_L [LIGHTOFF, SELF, IDLE] (right-only), IDLE_L [SELF, IDLE]
# (right-only), ABORT_L all five. Nothing pruned. relcert --wellformed: STARTER ok
# (exit->LIGHTOFF,ABORT), LIGHTOFF ok (exit->SELF), SELF ok (exit->IDLE), IDLE ok (invariant),
# ABORT ok (invariant).
[problem]
name = engine_start_highidle
max_depth = 8
lambda_min = 1.0
lambda_max = 1.0
bound_T = 120.0

[Lsys]
state_vars = [n, t]
epsilon = 1.0

[Lsys.mode.STARTER]
ode = n' = smt2:(* 0.1 (- 30 n)); t' = 1.0;
guard = n >= 5.0 and n < 25.0 and t < 30.0
evolve = n >= 0.0 and n <= 110.0 and t >= 0.0
next = [STARTER, LIGHTOFF, ABORT]

[Lsys.mode.LIGHTOFF]
ode = n' = smt2:(* 0.08 (- 55 n)); t' = 0.0;
guard = n >= 25.0 and n < 50.0
evolve = n >= 0.0 and n <= 110.0 and t >= 0.0
next = [LIGHTOFF, SELF]

[Lsys.mode.SELF]
ode = n' = smt2:(* 0.15 (- 66 n)); t' = 0.0;
guard = n >= 50.0 and n < 60.0
evolve = n >= 0.0 and n <= 110.0 and t >= 0.0
next = [SELF, IDLE]

[Lsys.mode.IDLE]
ode = n' = smt2:(* 0.5 (- 66 n)); t' = 0.0;
guard = n >= 60.0
evolve = n >= 0.0 and n <= 110.0 and t >= 0.0
next = [IDLE]

[Lsys.mode.ABORT]
ode = n' = smt2:0.0; t' = 0.0;
guard = n < 25.0 and t >= 30.0
evolve = n >= 0.0 and n <= 110.0 and t >= 0.0
next = [ABORT]

[Rsys]
state_vars = [n, t]
epsilon = 1.0

[Rsys.mode.STARTER]
ode = n' = smt2:(* 0.1 (- 30 n)); t' = 1.0;
guard = n >= 5.0 and n < 25.0 and t < 30.0
evolve = n >= 0.0 and n <= 110.0 and t >= 0.0
next = [STARTER, LIGHTOFF, ABORT]

[Rsys.mode.LIGHTOFF]
ode = n' = smt2:(* 0.08 (- 55 n)); t' = 0.0;
guard = n >= 25.0 and n < 50.0
evolve = n >= 0.0 and n <= 110.0 and t >= 0.0
next = [LIGHTOFF, SELF]

[Rsys.mode.SELF]
ode = n' = smt2:(* 0.15 (- 62 n)); t' = 0.0;
guard = n >= 50.0 and n < 60.0
evolve = n >= 0.0 and n <= 110.0 and t >= 0.0
next = [SELF, IDLE]

[Rsys.mode.IDLE]
ode = n' = smt2:(* 0.5 (- 62 n)); t' = 0.0;
guard = n >= 60.0
evolve = n >= 0.0 and n <= 110.0 and t >= 0.0
next = [IDLE]

[Rsys.mode.ABORT]
ode = n' = smt2:0.0; t' = 0.0;
guard = n < 25.0 and t >= 30.0
evolve = n >= 0.0 and n <= 110.0 and t >= 0.0
next = [ABORT]

[relational_invariant]
STARTER = n[l] <= n[r] + 0.0 and t[r] <= t[l]
LIGHTOFF = n[l] <= n[r] + 0.0
SELF = n[l] <= n[r] + 4.0
IDLE = n[l] <= n[r] + 4.0
ABORT = n[l] <= n[r] + 4.0
