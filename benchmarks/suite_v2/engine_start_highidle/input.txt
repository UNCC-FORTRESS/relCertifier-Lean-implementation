# engine_start_highidle: a turbofan ground start with the FADEC's high-idle schedule selected
# (anti-ice / bleed demand), against the same start with ground idle.
# scenario: controller-change
# mechanisms: R D I (right-only repositioning; mode-dependent rows, uniform rows decline; checked
#   cuts, RELCERT_NO_CUT=1 declines; matrix codes M5 M6 M6+)
#
# System. Core speed N2 in % of maximum, light-off timer t in s, start-air supply pressure p in
# psig at the starter valve. A two-spool turbofan ground start (numbers typical of a CFM56-class
# engine: light-off near 25 % N2, starter cut-out at 50 %, ground idle about 62 %), each phase a
# first-order spool response, the start sequencer re-deciding every 1 s. The supply pressure p is
# set by the bleed source (APU or ground cart) for the whole start and is frozen (p' = 0). The
# sequencer's light-off timer t runs in the starter phases (t' = 1) and is frozen in every other
# phase; the start is aborted when no light-off has occurred within the 30 s time-out:
#   STARTER      5 <= N2 < 25, t < 30, p >= 35  rated supply, motoring toward 30 %:  0.1 (30 - N2)
#   STARTER_LOW  5 <= N2 < 25, t < 30, p < 35   low supply (cold-soaked or loaded APU), torque
#                                               limit reached at 25.5 %:             0.1 (25.5 - N2)
#   LIGHTOFF    25 <= N2 < 50                   fuel on, starter assist, toward 55 %: 0.08 (55 - N2)
#   SELF        50 <= N2 < 60                   starter cut out, to idle:            0.15 (idle - N2)
#   IDLE        N2 >= 60                        idle governor:                       0.5 (idle - N2)
#   ABORT       N2 < 25, t >= 30                start aborted (starter, fuel off):   N2' = 0
# ABORT is reached by ordinary starts (revised 2026-10-29 after review round 4, which found that the
# earlier single-supply model reached ABORT only from STARTER starts whose timer was already near
# 30 s, since a rated start from t = 0 reaches 25 % by 16.1 s). On low supply the start is slow: from
# rest (N2 = 5 %, t = 0) N2 is 24.48 % at t = 30 and the sequencer aborts (a hung start); a start
# from t = 0 lights off within the time-out only from N2 above about 15.5 % (an engine already
# turning). The rated-supply start from rest lights off at 16.1 s.
#
# Right (reference): ground idle, idle = 62 %. Left (deployed): high idle selected, idle = 66 %
# (SELF and IDLE aim at 66). One cause: the idle set point (+4 % N2); the start phases below
# starter cut-out are untouched, as the FADEC schedules them independently of the idle selection.
# Both runs start on the same bleed source (p_L = p_R).
#
# Property (mode-dependent).
#   STARTER, STARTER_LOW: N2_L <= N2_R, t_R <= t_L and p_L = p_R. LIGHTOFF, ABORT: N2_L <= N2_R.
#     The start phases are certified on the ground-idle schedule (starter duty, light-off and EGT
#     limits); the requirement is that high idle leaves them unchanged, that the reference's
#     light-off timer is no later than the deployed's (the reference times out only after the
#     deployed has), and that an aborted deployed start is not above the reference. Forced by the
#     reachable abort (measured 2026-10-29): a lead of 0.01 % declines in each of the STARTER,
#     STARTER_LOW and LIGHTOFF rows, a timer slack of 0.01 s declines in each starter row, and the
#     timer row removed declines in each (on low supply a reference reaching 25 % just at the
#     time-out, as a start from about 15.5 % at t = 0 does, aborts while a deployed 0.01 % ahead
#     lights off and runs to 66 %). ABORT tightest 0.00 (-0.01 declines). The supply equality is
#     load-bearing in the STARTER row (p_L <= p_R + 0.01 declines: a deployed on rated supply
#     against a reference on low supply outruns it).
#   SELF, IDLE: N2_L <= N2_R + 4. Requirement: above starter cut-out the deployed may exceed the
#     reference start profile by at most the 4 % idle increment. Tightest 4.00 (3.99 declines in
#     SELF and in IDLE).
# Both relations hold up to the reference's re-timing (it may run ahead alone, see R).
# Mode dependence is load-bearing (D): uniform N2_L <= N2_R + 4 declines, also with the timer and
# supply rows added (the reachable low-supply abort; it declines with only the STARTER_LOW row
# relaxed to +4), and the uniform starter row declines (the idle increment, physical: equilibria 66
# against 62, tight at 4.00). The handoffs only relax (exact to +4 at LIGHTOFF -> SELF):
# --handoff 12/12 unsat.
#
# Why right-only repositioning (R). From a deployed SELF window (aiming at 66 %) the reference may
# start in LIGHTOFF (aiming at 55 %): the joint segment fails, so the reference runs alone into
# SELF (left frozen); likewise SELF -> IDLE for a deployed IDLE window. RELCERT_SYNC=1 (no right-only
# steps) DECLINES and RELCERT_NO_REPO=1 DECLINES; every cover is at lambda 1, so no S.
# Nothing is pruned (ABORT is entered by a guard, not excluded by a flow): RELCERT_NO_PRUNE=1 and
# RELCERT_NO_CHOICE=1 CERTIFY.
# Cuts (I). The implied contraction atoms (N2 <= 30 in STARTER, N2 <= 25.5 in STARTER_LOW, N2 <= 55
# in LIGHTOFF, N2 <= idle) are load-bearing: DECLINED with RELCERT_NO_CUT=1, with
# RELCERT_NO_IMPLIED_CUT=1 and without RELCERT_IMPLIED_CUT.
#
# Domains. 0 <= N2 <= 110 %, t >= 0 s and 0 <= p <= 60 psig on both sides: the physical range of
# the core speed (rest to the 110 % overspeed limit of the N2 red line), the sequencer's timer,
# which only counts up, and the range of the starter duct pressure transducer. Forward invariant in
# every phase (every aim in [25.5, 66], so N2 never leaves [0, 110]; t is frozen outside the
# starter phases and runs at 1 /s inside them; p is frozen). Not load-bearing: every bound widened
# by 20 % of its range CERTIFIES, and the p bounds removed CERTIFY. The right guards partition
# {N2 >= 5} (STARTER and STARTER_LOW split the starter region at p = 35, and both against ABORT at
# t = 30; no coverage gap); states with N2 < 5 are in no right guard (the start sequence is engaged
# from the starter's minimum motoring speed; RELCERT_OPREGION=1 CERTIFIES; every admitted start lies
# in some right guard except in ABORT_L, whose row admits a reference below 5 % with its timer under
# 30 s, a state in no right guard: such a pair has no reference run and is not a case of the claim);
# every left mode has a satisfiable start (N2_R = N2_L, t_R = t_L, p_R = p_L).
#
# Stretch pinned (2026-10-27): lambda_max 1; every cover is at lambda 1 and the requirement is a
# real-time one.
# Verdicts (RELCERT_IMPLIED_CUT=1 unless stated, measured 2026-10-29 on the installed model):
# CERTIFIED (0.8 to 1.1 s); CERTIFIED under RELCERT_NO_PRUNE=1, RELCERT_NO_CHOICE=1,
# RELCERT_NO_PRUNE=1 RELCERT_NO_CHOICE=1, RELCERT_NO_LINEAR_CUT=1, RELCERT_NO_PAIR_STRETCH=1,
# RELCERT_WELLFORMED_STRICT=1, RELCERT_OPREGION=1 (every admitted start in some right guard but in ABORT_L, above);
# DECLINED under RELCERT_SYNC=1, RELCERT_NO_REPO=1, RELCERT_NO_CUT=1, RELCERT_NO_IMPLIED_CUT=1 and
# without RELCERT_IMPLIED_CUT.
# Cover: lambda 1, budget 1 in every left mode; admissible STARTER_L [STARTER, LIGHTOFF, SELF, IDLE],
# STARTER_LOW_L [STARTER_LOW, LIGHTOFF, SELF, IDLE], LIGHTOFF_L [LIGHTOFF, SELF, IDLE], SELF_L
# [LIGHTOFF, SELF, IDLE] (right-only), IDLE_L [SELF, IDLE] (right-only), ABORT_L all six. Nothing
# pruned. relcert --wellformed: STARTER ok (exit->LIGHTOFF,ABORT), STARTER_LOW ok
# (exit->LIGHTOFF,ABORT), LIGHTOFF ok (exit->SELF), SELF ok (exit->IDLE), IDLE ok (invariant),
# ABORT ok (invariant).
[problem]
name = engine_start_highidle
max_depth = 8
lambda_min = 1.0
lambda_max = 1.0
bound_T = 120.0

[Lsys]
state_vars = [n, t, p]
epsilon = 1.0

[Lsys.mode.STARTER]
ode = n' = smt2:(* 0.1 (- 30 n)); t' = 1.0; p' = 0.0;
guard = n >= 5.0 and n < 25.0 and t < 30.0 and p >= 35.0
evolve = n >= 0.0 and n <= 110.0 and t >= 0.0 and p >= 0.0 and p <= 60.0
next = [STARTER, LIGHTOFF, ABORT]

[Lsys.mode.STARTER_LOW]
ode = n' = smt2:(* 0.1 (- 25.5 n)); t' = 1.0; p' = 0.0;

[Lsys.mode.LIGHTOFF]

guard = n >= 25.0 and n < 50.0
evolve = n >= 0.0 and n <= 110.0 and t >= 0.0 and p >= 0.0 and p <= 60.0
next = [LIGHTOFF, SELF]

[Lsys.mode.SELF]

evolve = n >= 0.0 and n <= 110.0 and t >= 0.0 and p >= 0.0 and p <= 60.0

[Lsys.mode.IDLE]

[Lsys.mode.ABORT]

guard = n < 25.0 and t >= 30.0
evolve = n >= 0.0 and n <= 110.0 and t >= 0.0 and p >= 0.0 and p <= 60.0
next = [ABORT]
