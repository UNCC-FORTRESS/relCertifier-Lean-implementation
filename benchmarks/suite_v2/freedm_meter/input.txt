# freedm_meter: initial-state nondeducibility of a battery level through the grid meter
# (sampled, single-transformer form of the FREEDM case study of hybrid-dynamic information flow).
# scenario: information-flow
# mechanisms: X (committed successor subsets: the second run commits to the mode that copies
#   the first run's meter, chosen per window)
#
# SOURCE. Bohrer and Platzer, "A hybrid, dynamic logic for hybrid-dynamic information flow"
# (LICS 2018), the FREEDM model of Figure 2 (Section 3), nondeducibility (its Definition 5),
# the leak of batI (Section 8, Proposition 10) and the security of batS (Section 9,
# Proposition 11): a FREEDM microgrid transformer serves a demand d from a
# renewable source r, its battery B, or the macrogrid; the battery level is private, the grid
# draw gr and time are public. Nondeducibility: for every run from a state and every other
# private battery level, a run from the other level with the same public values exists. The
# deterministic controller batI (battery while B < Bmax, grid otherwise) leaks B = Bmax; the
# controller batS, whose source choice is free, is proved secure because the grid branch is
# always available and the second run compensates with its own demand and renewable inputs.
#
# THE FORM HERE (the deviations from the source, each a modelling choice stated once).
# (1) The public quantity is the utility METER, the cumulative grid energy E (E' = d - r on the
#     grid, E' = 0 on the battery), instead of the instantaneous draw gr, which the source
#     resets by assignment at every cycle; the draw is the meter's derivative, so equal meters at
#     all times are equal draws. (2) One transformer, no power migration: with migration the
#     second run's compensation depends on the migrated power, which finite inputs cannot track.
# (3) Demand d in {0, 1, 2} and renewable r in {0, 1} per cycle, a mode choice on both sides
#     (reals in the source). Both sides run batS, whose battery branch is guarded by the source's
#     test "(B < Bmax) or (n > 0 and B > 0)" (the battery can still charge or still discharge) and
#     whose grid branch is free: here a battery mode is enabled when one period of it keeps the
#     level in [0, Bmax] (Bmax = 10), the sampled form of that test (it also admits a zero-net
#     battery cycle at a full battery, which the source's test does not), and a grid mode
#     always. The evolve domain adds the capacity B <= Bmax to the source's B >= 0; the meter E
#     has no domain (it may decrease when a surplus is sold). The literal charge test B < Bmax
#     in place of "one period keeps the level in [0, Bmax]" also CERTIFIES (relcert --wellformed
#     then reports one right mode, BatD0R1, UNKNOWN, not blocking; measured 2026-10-28).
# (4) The source is not time-triggered: its plant carries no t <= eps, the ODE may run for any
#     duration and the controller runs at every cycle end. Both sides here are sampled at period
#     1 (the left may switch earlier). This is harmless: every mode's flow is autonomous with
#     constant inputs, so a source cycle of any duration is the same run as re-choosing the same
#     mode at every period, and equal meters at every instant from equal starts are equal draws
#     almost everywhere, the source's agreement on gr at every cycle end.
# PROPERTY. The suite's Definition 1 (the source's nondeducibility) at E_L = E_R (two
# inequalities), every pair of battery levels an admissible start: the secret B is
# unconstrained on either side. Witness: the right copies the left's source and inputs when its
# battery allows, otherwise draws from the grid with d = r
# (zero net draw). Existential mode choice (the tool's default): the right commits to one mode.
# Why committed choice is needed (X): the witness mode depends on the second run's own battery
# level, so the right must choose it; without the choice (RELCERT_NO_CHOICE=1) the right must
# flow on in whatever admissible mode it holds at the window start, and the meters separate:
# DECLINED.
# The leaky controller batI is benchmarks/negative/freedm_meter_leaky (expected DECLINED).
# Verdicts (RELCERT_IMPLIED_CUT=1 unless stated, measured 2026-10-26, re-measured 2026-10-28 on
# branch benchmark-fixes, unchanged): CERTIFIED (about 2.5 s); CERTIFIED under RELCERT_SYNC=1,
# RELCERT_NO_PRUNE=1, RELCERT_NO_CUT=1, RELCERT_NO_IMPLIED_CUT=1, RELCERT_NO_LINEAR_CUT=1,
# RELCERT_NO_PAIR_STRETCH=1, RELCERT_NO_REPO=1, RELCERT_OPREGION=1, RELCERT_WELLFORMED_STRICT=1
# and without RELCERT_IMPLIED_CUT; DECLINED under RELCERT_NO_CHOICE=1, RELCERT_SYNC=1 RELCERT_NO_CHOICE=1
# and RELCERT_NO_PRUNE=1 RELCERT_NO_CHOICE=1. Rows identical (--handoff vacuous, 144/144).
# relcert --wellformed: all 12 right modes ok (8 invariant, 4 exit).
