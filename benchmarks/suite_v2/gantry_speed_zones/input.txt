# match_multi_rate: a synthetic rate-ratio exhibit: a left system cycling through three speed
# bands at different rates against one reference drive loop, each band matched at its own stretch.
# scenario: model-refinement
# mechanisms: S M (a different time stretch per left mode, RELCERT_SYNC=1 declines; multi-step
#   covers of 3 and 2 right cycles, matrix codes M1 M2)
#
# What it is. A synthetic exhibit, not a physical plant: v is a normalized speed (fraction of the
# cruise speed 1.0, unitless), s the distance it integrates (s' = v), time in control periods
# (epsilon 0.3 on both sides). It isolates heterogeneous rate matching: one left cycle visits
# modes whose rates differ from the single reference rate by different integer ratios.
#   Right (reference): one DRIVE loop, v' = 1 (1 - v), guard 0.2 <= v <= 1.0 (the band reaches
#     the equilibrium 1.0, so DRIVE keeps its own guard), self-loop; plus a STALL fallback below
#     the drive floor 0.2 (drive cut, v' = -2 v, s keeps integrating; sink).
#   Left: the same loop toward 1.0 at three gains by speed band, FAST 3 on [0.2, 0.5), MEDIUM 2
#     on [0.5, 0.7), SLOW 1 on [0.7, 0.95], and a RESET dip v' = 4 (0.1 - v) on [0.95, 1.0) that
#     takes v back to the FAST band (FAST -> MEDIUM -> SLOW -> RESET -> FAST). Each band's
#     successors are itself and the next band only; a cycle that overshoots the next band ends
#     the run (the left is a test pattern, not a complete controller).
# The single difference per mode is the rate ratio 3 / 2 / 1 against the reference's gain 1.
#
# Property (every left mode): v_L <= v_R, the left never runs faster than the reference (no
# constant). Not implied by the domains. RESET only lowers v_L, so it keeps the row trivially.
#
# Why the stretch is needed (S, M). In FAST and MEDIUM the left relaxes 3 and 2 times faster
# than DRIVE; the cover matches FAST at lambda = 3 with budget 3 and MEDIUM at lambda = 2 with
# budget 2 (3 and 2 right cycles per left cycle), SLOW and RESET at lambda = 1 with budget 1.
# FAST needs lambda >= 3 on the tool's grid (with lambda_max = 2.9 the file DECLINES), and
# RELCERT_SYNC=1 DECLINES.
# Fallback. DRIVE -> STALL is declared and would break the row (the reference speed decays while
# the left accelerates), but DRIVE's flow points away from the 0.2 floor (v' = 0.8 > 0 there), so
# the edge is pruned by a non-connection certificate; STALL is no admissible start (every left
# guard has v_L >= 0.2 and the row gives v_R >= v_L). Pruning and the committed choice each close
# this fallback: RELCERT_NO_PRUNE=1 alone certifies, only RELCERT_NO_PRUNE=1 RELCERT_NO_CHOICE=1
# declines (no P).
#
# Domains (both sides): s >= 0, 0 <= v <= 1.15 (the normalized speed range with a margin above
# cruise). Coverage: the right guards cover [0, 1.0]; v in (1.0, 1.15] is in no right guard and
# is never reached (every left mode starts at v <= 1 and relaxes toward 1.0 or below; DRIVE from
# v <= 1 stays <= 1). Every left mode has a satisfiable start (v_L = v_R in its band).
#
# Verdicts (RELCERT_IMPLIED_CUT=1 unless stated): CERTIFIED; CERTIFIED under RELCERT_NO_CHOICE=1,
# RELCERT_NO_PRUNE=1, RELCERT_NO_CUT=1, without RELCERT_IMPLIED_CUT, NO_IMPLIED_CUT, NO_LINEAR_CUT
# and the operating region; DECLINED under RELCERT_SYNC=1, SYNC+NO_CHOICE and NO_PRUNE+NO_CHOICE.
# Covers: FAST lambda 3 budget 3, MEDIUM lambda 2 budget 2, SLOW and RESET lambda 1 budget 1,
# admissible start DRIVE; pruned DRIVE -> STALL; rows identical (--handoff 8/8 vacuous).
[problem]
name = match_multi_rate
max_depth = 16
lambda_min = 1.0
lambda_max = 6.0
bound_T = 2.0
[Lsys]
state_vars = [v, s]
epsilon = 0.3
[Lsys.mode.FAST]
ode = v' = smt2:(* 3 (- 1.0 v)); s' = v;
guard = v >= 0.2 and v < 0.5
evolve = s >= 0.0 and v >= 0.0 and v <= 1.15
next = [MEDIUM, FAST]
[Lsys.mode.MEDIUM]
ode = v' = smt2:(* 2 (- 1.0 v)); s' = v;
guard = v >= 0.5 and v < 0.7
evolve = s >= 0.0 and v >= 0.0 and v <= 1.15
next = [SLOW, MEDIUM]
[Lsys.mode.SLOW]
ode = v' = smt2:(* 1 (- 1.0 v)); s' = v;
guard = v >= 0.7 and v <= 0.95
evolve = s >= 0.0 and v >= 0.0 and v <= 1.15
next = [RESET, SLOW]
[Lsys.mode.RESET]
ode = v' = smt2:(* 4 (- 0.1 v)); s' = v;
guard = v >= 0.95 and v < 1.0
evolve = s >= 0.0 and v >= 0.0 and v <= 1.15
next = [FAST, RESET]
[Rsys]
state_vars = [v, s]
epsilon = 0.3
[Rsys.mode.DRIVE]
ode = v' = smt2:(* 1 (- 1.0 v)); s' = v;
# The guard reaches the equilibrium 1.0, so DRIVE keeps its own guard (contract-inside); the
# envelope v <= 1.15 strictly contains it.
guard = v >= 0.2 and v <= 1.0
evolve = s >= 0.0 and v >= 0.0 and v <= 1.15
next = [DRIVE, STALL]
# STALL: the stall fallback (see header). Drive cut: v decays, s keeps integrating. Sink.
[Rsys.mode.STALL]
ode = v' = smt2:(* -2 v); s' = v;
guard = v < 0.2
evolve = s >= 0.0 and v >= 0.0 and v <= 1.15
next = [STALL]
[relational_invariant]
FAST = v[l] <= v[r]
MEDIUM = v[l] <= v[r]
SLOW = v[l] <= v[r]
RESET = v[l] <= v[r]
