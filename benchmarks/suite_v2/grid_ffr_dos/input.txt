# grid_ffr_dos: an island grid's fast frequency response (FFR) under a denial-of-service attack on
# the FFR command link, against the same grid with the command delivered every cycle.
# scenario: dos-attack
# mechanisms: M P (multi-cycle matching: one attacked cycle against three nominal cycles;
#   non-connection pruning of the under-frequency trip, RELCERT_NO_PRUNE=1 declines; matrix codes
#   M2 M4)
#
# System. Frequency deviation x in Hz (50 Hz base), time in s. Aggregated swing equation of a small
# island grid with instantaneous primary droop: inertia H = 4 s, droop 5 %, load damping 1, i.e.
#   x' = (50 / 2H) (0.1 a - d) - (21 / 2H) x = 6.25 (0.1 a - d) - 2.625 x,
# where d (pu, constant over the event) is the lost infeed, d in [0.05, 0.3] (0.3 = the largest unit,
# the reference incident), and a in [0, 1] is the activated share of a 0.1 pu battery FFR. Without
# FFR the frequency settles at -d / 0.42, between -0.12 and -0.71 Hz.
# Supervisor (identical logic on both sides):
#   NORMAL  x > -0.4 and a <= 0      FFR idle, a' = 0
#   FFR     x - 2a <= -0.4, x >= -1.5 FFR triggered at 49.6 Hz and latched: the battery ramps to
#                                     full power with time constant 0.2 s, a' = 5 (1 - a); the
#                                     release line -0.4 + 2a Hz rises above the model's range once
#                                     a > 0.7, so FFR never drops out (the guard is kept by the flow)
#   TRIP    x < -1.5                  generator under-frequency protection (48.5 Hz): the units trip
#                                     and the frequency collapses toward 47.5 Hz, x' = 0.5 (-2.5 - x)
#                                     (latched). NORMAL and FFR declare TRIP.
#
# Right (nominal): the FFR command is delivered every cycle, epsilon 0.1 s.
# Left (attacked): a DoS drops two of every three commands on the FFR link, so each supervisor
# decision is held for up to 0.3 s (epsilon 0.3 s, lambda 1: one attacked cycle against three
# nominal cycles). One cause: the hold time; same grid, same thresholds, same battery. The left
# model has no TRIP mode: x >= -1.5 is forward invariant under both deployed modes for every legal
# d (the flows at -1.5 Hz are >= 2.06 Hz/s upward) and every deployed start lies above it, so the
# deployed's trip relay can never fire; the rows then need no vacuous trip row.
#
# Property (both left modes): x_L <= x_R, x_R <= x_L + 0.24 a_R, a_L <= a_R, d_L = d_R (the same
# incident). Reading: the attacked island never activates its FFR before the nominal one and never
# runs above it; while the nominal FFR is idle (a_R = 0) the two frequencies agree exactly, and once
# it activates the attacked frequency is at most 0.24 a_R Hz below the nominal one.
# Requirement (FFR-loss margin): the attack may cost the island at most the frequency support of the
# FFR itself, P_ffr / (droop + damping) = 0.1 / 0.42 = 0.238 Hz, rounded up to 0.24 Hz. This is the
# margin the island already carries for an unavailable FFR: its under-frequency protection (the
# 48.5 Hz generator trip) is cleared by the reference incident with no FFR at all (the no-FFR
# frequency settles monotonically at -0.71 Hz), so a deviation from the nominal island within the
# FFR's own support keeps the attacked island inside the protection plan for every incident in range.
# Tightest 0.24 (0.23 declines). Not implied by the domains (a_L <= a_R and the exact agreement at
# a_R = 0 constrain states the domains admit).
# The bound also holds for other deployed behaviour (measured 2026-10-27): a 1 s hold (left epsilon
# 1.0) CERTIFIES at 0.24, and so does a deployed FFR that never activates (left FFR with a' = 0);
# the 0.24 a_R band is the FFR-loss margin, which covers any delay of the FFR. Without the attack
# (left epsilon 0.1 s) the exact claim x_L = x_R, a_L = a_R CERTIFIES; with the 0.3 s hold it
# DECLINES, so the attack's effect is visible as the 0.24 a_R band.
# Why pruning is needed (P). NORMAL -> TRIP and FFR -> TRIP are pruned by non-connection
# certificates (at -1.5 Hz both flows point up for every legal d). Without pruning, after a nominal
# NORMAL segment inside an attacked window the cover must also take TRIP, and (NORMAL_L, TRIP_R)
# separates the frequencies. The existential choice cannot drop TRIP there: for d > 0.168 the NORMAL
# equilibrium lies below its own -0.4 Hz floor, so no checked cut bounds x below at a segment end,
# and (with a_R = 0) the rows tie x_R to the uncut x_L. Window (measured 2026-10-27): P holds for
# every largest incident d_max in (0.168, 0.63) pu (0.168 = 0.42 x 0.4: NORMAL holds above 49.6 Hz,
# RELCERT_NO_PRUNE=1 certifies at d_max = 0.15 and declines at 0.17; 0.63 = 0.42 x 1.5: beyond it
# the trip is reachable and the file declines, measured CERTIFIED at 0.62 and DECLINED at 0.65).
# The stated range (largest unit 0.3 pu) is the design condition of FFR itself: large enough to
# need the FFR, too small to reach the generator trip.
# Multi-cycle matching (M): budget 3, joint steps through NORMAL and FFR.
#
# Domains. -2.5 <= x <= 1.0 Hz, 0.05 <= d <= 0.3, 0 <= a <= 1 on both sides: forward invariant in
# every mode (at x = 1.0 every flow is negative, at -2.5 NORMAL and FFR rise and TRIP rests). Coverage
# gap of the right guards: states with a > 0 and x > 2a - 0.4 (a partly ramped FFR above its release
# line) lie in no right guard; they are unreachable (a > 0 only inside FFR, whose guard its flow
# keeps). RELCERT_OPREGION=1 reports that the rows admit such starts for both left modes (a reference
# with a_R > 0 above the line); they are outside the right's operating region and excluded by
# Theorem 3's premise. Every left mode has a satisfiable start (x_R = x_L, a_R = a_L).
#
# Verdicts (RELCERT_IMPLIED_CUT=1 unless stated, measured 2026-10-27 on branch benchmark-fixes):
# CERTIFIED; CERTIFIED under RELCERT_SYNC=1, RELCERT_NO_CHOICE=1, SYNC+NO_CHOICE, RELCERT_NO_CUT=1,
# RELCERT_NO_IMPLIED_CUT=1, RELCERT_NO_LINEAR_CUT=1, RELCERT_NO_REPO=1, RELCERT_NO_PAIR_STRETCH=1,
# without RELCERT_IMPLIED_CUT, RELCERT_OPREGION=1 (it reports admitted starts outside every right
# guard for both left modes, see Domains) and RELCERT_WELLFORMED_STRICT=1; DECLINED under
# RELCERT_NO_PRUNE=1 and NO_PRUNE+NO_CHOICE. Cover: lambda 1, budget 3; NORMAL_L admissible
# [NORMAL, FFR], FFR_L [FFR]; joint segments only. Pruned NORMAL->TRIP, FFR->TRIP. Rows identical
# (--handoff vacuous, 3/3). relcert --wellformed (both clauses): NORMAL ok (exit->FFR), FFR ok
# (invariant), TRIP ok (invariant), 0 UNKNOWN, 0 BLOCKING. Letters: M P.
[problem]
name = grid_ffr_dos
max_depth = 8
lambda_min = 1.0
lambda_max = 1.0
bound_T = 10.0

[Lsys]
state_vars = [x, d, a]
epsilon = 0.3

[Lsys.mode.NORMAL]
ode = x' = smt2:(- (* 6.25 (- (* 0.1 a) d)) (* 2.625 x)); d' = smt2:0.0; a' = smt2:0.0;
guard = x > -0.4 and a <= 0.0 and x >= -2.5 and x <= 1.0 and d >= 0.05 and d <= 0.3 and a >= 0.0 and a <= 1.0
evolve = x >= -2.5 and x <= 1.0 and d >= 0.05 and d <= 0.3 and a >= 0.0 and a <= 1.0
next = [NORMAL, FFR]

[Lsys.mode.FFR]
ode = x' = smt2:(- (* 6.25 (- (* 0.1 a) d)) (* 2.625 x)); d' = smt2:0.0; a' = smt2:(* 5 (- 1 a));
guard = x - 2.0*a <= -0.4 and x >= -1.5 and x >= -2.5 and x <= 1.0 and d >= 0.05 and d <= 0.3 and a >= 0.0 and a <= 1.0
evolve = x >= -2.5 and x <= 1.0 and d >= 0.05 and d <= 0.3 and a >= 0.0 and a <= 1.0
next = [FFR]

[Rsys]
state_vars = [x, d, a]
epsilon = 0.1

[Rsys.mode.NORMAL]
ode = x' = smt2:(- (* 6.25 (- (* 0.1 a) d)) (* 2.625 x)); d' = smt2:0.0; a' = smt2:0.0;
guard = x > -0.4 and a <= 0.0 and x >= -2.5 and x <= 1.0 and d >= 0.05 and d <= 0.3 and a >= 0.0 and a <= 1.0
evolve = x >= -2.5 and x <= 1.0 and d >= 0.05 and d <= 0.3 and a >= 0.0 and a <= 1.0
next = [NORMAL, FFR, TRIP]

[Rsys.mode.FFR]
ode = x' = smt2:(- (* 6.25 (- (* 0.1 a) d)) (* 2.625 x)); d' = smt2:0.0; a' = smt2:(* 5 (- 1 a));
guard = x - 2.0*a <= -0.4 and x >= -1.5 and x >= -2.5 and x <= 1.0 and d >= 0.05 and d <= 0.3 and a >= 0.0 and a <= 1.0
evolve = x >= -2.5 and x <= 1.0 and d >= 0.05 and d <= 0.3 and a >= 0.0 and a <= 1.0
next = [FFR, TRIP]

[Rsys.mode.TRIP]
ode = x' = smt2:(* 0.5 (- (- 2.5) x)); d' = smt2:0.0; a' = smt2:0.0;
guard = x < -1.5 and x >= -2.5 and x <= 1.0 and d >= 0.05 and d <= 0.3 and a >= 0.0 and a <= 1.0
evolve = x >= -2.5 and x <= 1.0 and d >= 0.05 and d <= 0.3 and a >= 0.0 and a <= 1.0
next = [TRIP]

[relational_invariant]
NORMAL = smt2:(and (<= L_x R_x) (<= R_x (+ L_x (* 0.24 R_a))) (<= L_a R_a) (<= L_d R_d) (<= R_d L_d))
FFR = smt2:(and (<= L_x R_x) (<= R_x (+ L_x (* 0.24 R_a))) (<= L_a R_a) (<= L_d R_d) (<= R_d L_d))
