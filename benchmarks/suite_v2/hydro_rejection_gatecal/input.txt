# hydro_rejection_gatecal: a hydro generating unit whose gate-position transducer was recalibrated
# 2 % of stroke low after maintenance, against the commissioned unit, in a load-rejection test: on
# the grid the requirement is on power, after the breaker opens it is on speed.
# scenario: degraded-sensor
# mechanisms: D (mode-dependent rows: on the grid the two speeds are the shared grid frequency and
#   the row keeps them equal, after the rejection each unit's speed is its own and the row bounds
#   their difference; every uniform row declines at the requirement; matrix code M5)
#
# System (both sides). Procedure clock t in s (the test sequencer's), wicket-gate opening g in
# per unit of stroke, speed deviation w in per unit of rated speed; the digital governor re-decides
# every 0.1 s (epsilon 0.1 on both sides). Gate servomotor effective time constant 4 s, mechanical
# starting time T_m = 8 s, turbine self-regulation 1 pu torque per pu speed, speed-no-load gate
# 0.1, permanent droop 5 % (the primary frequency response every synchronized unit must provide).
#   ONGRID  t < 20  synchronized: the speed is the grid frequency, constant over the test,
#                   |w| <= 0.004 (the synchronous area's maximum steady-state deviation, 0.2 Hz
#                   at 50 Hz), w' = 0; the governor holds the 0.85 load reference with droop:
#                   g' = (0.85 - g_meas - w / 0.05) / 4
#   REJECT  t >= 20 the breaker is opened (the test): the governor drives the gate to the
#                   speed-no-load position, g' = (0.1 - g_meas) / 4, and the unloaded unit
#                   accelerates on the excess gate, w' = (g - 0.1 - w) / 8
# with t' = 1 in both. ONGRID -> [ONGRID, REJECT], REJECT -> [REJECT] (re-synchronization and
# the later speed-no-load regulation are not modeled).
# Right (reference): the commissioned unit, g_meas = g.
# Left (deployed): the same unit after maintenance; its gate transducer reads 0.02 of stroke low,
# g_meas = g - 0.02, so its gate loop sits 0.02 more open in both modes (on the grid toward
# 0.87 - 20 w, after the rejection toward 0.12). The transducer offset is the only difference
# (same governor, settings, turbine, grid and test timing).
#
# Property (mode-dependent).
#   ONGRID: t_L = t_R, w_L = w_R, |g_L - g_R| <= 0.027.
#   REJECT: t_L = t_R, |w_L - w_R| <= 0.09, |g_L - g_R| <= 0.027.
# Requirements. Power: the plant's dispatch tolerance, +-3 % of rated output; with power
# proportional to the gate above no-load, P = (g - 0.1) / 0.9, that is +-0.027 of stroke. Speed:
# the unit's overspeed protection is set at 1.30 pu; the commissioned rejection peaks at 1.2055 pu
# (simulated from every on-grid start, the highest from w = -0.004), so the deployed speed may
# exceed the commissioned speed trajectory by at most 0.0945, rounded down to 0.09. On the grid
# the two runs see the same grid frequency (w_L = w_R, the comparison's premise, as a shared
# inflow would be); after the breaker opens the speed is no longer the grid's. The REJECT gate row
# is a stated strengthening (the speed is driven by the gate; without it the file DECLINES).
# Tightest: gate 0.02 (0.019 declines) = the transducer offset; speed 0.02 with the gate at 0.02
# (0.019 declines; the speed row needs a gate bound no larger than itself, since the speed gap is
# driven by the gate gap through the unit self-regulation of 1 pu); keyed rows certify for every
# gate tolerance in [0.02, 0.09] at speed 0.09. Not implied by the domains (they allow a gate gap
# of 1 and a speed gap of 2). Simulated: the deployed rejection peaks 0.0101 pu above the
# commissioned one and settles 0.02 pu above it (its no-load gate is 0.02 more open).
#
# Why the rows must differ (D). Uniform rows with exact speeds (the ONGRID rows in both modes)
# DECLINE at every gate tolerance up to 1 (after the rejection the deployed unit, 0.02 more open,
# runs faster: the exact speed row is false). Uniform rows with the speed band (the REJECT rows in
# both modes) DECLINE at the requirement and at every gate tolerance with the 0.09 speed band: on
# the grid the 5 % droop turns a speed gap s into a gate gap 20 s, so the on-grid gate row needs a
# tolerance of at least 0.02 + 20 x 0.008 = 0.18 (the ONGRID mode facts bound each speed by 0.004),
# while the REJECT speed row needs the gate tolerance below the speed tolerance. The smallest
# uniform band that certifies is 0.18 on both rows (0.17 declines): six times the power
# requirement, twice the speed requirement. So no uniform row meets the requirement; the keyed
# rows do. The handoff ONGRID -> REJECT relaxes w_L = w_R to the band (--handoff 3/3 unsat). This
# is not molding_pack_checkring's gate-freeze drop: here the dropped conjunct is an exact equality
# that the shared grid imposes and the droop feedback needs, and the requirement itself switches
# from power to speed. The D needs the droop coupling: with no frequency response (droop term
# removed) the uniform speed band certifies at the requirement (measured).
# How the bound depends on the cause (measured, tightest gate tolerance with the speed at 0.09):
# offset 0: the exact uniform claim (all constants 0) CERTIFIES, nothing mode-dependent; 0.01:
# 0.01; 0.02 (this file): 0.02; 0.03: 0.03, and the file DECLINES at the requirement (+-3 % of
# rated power tolerates an offset below 0.027 of stroke); 0.05: 0.05. Law dependence: an arbitrary
# deployed mode schedule (every left guard the clock domain, each mode a successor of the other)
# DECLINES.
#
# Domains. t >= 0 s (the sequencer clock, forward invariant); g in [0, 1] (closed to fully open,
# the servomotor's stroke limits; from every ONGRID start the gate relaxes toward 0.77..0.95, after
# the rejection toward 0.1 resp. 0.12, inside); w in [-1, 1] pu (standstill to twice rated speed,
# below the runaway speed; in REJECT w' < 0 at w = 1 and > 0 at w = -1, on the grid w is
# constant). The right guards partition the clock except synchronized states with |w| > 0.004
# (t < 20): unreachable, the grid holds the speed in its band (RELCERT_OPREGION=1 CERTIFIES).
# Every left mode has a satisfiable start (equal states).
#
# Verdicts (RELCERT_IMPLIED_CUT=1 unless stated, measured 2026-10-27 on branch benchmark-fixes): CERTIFIED
# (0.35 s); CERTIFIED under RELCERT_SYNC=1, RELCERT_NO_PRUNE=1, RELCERT_NO_CHOICE=1,
# NO_PRUNE+NO_CHOICE, SYNC+NO_CHOICE, RELCERT_NO_CUT=1, RELCERT_NO_IMPLIED_CUT=1,
# RELCERT_NO_LINEAR_CUT=1, RELCERT_NO_PAIR_STRETCH=1, without RELCERT_IMPLIED_CUT,
# RELCERT_OPREGION=1 and RELCERT_WELLFORMED_STRICT=1. Cover: both left modes at lambda 1, budget
# 1, admissible start the same mode, joint segments only. Nothing pruned. relcert --wellformed:
# ONGRID ok (exit->REJECT), REJECT ok (invariant), 0 UNKNOWN, 0 BLOCKING. Letters: D.
[problem]
name = hydro_rejection_gatecal
max_depth = 8
lambda_min = 1.0
lambda_max = 1.0
bound_T = 60.0

[Lsys]
state_vars = [t, g, w]
epsilon = 0.1

[Lsys.mode.ONGRID]
ode = t' = 1.0; g' = smt2:(* 0.25 (- (- 0.87 g) (* 20.0 w))); w' = 0.0;
guard = t < 20.0 and w >= -0.004 and w <= 0.004 and t >= 0.0 and g >= 0.0 and g <= 1.0 and w >= -1.0 and w <= 1.0
evolve = t >= 0.0 and g >= 0.0 and g <= 1.0 and w >= -1.0 and w <= 1.0
next = [ONGRID, REJECT]

[Lsys.mode.REJECT]
ode = t' = 1.0; g' = smt2:(* 0.25 (- 0.12 g)); w' = smt2:(* 0.125 (- (- g 0.1) w));
guard = t >= 20.0 and t >= 0.0 and g >= 0.0 and g <= 1.0 and w >= -1.0 and w <= 1.0
evolve = t >= 0.0 and g >= 0.0 and g <= 1.0 and w >= -1.0 and w <= 1.0
next = [REJECT]

[Rsys]
state_vars = [t, g, w]
epsilon = 0.1

[Rsys.mode.ONGRID]
ode = t' = 1.0; g' = smt2:(* 0.25 (- (- 0.85 g) (* 20.0 w))); w' = 0.0;
guard = t < 20.0 and w >= -0.004 and w <= 0.004 and t >= 0.0 and g >= 0.0 and g <= 1.0 and w >= -1.0 and w <= 1.0
evolve = t >= 0.0 and g >= 0.0 and g <= 1.0 and w >= -1.0 and w <= 1.0
next = [ONGRID, REJECT]

[Rsys.mode.REJECT]
ode = t' = 1.0; g' = smt2:(* 0.25 (- 0.1 g)); w' = smt2:(* 0.125 (- (- g 0.1) w));
guard = t >= 20.0 and t >= 0.0 and g >= 0.0 and g <= 1.0 and w >= -1.0 and w <= 1.0
evolve = t >= 0.0 and g >= 0.0 and g <= 1.0 and w >= -1.0 and w <= 1.0
next = [REJECT]

[relational_invariant]
ONGRID = t[l] <= t[r] and t[r] <= t[l] and w[l] <= w[r] and w[r] <= w[l] and g[r] <= g[l] + 0.027 and g[l] <= g[r] + 0.027
REJECT = t[l] <= t[r] and t[r] <= t[l] and w[r] <= w[l] + 0.07 and w[l] <= w[r] + 0.07 and g[r] <= g[l] + 0.027 and g[l] <= g[r] + 0.027
