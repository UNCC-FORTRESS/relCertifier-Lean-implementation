# lit_csf21_vehicle_thermo: robustness of a car's high-integrity state (distance to the obstacle,
# velocity) when its interior-temperature sensor is attacked (the vehicle with interior
# temperature control of the relational analysis of sensor attacks).
# scenario: sensor-attack
# mechanisms: X (committed successor subsets: the genuine car hops into the attacked car's action,
#   with its own thermostat setting, at the start of every window)
#
# SOURCE. Xiang, Fulton, Chong, "Relational analysis of sensor attacks on cyber-physical
# systems", CSF 2021 (arXiv 2106.01850): the car of Fig. 4 with the interior temperature control
# of Fig. 6 (Sec. III-C(b), "Robustness of High-Integrity State"), proved in Sec. V by the
# interleaved composition of its canonical form (Figs. 7-8, KeYmaera X). Car d' = -v, v' = a,
# temp' = thermo, t' = 1 & (v >= 0 and t <= eps); accel = ?psi; a := A with
# psi = 2B d > v^2 + (A + B)(A eps^2 + 2 v eps); brake = a := -B (unguarded); thermostat
# temps := temp; (?temps > T; thermo := -1) or (?temps < T; thermo := 1) or (?temps = T) (kept).
# Attack ATTACKED(P, {temps}): temps := * (the reading is arbitrary). Property (H-equivalence,
# Def. 5, lock-step): for every run of the attacked car there is a run of the genuine car with
# the same high-integrity values after every control iteration; the proof's equivalence formula
# is v = v1 and d = d1 (Fig. 8, line 6). A, B, eps and T are symbolic in the source.
#
# THIS FILE. Left = attacked car, right = genuine car, same plant. Constants A = B = 1 m/s^2 and
# eps = 1 s, the values the journal follow-up sets for this car (Xiang, Lanotte, Tini, Chong,
# Merro, NAHS 56 (2025), Sec. 6.2); T = 20 (degrees C, ours). Modes = action x thermostat:
# Acc (a = 1) / Coast (a = 0) / Brk (a = -1) x Cool (thermo = -1) / Heat (thermo = 1). Acc is
# guarded on both sides by the source's psi at these constants, 2d > v^2 + 4v + 2 (strict, as in
# the source). The attacked thermostat is free: every mode whose action guard holds is enabled.
# The genuine thermostat reads the true temperature: Cool needs temp >= 20, Heat temp <= 20, at
# the window start. Stretch pinned to 1 (lambda in [1, 1]): the source's definition is lock-step
# (the attack does not change the control rate).
#
# CLAIM (every left mode): d_L = d_R and v_L = v_R (two inequalities each), the source's
# equivalence formula, here at every instant (the source asks it after every loop iteration).
# Requirement: the attacker who owns the cabin-temperature reading cannot change how the car
# moves. Not implied by the domains; every left mode has a satisfiable start (equal d and v in the
# mode's action guard, any temperatures). The rows leave both cabin temperatures free, so the claim
# holds from every pair of cabin temperatures; this per-state form implies the source's, whose
# genuine run may also choose its start temperature. The source's Def. 5 is symmetric (each
# program's runs are matched by the other's); the converse direction, every run of the genuine
# car matched by the attacked car, is immediate, since the attacked program contains the genuine
# one (temps := * includes temps := temp), so the direction certified here is the one with
# content.
#
# Where this file departs from the source.
# (1) Coast and low-speed braking. A Coast action (a = 0, enabled only at v <= 1 = B eps) is
#   added on both sides and Brk is enabled only from v >= 1, as in lit_drl_car_stop: the source's
#   braking run stops at v = 0 before the period ends (its domain v >= 0), which a right mode may
#   not do (Assumption 1 asks every right mode for a run of a full control interval); Coast is
#   the one-period stand-in for braking to rest and keeps the genuine car complete where neither
#   psi nor v >= 1 holds. Until 2026-10-28 Coast was enabled at any speed; restricting it to
#   v <= 1 makes the attacked car a subset of the source's attacked car plus that stand-in,
#   instead of a car that may coast at any speed, and changes no verdict.
# (2) Top speed. Domain 0 <= v <= 40 (m/s, ours; the source has v >= 0 only), and Acc needs
#   v <= 39 so that one period of acceleration stays below it. It bounds the rate of the psi atom,
#   which the Assumption 1 check needs: without it the file still CERTIFIES (measured), but
#   relcert --wellformed reports both Acc modes UNKNOWN (true by hand).
# (3) Thermostat values. thermo is -1 or 1 only (the source's initial thermo is unconstrained and
#   "?temps = T" keeps it); at temp = 20 exactly both genuine settings are enabled (closed
#   guards), where the source keeps the previous one. Temperature has no domain (as the source).
#
# Why committed choice is needed (X). At the start of each window the genuine car hops into the
# attacked car's action and picks the thermostat setting its own temperature allows (Cool at
# temp >= 20, Heat at temp <= 20); its d and v then move with the attacked car's. Without the
# choice (RELCERT_NO_CHOICE=1) it must flow on in the action it holds: DECLINED.
#
# Tightness. The claim is the source's equality (tolerance 0 on d and v); there is no slack to
# measure, and no positive tolerance is needed or claimed.
#
# Cause test (measured 2026-10-29). The source's claim holds because the thermostat command never
# reaches the drive: the d and v flows do not read temp or the setting. Remove that separation and
# the verdict changes: benchmarks/negative/lit_csf21_vehicle_thermo_leaky (the same file with an
# air-conditioning load on both sides, AccCool: v' = 0.8 instead of 1) is DECLINED (0.9 s), and its
# header gives an attacked run that no genuine run matches from any start temperature, so the
# source's H-equivalence fails there too, not only this file's per-state form. The witness copies
# d and v (it enters the attacked car's action), but that copy is the source's claim itself
# (H-equivalence asks for equal high-integrity values); the genuine thermostat setting is not
# copied (it is the one the true temperature allows).
#
# Verdicts (RELCERT_IMPLIED_CUT=1 unless stated, measured 2026-10-29 on branch benchmark-fixes,
# tip 131cb10): CERTIFIED (about 2.4 s); CERTIFIED under RELCERT_SYNC=1, RELCERT_NO_PRUNE=1,
# RELCERT_NO_CUT=1, RELCERT_NO_REPO=1, RELCERT_NO_IMPLIED_CUT=1, RELCERT_NO_LINEAR_CUT=1,
# RELCERT_NO_PAIR_STRETCH=1, RELCERT_OPREGION=1, RELCERT_WELLFORMED_STRICT=1 and without
# RELCERT_IMPLIED_CUT; DECLINED under RELCERT_NO_CHOICE=1, RELCERT_NO_PRUNE=1 RELCERT_NO_CHOICE=1
# and RELCERT_SYNC=1 RELCERT_NO_CHOICE=1. Cover: every left mode at lambda 1, budget 1, all six
# right modes admissible starts, closed by a hop into the left's action (both thermostat settings
# pass); nothing pruned. Rows identical (--handoff vacuous, 36/36). relcert --wellformed: all six right
# modes ok (exit; Acc and Brk into a Coast or Brk mode by the end speed, each Coast mode into the
# other setting's Coast), 0 UNKNOWN, 0 BLOCKING. scripts/check_one_domain.py: PASS.
[problem]
name = lit_csf21_vehicle_thermo
max_depth = 8
lambda_min = 1.0
lambda_max = 1.0
bound_T = 40.0

[Lsys]
state_vars = [d, v, temp]
epsilon = 1.0

[Lsys.mode.AccCool]
ode = d' = smt2:(- 0.0 v); v' = smt2:1.0; temp' = smt2:(- 0.0 1.0);
guard = smt2:(and (>= v 0.0) (<= v 39.0) (> (* 2.0 d) (+ (* v v) (* 4.0 v) 2.0)))
evolve = v >= 0.0 and v <= 40.0
next = [AccCool, AccHeat, CoastCool, CoastHeat, BrkCool, BrkHeat]

[Lsys.mode.AccHeat]
ode = d' = smt2:(- 0.0 v); v' = smt2:1.0; temp' = smt2:1.0;
guard = smt2:(and (>= v 0.0) (<= v 39.0) (> (* 2.0 d) (+ (* v v) (* 4.0 v) 2.0)))
evolve = v >= 0.0 and v <= 40.0
next = [AccCool, AccHeat, CoastCool, CoastHeat, BrkCool, BrkHeat]

[Lsys.mode.CoastCool]
ode = d' = smt2:(- 0.0 v); v' = smt2:0.0; temp' = smt2:(- 0.0 1.0);
guard = smt2:(and (>= v 0.0) (<= v 1.0))
evolve = v >= 0.0 and v <= 40.0
next = [AccCool, AccHeat, CoastCool, CoastHeat, BrkCool, BrkHeat]

[Lsys.mode.CoastHeat]
ode = d' = smt2:(- 0.0 v); v' = smt2:0.0; temp' = smt2:1.0;
guard = smt2:(and (>= v 0.0) (<= v 1.0))
evolve = v >= 0.0 and v <= 40.0
next = [AccCool, AccHeat, CoastCool, CoastHeat, BrkCool, BrkHeat]

[Lsys.mode.BrkCool]
ode = d' = smt2:(- 0.0 v); v' = smt2:(- 0.0 1.0); temp' = smt2:(- 0.0 1.0);
guard = smt2:(and (>= v 1.0))
evolve = v >= 0.0 and v <= 40.0
next = [AccCool, AccHeat, CoastCool, CoastHeat, BrkCool, BrkHeat]

[Lsys.mode.BrkHeat]
ode = d' = smt2:(- 0.0 v); v' = smt2:(- 0.0 1.0); temp' = smt2:1.0;
guard = smt2:(and (>= v 1.0))
evolve = v >= 0.0 and v <= 40.0
next = [AccCool, AccHeat, CoastCool, CoastHeat, BrkCool, BrkHeat]

[Rsys]
state_vars = [d, v, temp]
epsilon = 1.0

[Rsys.mode.AccCool]
ode = d' = smt2:(- 0.0 v); v' = smt2:1.0; temp' = smt2:(- 0.0 1.0);
guard = smt2:(and (>= v 0.0) (<= v 39.0) (> (* 2.0 d) (+ (* v v) (* 4.0 v) 2.0)) (>= temp 20.0))
evolve = v >= 0.0 and v <= 40.0
next = [AccCool, AccHeat, CoastCool, CoastHeat, BrkCool, BrkHeat]

[Rsys.mode.AccHeat]
ode = d' = smt2:(- 0.0 v); v' = smt2:1.0; temp' = smt2:1.0;
guard = smt2:(and (>= v 0.0) (<= v 39.0) (> (* 2.0 d) (+ (* v v) (* 4.0 v) 2.0)) (<= temp 20.0))
evolve = v >= 0.0 and v <= 40.0
next = [AccCool, AccHeat, CoastCool, CoastHeat, BrkCool, BrkHeat]

[Rsys.mode.CoastCool]
ode = d' = smt2:(- 0.0 v); v' = smt2:0.0; temp' = smt2:(- 0.0 1.0);
guard = smt2:(and (>= v 0.0) (<= v 1.0) (>= temp 20.0))
evolve = v >= 0.0 and v <= 40.0
next = [AccCool, AccHeat, CoastCool, CoastHeat, BrkCool, BrkHeat]

[Rsys.mode.CoastHeat]
ode = d' = smt2:(- 0.0 v); v' = smt2:0.0; temp' = smt2:1.0;
guard = smt2:(and (>= v 0.0) (<= v 1.0) (<= temp 20.0))
evolve = v >= 0.0 and v <= 40.0
next = [AccCool, AccHeat, CoastCool, CoastHeat, BrkCool, BrkHeat]

[Rsys.mode.BrkCool]
ode = d' = smt2:(- 0.0 v); v' = smt2:(- 0.0 1.0); temp' = smt2:(- 0.0 1.0);
guard = smt2:(and (>= v 1.0) (>= temp 20.0))
evolve = v >= 0.0 and v <= 40.0
next = [AccCool, AccHeat, CoastCool, CoastHeat, BrkCool, BrkHeat]

[Rsys.mode.BrkHeat]
ode = d' = smt2:(- 0.0 v); v' = smt2:(- 0.0 1.0); temp' = smt2:1.0;
guard = smt2:(and (>= v 1.0) (<= temp 20.0))
evolve = v >= 0.0 and v <= 40.0
next = [AccCool, AccHeat, CoastCool, CoastHeat, BrkCool, BrkHeat]

[relational_invariant]
AccCool = d[l] <= d[r] and d[r] <= d[l] and v[l] <= v[r] and v[r] <= v[l]
AccHeat = d[l] <= d[r] and d[r] <= d[l] and v[l] <= v[r] and v[r] <= v[l]
CoastCool = d[l] <= d[r] and d[r] <= d[l] and v[l] <= v[r] and v[r] <= v[l]
CoastHeat = d[l] <= d[r] and d[r] <= d[l] and v[l] <= v[r] and v[r] <= v[l]
BrkCool = d[l] <= d[r] and d[r] <= d[l] and v[l] <= v[r] and v[r] <= v[l]
BrkHeat = d[l] <= d[r] and d[r] <= d[l] and v[l] <= v[r] and v[r] <= v[l]
