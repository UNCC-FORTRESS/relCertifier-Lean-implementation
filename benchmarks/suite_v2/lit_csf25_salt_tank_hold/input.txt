# lit_csf25_salt_tank_hold: a brine-mixing tank whose salt sensor is silenced for two minutes, so that
# one control decision is held for three minutes, stays within 1.31 lb per minute of the genuine tank
# re-timed to one minute per cycle (the case study of formal robustness under timed attacks).
# scenario: dos-attack
# mechanisms: S D I (stretch: the genuine tank answers the held 3-min window over [1, 3] min, the
#   paper's re-timing by 1/3; RELCERT_SYNC=1 declines. Mode-dependent rows: the held-Inc and held-Dec
#   windows have different bands and envelopes, every uniform row set DECLINES. Mode facts: the guard
#   conjuncts of the held decision; RELCERT_NO_CUT=1 declines)
#
# SOURCE. Xiang, Lanotte, Tini, Chong, Merro, "Formal robustness for cyber-physical systems under
# timed attacks", IEEE CSF 2025. Sec. VII (case study) and Fig. 8 (model), Figs. 9-12 (the proof and
# its formulas; Fig. 11 the increasing case), Sec. III-A and Fig. 3 (scheduled sensor attacks, the DoS
# payload), Sec. IV (Defs. 4-6), Sec. V-A (Def. 8 timed simulation distance, Thm. 1), Sec. V-B (Cors. 1-2),
# Prop. 4 (time-split of the loop), Prop. 6 (merge the held attacked cycles into one plant run of
# D + eps), Prop. 7 (scale the genuine plant's time). A tank of xL = 100 gal holds xp lb of salt;
# brine of concentration sc lb/gal enters at r = 3 gal/min and the stirred mixture drains at r:
# plant xp' = r (sc - xp/xL), clockG' = 1, tSYS' = 1 & xp >= 0 and tSYS <= eps, eps = 1 (min);
# ctrl tSYS := 0; xs := xp; (?xs < 35; sc := 1) or (?xs >= 35; sc := 1/4). Pre xp = 36, clockG = 0;
# post 29.5 <= xp <= 42.1; the genuine tank stays in about 34.5 <= xp <= 37.1. Attack: scheduled
# sensor DoS from S = 5 for D = 2 (M == (?trigger; skip) or (?not trigger; xs := xp), trigger ==
# S <= clockG <= S + D): the decision taken at S is applied for D + eps = 3 min. Source result:
# attacked and genuine at timed simulation distance 6 on H = {xp}; the proof merges the held cycles
# into one 3-min plant run (Prop. 6), scales the genuine plant by 1/3 so one genuine 1-min cycle
# answers it (Prop. 7), and bounds the increasing case by C: xp - xp1 <= 2.1 + 1.3 (t - t_old),
# t - t_old <= D + eps (Fig. 11), with the genuine envelope 34.5 < xp1 < 37.1 (Fig. 10, psi_b).
#
# THIS FILE. The paper's own proof step: one held attacked window against the genuine tank re-timed.
# Left (forall) = the attacked tank over the attack: one window of up to 3 min (epsilon 3) from the
# attack start t = 5, in the decision taken there and never revised (HoldInc: guard xp < 35, HoldDec:
# xp >= 35, each with t = 5; next = itself only). Right (exists) = the genuine tank, 1-min cycles
# (epsilon 1), guards partition xp, next = [Inc, Dec]; stretch lambda in [1/3, 1], so the genuine
# answer spans 1 to 3 min (lambda 1/3 is the paper's Prop. 7 scaling). Flows in set-point form: Inc
# (sc = 1) xp' = 0.03 (100 - xp), Dec (sc = 1/4) xp' = 0.03 (25 - xp), the source's 3 (sc - xp/100);
# t is the source's clockG on both sides.
#
# CLAIM. HoldInc: xp_R <= xp_L <= xp_R + 1.31 (t_L - 5) and xp_R >= 34.5; HoldDec: xp_L <= xp_R <=
# xp_L + 0.25 (t_L - 5) and xp_R <= 37.1. At the attack start (t = 5) the rows force equality (the
# paper's distance 0 before S, Prop. 4); through the held window the gap stays under the slope times
# the elapsed attack time, at most 3.93 lb at the end of the 3-min hold (Inc) and 0.75 lb (Dec). The
# envelopes are the paper's psi_b bounds on the genuine tank. Not comparable with the paper's
# distance 6: that value is 2.1 + 3 x 1.3, the stale-reading offset of its case mid_a (Fig. 10) plus
# the slope over the hold, and this file does not model the stale case (departure (3)).
#
# TIGHTNESS (measured 2026-10-29, bisection 0.01, other rows fixed). Inc slope 1.31 certifies, 1.30
# DECLINES; Dec slope 0.25 certifies, 0.24 DECLINES. The Inc slope is the same mechanism as the
# paper's 1.3 of Fig. 11 (an unscaled held Inc flow against a genuine Inc flow re-timed by 1/3), at a
# different start: the paper bounds the rate gap where xp_L >= 35 (0.03 x 65 - 0.01 x 65.5 = 1.295 <=
# 1.3, sound), this file's worst case is xp_L = xp_R = 34.5 (0.03 x 65.5 x 2/3 = 1.3100). The tight
# slope is 0.03 x 65.5 x (1 - 1/H) for a hold of H min (independent audit, 2026-10-29).
#
# CAUSE TEST (measured 2026-10-29; the hold length H = D + eps is the attack's effect; epsilon_L = H,
# lambda_min = 1/H). H = 1 (no attack, the decision is fresh every minute): slopes 0 and 0 certify
# (equality throughout). H = 2: Inc 0.99 (0.98 declines). H = 3 (this file): 1.31 (1.30 declines). H = 4:
# Inc 1.48 (1.47 declines; with the Dec slope relaxed to 0.3, 0.27 declines at H = 4). The tight
# slope grows with the attack duration.
#
# Where this file departs from the source.
# (1) Evolve domain 0 <= xp <= 300 on every mode of both sides (the source: xp >= 0): 300 lb is the
#   brine saturation of 100 gal (about 3 lb of salt per gal), a physical limit; it gives relcert
#   --wellformed the rate bound of Dec (with xp >= 0 alone Dec is reported UNKNOWN, which the strict
#   gate rejects).
# (2) The global clock clockG is a state variable t on both sides; the window clock tSYS is the tool's
#   period (epsilon).
# (3) The stale reading xs is eliminated and the held decision is keyed on the level at S (HoldInc at
#   xp < 35, HoldDec at xp >= 35, at t = 5). NOT exact, and not forced (independent audit, 2026-10-29):
#   the source's payload skip keeps the reading of the last fresh sample, taken before S, so the held
#   decision may disagree with xp(5) (the paper's worst case mid_a: xs < 35 while xp >= 35, Fig. 10).
#   Measured by the audit: with the held decision widened to the stale case (HoldInc at xp < 36.92,
#   the largest level one Inc minute reaches from below 35; HoldDec at xp >= 34.7) or left free on
#   [34.5, 37.1], the file CERTIFIES with Inc slope about 2.06 (about 6.2 lb at the end of the hold,
#   the paper's 6) and Dec about 1.0, but only without the psi_b envelope rows (with them it DECLINES
#   even at slope 10). This file keeps the fresh-decision step with the envelopes.
# (4) The attack is one-shot from the attack start, the source's threat model (a single scheduled
#   attack at S = 5): both left modes are entered only at the start (t = 5) by design, so the suite's
#   start-only rule (no mode entered only from starts) does not apply here; the pre-attack phase is
#   the equality the rows force at t = 5.
# (5) The post-attack phase is out of scope: once the attacked tank resumes fresh samples, the two
#   genuine controllers are desynchronized and can take opposite decisions; a file with recovery and
#   post-attack modes DECLINES for every constant band below 75 (= 100 - 25, the set-point spread).
#   The source's tolerance claim on (0, 13.7) is not this file's claim.
# (6) The band is linear in the attack time (the paper's own C is too) instead of psi_b's constant 6;
#   the claim holds from every pair satisfying the rows at t = 5, which includes the paper's states.
# Assumption 1 holds without a stand-in: the right guards partition xp, so every run ends in the guard
# of a declared successor; a full 1-min run exists from either guard inside the domain (the explicit
# exponential, Inc rising toward 100, Dec falling toward 25), proved in
# InstancesV2/WellFormed/LitCsf25SaltTankHold.lean.
#
# RELATION TO OTHER TANKS. lit_nahs25_salt_tank (same authors, NAHS 2025): another salt tank (r = 10
# or 0, threshold 25) under a bounded sensor error at every sample, a constant band 3, lambda 1,
# letter I. Here: inflow concentration 1 or 1/4 at r = 3 (equilibria 100 and 25 straddling 35), a
# timed DoS, a band growing with the attack time, the paper's re-timing as a stretch.
#
# Verdicts (RELCERT_IMPLIED_CUT=1 unless stated, measured 2026-10-29 on branch benchmark-fixes):
# CERTIFIED (about 0.24 s); CERTIFIED under RELCERT_NO_CHOICE=1, RELCERT_NO_PRUNE=1,
# RELCERT_NO_REPO=1, RELCERT_NO_PAIR_STRETCH=1; DECLINED under RELCERT_SYNC=1, RELCERT_NO_CUT=1 and
# RELCERT_NO_IMPLIED_CUT=1. relcert --wellformed: Inc ok (exit), Dec ok (exit), 0 UNKNOWN, 0 BLOCKING.
[problem]
name = lit_csf25_salt_tank_hold
max_depth = 8
lambda_min = 0.3333333333
lambda_max = 1.0
bound_T = 40.0

[Lsys]
state_vars = [xp, t]
epsilon = 3.0

[Lsys.mode.HoldInc]
ode = xp' = smt2:(* 0.03 (- 100.0 xp)); t' = smt2:1.0;
guard = xp < 35.0 and t >= 5.0 and t <= 5.0
evolve = xp >= 0.0 and xp <= 300.0
next = [HoldInc]

[Lsys.mode.HoldDec]
ode = xp' = smt2:(* 0.03 (- 25.0 xp)); t' = smt2:1.0;
guard = xp >= 35.0 and t >= 5.0 and t <= 5.0
evolve = xp >= 0.0 and xp <= 300.0
next = [HoldDec]

[Rsys]
state_vars = [xp, t]
epsilon = 1.0

[Rsys.mode.Inc]
ode = xp' = smt2:(* 0.03 (- 100.0 xp)); t' = smt2:1.0;
guard = xp < 35.0
evolve = xp >= 0.0 and xp <= 300.0
next = [Inc, Dec]

[Rsys.mode.Dec]
ode = xp' = smt2:(* 0.03 (- 25.0 xp)); t' = smt2:1.0;
guard = xp >= 35.0
evolve = xp >= 0.0 and xp <= 300.0
next = [Inc, Dec]

[relational_invariant]
HoldInc = xp[r] <= xp[l] and xp[l] <= xp[r] + t[l]*1.31 - 6.55 and xp[r] >= 34.5
HoldDec = xp[l] <= xp[r] and xp[r] <= xp[l] + t[l]*0.25 - 1.25 and xp[r] <= 37.1
