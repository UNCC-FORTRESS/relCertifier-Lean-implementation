# platoon3_linkloss: three-follower CACC string with a latched radar-only mode after a V2V link loss on the lead link, against the design model.
# scenario: sensor-attack
# mechanisms: M2 M4 M5 M6
#
# Dimension lift (pass 6) of platoon_delay_linkloss: a lead vehicle cruising at constant
# speed and THREE automated followers; per link i = 1, 2, 3 (link i = follower i behind
# its predecessor) the gap g_i (m) and the closing-rate state r_i = v_{i-1} - v_i (m/s),
# so g_i' = r_i: state (g1, r1, g2, r2, g3, r3) per side (6 D, linear).
#
# THE LOOP (both sides). Follower i commands a_i = a_{i-1} + kp (g_i - c) + kd r_i (CACC:
# the predecessor's acceleration a_{i-1} arrives over V2V as feed-forward; a_0 = 0, the
# leader cruises). Then r_i' = a_{i-1} - a_i = -kp (g_i - c) - kd r_i: every link is the
# same second-order loop, the feed-forward cancelling the coupling. kp = 0.125 /s^2,
# kd = 0.75 /s: s^2 + 0.75 s + 0.125 = (s + 0.25)(s + 0.5), OVER-DAMPED with rational
# roots, so the linear forms p_j = r + rho_j (g - c) (rho_1 = 0.25, rho_2 = 0.5) obey
# p_1' = -0.5 p_1, p_2' = -0.25 p_2 (the L7 decoupling forms).
# Reference (right, the design model): set point c = 30 m (1.2 s at 25 m/s) on every link.
# Deployed (left): acts on a gap fused with a 40 ms-old V2V position, overstated by 1 m
# at 25 m/s, so its loops settle at 29 m true. When the V2V link to the LEADER is LOST
# (jamming or dropout), follower 1 LATCHES a radar-only gap keeper with the larger
# stand-off 35 m (radar-measured, no overstatement; same gains): LOST: r1' = -kp (g1 - 35)
# - kd r1; links 2 and 3 keep their V2V and the CACC law. No way back (the link is
# re-established at the next platoon join, not modeled).
#
# PHYSICAL DOMAIN (both sides): 0 <= g_i <= 60 m (the radar's range), |r_i| <= 10 m/s
# (the closing-rate range); no certificate stands on them (widening test: CERTIFIED with
# every bound widened at once, no load-bearing group).
# Guards (OPERATING RANGE, controller design; changed 2026-10-10, docs/SUITE-REDESIGN.md
# section 20). The controller stays engaged throughout its operating range; the guard is
# not the engagement band. Reference FOLLOW: every gap above the AEB floor and within the
# radar's range, 20 <= g_i <= 60, every closing rate within the rated limit |r_i| <= 10,
# and the AEB not imminent: the gap projected 2 s ahead at the current closing rate stays
# 1 m above the floor and 1 m inside the range, 21 <= g_i + 2 r_i <= 59 (i.e.
# -4.5 <= r_i + 0.5 (g_i - 30) <= 14.5, the slow decoupling form p_2, which only decays
# under FOLLOW: the guard is forward invariant, the controller never leaves it; at the floor
# g_i = 20 it gives r_i >= 0.5 > 0, the repelling flow the non-connection check needs, and at
# the range g_i = 60 it gives r_i <= -0.5). Deployed FOLLOW, the same with the 1 m
# overstatement: 19 <= g_i <= 59, |r_i| <= 10, 20 <= g_i + 2 r_i <= 58. LOST (radar-only on
# link 1, latched): links 2, 3 as FOLLOW; link 1 25 <= g1 <= 59, |r1| <= 10,
# 20 <= g1 + 2 r1 <= 58 (the LOST row lets the reference's gap be up to 5 m below the
# deployed's, g1_R >= g1_L - 5, so the floor 25 keeps every row-related reference state

# Why: the old guards were the ENGAGEMENT band (reference 26 <= g_i <= 34, |r_i| <= 1;
# deployed 25..33), and FOLLOW's only successors are FOLLOW and the brake sinks (g_k < 20):
# a sampled controller whose stay guard is a band, with no catch-all mode, BLOCKS after a
# cycle that ends at g > 34 (or 20 <= g < 26, or |r| > 1), violating Assumption 1
# (nonblocking). The certificate cannot see it (its Assumption 1 is a hypothesis); the
# mechanization found it (the guarded Theorem 3 was false on the old model, kernel-checked).
# The plain operating range (without the projected-gap conjunct) DECLINES: from g = 20,
# r = -10 the reference reaches the AEB floor within one period (pruning lost; no floor in
# [21, 35] restores it with |r| <= 10). The design model declares, per follower k, an AEB
# fallback BRAKEk below a 20 m gap (g_k < 20; 2/3 of the set gap, a controller-design
# floor): follower k brakes at 4 m/s^2 (a_k = -4), the followers behind it keep the CACC
# law (their feed-forward carries the braking); sinks.
#
# Rows (MODE-DEPENDENT, M5; Delta = L - R, e1 = Delta g1 + 1 the deviation from the
# deployed's 1 m offset):
#   FOLLOW: Delta r_i + rho_j (Delta g_i + 1) = 0 for every link i and j = 1, 2 (EXACT

#     g1_R - 1 <= g1_L <= g1_R + 5: the radar-only follower never closes in on the
