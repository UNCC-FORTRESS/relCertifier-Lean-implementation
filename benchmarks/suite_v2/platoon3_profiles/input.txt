# scenario: sensor-attack
# mechanisms: M2 M3 M4 M6 M6+ M6L

# Dimension lift (pass 6) of platoon_delay_profiles: a lead vehicle cruising at constant
# speed and THREE automated followers; per link i = 1, 2, 3 the gap g_i (m) and the
# closing-rate state r_i = v_{i-1} - v_i (m/s), g_i' = r_i: state (g1, r1, g2, r2, g3, r3)
# per side (6 D, linear).
#
# THE LOOP (both sides). Follower i commands a_i = a_{i-1} + kp (g_i - c) + kd r_i (CACC
# with V2V feed-forward; a_0 = 0, the leader cruises), so r_i' = -kp (g_i - c) - kd r_i;
# kp = 0.125 /s^2, kd = 0.75 /s, s^2 + 0.75 s + 0.125 = (s + 0.25)(s + 0.5): over-damped,
# rational roots rho_1 = 0.25, rho_2 = 0.5.
# Reference (right, the design model): the driver selects the gap profile CLOSE 28 m,
# NORMAL 30 m or FAR 32 m (the time-gap button; NORMAL <-> CLOSE / FAR), applied to all
# three links. Deployed (left): the nominal setting, acting on a gap fused with a 40 ms-old
# V2V position, overstated by 1 m at 25 m/s: its loops settle at 29 m true.
#
# PHYSICAL DOMAIN (both sides): 0 <= g_i <= 60 m (the radar's range), |r_i| <= 10 m/s
# (the closing-rate range); no certificate stands on them (widening test).
# Guards (entry conditions, controller design): a profile engages when every MEASURED gap
# is within 4 m of its set point and every closing rate within 1 m/s (CLOSE 24..32,
# NORMAL 26..34, FAR 28..36; the deployed 25..33 true); per follower k the design model
# declares an AEB fallback BRAKEk below a 20 m gap (g_k < 20, a controller-design floor):
# follower k brakes at 4 m/s^2, the followers behind it keep the CACC law; sinks.
#
# CLAIM, derived (Delta = L - R, e_i = Delta g_i + 1 the deviation from the deployed's
# 1 m offset against NORMAL): for every link
#   Delta r_i + rho_j e_i in [-2 rho_j, 2 rho_j] (j = 1, 2), then |e_i| <= 2,
# i.e. g_i^R - 3 <= g_i^L <= g_i^R + 1 whichever profile the driver selects. Against a
# profile with set point c_k the forms Q_j = Delta r_i + rho_j e_i obey
# Q_j' = -rho_{3-j} (Q_j - rho_j (30 - c_k)): they contract toward 0 (NORMAL) or
# +-2 rho_j (CLOSE / FAR), so [-2 rho_j, 2 rho_j] is the tightest box invariant under all
# three; |e_i| <= 2 is stratified on the proven Q_1 rows. One step tighter (measured on
# the stretch grid): the Q box at 1.9 rho_j DECLINED (27.9 s); |e_i| <= 1.9 DECLINED
# (28.9 s).
# Covers (measured): stretch grid lambda in [1, 6]; the cover is found at lambda = 1 (the
# same gains on both sides; no M1), budget 2; the cover from NORMAL takes a joint step

# counter-runs re-try the failing segments at every grid point: NO_PRUNE needs 8 824
# Z3 queries (DECLINED in 27.3 s), NO_CUT / NO_IMPLIED_CUT / NO_LINEAR_CUT about 7 200
# (DECLINED in 16.2-16.5 s), within the default query budget of 20 000

# Fallback (M4): every profile -> BRAKE1/2/3 pruned (nine edges): the L7 chain on each
# profile's engagement box keeps r + 0.5 (g - c_k) >= -3, so g_i >= c_k - 6 >= 22 > 20;
# RELCERT_NO_PRUNE=1 DECLINES. The chain is what proves the non-connection, so
