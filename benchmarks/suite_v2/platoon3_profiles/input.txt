# Dimension lift (pass 6) of platoon_delay_profiles: a lead vehicle cruising at constant

# Reference (right, the design model): the driver selects the gap profile CLOSE 28 m,

# three links. Deployed (left): the nominal setting, acting on a gap fused with a 40 ms-old
# V2V position, overstated by 1 m at 25 m/s: its loops settle at 29 m true.
#
# PHYSICAL DOMAIN (both sides): 0 <= g_i <= 60 m (the radar's range), |r_i| <= 10 m/s
# (the closing-rate range); no certificate stands on them (widening test).
# Guards (OPERATING RANGE, controller design; changed 2026-10-10, docs/SUITE-REDESIGN.md

# profile; the guards are not the engagement bands. Reference CLOSE / NORMAL / FAR (the same
# guard; the driver may select any profile anywhere in the range): 20 <= g_i <= 60 (above

# so the guard is forward invariant under every profile and the flow repels at g_i = 20).

# reference's gap be up to 1 m below the deployed's, g_i^R >= g_i^L - 1, so the floor 21
# keeps every row-related reference state above the AEB floor; with 19 or 20 the brake
# sinks are admissible starts and the run DECLINES).

# |r_i| <= 1; deployed 25..33): a sampled controller whose stay guards are bands, with no

# model, kernel-checked). The plain operating range DECLINES (pruning lost). Per follower k
# the design model declares an AEB fallback BRAKEk below a 20 m gap (g_k < 20, a
# controller-design floor): follower k brakes at 4 m/s^2, the followers behind it keep the
# CACC law; sinks.
#

# Q_j' = -rho_{3-j} (Q_j - rho_j (30 - c_k)): they contract toward 0 (NORMAL) or
# +-2 rho_j (CLOSE / FAR), so [-2 rho_j, 2 rho_j] is the tightest box invariant under all
# three; |e_i| <= 2 is stratified on the proven Q_1 rows. One step tighter (measured on
# the stretch grid): the Q box at 1.9 rho_j DECLINED (27.9 s); |e_i| <= 1.9 DECLINED
# (28.9 s).
# Covers (measured, operating-range guards): the cover is found at lambda = 1 (no M1),
