# platoon_delay_profiles: the platoon follower on a delayed link against a reference with two catch-up profiles.
# scenario: degraded-sensor
# mechanisms: S M B P I (per-pairing time stretch, RELCERT_SYNC=1 declines; multi-step covers;
#   branching joint steps; pruned AEB edge; implied cuts, matrix codes M1 M2 M3 M4 M6 M6+)
#
# System. Gap g (m) to a leader at constant speed; desired gap 30 m; follower loops
# g' = -k (g - g*). Reference follower (right): FOLLOW k = 0.5 toward 30 m in the band 20..40 m;
# from a wide gap (>= 30 m) it may re-engage with either catch-up profile, GENTLE (k = 0.6) or
# ASSERTIVE (k = 0.7), selected when it leaves FOLLOW; the AEB brake BRAKE below 20 m (the gap
# opens at 1.5 m/s) re-engages FOLLOW at 20 m. Deployed follower (left): the same loops acting on
# a delayed link whose reading overstates the gap by 1 m (the loops settle at 29 m); under its
# delay-mitigation policy it re-engages with the gentle profile only. One cause: the delayed link
# (and the policy that answers it).
#
# Guards. Left FOLLOW: 24..40 m. 24 m = 0.8 x the 30 m desired gap: the follow controller engages
# only at 80 % of its desired gap or more (its engagement threshold; the AEB releases at 20 m,
# so engagement and release are separated by a 4 m hysteresis). Left GENTLE: g >= 30. Right as
# above; the right guards cover [0, 60] (BRAKE below 20, FOLLOW 20..40, profiles above 30).
# Physical domain 0 <= g <= 60 m both sides. relcert --wellformed: FOLLOW, GENTLE, ASSERTIVE ok
# (invariant), BRAKE ok (exit->FOLLOW).
#
# Property (every mode): g_L <= g_R + 4 and g_R <= g_L + 1.
#   g_R <= g_L + 1: the deployed follower never closes in by more than the link's 1 m
#     overstatement (the attack-free safety margin); tight: 1.00 certifies, 0.99 declines.
#   g_L <= g_R + 4: against an assertive reference re-engaging from a wide gap the gentle
#     deployed follower trails wider; requirement: at most one car length (4 m) wider, beyond
#     which cut-ins into the gap become likely. Tightest 3.43 (3.42 declines).
# BRAKE is no admissible start: g_L >= 24 and g_L <= g_R + 4 give g_R >= 20. The two constants
# meet exactly there (24 - 4 = 20): a width tolerance above 4 m, or an engagement threshold
# below 24 m, lets a reference in its AEB brake pair with a following deployed car, which the
# cover cannot match (DECLINED; with the floor at 20 or 21 the file declines for every width
# tolerance that certifies at 24).
#
# Verdicts (RELCERT_IMPLIED_CUT=1 unless stated): CERTIFIED; CERTIFIED under NO_CHOICE,
# NO_LINEAR_CUT, RELCERT_WELLFORMED_STRICT=1; DECLINED under RELCERT_SYNC=1, SYNC+NO_CHOICE,
# NO_PRUNE and NO_PRUNE+NO_CHOICE (FOLLOW -> BRAKE must be pruned: the gentle loop opens the gap
# at 20 m), without RELCERT_IMPLIED_CUT and NO_IMPLIED_CUT (the implied contraction atoms g >= 30
# of the right profiles and g >= 29 of the left GENTLE are load-bearing: the gap domain floor is
# the physical 0 m), and NO_CUT. Covers: FOLLOW lambda 1 budget 2, GENTLE lambda 5/4 budget 3
# (per pairing 1); joint steps from FOLLOW retain GENTLE and ASSERTIVE (branch 2). --handoff 4/4
# vacuous (rows identical). Units m, s.
[problem]
name = platoon_delay_profiles
max_depth = 8
lambda_min = 1.0
lambda_max = 6.0
bound_T = 4.0
[Lsys]
state_vars = [g]
epsilon = 2.0
[Lsys.mode.FOLLOW]
ode = g' = smt2:(* -0.5 (- g 29.0));
guard = g >= 24.0 and g <= 40.0
evolve = g >= 0.0 and g <= 60.0
next = [GENTLE, FOLLOW]
[Lsys.mode.GENTLE]
ode = g' = smt2:(* -0.6 (- g 29.0));
guard = g >= 30.0
evolve = g >= 0.0 and g <= 60.0
next = [FOLLOW, GENTLE]
[Rsys]
state_vars = [g]
epsilon = 1.0
[Rsys.mode.FOLLOW]
ode = g' = smt2:(* -0.5 (- g 30.0));
guard = g >= 20.0 and g <= 40.0
evolve = g >= 0.0 and g <= 60.0
next = [GENTLE, ASSERTIVE, FOLLOW, BRAKE]
[Rsys.mode.GENTLE]
ode = g' = smt2:(* -0.6 (- g 30.0));
guard = g >= 30.0
evolve = g >= 0.0 and g <= 60.0
next = [FOLLOW, GENTLE]
[Rsys.mode.ASSERTIVE]
ode = g' = smt2:(* -0.7 (- g 30.0));
guard = g >= 30.0
evolve = g >= 0.0 and g <= 60.0
next = [FOLLOW, ASSERTIVE]
[Rsys.mode.BRAKE]
ode = g' = smt2:1.5;
guard = g < 20.0
evolve = g >= 0.0 and g <= 60.0
next = [BRAKE, FOLLOW]
[relational_invariant]
FOLLOW    = smt2:(and (<= L_g (+ R_g 4.0)) (<= R_g (+ L_g 1.0)))
GENTLE    = smt2:(and (<= L_g (+ R_g 4.0)) (<= R_g (+ L_g 1.0)))
