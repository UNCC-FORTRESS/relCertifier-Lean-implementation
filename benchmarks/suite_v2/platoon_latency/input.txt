# platoon_latency: a CACC follower whose V2V feed-forward (the predecessor's acceleration) arrives
# late, against the design follower with an ideal (zero-latency) link.
# scenario: degraded-network
# mechanisms: D (mode-dependent rows: the AEB row differs from the CACC row, the 7 handoffs unsat
#   or implied, uniform rows decline; matrix code M5)
#
# Shared platoon model (identical in platoon_linkloss and this file, and in the round-2 platoon
# designs platoon_profiles and the reserve's platoon3_linkloss, platoon3_profiles). A lead vehicle cruises at the platoon reference speed
# v_ref = 25 m/s (90 km/h). Per link (follower behind its predecessor): the gap g (m, bumper to
# bumper) and the range rate r = v_pred - v (m/s, positive = opening), g' = r. Units m, m/s, s.
# Spacing policy (constant time gap): standstill distance d0 = 5 m. CACC: time gap h_c = 0.6 s on
#   the V2V-broadcast reference speed, desired gap d0 + h_c v_ref = 20 m.
# CACC (V2V predecessor-acceleration feed-forward u_ff): a = u_ff + kp (g - 20) + kd r with
#   kp = 0.125 /s^2, kd = 0.75 /s: closed-loop poles 0.25 and 0.5 /s (over-damped). With an ideal
#   link u_ff = a_pred and r' = a_pred - a = -kp (g - 20) - kd r.
# AEB (radar, the same function on every vehicle): triggers when the time to reach the standstill
#   distance at the current closing rate falls below T = 2 s, (g - d0) + T r < 0, i.e.
#   g + 2 r < 5; it then matches the predecessor's speed, r' = -0.5 r (relative deceleration
#   5 m/s^2 at the rated 10 m/s closing rate), which conserves the projected stop gap g + 2 r, and
#   stays latched until the driver resumes (not modeled). Trigger region as modeled:
#   0 <= g + 2 r < 5 (a projected stop gap below 0 is a collision the matching law cannot avoid).
# CACC operating range (the engagement spec, the same on both sides): |r| <= 10 (rated closing
#   rate) and 5 <= g + 2 r <= 60 (TTC to the standstill distance at least 2 s, and the gap
#   projected 2 s ahead inside the 60 m radar range gate).
# Control period 0.1 s on both sides (10 Hz V2V messages, the ETSI CAM / SAE BSM rate).
# Domain per link (both sides, every mode): 0 <= g <= 60 m (radar range gate), |r| <= 10 m/s
#   (rated closing rate).
#
# The cause: V2V latency. The deployed follower's feed-forward is the predecessor's acceleration
# tau = 0.2 s old: the newest message is up to one 0.1 s control period old when it is used, plus
# the 0.1 s end-to-end latency budget of V2V safety messages, so the follower acts on the
# predecessor's acceleration two control periods late. The predecessor's jerk is bounded by
# J = 2.5 m/s^3 (the ISO 15622 ACC jerk limit above 20 m/s, assumed here as a pointwise bound on
# the predecessor's automated longitudinal control). The delayed feed-forward is modeled by its
# first-order lag (time constant tau, u_ff' = (a_pred - u_ff) / tau, the Pade (0,1) model of the
# delay). Its error e = a_pred - u_ff (m/s^2) obeys e' = j_pred - e / tau and enters the loop as
# r' = e - kp (g - 20) - kd r. Like the pure delay's error a_pred(t) - a_pred(t - tau), it is
# bounded by W = J tau = 0.5 m/s^2.
# Left (deployed follower, state g, r, e): CACC_UP and CACC_DN are the same CACC while the
#   predecessor's acceleration rises (j_pred = +J) or falls (j_pred = -J) at the jerk limit; the
#   predecessor may switch between them at every control instant (next [CACC_UP, CACC_DN, AEB]).
#   The field is affine in j_pred, so every face condition that holds at both extremes holds for
#   every jerk in between. Guards: the operating range (same as the design's), any e. AEB: the
#   shared AEB (radar only, the feed-forward is unused; its error is frozen, e' = 0), latched.
# Right (design follower, state g, r): the same CACC with an ideal link (e = 0, so the design has
#   no e coordinate) and the same AEB; CACC -> [CACC, AEB], AEB latched.
# One cause: the latency (the lag and its error e). Same plant, gains, AEB, operating range and
# control period on both sides; lambda_min = lambda_max = 1 (same time). The predecessor is the
# same on both sides; the relative coordinates make the design's motion independent of it.
#
# Property (Delta = L - R; rows CACC_UP and CACC_DN identical, AEB separate).
#   CACC_UP, CACC_DN:
#     |Delta g| <= 4. Requirement (the latency's spacing-error allowance): a feed-forward error
#       held at its bound W shifts the CACC's equilibrium gap by W / kp = J tau / kp =
#       2.5 x 0.2 / 0.125 = 4 m (0.16 s of time gap at v_ref); the requirement is that the
#       transient never exceeds this static allowance, for every predecessor manoeuvre within the
#       jerk limit. Tight: 4.00 certifies, 3.99 declines (the loop is over-damped, so the error
#       never overshoots its static value).
#     |Delta r + 0.25 Delta g| <= 1 and |Delta r + 0.5 Delta g| <= 2 (derived, 2 W and 4 W): the
#       forms Q_rho = Delta r + rho Delta g obey Q_0.25' = -0.5 Q_0.25 + e and
#       Q_0.5' = -0.25 Q_0.5 + e, and Delta g' = Q_0.25 - 0.25 Delta g; both tight (0.99, 1.99
#       decline).
#     g_L >= 5 and g_L + 2 r_L >= 5: collision freedom of the deployed (gap at least d0) and its
#       TTC to d0 at least 2 s (the AEB threshold: the deployed never brakes in emergency where
#       the design would not). d/dt (g + 2 r) = -0.25 (g + 2 r - 20) + 2 e, so the TTC floor is
#       kept iff W <= 0.25 x 15 / 2 = 1.875 m/s^2 (tau <= 0.75 s at J = 2.5). 5.00 is tight for
#       the gap floor (5.01 declines: it is kept only through the TTC floor); TTC floors up to
#       20 - 8 W = 16 m certify (16.01 declines): the latency costs the deployed 4 m of projected
#       stop gap.
#     5 <= g_R + 2 r_R <= 60 (strengthening, the lower half needed): the design follower is in
#       its operating range (engaged). Without the lower half the AEB is an admissible start of
#       CACC_UP_L (a design follower braking, paired with a deployed one up to 4 m away) and the
#       segment (CACC_UP_L, AEB_R) fails (DECLINED, as in platoon_linkloss). The upper half keeps
#       every admitted start inside a right guard (RELCERT_OPREGION=1). The pairs the deployed
#       and design runs reach satisfy both: they start together in the CACC, whose operating
#       range is forward invariant on both sides.
#   AEB: exact, Delta r = 0 and Delta (g + 2 r) = 0 (the two AEBs are the same function).
#
# The bound grows with the latency (measured, every other constant at its derived value 2 W,
# 4 W): tightest |Delta g| = 2.00 / 4.00 / 6.00 / 10.00 m at tau = 0.1 / 0.2 / 0.3 / 0.5 s, i.e.
# J tau / kp. Without latency (J tau = 0, e = 0) the exact claim (every Delta = 0) CERTIFIES. At
# tau = 0.75 s the file still CERTIFIES (with |Delta g| <= 15); at tau = 0.8 s it DECLINES: the
# segment (CACC_UP_L, CACC_R) fails, the deployed can reach its AEB threshold while the design
# cannot.
#
# Domains. Both sides 0 <= g <= 60, |r| <= 10 (as above); left also |e| <= W = 0.5 m/s^2, forward
# invariant (e' = +-J - e / tau never points outward at e = +-W; e' = 0 in AEB). The CACC operating
# range is forward invariant on both sides (TTC floor above; g + 2 r <= 60 since the CACC drives
# g + 2 r toward 20 +- 8 W; the |r| <= 10 faces hold below 70 m), so the deployed's CACC never
# triggers the AEB either; the design's CACC -> AEB edge is pruned (non-connection), the deployed's
# CACC -> AEB handoffs are unsat (the rows keep its TTC >= 2 s).
# Coverage of the right guards: CACC and AEB cover every domain state with 0 <= g + 2 r <= 60;
# states with g + 2 r < 0 or > 60 are in no right guard and no run reaches them (both guards are
# forward invariant). Every left mode has a satisfiable start (g_L = g_R = 20, r = 0, any e for
# CACC_UP / CACC_DN; g = 3, r = 0 for AEB).
#
# Verdicts (RELCERT_IMPLIED_CUT=1 unless stated, measured 2026-10-26): CERTIFIED; CERTIFIED also
# under RELCERT_SYNC=1, RELCERT_NO_PRUNE=1, RELCERT_NO_CHOICE=1, RELCERT_NO_PRUNE=1
# RELCERT_NO_CHOICE=1, RELCERT_SYNC=1 RELCERT_NO_CHOICE=1, without RELCERT_IMPLIED_CUT,
# RELCERT_NO_IMPLIED_CUT=1, RELCERT_NO_LINEAR_CUT=1, RELCERT_NO_CUT=1, RELCERT_OPREGION=1 (every
# admitted start in some right guard) and RELCERT_WELLFORMED_STRICT=1 (no S, M, B, P, I, X).
# Uniform rows decline: the CACC row on every mode without the deployed's TTC floor (so that AEB
# has a start) DECLINES (with the floor the AEB row would have no start): D.
# Covers: every left mode at lambda 1, budget 1 (single segment); admissible starts
# CACC_UP_L, CACC_DN_L: [CACC], AEB_L: [AEB]; pruned CACC -> AEB (not load-bearing at budget 1).
# --handoff 7/7 pass (rows differ). relcert --wellformed: CACC ok (invariant), AEB ok
# (invariant), 0 UNKNOWN.
[problem]
name = platoon_latency
max_depth = 8
lambda_min = 1.0
lambda_max = 1.0
bound_T = 4.0
[Lsys]
state_vars = [g, r, e]
epsilon = 0.1
[Lsys.mode.CACC_UP]
ode = g' = smt2:r; r' = smt2:(- (- e (* 0.125 (- g 20.0))) (* 0.75 r)); e' = smt2:(- 2.5 (* 5.0 e));
guard = r >= -10.0 and r <= 10.0 and g + 2.0 * r >= 5.0 and g + 2.0 * r <= 60.0
evolve = g >= 0.0 and g <= 60.0 and r >= -10.0 and r <= 10.0 and e >= -0.5 and e <= 0.5
next = [CACC_UP, CACC_DN, AEB]
[Lsys.mode.CACC_DN]
ode = g' = smt2:r; r' = smt2:(- (- e (* 0.125 (- g 20.0))) (* 0.75 r)); e' = smt2:(- (- 0.0 2.5) (* 5.0 e));
guard = r >= -10.0 and r <= 10.0 and g + 2.0 * r >= 5.0 and g + 2.0 * r <= 60.0
evolve = g >= 0.0 and g <= 60.0 and r >= -10.0 and r <= 10.0 and e >= -0.5 and e <= 0.5
next = [CACC_UP, CACC_DN, AEB]
[Lsys.mode.AEB]
ode = g' = smt2:r; r' = smt2:(* -0.5 r); e' = smt2:0.0;
guard = g + 2.0 * r < 5.0 and g + 2.0 * r >= 0.0 and g >= 0.0
evolve = g >= 0.0 and g <= 60.0 and r >= -10.0 and r <= 10.0 and e >= -0.5 and e <= 0.5
next = [AEB]
[Rsys]
state_vars = [g, r]
epsilon = 0.1
[Rsys.mode.CACC]
ode = g' = smt2:r; r' = smt2:(- (* -0.125 (- g 20.0)) (* 0.75 r));
guard = r >= -10.0 and r <= 10.0 and g + 2.0 * r >= 5.0 and g + 2.0 * r <= 60.0
evolve = g >= 0.0 and g <= 60.0 and r >= -10.0 and r <= 10.0
next = [CACC, AEB]
[Rsys.mode.AEB]
ode = g' = smt2:r; r' = smt2:(* -0.5 r);
guard = g + 2.0 * r < 5.0 and g + 2.0 * r >= 0.0 and g >= 0.0
evolve = g >= 0.0 and g <= 60.0 and r >= -10.0 and r <= 10.0
next = [AEB]
[relational_invariant]
CACC_UP = smt2:(and (>= (+ (- L_r R_r) (* 0.25 (- L_g R_g))) (- 0.0 1.0)) (<= (+ (- L_r R_r) (* 0.25 (- L_g R_g))) 1.0) (>= (+ (- L_r R_r) (* 0.5 (- L_g R_g))) (- 0.0 2.0)) (<= (+ (- L_r R_r) (* 0.5 (- L_g R_g))) 2.0) (>= (- L_g R_g) (- 0.0 4.0)) (<= (- L_g R_g) 4.0) (>= (+ R_g (* 2.0 R_r)) 5.0) (<= (+ R_g (* 2.0 R_r)) 60.0) (>= L_g 5.0) (>= (+ L_g (* 2.0 L_r)) 5.0))
CACC_DN = smt2:(and (>= (+ (- L_r R_r) (* 0.25 (- L_g R_g))) (- 0.0 1.0)) (<= (+ (- L_r R_r) (* 0.25 (- L_g R_g))) 1.0) (>= (+ (- L_r R_r) (* 0.5 (- L_g R_g))) (- 0.0 2.0)) (<= (+ (- L_r R_r) (* 0.5 (- L_g R_g))) 2.0) (>= (- L_g R_g) (- 0.0 4.0)) (<= (- L_g R_g) 4.0) (>= (+ R_g (* 2.0 R_r)) 5.0) (<= (+ R_g (* 2.0 R_r)) 60.0) (>= L_g 5.0) (>= (+ L_g (* 2.0 L_r)) 5.0))
AEB = smt2:(and (>= (- L_r R_r) 0.0) (<= (- L_r R_r) 0.0) (>= (+ (- L_g R_g) (* 2.0 (- L_r R_r))) 0.0) (<= (+ (- L_g R_g) (* 2.0 (- L_r R_r))) 0.0))
