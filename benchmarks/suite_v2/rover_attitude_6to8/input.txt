# rover_attitude_6to8: attitude-distance ladder, step 6 -> 8: heading and pitch become second
# order (the right moves 6 coordinates, the left 8). Followed by rover_attitude_8to12.
# scenario: model-refinement
#
# System: the terrain-zone rover (zones STEEP / MODER / FLAT by odometer s, speed set points
# 0.30 / 0.50 / 0.65, v' = 3 (c - v), s' = v (1 - psi^2/2 - 0.3 theta_p^2)).
#
# Left (8-DOF): heading psi and pitch theta_p are critically damped second-order loops
# (psi'' + 2 psi' + psi = 0), written in their cascade chart u = psi' + psi: psi' = u - psi,
# u' = -u (u is the state omega_psi; theta_p / omega_theta alike); heave z' = -z, roll
# phi_r' = -phi_r first order.
# Right (6-DOF plan): first-order attitude psi' = -psi, theta_p' = -theta_p, the same z, phi_r, v, s
# laws; omega_psi, omega_theta pinned (omega' = 0). Same guards (odometer bands) on both sides.
#
# Property (the same rows in every left mode): for heading, with gap d = psi_L - psi_R and left
# heading rate r = psi_L' = omega_psi_L - psi_L,
#   D_psi = 2 d^2 + 2 d r + r^2 = d^2 + (d + r)^2 <= 0.25, and D_theta alike.
# Since D >= d^2 the 8-DOF attitude stays within 0.5 rad of the 6-DOF plan's (requirement: the
# planner's attitude prediction-error budget is 0.5 rad; with the plan's attitude in
# [-0.5, 0.15] the predicted band [-1, 0.65] stays inside the small-angle validity range [-1, 1]
# of the progress model). Not implied by the domains (D reaches 2.42 on them).
# Before 2026-10-26 STEEP alone also carried v_L <= v_R (rows differed only for that); the
# attitude claim does not need it, and with v_L <= v_R in every mode the run exceeds the time
# budget (ERROR), so the rows are now the attitude rows in every mode.
# Tightest certifying constant: 0.25 (0.24 declines); the requirement value is the tight one.
#
# Domains: left |omega_psi|, |omega_theta| <= 0.6 and |psi|, |theta_p| <= 0.6 are forward
# invariant in the cascade chart (u' = -u; at psi = 0.6, psi' = u - 0.6 <= 0); right attitude
# boxes [-0.5, 0.15] forward invariant (decay); z, phi_r boxes forward invariant on both sides;
# v in [0, 0.8] forward invariant; s >= 0 unbounded above. The right guards cover s >= 0.
#
# Verdicts (RELCERT_IMPLIED_CUT=1): CERTIFIED under control, NO_CHOICE, SYNC, SYNC+NO_CHOICE,
# NO_PRUNE, NO_PRUNE+NO_CHOICE, OPREGION, NO_CUT, NO_IMPLIED_CUT, NO_LINEAR_CUT and without
# RELCERT_IMPLIED_CUT. Covers: lambda 1, budget 1 in every left mode; nothing pruned; cuts kept
# but not load-bearing; handoff vacuous (rows identical, a window claim). A ladder rung: no
# Table 1 mechanism.
