# rover_attitude_8to12: attitude-distance ladder, step 8 -> 12: roll, heave and lateral offset
# become second order (the right moves 8 coordinates, the left 12). Follows rover_attitude_6to8.
# scenario: model-refinement
#
# System: the terrain-zone rover of rover_attitude_6to8 (zones STEEP / MODER / FLAT by odometer
# s, set points 0.30 / 0.50 / 0.65, s' = v (1 - psi^2/2 - 0.3 theta_p^2)).
#
# Left (12-DOF): every attitude/position channel x in {psi, theta_p, z, phi_r, y} is a critically
# damped second-order loop (x'' + 2 x' + x = 0), all written in the cascade chart u = x' + x:
# x' = u - x, u' = -u (u is the state omega_x). Before 2026-10-26 the left was in the
# (angle, rate) chart, where its box was not forward invariant, while this header claimed the
# cascade chart; the dynamics are the same, the coordinates are now the cascade ones.
# Right (8-DOF; exactly rover_attitude_6to8's left with omega_z, omega_phi, y, omega_y pinned):
# psi, theta_p second order in the cascade chart, z' = -z, phi_r' = -phi_r first order;
# y' = 0 since 2026-10-26 (before y' = -y: the right moved 9 coordinates).
#
# Property (the same rows in every left mode): D_psi = (psi_L - psi_R)^2 + (omega_psi_L -
# omega_psi_R)^2 <= 0.25 and D_theta alike. This is the former row (gap^2 + 2 gap * rate gap +
# rate gap^2 with rate gap = (omega_L - psi_L) - (omega_R - psi_R)) rewritten in the cascade
# chart. D >= gap^2, so the 12-DOF heading and pitch stay within 0.5 rad of the 8-DOF model's
# (requirement: the 0.5 rad attitude prediction-error budget of rover_attitude_6to8). Chained
# with rover_attitude_6to8 (whose left is this file's right), the 12-DOF attitude stays within
# 1.0 rad of the 6-DOF plan (triangle inequality on the gap bounds). Not implied by the
# domains. The new channels (roll, heave, lateral) do not enter the property: this rung shows the
# attitude distance carries through a refinement whose new channels are off its projection.
# Before 2026-10-26 STEEP alone also carried v_L <= v_R; dropped as in rover_attitude_6to8.
# Tightest certifying constant: any level tried down to 0.01 (both sides run the same cascade
# loop on psi, theta_p, so D' = -2 d^2 + 2 d e - 2 e^2 <= -(d^2 + e^2) at lambda = 1); the claim
# keeps the requirement value.
#
# Domains: left |omega_psi|, |omega_theta| <= 0.6 with |psi|, |theta_p| <= 0.6 (as the right);
# |omega_z|, |omega_phi|, |omega_y| <= 0.4 with z in [-1, 1], phi_r in [-0.5, 0.5], y in
# [-0.5, 0.5]: in the cascade chart each box with |u| inside the angle box is forward invariant
# (u' = -u; at x = b, x' = u - b <= 0). Right boxes as rover_attitude_6to8's left, pinned
# coordinates boxed. v in [0, 0.8], s >= 0 unbounded above (left FLAT guard s < 899.95 dropped).
#
# Verdicts (RELCERT_IMPLIED_CUT=1): CERTIFIED under control, NO_CHOICE, SYNC, SYNC+NO_CHOICE,
# NO_PRUNE, NO_PRUNE+NO_CHOICE, OPREGION, NO_CUT, NO_IMPLIED_CUT, NO_LINEAR_CUT and without
# RELCERT_IMPLIED_CUT. Covers: lambda 1, budget 1 in every left mode; nothing pruned; cuts kept
# but not load-bearing; handoff vacuous (rows identical, a window claim). A ladder rung: no
# Table 1 mechanism.
