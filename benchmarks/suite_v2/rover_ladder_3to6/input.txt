# rover_ladder_3to6: rover hierarchy, step 3 -> 6: pitch, heave and roll move.
# scenario: model-refinement
# mechanisms: none (a ladder rung: CERTIFIED under every counter-run; lambda 1, one segment per
#   window)
#
# System (the canonical rover hierarchy, stated in full here and shared by rover_ladder_2to3,
# 3to6, 6to8 and 8to12; SI units, time in s, angles in rad): a four-wheel UGV (track 1.8 m, centre
# of gravity 0.9 m high, so the load-transfer ratio is LTR = a_b/g + phi_r and the static rollover
# threshold is 1 g; governed top speed 8 m/s) drives a route of three straight zones indexed by its
# odometer s [m]: STEEP s in [0, 60) (grade 0.15, cross-slope 0.10, speed set point c = 3.0 m/s),
# MODER [60, 140) (0.05, 0.05, 5.0 m/s), FLAT s >= 140 (level, 6.5 m/s). Speed loop v' = 0.5 (c - v)
# on every level (time constant 2 s); control interval 1 s on both sides. r = psi' is the yaw-rate
# error (r = -psi at L3 and L6, omega_psi - psi at L8 and L12), a = v r the lateral acceleration
# [m/s^2] of the heading corrections, g = 9.81 m/s^2. The levels:
#   L2 (v, s): s' = v.
#   L3 + heading error psi (steering loop 1 rad/s): psi' = -psi; s' = v (1 - psi^2/2) (along-track
#       component).
#   L6 + pitch theta_p, heave z [m], roll phi_r (terrain-following suspension, time constant 1 s):
#       theta_p' = -theta_p + grade + 0.5 z (bounce-pitch coupling), z' = -z, phi_r' = -phi_r +
#       xslope + 0.015 a (roll gradient 0.015 rad per m/s^2); s' = v (1 - psi^2/2 - 0.3 theta_p^2 -
#       0.2 phi_r^2) (wheel slip on the grade, crabbing on the cross-slope).
#   L8 + yaw and pitch inertia (critically damped at 1 rad/s, cascade chart w = x' + x; L6's heading
#       is L8's at omega_psi = 0): psi' = omega_psi - psi, omega_psi' = -omega_psi; theta_p' =
#       omega_theta - theta_p, omega_theta' = -omega_theta + grade + 0.5 z.
#   L12 + heave and roll inertia and tire slip: z' = omega_z - z, omega_z' = -omega_z; phi_r' =
#       omega_phi - phi_r, omega_phi' = -omega_phi + xslope + 0.015 a_b with the body lateral
#       acceleration a_b = a + y''; slip offset y [m]: y' = omega_y - y, omega_y' = -omega_y + 0.03
#       (a + g phi_r) (tire lateral compliance 0.03 m per m/s^2 of lateral load: centripetal plus
#       gravity on the rolled chassis), so y'' = y - 2 omega_y + 0.03 (a + g phi_r): slip moves the
#       rover sideways and drives roll.
# Requirements (one constant each): heading 0.35 rad = half field of view of the navigation camera
# (the path stays in view); pitch 0.25 rad = range of the mast camera's tilt stabilizer; roll 0.2
# rad = suspension roll stop; LTR 0.8 = 20 % margin to wheel lift (LTR = 1); lane 0.25 m = corridor
# half-width 1.25 m minus vehicle half-width 1.0 m. In the cascade chart the rate state carries its
# angle's tolerance (abs(x' + x) <= tol keeps the critically damped angle inside abs(x) <= tol).
# Each rung carries the requirements of the dynamics it adds: heading (2to3); pitch (3to6); heading,
# pitch, roll and rollover under yaw and pitch inertia (6to8); heading, roll, rollover and lane
# under roll inertia and tire slip (8to12).
#
# Left (L6: all six coordinates move). Right (L3, rover_ladder_2to3's left: v, s, psi move; theta_p,
# z, phi_r frozen: rate 0 and absent from the other rates). The one difference is the suspension
# attitude: pitch settling to the grade and kicked by heave, roll settling to the cross-slope and
# driven by the lateral acceleration, and their slip and crabbing losses in s'.
#
# Property (the same rows in every left mode):
#   v_L <= v_R and s_L <= s_R (clearance, as in rover_ladder_2to3; s_L + 1 <= s_R also certifies,
#     s_L <= s_R + 1 DECLINES).
#   psi_L = psi_R: the heading loop is identical on both sides and the cover is synchronous, so the
#     headings coincide (the true row the dynamics imply; with it the attitude losses only slow the
#     rover).
#   abs(theta_p_L) <= 0.25 (pitch requirement, the step's new channel: grade plus heave-induced
#     pitch stays inside the tilt-stabilizer range). Tightest certifying 0.23 (0.22 declines): the
#     steepest grade plus the heave kick, 0.15 + 0.5 x 0.15 = 0.225. The pitch row reads the model:
#     with the bounce-pitch coupling tripled the file DECLINES (round-2 review variant
#     ladder36_heave3x).
#
# Stretch range: lambda_min = lambda_max = 1. This rung certifies synchronously (RELCERT_SYNC=1
# CERTIFIES), so it uses none of the ladder's timetable margin (the 25 % of rover_ladder_6to8's
# header).
#
# Domains (validity ranges, symmetric, forward invariant face by face, checked with Z3 for every
# level and zone): v in [0, 8] m/s (governed top speed); s >= 0 (s' >= 0); psi, omega_psi, theta_p,
# omega_theta in [-0.6, 0.6] (small-angle validity of the cos and slip expansions); z, omega_z in
# [-0.15, 0.15] m (suspension travel); phi_r, omega_phi in [-0.5, 0.5]; y, omega_y in [-0.5, 0.5] m.
# One domain, the same text on both sides and in every mode: v in [0, 8], s >= 0, psi, theta_p in
# [-0.6, 0.6], z in [-0.15, 0.15], phi_r in [-0.5, 0.5]; the right's frozen theta_p, z, phi_r stay
# at their start values, inside the box. Every requirement constant lies strictly inside its
# coordinate's validity range, so no row is implied by the domains. Load-bearing (domain scan
# 2026-10-29 on the one domain, one nonzero bound at a time widened by 20 % of its range): only the
# suspension-travel ceiling z <= 0.15 m, the bump stop of the suspension (the pitch row's envelope
# is held by the travel the hardware allows, not by a reachable-set estimate); all nonzero bounds
# widened by 5 % CERTIFIES, all other nonzero bounds widened by 20 % CERTIFIES. The zero bound v >= 0

# Guards: the zones on s, on both sides (they partition s >= 0: every state is in exactly one
# guard). No speed condition (this lambda = 1 rung does not need the zone entry speed v <= c the
# re-timed rungs carry).
# Every left mode has a satisfiable start (the reference in the same zone with the same v and s, its
# attitude at the zone's equilibrium). RELCERT_OPREGION=1 CERTIFIES (every admitted start is in some
# right guard).
#
# Composes: after rover_ladder_2to3, before rover_ladder_6to8 (whose right is this file's left with
# omega_psi, omega_theta frozen, and whose plan tolerances on this model are the heading, pitch and
# roll requirements); the clearance rows chain by transitivity.
# One domain (2026-10-29): right theta_p, z, phi_r in [0, 0] -> the validity box (theta_p in

# Verdicts (RELCERT_IMPLIED_CUT=1 unless stated; measured 2026-10-26 with the design binary, again
