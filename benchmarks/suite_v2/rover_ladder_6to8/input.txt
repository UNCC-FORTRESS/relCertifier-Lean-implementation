# rover_ladder_6to8: rover ladder, step 6 -> 8: heading and pitch become second order (their
# rates omega_psi, omega_theta move).
# scenario: model-refinement
# mechanisms: S M I (time stretch lambda = 3/2 and two right segments per window, RELCERT_SYNC=1
#   declines; the zone facts s >= zone floor and v <= set point are load-bearing mode facts,
#   RELCERT_NO_CUT=1 declines; matrix codes M1 M2 M6)
#
# System (the rover ladder; normalized units, time in s): a rover drives a three-zone route
# indexed by its odometer s: STEEP s in [0, 0.6), MODER [0.6, 1.4), FLAT s >= 1.4, speed set
# points c = 0.30 / 0.50 / 0.65, first-order speed loop v' = 3 (c - v). The ladder's models:
#   2-DOF plan (v, s): s' = v.
#   3-DOF: + heading psi' = -psi; s' = v (1 - psi^2/2) (only the along-track component of the
#     speed counts: cos psi to second order).
#   4-DOF: + pitch theta_p' = -theta_p; s' = v (1 - psi^2/2 - 0.3 theta_p^2) (wheel slip on a slope).
#   6-DOF: + heave z' = -z and roll phi_r' = -phi_r. Roll costs progress (cross-slope crabbing: on
#     a rolled chassis the rover crabs uphill to hold its track), s' = v (1 - psi^2/2 - 0.3 theta_p^2
#     - 0.2 phi_r^2); heave pitches the chassis (bounce-pitch coupling, softer rear suspension),
#     theta_p' = -theta_p + 0.5 z, so heave reaches progress through pitch.
#   8-DOF: heading and pitch become second order, critically damped (x'' + 2 x' + x = forcing),
#     written in the cascade chart omega = x' + x: psi' = omega_psi - psi, omega_psi' = -omega_psi,
#     theta_p' = omega_theta - theta_p, omega_theta' = -omega_theta + 0.5 z; heave, roll as 6-DOF.
#   12-DOF: heave, roll and lateral sway y become second order too (cascade chart, omega_z,
#     omega_phi, omega_y), and roll is driven by the sway acceleration y'' = y - 2 omega_y:
#     omega_phi' = -omega_phi + 0.2 (y - 2 omega_y), so sway reaches progress through roll.
#
# Left (8-DOF, all 8 coordinates move). Right (6-DOF, rover_ladder_3to6's left): omega_psi,
# omega_theta pinned. The one difference is the second-order attitude lag (heading and pitch
# decay through their rates instead of directly). Both sides' zone guards carry the zone entry
# condition v <= set point (the right's because it is rover_ladder_3to6's left verbatim).
#
# Property (the same rows in every left mode): v_L <= v_R and s_L <= s_R (never faster, never
# ahead: the clearance requirement of rover_ladder_2to3). The s offset 0 is the requirement value
# (s_L + 1 <= s_R also certifies: the gap only grows). The rows do not relate the attitudes (the
# attitude gap is the subject of rover_attitude_6to8). Not implied by the domains.
#
# Why stretching is needed (S, M). The rows leave the plan's attitude free, so its progress factor
# 1 - psi^2/2 - 0.3 theta_p^2 - 0.2 phi_r^2 can be as low as 0.75 (every angle at -0.5) against the
# rover's 1: the plan must run at least 4/3 as fast (measured with a fixed stretch: 1.33 declines,
# 1.34 certifies). The cover uses lambda = 3/2 with two plan segments per window (budget 2);
# under RELCERT_SYNC=1 it DECLINES.
# Why the mode facts are needed (I). The stretched plan's speed loop 3 lambda (c - v) dominates the
# rover's only below the set point, and the progress comparison needs s inside the zone: the
# checked cuts s >= zone floor and v <= set point (guard conjuncts kept along each mode's flow)
# carry this; under RELCERT_NO_CUT=1 it DECLINES. The entry condition is needed on at least one
# side: without it on both sides the benchmark DECLINES, without it on either side alone it
# certifies.
#
# Domains: left psi, theta_p, omega_psi, omega_theta in [-0.6, 0.6] (forward invariant in the
# cascade chart: x' = omega - x points inward when the omega box lies inside the x box; pitch
# forcing 0.5 z with z in [-1, 0.15] keeps omega_theta' inward on both faces), phi_r in
# [-0.5, 0.15], z in [-1, 0.15], v in [0, 0.8], s >= 0. Right: the 6-DOF boxes of
# rover_ladder_3to6 (forward invariant), pinned omega boxes containing their constants.
# Coverage: the right's guards carry the zone entry condition, so a right state above its zone's
# set point is in no right guard. Such states are unreachable for the right: it starts in a guard
# (v <= set point), v' = 3 (c - v) keeps v <= c inside a zone, and set points increase along the
# route. Every left mode has a satisfiable start.
#
# Composes: after rover_ladder_3to6, before rover_ladder_8to12 (whose right is this file's left
# with omega_z, omega_phi, y, omega_y pinned); the v and s rows chain by transitivity.
# Verdicts (RELCERT_IMPLIED_CUT=1 unless stated): CERTIFIED; CERTIFIED under RELCERT_NO_CHOICE=1,
# RELCERT_NO_PRUNE=1, NO_PRUNE+NO_CHOICE, RELCERT_NO_IMPLIED_CUT=1, RELCERT_NO_LINEAR_CUT=1,
# RELCERT_OPREGION=1 and without RELCERT_IMPLIED_CUT; DECLINED under RELCERT_SYNC=1,
# SYNC+NO_CHOICE and RELCERT_NO_CUT=1. Covers: lambda 3/2 and budget 2 in every left mode; nothing
# pruned; no right-only reposition; rows identical (--handoff vacuous, 5/5).
