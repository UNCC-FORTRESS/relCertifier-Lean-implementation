# rover_lateral_8to12: lateral corridor keeping on both axles, the 12-DOF rover refining the
#   8-state lateral rover (step 8 -> 12: the right moves 8 coordinates, the left 12).
# scenario: model-refinement
# mechanisms: none (a ladder rung: CERTIFIED under every counter-run, RELCERT_SYNC=1,
#   RELCERT_NO_CHOICE=1, RELCERT_NO_PRUNE=1, RELCERT_NO_CUT=1 and without RELCERT_IMPLIED_CUT;
#   lambda 1, one segment per window)
#
# Coordinates: v, s, psi (heading), theta_p (pitch), z, phi_r as in rover_lateral_6to8; y lateral
#   offset of the front axle from the lane centreline (m, positive right) and w its regulated
#   lateral speed; y2, w2 the same for the rear axle; w3, w4 the front and rear lateral
#   tyre-slip velocities (m/s).
# Right (reasoning): rover_lateral_6to8's left model, the 8-state lateral rover (6-DOF rover with
#   phi_r decaying, front-axle regulator y' = w, w' = -y - 2w, no slip), with the four 12-DOF
#   coordinates pinned: y2' = 0, w2' = 0, w3' = 0, w4' = 0.
# Left (deployed, all 12 coordinates move): the same, plus the rear-axle regulator
#   y2' = w2 + w4, w2' = -y2 - 2 w2 (critically damped like the front), and tyre slip: each
#   axle's lateral velocity is the regulated speed plus the slip velocity, y' = w + w3,
#   y2' = w2 + w4, and the slip relaxes with the tyre relaxation time 0.5 s, w3' = -2 w3,
#   w4' = -2 w4 (a transient left by a terrain disturbance before the window starts). The two
#   sides differ exactly in y', y2', w2', w3', w4' (one cause: the rear axle and tyre slip
#   are modeled); modes, successors and guards are equal.
# Modes: STEEP (s in [0, 0.6), set speed 0.30), MODER (s in [0.6, 1.4), 0.50), FLAT (s >= 1.4,
#   0.65, terminal); next = [MODER, STEEP], [FLAT, MODER], [FLAT]. Every s >= 0 lies in exactly
#   one guard on each side (no coverage gap); every left mode has a satisfiable start.
# Property (the same rows in every mode): the ladder rows v_L <= v_R, s_L <= s_R,
#   psi_L = psi_R, theta_p_L = theta_p_R; corridor keeping on both axles, y_L <= y_R + d and
#   y2_L <= y2_R + d; and the slip-inclusive leads y_L + w_L + w3_L <= y_R + w_R + d and
#   y2_L + w2_L + w4_L <= y2_R + d. The leads are what make the corridor rows inductive: with
#   c = y + w + w3 the left's front pair is c' = -c, y' = c - y (the slip relaxing twice as fast
#   as the regulator cancels its own effect on c), the right's is the same with w3 = 0. The
#   slip-free lead y_L + w_L <= y_R + w_R + d DECLINES (the slip pushes the deployed rover past
#   it), as does a slip relaxing at rate 1 (resonant with the regulator).
# Requirement behind d = 0.5 m (both axles): as in rover_lateral_6to8, the deployed rover may be
#   at most one lane half-width further right than the reference on each axle. Tightest
#   certifiable constants: front 0.00 (-0.01 DECLINES: a deployed rover whose slip-inclusive
#   lead starts no further right stays no further right), rear 0.50 (0.49 DECLINES: against a
#   frozen rear offset at the left edge the rear regulator recentres by the full half-width).
# Domains (both sides, every mode): lane -0.5 <= y, y2 <= 0.5; leads in [-0.5, 0.5] (left:
#   y + w + w3 and y2 + w2 + w4, forward-invariant since c' = -c; right: y + w and y2 + w2,
#   forward-invariant under its regulator and frozen rear); lateral speeds and slip velocities
#   in [-1, 1] (each face inflows: w' = -y - 2w, w3' = -2 w3); attitude and heave boxes as in
#   rover_lateral_6to8 (forward-invariant); v in [0, 0.8]; s >= 0. No row follows from the
#   domains. Load-bearing bound (scripts/domain_widening.py): only the right's rear lane edge
#   y2_R >= -0.5.
# Verdicts (RELCERT_IMPLIED_CUT=1 unless stated): CERTIFIED; CERTIFIED under RELCERT_SYNC=1,
#   RELCERT_NO_CHOICE=1, SYNC+NO_CHOICE, RELCERT_NO_PRUNE=1, NO_PRUNE+NO_CHOICE, RELCERT_NO_CUT=1,
#   RELCERT_NO_IMPLIED_CUT=1, RELCERT_NO_LINEAR_CUT=1, RELCERT_OPREGION=1 and without
#   RELCERT_IMPLIED_CUT. Covers: lambda 1, budget 1 in every left mode; nothing pruned; no
#   right-only reposition; guard cuts kept but not load-bearing; rows identical (--handoff
#   vacuous, 5/5).
