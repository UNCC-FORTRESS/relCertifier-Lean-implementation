# rover_rollover_6to12: rollover safety of the 12-DOF rover against its 6-DOF terrain plan, the
# direct refinement step 6 -> 12 of the rollover ladder (rover_rollover_6to7, rover_rollover_7to12).
# scenario: model-refinement
# mechanisms: S M I (time stretch 5/4, RELCERT_SYNC=1 declines; two plan cycles per window; the
#   guard conjuncts as load-bearing checked cuts; matrix codes M1 M2 M6)
#
# System. A rover crosses three terrain zones by odometer s: STEEP (0 <= s < 0.6, speed set
# point c = 0.30), MODER (0.6 <= s < 1.4, c = 0.50), FLAT (s >= 1.4, c = 0.65), with
# v' = 3 (c - v) and s' = v (1 - psi^2/2 - 0.3 theta_p^2) (attitude angles psi, theta_p in rad).
# Yaw channel: heading error e, yaw rate r. Roll (phi_r, omega_phi), heave z, lateral offset y.
#
# Left (12-DOF, all 12 coordinates move; the same model as rover_rollover_7to12's left):
# attitude psi' = omega_psi, omega_psi' = -psi - 2 omega_psi (theta_p, omega_theta and the roll
# pair alike; critically damped), yaw e' = r, r' = -4 e - 4 r, heave z' = -z, lateral y' = -y.
# Right (6-DOF plan, 6 coordinates move; the same model as rover_rollover_6to7's right): v, s and
# the first-order psi' = -psi, theta_p' = -theta_p, e' = -e, phi_r' = -phi_r; omega_psi,
# omega_theta, r, omega_phi, z, y are pinned (derivative 0). Its guards carry the zone entry
# condition v <= c (a zone is entered at or below its set point; v' = 3 (c - v) keeps it there,
# and the next zone's set point is higher, so the plan's own switches always meet it).
#
# Property (the same rows in every left mode).
#   v_L <= v_R and s_L <= s_R: the rover is never faster than, and never ahead of, the plan.
#   |v_L r_L| <= 1.0: lateral acceleration within a_max = 1.0 (track / (2 h_cg) g, the rollover
#   threshold). Unstatable below this fidelity on the right: the plan's r is pinned.
#   V(e_L, r_L) = 1.125 e^2 + 0.25 e r + 0.156 r^2 <= 0.33: a Lyapunov function of the yaw loop
#   (V' = -e^2 + 0.002 e r - 0.998 r^2 < 0). 0.33 is the largest two-decimal level whose sublevel
#   set (|r| <= 1.524) gives |v r| <= 0.65 * 1.524 = 0.99 < a_max at the top set point 0.65.
# Tightest certifying constants: the s offset certifies at every value tried down to -1 (the plan
# runs on the stretched clock and is never slower), the energy at every level down to 0 (any
# sublevel set of V is invariant), |v r| down to 0.47 (0.46 declines); the claim keeps the
# requirement values. Not implied by the domains (they allow V up to about 3.5 and |v r| up to 1.2).
#
# Domains (the audit of rover_rollover_7to12). Left attitude and roll psi, omega_psi, theta_p,
# omega_theta, phi_r, omega_phi in [-1, 1], the small-angle model's validity range (before:
# [-0.5, 0.5], not forward invariant, the damped loops overshoot it). The left guards carry the two
# start conditions 7to12 needs (settled attitude psi, omega_psi, theta_p, omega_theta >= -0.25;
# zone entry v <= c), because the left is one model for both files; this file certifies without
# either. Left e in [-1.5, 1.5], r in [-1.52, 1.52], v in [0, 0.8]: physical limits, not
# load-bearing (widened to e, r in [-3, 3], v in [0, 1]: CERTIFIED). Left z, y in [-1, 0.15] and
# every right box are forward invariant (contractions toward 0, pinned coordinates, v toward c);
# s >= 0 is unbounded above (the left's s <= 1000 and FLAT guard s < 899.95 were dropped).
#
# Operating region. RELCERT_OPREGION=1 reports, per left mode, right states the invariant admits
# in no right guard: right speeds above their zone's set point. They are outside the plan's
# operating region (never reached from a guard) and Theorem 3's premise excludes them as starts.
#
# Composition. With the same three models, rover_rollover_7to12 relates the 12-DOF left to the
# 7-DOF intermediate IM by v_L <= v_IM, s_L <= s_IM and the two rollover rows on the left, and
# rover_rollover_6to7 relates IM to this file's right by v_IM <= v_R, s_IM <= s_R. Chained, the
# rows give exactly this file's rows (v and s by transitivity, the rollover rows from 7to12;
# 7to12's attitude rows are extra).
#
# Verdicts (RELCERT_IMPLIED_CUT=1 unless stated, measured 2026-10-26): CERTIFIED (also NO_CHOICE,
# NO_PRUNE, NO_PRUNE+NO_CHOICE, NO_IMPLIED_CUT, NO_LINEAR_CUT, OPREGION, and without
# RELCERT_IMPLIED_CUT); DECLINED under SYNC, SYNC+NO_CHOICE and NO_CUT. Without the two left start
# conditions (settled attitude, zone entry v <= c) the file still CERTIFIES; with an s offset of
# +0.2 too. Covers: lambda 5/4 and budget 2 in every left mode (S, M; admissible right starts:
# from STEEP all three zones, from MODER MODER and FLAT, from FLAT FLAT); checked cuts
# load-bearing (I); nothing pruned; handoff vacuous (rows identical, 5/5).
