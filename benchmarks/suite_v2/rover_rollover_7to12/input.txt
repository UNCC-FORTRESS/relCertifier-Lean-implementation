# s, speed set points 0.30 / 0.50 / 0.65, s' = v (1 - psi^2/2 - 0.3 theta_p^2)).
#
# Left (12-DOF, all 12 coordinates move; the same model as rover_rollover_6to12's left): attitude
# psi' = omega_psi, omega_psi' = -psi - 2 omega_psi (theta_p and roll alike; critically damped),
# yaw e' = r, r' = -4 e - 4 r (original chart: r is the yaw rate), heave z' = -z, lateral y' = -y.
# Right (the 7-DOF intermediate model IM; the same model as rover_rollover_6to7's left): first-order
# attitude psi' = -psi, theta_p' = -theta_p, roll phi_r' = -phi_r, the same yaw loop in its
# cascade chart (r_R = yaw rate + 2 e: e' = r - 2 e, r' = -2 r, a linear bijection under which the
# e, r box is forward invariant); omega_psi, omega_theta, omega_phi, z, y pinned. No speed
# condition in its guards.
#
# Property (the same rows in every left mode; before 2026-10-26 the file had the attitude rows
# only, plus v_L <= v_R in STEEP, and carried no rollover property).
#   v_L <= v_R and s_L <= s_R: the rover is never faster than, and never ahead of, IM.
#   |v_L r_L| <= 1.0 and V(e_L, r_L) <= 0.33: rover_rollover_6to12's rollover rows (a_max = 1.0;
#   0.33 the largest two-decimal yaw-energy level giving |v r| < a_max at v <= 0.65).
#   D_psi = 2 (psi_L - psi_R)^2 + 2 (psi_L - psi_R) omega_psi_L + omega_psi_L^2 <= 0.25, D_theta
#   alike: D >= (psi_L - psi_R)^2, so the attitude gap stays within 0.5 rad; with the reference
#   in [-0.5, 0.15] the 12-DOF attitude stays in [-1, 0.65], inside the small-angle validity
#   range [-1, 1] of the left domain.
# Tightest certifying constants: D 0.22 (0.21 does not certify: the run ends in the tool's time
# budget), |v r| 0.47 (0.46 declines), s offset any
# value tried down to -1, energy any level down to 0; the claim keeps the requirement values. With
# an s offset of +0.2 the file DECLINES (the right-only reposition that a lagging IM needs breaks
# the attitude rows). Not implied by the domains.
#
# DOMAIN AUDIT (docs/SUITE-REDESIGN.md section 13; resolved 2026-10-08, user decision). Left
# attitude domains are the PHYSICAL validity range of the small-angle model: psi, omega_psi,
# theta_p, omega_theta in [-1, 1] (before: [-0.5, 0.5], a floor the claim stood on although the
# loop overshoots it); roll phi_r, omega_phi likewise in [-1, 1] since 2026-10-26. The deployed
# terrain controller switches zones, and starts its first zone, only when the attitude is SETTLED:
# every left guard carries psi, omega_psi, theta_p, omega_theta >= -0.25, a controller-design
# condition on the switch (the flow may leave it after entry). Why D needs it: the left attitude
# loop is critically damped, so q = omega_psi + psi satisfies q' = -q; from the entry box
# q >= -0.5 (linear-form cut) and inside it psi >= -0.5 (derived-bound cut). With psi_L = -0.95,
# omega_psi_L = 0.232, psi_R = -0.5 the derivative of D is -0.522 + 0.668 lambda > 0 for every
# lambda >= 1, so some floor is necessary. Second start condition: zone entry v <= c in every
# left guard (needed: without it, and without speed conditions on the right, the file DECLINES).
# Left e in [-1.5, 1.5], r in [-1.52, 1.52], v in [0, 0.8]: physical limits, not load-bearing
# (widened to e, r in [-3, 3], v in [0, 1]: CERTIFIED). The right attitude caps psi, theta_p <= 0.15
# are load-bearing (0.475: DECLINED) and forward invariant (psi' = -psi points inward). Every
# other box is forward invariant; s >= 0 unbounded above (left FLAT guard s < 899.95 dropped).
#
# Verdicts (RELCERT_IMPLIED_CUT=1 unless stated, measured 2026-10-26): CERTIFIED (also NO_CHOICE,
# NO_PRUNE, NO_PRUNE+NO_CHOICE, OPREGION: every admitted start in some right guard); DECLINED
