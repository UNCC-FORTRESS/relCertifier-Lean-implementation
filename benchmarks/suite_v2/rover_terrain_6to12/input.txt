# rover_terrain_6to12: terrain ladder, step 6 -> 12: attitude and heave become second order and
# the body accelerations become states; the right moves 6 coordinates, the left all 12.
# scenario: model-refinement
# mechanisms: M1 M2 M6
#
# System: the terrain-zone rover of rover_terrain_3to6 (zones STEEP / MODER / FLAT by odometer s,
# set points c = 0.30 / 0.50 / 0.65, speed loop v' = 3 (c - v) on both sides,
# s' = v (1 - psi^2/2 - 0.3 theta_p^2 - 0.2 phi_r^2) on both sides: pitch and roll cost progress).
#
# Right (6-DOF; exactly rover_terrain_3to6's left): psi, phi_r, z decay first order, pitch is
# driven by heave, theta_p' = -theta_p + 0.5 z; omega_psi, omega_theta, omega_phi, vz, ax, ay
# pinned. Until 2026-10-26 the right had s' = v, and (until the second 2026-10-26 revision) heave
# and roll entered no equation of the 6-DOF model.
# Left (12-DOF): heading, pitch, roll and heave are critically damped second-order loops (heave
# damped by the suspension; before 2026-10-26 heave was an undamped oscillator z'' = -z), each
# in its CASCADE CHART (omega_x := x' + x, so x' = omega_x - x, omega_x' = -omega_x + forcing;
# vz is heave's omega). The body accelerations are first-order lagged states (time constant
# 0.2): longitudinal ax' = 5 (3 (c - v) - ax) tracks the speed loop's acceleration, lateral
# ay' = 5 (v psi_rate - ay) with psi_rate = omega_psi - psi tracks the centripetal acceleration.
# They load the chassis: pitch squat and bounce-pitch omega_theta' = -omega_theta + 0.1 ax + 0.5 z
# (pitch costs progress), body roll omega_phi' = -omega_phi + 0.1 ay (0.1 rad per unit
# acceleration; roll costs progress). Before
# 2026-10-26 ax, ay were pinned on the left too (the step moved 10, not 12, coordinates).
#
# Property (the same rows in every left mode): v_L <= v_R and s_L <= s_R: the rover is never
# faster than, and never ahead of, the 6-DOF plan. Offset 0 (before: + 0.2, not a requirement).
# Not implied by the domains.
# Tightest: the s offset certifies at every value tried down to -1; the claim keeps 0.
#
# DOMAIN AUDIT (2026-10-26): the left used to be in the (angle, rate) chart with an undamped heave,
# a box the flow leaves. Now every left box is forward invariant: angles psi, theta_p, phi_r and z
# in the validity range [-1, 1] with their cascade coordinates in [-1, 1] (inflow when |omega| <=
# the bound and the forcing is below 1: |0.1 ay| <= 0.16, |0.1 ax + 0.5 z| <= 0.695); ax in [-1.5, 1.95] = the range of 3 (c - v) over v in [0, 0.8] and
# the three set points; ay in [-1.6, 1.6] = the bound of v psi_rate (|psi_rate| <= 2, v <= 0.8);
# v in [0, 0.8]; s >= 0 unbounded above (caps s <= 1000, FLAT s < 899.95 dropped). Guards: zone
# band and zone entry v <= set point on both sides (left caps added for consistency with
# rover_terrain_3to6; not load-bearing). A state with v above its zone's set point lies in no
# guard: unreachable from a guarded entry (v' = 3 (c - v) keeps v <= c; set points increase).
#
# Composition: the right model is rover_terrain_3to6's left with the six new coordinates pinned,
# so this file's v and s rows chain with 3to6's by transitivity (12-DOF <= 6-DOF <= 3-DOF plan).
# rover_terrain_6to8 is a sibling refinement of the same 6-DOF model (its 8-DOF left has no squat
# coupling), not an intermediate step of this one.
#
# Verdicts (RELCERT_IMPLIED_CUT=1): CERTIFIED (also NO_CHOICE, NO_PRUNE, NO_PRUNE+NO_CHOICE,
# OPREGION, NO_IMPLIED_CUT, NO_LINEAR_CUT, and without RELCERT_IMPLIED_CUT); DECLINED under SYNC,
# SYNC+NO_CHOICE, NO_CUT. Covers: lambda 3/2, budget 2 in every left mode (M1, M2); checked cuts
# load-bearing (M6); nothing pruned; no right-only reposition; handoff vacuous (rows identical).
