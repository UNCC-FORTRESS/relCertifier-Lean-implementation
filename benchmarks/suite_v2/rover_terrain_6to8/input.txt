# rover_terrain_6to8: terrain ladder, step 6 -> 8: heading and pitch become second order
# (rotational inertia); the right moves 6 coordinates, the left 8.
# scenario: model-refinement
# mechanisms: M1 M2 M6
#
# System: the terrain-zone rover of rover_terrain_3to6 (zones STEEP / MODER / FLAT by odometer s,
# set points 0.30 / 0.50 / 0.65, speed loop v' = 3 (c - v) on both sides,
# s' = v (1 - psi^2/2 - 0.3 theta_p^2) on both sides).
#
# Right (6-DOF; exactly rover_terrain_3to6's left): psi' = -psi, theta_p' = -theta_p,
# z' = -z, phi_r' = -phi_r; omega_psi, omega_theta pinned. Until 2026-10-26 the right had
# s' = v, contradicting the "previous rung's fine model" claim.
# Left (8-DOF): heading and pitch are critically damped second-order loops (psi'' = -psi - 2 psi',
# theta_p alike), written in their CASCADE CHART: omega_psi := psi' + psi (likewise omega_theta),
# a linear bijection under which the loop reads psi' = omega_psi - psi, omega_psi' = -omega_psi.
# Heave and roll first order as on the right.
#
# Property (the same rows in every left mode): v_L <= v_R and s_L <= s_R: the rover is never
# faster than, and never ahead of, the 6-DOF plan. Offset 0 (before 2026-10-26: + 0.2, not a
# requirement). Not implied by the domains.
# Tightest: the s offset certifies at every value tried down to -1; the claim keeps 0.
#
# DOMAIN AUDIT (2026-10-26): the left used to be in the (angle, rate) chart with the box
# psi, theta_p in [-0.5, 0.5], rates in [-1, 1], which the loop leaves (not forward invariant).
# Now the left attitude box is the small-angle validity range psi, theta_p in [-1, 1] with
# omega_psi, omega_theta in [-1, 1] in the cascade chart, where it is forward invariant
# (angle' = omega - angle points inward when |omega| <= the angle bound; omega' = -omega).
# Narrower boxes (0.5, 0.8) also certify. phi_r in [-0.5, 0.15], z in [-1, 0.15], v in [0, 0.8]
# forward invariant; s >= 0 unbounded above (the left caps s <= 1000 and FLAT s < 899.95 dropped).
# Guards: zone band of s and zone entry v <= set point on both sides (left caps added for
# consistency with rover_terrain_3to6; not load-bearing). A state with v above its zone's set
# point lies in no guard: unreachable from a guarded entry (v' = 3 (c - v) keeps v <= c inside a
# zone; set points increase along the route).
#
# Composition: the right model is rover_terrain_3to6's left with the two rates pinned, so this
# file's v and s rows chain with 3to6's by transitivity (8-DOF <= 6-DOF <= 3-DOF plan).
# rover_terrain_6to12 is a sibling refinement of the same 6-DOF model, not a continuation.
#
# Verdicts (RELCERT_IMPLIED_CUT=1): CERTIFIED (also NO_CHOICE, NO_PRUNE, NO_PRUNE+NO_CHOICE,
# OPREGION, NO_IMPLIED_CUT, NO_LINEAR_CUT, and without RELCERT_IMPLIED_CUT); DECLINED under SYNC,
# SYNC+NO_CHOICE, NO_CUT. Covers: lambda 5/4, budget 2 in every left mode (M1, M2); checked cuts
# load-bearing (M6); nothing pruned; no right-only reposition; handoff vacuous (rows identical).
