# salt_tank_sensor: a brine-mixing tank whose salt sensor is under a bounded attack holds within
# 3 lb of salt of the genuine tank (the forward simulation distance of measuring robustness of
# cyber-physical systems under sensor attacks).
# scenario: sensor-attack
# mechanisms: I (mode facts are load-bearing: the attacked Off holds its level, xp <= 28, and
#   the genuine On flow keeps xp >= 25; RELCERT_NO_CUT=1 declines)
#
# SOURCE. Xiang, Lanotte, Tini, Chong, Merro, "Measuring robustness in cyber-physical systems
# under sensor attacks", Nonlinear Analysis: Hybrid Systems 56 (2025) (arXiv 2403.05829), Sec. 7,
# Fig. 7 (model) and Figs. 8-13 (proof of the forward distance); the same tank is the forall-exists
# case study of Xiang and Chong, "Extending dynamic logics with first-class relational reasoning"
# (NFM 2025, Sec. 5). A tank of xL = 100 gal holds xp lb of salt; brine of 1/4 lb/gal enters at
# r gal/min and the stirred mixture drains at r: xp' = r/4 - r xp/xL, t' = 1 & t <= eps, eps = 1
# (min). Controller xs := xp; (?xs >= 25; r := 10) or (?xs < 25; r := 0). Pre xp = 50; safety
# xp >= 20. Bounded sensor attack: xs := *; ?(xp - 3 <= xs <= xp + 3). Claim: attacked(P) and P are
# at forward distance 3 on H = {xp} (Figs. 8-9), with the proof invariant
# (25 < xp < 28 and 25 < xp1 < 28) or (xp = xp1 and xp >= 28).
#
# THIS FILE. Left = attacked controller, right = genuine controller, same plant. The attacked
# reading is projected onto the physical level, exactly: On (r = 10) is possible when some reading
# in [xp - 3, xp + 3] is >= 25, i.e. xp >= 22; Off (r = 0) when some reading is < 25, i.e.
# xp < 28. Genuine: On iff xp >= 25, Off iff xp < 25. Flows On xp' = 0.1 (25 - xp) (the source's
# 10/4 - 10 xp/100, written in set-point form), Off xp' = 0. Stretch pinned to 1 (both tanks run
# the 1-min control period in lock step, as the source's proof does).
#
# CLAIM (both left modes): |xp_L - xp_R| <= 3 (two rows), xp_L >= 25 and xp_R >= 25. The band is the
# source's distance; the lower bounds are those of the source's invariant (from the pre xp = 50
# both tanks stay above the On equilibrium 25). Requirement: a reading error of at most 3 lb moves
# the salt by at most 3 lb. Tight: xp_L <= xp_R + c certifies down to c = 3.00 (2.99 declines),
# the paper's distance (the attacked tank can hold its salt (Off) just below 28 while the genuine
# one settles toward 25). The other row is slack: xp_R <= xp_L certifies (c' = 0; -0.01 declines):
# the genuine tank never holds more salt than the attacked one. Not implied by the domain
# (xp >= 0); every left mode has a satisfiable start (xp_L = xp_R = 26).
#
# Where this file departs from the source.
# (1) Domain xp >= 0 added (salt is nonnegative; forward invariant under both flows).
# (2) The band and the two lower bounds replace the source's disjunctive invariant (they imply the
#   same distance 3); the claim holds from every related pair, which implies the source's forward
#   distance from xp = 50.
# (3) The source's proof figures write r := 5 in off where Fig. 7 writes r := 0; this file follows
#   Fig. 7.
#
# RELATION TO THE RUNNING EXAMPLE (watertank). Not the same benchmark: different plant (salt
# mixing with an on/off brine valve, 2 modes, one equilibrium at 25, vs a water level under
# proportional pumps toward three set points, 3 attacked and 5 reference modes); different attack
# (a bounded reading error anywhere in [-3, 3] at every sample, nondeterministic, vs a constant
# 3 dm offset together with a tampered pump); different mechanisms (watertank S M B with
# stretch 2; here lambda = 1 and I). Shared: one tank, a sensor attack of magnitude 3 and a
# deviation band equal to it, the forward-distance scenario of this source.
#
# Verdicts (RELCERT_IMPLIED_CUT=1 unless stated, measured 2026-10-27 on branch benchmark-fixes, batch I8):
# CERTIFIED (about 0.12 s); CERTIFIED under RELCERT_SYNC=1, RELCERT_NO_PRUNE=1,
# RELCERT_NO_CHOICE=1, RELCERT_NO_PRUNE=1 RELCERT_NO_CHOICE=1, RELCERT_SYNC=1 RELCERT_NO_CHOICE=1,
# RELCERT_NO_LINEAR_CUT=1, RELCERT_NO_PAIR_STRETCH=1, RELCERT_OPREGION=1 and
# RELCERT_WELLFORMED_STRICT=1; DECLINED under RELCERT_NO_CUT=1, RELCERT_NO_IMPLIED_CUT=1 and without
# RELCERT_IMPLIED_CUT (the attacked Off with the genuine On fails without the mode facts). Cover:
# both left modes at lambda 1, budget 1, the genuine On the only admissible start (the rows exclude
# its Off), no choice needed; nothing pruned. Rows identical (--handoff
# vacuous, 4/4). relcert --wellformed: On ok (invariant), Off ok (invariant), 0 UNKNOWN (with the
# flow written 2.5 - 0.1 xp, On is UNKNOWN: the set-point form is what the check recognizes).
[problem]
name = salt_tank_sensor
max_depth = 8
lambda_min = 1.0
lambda_max = 1.0
bound_T = 40.0

[Lsys]
state_vars = [xp]
epsilon = 1.0

[Lsys.mode.On]
ode = xp' = smt2:(* 0.1 (- 25.0 xp));
guard = xp >= 22.0
evolve = xp >= 0.0
next = [On, Off]

[Lsys.mode.Off]
ode = xp' = smt2:0.0;
guard = xp >= 0.0 and xp < 28.0
evolve = xp >= 0.0
next = [On, Off]

[Rsys]
state_vars = [xp]
epsilon = 1.0

[Rsys.mode.On]
ode = xp' = smt2:(* 0.1 (- 25.0 xp));
guard = xp >= 25.0
evolve = xp >= 0.0
next = [On, Off]

[Rsys.mode.Off]
ode = xp' = smt2:0.0;
guard = xp >= 0.0 and xp < 25.0
evolve = xp >= 0.0
next = [On, Off]

[relational_invariant]
On = xp[l] <= xp[r] + 3.0 and xp[r] <= xp[l] + 3.0 and xp[l] >= 25.0 and xp[r] >= 25.0
Off = xp[l] <= xp[r] + 3.0 and xp[r] <= xp[l] + 3.0 and xp[l] >= 25.0 and xp[r] >= 25.0
