# sat_detumble_phases: microsatellite detumbling then fine rate damping, full gyrostat model
# against its design model, both with the same phase logic; the flight mode manager decides every
# 2 s, the design model every 1 s. The time unit is stylized (see THE PLANT).
# scenario: model-refinement
# mechanisms: M I X (multi-cycle matching: one 2 s flight decision against two 1 s design-model
#   cycles, budget 2, matrix code M2; the FINE capture envelope E <= 0.125 is a load-bearing checked
#   cut on the second design cycle, RELCERT_NO_CUT=1 declines, matrix code M6; committed successor
#   subsets that keep the design model in the deployed's phase, RELCERT_NO_CHOICE=1 declines). At
#   lambda = 1 (real time). Batch I9 (2026-10-27): the 2 s flight period is restored (the equal-period
#   file of batch I4 kept only X); M and I come from the period ratio, X from the shared phase logic.
#   One domain (2026-10-29): |w_i| <= 1, |h| <= 2 on both sides plus |h + 5 w3| <= 2 on the right
#   -> |w_i| <= 1 on every mode of both sides; CERTIFIED with the rows unchanged, same ablations.
#
# THE PLANT (both sides; a ~60 kg microsatellite, SI units). Body rates w1, w2, w3 (rad/s)
# about the principal axes, inertia J = diag(2, 4, 5) kg m^2, and the momentum h (N m s)
# of a reaction wheel on the z-axis. Euler's equations with the wheel (a gyrostat):
#   J1 w1' = (J2 - J3) w2 w3 - w2 h + tau1,   J2 w2' = (J3 - J1) w3 w1 + w1 h + tau2,
#   J3 w3' = (J1 - J2) w1 w2 - h',            h' = k J3 w3,
# with isotropic rate damping tau_i = -k J_i w_i on all three axes (the x, y actuators and the
# z-wheel at the same gain k; the wheel absorbs the z-rate):
# w1' = -0.5 w2 w3 - 0.5 w2 h - k w1, w2' = 0.75 w3 w1 + 0.25 w1 h - k w2,
# w3' = -0.4 w1 w2 - k w3, h' = 5 k w3.
# Isotropic damping is a requirement of the claim, not a convenience: the energy identity
# E' = -2 k E needs the same k on every axis. Magnetorquer-scale gains on x, y (about 2e-4 /s for
# 10 A m^2 rods in a 40 uT field; tested at 5e-4 and at 5e-3, ten times optimistic) together with
# a 0.5 /s wheel on z DECLINE, and the claim is false there: the couplings move rate from the
# nearly undamped x, y axes into the wheel-damped z axis on the left while the decoupled design
# model's x, y energy stays put, E_L - E_R = +0.067 at t = 2 s by RK4 (measured 2026-10-29). So
# the x, y actuators are modeled as rate dampers of the same authority as the wheel.
# The time unit is stylized: in SI seconds k = 0.5 /s (torque up to 1 N m at the DETUMBLE
# envelope) is about three orders above magnetorquer authority (4e-4 N m per axis for 10 A m^2
# rods at 40 uT) and one to two above a microsat wheel (2-30 mN m), and the 2 s time constant is
# a unit of this file, not a detumble time. The energy identity holds at any gain: with the
# damping gains divided by 1000 (k = 5e-4 / 3e-4 on all axes, couplings and periods unchanged)
# the file CERTIFIES with the same ablation pattern (NO_CHOICE and NO_CUT decline), measured
# 2026-10-29. The gyroscopic and wheel-coupling terms are
# genuine BILINEAR couplings (products w2 w3, w3 w1, w1 w2, w2 h, w1 h); they do no work,
# so the body energy E = 2 w1^2 + 4 w2^2 + 5 w3^2 (twice the rotational kinetic energy)
# obeys E' = -2 k E exactly, but only through the cancellation of the cubic terms,
# which every flow query has to establish (Z3, nonlinear real arithmetic).
# The DESIGN MODEL (right) neglects the couplings: w_i' = -k w_i, h' = 5 k w3.
# PHYSICAL DOMAIN (every mode, both sides): |w_i| <= 1 rad/s (the gyro's measurement range);
# the wheel momentum h is not bounded (see WHEEL MOMENTUM).
# Control periods. Right (design model): 1 s (epsilon = 1.0), the ADCS sensor cycle on which the
# design analysis evaluates the phase logic (the attitude solution of a CubeSpace CubeStar star
# tracker, the FINE phase's sensor, is updated at 1 Hz, CubeSpace sensor data sheet). Left (flight
# software): 2 s (epsilon = 2.0): the flight mode manager evaluates the phase handover on every other
# sensor cycle, so that a transition needs two consecutive agreeing readings (a two-sample debounce,
# a design value of this file; the round-2 file used the same 2 s). Every decision interval is at
# most the period; the damping laws are continuous in the ODEs, the period is that of the phase
# decision only. The claim compares the two at equal times (lambda 1), so one flight
# decision is matched by two design-model cycles (M).
# The M window: any left decision period strictly above the right's gives M, with budget
# ceil(left period / right period) (2 at the stated 2:1); the stated periods are not at an edge.
#
# PHASE LOGIC (the same on both sides). DETUMBLE (rate damping, k = 0.5 /s) engages with the
# body energy inside its authority envelope, E <= 1 (e.g. |w1| <= 0.71 rad/s about x alone).
# FINE (a fine rate-damping phase: the same actuators at the power-saving gain k = 0.3 /s, 60 %
# of the detumble gain; no attitude state is modeled, the capture criterion is the rate envelope)
# engages once the body energy is inside the capture envelope E <= 0.125: the 0.25 rad/s capture
# range of the mission's pointing loop about the minor axis x, J1 (0.25)^2 = 0.125, which bounds
# every rate (|w1| <= 0.25, |w2| <= 0.18, |w3| <= 0.16 rad/s). The mode manager hands over to FINE
# at a decision point of its choosing once E <= 0.125 (DETUMBLE -> FINE, DETUMBLE) and falls back
# to DETUMBLE on a capture loss or a ground command (FINE -> FINE, DETUMBLE); both transitions are
# modeled as enabled whenever the target's entry envelope holds. The design model also declares
# the FDIR SAFE mode on the energy threshold E > 1 (actuators inhibited, a sink; modeled frozen),
# as in sat_detumble_nominal (in benchmarks/reserve/ since 2026-10-27); the right guards cover the domain (DETUMBLE and FINE inside E <= 1,
# SAFE outside): no coverage gap.
#
# The sides differ in the gyroscopic and wheel couplings (the model refinement) and in the phase
# decision period (2 s flight, 1 s design). Gains, guards, phase logic and successor sets are the
# same on both sides (the design model adds only its SAFE sink).
#
# CLAIM (both phases): E_L <= E_R and E_R <= E_L: the full rigid body's energy EQUALS the design
# model's at every instant, through the phase handovers (tolerance 0 in both directions; no
# tighter claim exists). Requirement: the design model's energy prediction is exact for the real
# body in both phases, so detumble-time and capture-time budgets computed on it hold. Not
# implied by the domains. Every left mode has a satisfiable start (DETUMBLE: E_L = E_R <= 1;
# FINE: E_L = E_R <= 0.125). The claim is synchronous: lambda in [1, 1].
#
# The claim depends on the cause (measured 2026-10-26, again 2026-10-29): with the wheel
# back-reaction on w1 removed (the term -0.5 w2 h of w1' set to 0 on the left, so the w1-h
# coupling does work, E' = -2 k E + 2 w1 w2 h) the same claim DECLINES.
#
# Why the choice (X). After every segment the design model's successors include the other phase
# (DETUMBLE -> FINE inside E <= 0.125, FINE -> DETUMBLE always); the phase it is in must be the
# deployed's, since the two gains decay the energy at different rates (-1.0 E against -0.6 E).
# The cover commits it: in a DETUMBLE window a design model in FINE hops to DETUMBLE, in a FINE
# window a design model in DETUMBLE hops to FINE (committed successor subsets). Without the
# choice (RELCERT_NO_CHOICE=1) the cover owes the mismatched phase: DECLINED. The relation is
# energy equality between different dynamics, not the identity, so the hop is not a copy of the
# deployed's state. X comes from the shared phase logic, not from the couplings: with the
# couplings removed from the left (left = design model) RELCERT_NO_CHOICE=1 still DECLINES.
# Letter window over the FINE gain k_F (measured 2026-10-26, again 2026-10-29, both sides changed):
# X holds whenever the FINE gain differs from the detumble gain (k_F = 0.3 here, also k_F = 0.45);
# with k_F = 0.5 the two phases coincide and RELCERT_NO_CHOICE=1 certifies.
# Fallback: DETUMBLE -> SAFE is pruned (source: no DETUMBLE entry state has E > 1; barrier: on
# E = 1 the design model's field gives E' = -E < 0); the committed successor subset closes the
# same fallback, so RELCERT_NO_PRUNE=1 alone CERTIFIES (no P).
#
# Verdicts (RELCERT_IMPLIED_CUT=1 unless stated, measured 2026-10-29, one domain): CERTIFIED (about
# 8 s on a shared machine); CERTIFIED under RELCERT_SYNC=1, RELCERT_NO_PRUNE=1,
# RELCERT_NO_IMPLIED_CUT=1, RELCERT_NO_LINEAR_CUT=1, RELCERT_NO_REPO=1, RELCERT_OPREGION=1,
# RELCERT_WELLFORMED_STRICT=1, without RELCERT_IMPLIED_CUT and with every evolve bound widened by
# 20 %; DECLINED under RELCERT_NO_CHOICE=1, NO_PRUNE+NO_CHOICE, SYNC+NO_CHOICE and RELCERT_NO_CUT=1
# (on the second design cycle of a FINE window the design model's FINE guard E <= 0.125 is a checked
# cut; without cuts the handover DETUMBLE -> FINE after the first cycle is not covered). Covers:
# both left modes at lambda 1, budget 2 (joint steps: DETUMBLE's design cycles retain DETUMBLE and
# FINE, FINE's retain FINE and DETUMBLE, one non-self successor each, no branching letter), by the
# choice cover (a hop into the deployed's phase at the window start), no right-only segment; pruned
# DETUMBLE -> SAFE (not load-bearing, NO_PRUNE certifies). Rows identical (--handoff 4/4 vacuous;
# the bridge instance takes the window form). relcert --wellformed: DETUMBLE, FINE, SAFE ok
# (invariant), 0 UNKNOWN, 0 BLOCKING. The right fields and guards are unchanged since batch I4
# (three modes); the right domain changed on 2026-10-29 (one domain: the band and the h box
# dropped), and the Lean Assumption 1 proof is redone on the w box (2026-10-29, Z3-free);
# the left changed in its period (1 -> 2 s, batch I9) and in its domain (2026-10-29). Letters:
# M I X.
#
# WHEEL MOMENTUM (not in the domain). Neither model has wheel-saturation dynamics, so the wheel's
# capacity (2 N m s) and the momentum dump that would handle it are coverage gaps of the models,
# not domain bounds: with |h| <= 2 in the domain the design model's own flow (h' = 5 k w3) crosses
# it, and relcert --wellformed reports DETUMBLE and FINE BLOCKING (leaves h >= -2.0; Assumption 1
# fails, measured 2026-10-29). The band |h + 5 w3| <= 2 (the z-axis total momentum within the
# wheel's capacity) is a first integral of every design-model mode but not of the gyrostat, where
# (h + 5 w3)' = -2 w1 w2 in both phases, so on the left it would be a reachable-set band. The
# claim needs neither: on both sides E' = -2 k E whatever h is.
[problem]
name = sat_detumble_phases
max_depth = 8
lambda_min = 1.0
lambda_max = 1.0
bound_T = 4.0
[Lsys]
state_vars = [w1, w2, w3, h]
epsilon = 2.0
[Lsys.mode.DETUMBLE]
ode = w1' = smt2:(- (- (* -0.5 (* w2 w3)) (* 0.5 (* w2 h))) (* 0.5 w1)); w2' = smt2:(- (+ (* 0.75 (* w3 w1)) (* 0.25 (* w1 h))) (* 0.5 w2)); w3' = smt2:(- (* -0.4 (* w1 w2)) (* 0.5 w3)); h' = smt2:(* 2.5 w3);
guard = w1*w1*2 + w2*w2*4 + w3*w3*5 <= 1.0
evolve = w1 >= -1.0 and w1 <= 1.0 and w2 >= -1.0 and w2 <= 1.0 and w3 >= -1.0 and w3 <= 1.0
next = [FINE, DETUMBLE]
[Lsys.mode.FINE]
ode = w1' = smt2:(- (- (* -0.5 (* w2 w3)) (* 0.5 (* w2 h))) (* 0.3 w1)); w2' = smt2:(- (+ (* 0.75 (* w3 w1)) (* 0.25 (* w1 h))) (* 0.3 w2)); w3' = smt2:(- (* -0.4 (* w1 w2)) (* 0.3 w3)); h' = smt2:(* 1.5 w3);
guard = w1*w1*2 + w2*w2*4 + w3*w3*5 <= 0.125
evolve = w1 >= -1.0 and w1 <= 1.0 and w2 >= -1.0 and w2 <= 1.0 and w3 >= -1.0 and w3 <= 1.0
next = [FINE, DETUMBLE]
[Rsys]
state_vars = [w1, w2, w3, h]
epsilon = 1.0
[Rsys.mode.DETUMBLE]
ode = w1' = smt2:(* -0.5 w1); w2' = smt2:(* -0.5 w2); w3' = smt2:(* -0.5 w3); h' = smt2:(* 2.5 w3);
guard = w1*w1*2 + w2*w2*4 + w3*w3*5 <= 1.0
evolve = w1 >= -1.0 and w1 <= 1.0 and w2 >= -1.0 and w2 <= 1.0 and w3 >= -1.0 and w3 <= 1.0
next = [DETUMBLE, FINE, SAFE]
[Rsys.mode.FINE]
ode = w1' = smt2:(* -0.3 w1); w2' = smt2:(* -0.3 w2); w3' = smt2:(* -0.3 w3); h' = smt2:(* 1.5 w3);
guard = w1*w1*2 + w2*w2*4 + w3*w3*5 <= 0.125
evolve = w1 >= -1.0 and w1 <= 1.0 and w2 >= -1.0 and w2 <= 1.0 and w3 >= -1.0 and w3 <= 1.0
next = [FINE, DETUMBLE]
[Rsys.mode.SAFE]
ode = w1' = smt2:0; w2' = smt2:0; w3' = smt2:0; h' = smt2:0;
guard = w1*w1*2 + w2*w2*4 + w3*w3*5 > 1.0
evolve = w1 >= -1.0 and w1 <= 1.0 and w2 >= -1.0 and w2 <= 1.0 and w3 >= -1.0 and w3 <= 1.0
next = [SAFE]
[relational_invariant]
DETUMBLE = w1[l]*w1[l]*2 + w2[l]*w2[l]*4 + w3[l]*w3[l]*5 <= w1[r]*w1[r]*2 + w2[r]*w2[r]*4 + w3[r]*w3[r]*5 and w1[r]*w1[r]*2 + w2[r]*w2[r]*4 + w3[r]*w3[r]*5 <= w1[l]*w1[l]*2 + w2[l]*w2[l]*4 + w3[l]*w3[l]*5
FINE = w1[l]*w1[l]*2 + w2[l]*w2[l]*4 + w3[l]*w3[l]*5 <= w1[r]*w1[r]*2 + w2[r]*w2[r]*4 + w3[r]*w3[r]*5 and w1[r]*w1[r]*2 + w2[r]*w2[r]*4 + w3[r]*w3[r]*5 <= w1[l]*w1[l]*2 + w2[l]*w2[l]*4 + w3[l]*w3[l]*5
