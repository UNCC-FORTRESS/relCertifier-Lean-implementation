# sat_detumble_weak: detumbling on weakened actuators against a design model with power profiles;
# both sides at the design-model level, same control period.
# scenario: degraded-actuator
# mechanisms: I X (the engagement envelope as a load-bearing checked cut, RELCERT_NO_CUT=1
#   declines, matrix code M6; committed successor subsets into a power-saving profile,
#   RELCERT_NO_CHOICE=1 declines). Single-step cover at lambda = 1. The round-2 file's M came only
#   from a 2 s left period against a 1 s right period and is gone with equal periods.
#
# THE SPACECRAFT (a ~60 kg microsatellite, SI units; the plant of sat_detumble_nominal, in benchmarks/reserve/). Body
# rates w1, w2, w3 (rad/s) about the principal axes, inertia J = diag(2, 4, 5) kg m^2, and the
# momentum h (N m s) of a reaction wheel on the z-axis; rate-damping magnetorquers on x, y and
# the wheel absorbing the z-rate, gain k. BOTH sides are the design model of this spacecraft:
# w_i' = -k w_i, h' = 5 k w3 (the gyroscopic and wheel couplings are not modeled on either side).
# The couplings do no work at any gain, so the full gyrostat's body energy equals the design
# model's at every instant (the refinement step that sat_detumble_nominal certifies exactly at
# k = 0.5); this file isolates the degradation at the design-model level. The body energy
# E = 2 w1^2 + 4 w2^2 + 5 w3^2 (twice the rotational kinetic energy) obeys E' = -2 k E.
# PHYSICAL DOMAIN (both sides): |w_i| <= 1 rad/s (the gyro's measurement range) and
# |h| <= 2 N m s (the wheel's momentum capacity); no certificate stands on them.
# Control period: 1 s on BOTH sides (epsilon = 1.0; every decision interval is at most 1 s), the
# attitude mode manager's cycle on a 1 Hz ADCS (the attitude solution of a CubeSpace CubeStar star
# tracker is updated at 1 Hz, CubeSpace sensor data sheet), as in sat_detumble_nominal.
# Guards (entry conditions): the detumble controller engages with the body energy inside
# its authority envelope, E <= 1 (e.g. |w1| <= 0.71 rad/s about x alone). The design
# model declares the FDIR SAFE mode on an ENERGY threshold, E > 1 (actuators inhibited,
# a sink; modeled frozen) -- a quadratic threshold, not a speed floor. The right guards cover
# the domain (the three profiles share E <= 1, SAFE is E > 1): no coverage gap.
#
# Degraded deployed (left): a bus under-voltage limits the torquer dipole and the wheel torque
# to 80 %: k_L = 0.4 /s (w_i' = -0.4 w_i, h' = 2 w3). The design model (right) offers three
# ground-selectable detumble power profiles, NOMINAL k = 0.5, ECONOMY 0.45 and SURVIVAL 0.42
# (battery states), switchable NOMINAL <-> ECONOMY / SURVIVAL; each declares SAFE.
# One cause between the sides: the actuator degradation (k_L = 0.4 against the profiles'
# 0.5 / 0.45 / 0.42). (The round-2 file also gave the left the couplings, a second difference;
# it is removed here: same model level on both sides.)
#
# CLAIM: E_R <= E_L (the weakened spacecraft never detumbles faster than the design model;
# constant 0) and E_L <= E_R + 0.125. Requirement (residual rate): the energy the weakened
# spacecraft carries beyond the design model's is at most that of a 0.25 rad/s spin about the
# minor axis x, J1 (0.25)^2 = 0.125. So when the design model has come to rest the weakened
# spacecraft's rates are within the 0.25 rad/s capture range of the sun-acquisition mode that
# takes over after detumbling (a stated mission value): |w1| <= 0.25, |w2| <= 0.18,
# |w3| <= 0.16 rad/s, the minor axis x being the binding one.
# Derived bound: on the boundary E_L = E_R + d the gap grows at 2 k_R E_R - 2 k_L (E_R + d),
# which is <= 0 iff E_R <= d k_L / (k_R - k_L); with E_R <= E_L <= 1 (the engagement envelope, a
# checked cut) the tangent tolerance against a profile of gain k_R is d* = 1 - k_L / k_R:
# 0.2 against NOMINAL, 1/9 = 0.111 against ECONOMY, 0.048 against SURVIVAL. The requirement
# 0.125 lies between the ECONOMY and the NOMINAL bounds: a design run that stays in NOMINAL does
# not bound the weakened spacecraft, a design run that the ground switches to a power-saving
# profile does. Tightest certifying (measured 2026-10-26, edge re-checked 2026-10-27): 0.12 on the 0.01 grid (0.11 declines);
# finer, 0.1112 certifies and 0.1111 declines: the ECONOMY bound 1/9. Under RELCERT_NO_CHOICE=1
# the tightest is 0.20 (0.19 declines): the NOMINAL bound. Not implied by the domains; the left
# mode has a satisfiable start (E_L = E_R <= 1).
# Why the choice (X). A design run that starts in NOMINAL must be committed to ECONOMY or
# SURVIVAL: its NOMINAL segment fails (tangent bound 0.2 > 0.125), so the cover hops from
# NOMINAL into the power-saving profiles (committed successor subset). RELCERT_NO_CHOICE=1
# DECLINES.
# The claim and the letters depend on the cause (measured 2026-10-26): at k_L = 0.3 (60 %) the
# file DECLINES (the smallest tangent bound, against SURVIVAL, is then 0.29 > 0.125); without
# the degradation (k_L = 0.5) it CERTIFIES,
# RELCERT_NO_CUT=1 then CERTIFIES too (I is the degradation's: the envelope cut bounds the energy
# the gap can grow on), and RELCERT_NO_CHOICE=1 still DECLINES, but the commitment then goes into
# NOMINAL (the lower row needs the matching gain); the degradation is what moves the committed
# profile to ECONOMY / SURVIVAL and the tolerance from 0 to 1/9.
# Covers (measured): lambda in [1, 1] (synchronous, as sat_detumble_nominal; a weaker deployed
# gains nothing from a stretch), budget 1; admissible starts NOMINAL, ECONOMY, SURVIVAL; certified
# by the choice cover. The engagement envelope E <= 1 is a checked cut (a quadratic guard
# conjunct whose invariance is a DI-boundary query): RELCERT_NO_CUT=1 DECLINES (I).
# Fallback: NOMINAL/ECONOMY/SURVIVAL -> SAFE pruned as in sat_detumble_nominal; the committed
# successor subsets close the same fallback, so RELCERT_NO_PRUNE=1 alone CERTIFIES (no P).
#
# Verdicts (RELCERT_IMPLIED_CUT=1 unless stated, measured 2026-10-27 on branch benchmark-fixes):
# CERTIFIED (7.6 s); CERTIFIED under RELCERT_SYNC=1, RELCERT_NO_PRUNE=1,
# RELCERT_NO_IMPLIED_CUT=1, RELCERT_NO_LINEAR_CUT=1, RELCERT_OPREGION=1,
# RELCERT_WELLFORMED_STRICT=1 and without RELCERT_IMPLIED_CUT; DECLINED under RELCERT_NO_CHOICE=1,
# NO_PRUNE+NO_CHOICE, SYNC+NO_CHOICE and RELCERT_NO_CUT=1. Pruned: NOMINAL, ECONOMY, SURVIVAL ->
# SAFE (matrix: M4 vacuous, M6). One row (--handoff vacuous, 1/1). relcert --wellformed: NOMINAL,
# ECONOMY, SURVIVAL, SAFE ok (invariant), 0 UNKNOWN, 0 BLOCKING. The right model is unchanged from
# the suite file this one replaces (epsilon 1.0); the left changed (period 2 -> 1 s, couplings
# removed).
#
# MOMENTUM BAND (right evolve domains): |h + 5 w3| <= 2 N m s, the z-axis total angular momentum
# within the wheel's capacity. It is conserved by every design-model mode (h' = 5 k w3,
# w3' = -k w3), so it is a constraint on the initial state: the wheel can absorb the body's
# momentum. Off the band the wheel saturates before the body is stopped and the design model
# has no run of a full period (its Assumption 1 fails); the momentum dump that would handle
# that case is not modeled.
[problem]
name = sat_detumble_weak
max_depth = 8
lambda_min = 1.0
lambda_max = 1.0
bound_T = 4.0
[Lsys]
state_vars = [w1, w2, w3, h]
epsilon = 1.0
[Lsys.mode.DETUMBLE]
ode = w1' = smt2:(* -0.4 w1); w2' = smt2:(* -0.4 w2); w3' = smt2:(* -0.4 w3); h' = smt2:(* 2.0 w3);
guard = w1*w1*2 + w2*w2*4 + w3*w3*5 <= 1.0
evolve = w1 >= -1.0 and w1 <= 1.0 and w2 >= -1.0 and w2 <= 1.0 and w3 >= -1.0 and w3 <= 1.0 and h >= -2.0 and h <= 2.0
next = [DETUMBLE]
[Rsys]
state_vars = [w1, w2, w3, h]
epsilon = 1.0
[Rsys.mode.NOMINAL]
ode = w1' = smt2:(* -0.5 w1); w2' = smt2:(* -0.5 w2); w3' = smt2:(* -0.5 w3); h' = smt2:(* 2.5 w3);
guard = w1*w1*2 + w2*w2*4 + w3*w3*5 <= 1.0
evolve = w1 >= -1.0 and w1 <= 1.0 and w2 >= -1.0 and w2 <= 1.0 and w3 >= -1.0 and w3 <= 1.0 and h >= -2.0 and h <= 2.0 and h + 5.0*w3 >= -2.0 and h + 5.0*w3 <= 2.0
next = [NOMINAL, ECONOMY, SURVIVAL, SAFE]
[Rsys.mode.ECONOMY]
ode = w1' = smt2:(* -0.45 w1); w2' = smt2:(* -0.45 w2); w3' = smt2:(* -0.45 w3); h' = smt2:(* 2.25 w3);
guard = w1*w1*2 + w2*w2*4 + w3*w3*5 <= 1.0
evolve = w1 >= -1.0 and w1 <= 1.0 and w2 >= -1.0 and w2 <= 1.0 and w3 >= -1.0 and w3 <= 1.0 and h >= -2.0 and h <= 2.0 and h + 5.0*w3 >= -2.0 and h + 5.0*w3 <= 2.0
next = [ECONOMY, NOMINAL, SAFE]
[Rsys.mode.SURVIVAL]
ode = w1' = smt2:(* -0.42 w1); w2' = smt2:(* -0.42 w2); w3' = smt2:(* -0.42 w3); h' = smt2:(* 2.1 w3);
guard = w1*w1*2 + w2*w2*4 + w3*w3*5 <= 1.0
evolve = w1 >= -1.0 and w1 <= 1.0 and w2 >= -1.0 and w2 <= 1.0 and w3 >= -1.0 and w3 <= 1.0 and h >= -2.0 and h <= 2.0 and h + 5.0*w3 >= -2.0 and h + 5.0*w3 <= 2.0
next = [SURVIVAL, NOMINAL, SAFE]
[Rsys.mode.SAFE]
ode = w1' = smt2:0; w2' = smt2:0; w3' = smt2:0; h' = smt2:0;
guard = w1*w1*2 + w2*w2*4 + w3*w3*5 > 1.0
evolve = w1 >= -1.0 and w1 <= 1.0 and w2 >= -1.0 and w2 <= 1.0 and w3 >= -1.0 and w3 <= 1.0 and h >= -2.0 and h <= 2.0 and h + 5.0*w3 >= -2.0 and h + 5.0*w3 <= 2.0
next = [SAFE]
[relational_invariant]
DETUMBLE = w1[l]*w1[l]*2 + w2[l]*w2[l]*4 + w3[l]*w3[l]*5 <= w1[r]*w1[r]*2 + w2[r]*w2[r]*4 + w3[r]*w3[r]*5 + 0.125 and w1[r]*w1[r]*2 + w2[r]*w2[r]*4 + w3[r]*w3[r]*5 <= w1[l]*w1[l]*2 + w2[l]*w2[l]*4 + w3[l]*w3[l]*5
