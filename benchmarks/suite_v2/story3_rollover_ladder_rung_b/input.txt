# Left attitude domains are the PHYSICAL validity range of the small-angle model:
# psi, omega_psi, theta_p, omega_theta in [-1, 1] (rad, rad/s). (Before: [-0.5, 0.5],

# controller switches zones -- and starts its first zone -- only when the attitude is
# SETTLED: every left guard carries the entry condition psi, omega_psi, theta_p,
# omega_theta >= -0.25. This is a controller-design condition on the switch (a guard),
# not a domain restriction: the flow may leave it freely after entry.
# Why the claim needs it, and what it buys: the left attitude loop psi' = omega_psi,
# omega_psi' = -psi - 2 omega_psi (theta_p alike) is critically damped (double root 1),
# so q = omega_psi + psi satisfies q' = -q. From the entry box q >= -0.5 (kind
# linear-form, O1 rational, O2 linear-shape), and inside it psi >= -0.5 (kind
# derived-bound, O1 rational, O2 derived-shape): the floor the energy row needs is now
# DERIVED, not declared (with psi_L = -0.95, omega_psi_L = 0.232, psi_R = -0.5 the row's
# derivative is -0.522 + 0.668 lambda > 0 for every lambda >= 1, so some floor is
# necessary). Counter-runs: RELCERT_NO_LINEAR_CUT=1, RELCERT_NO_IMPLIED_CUT=1 and
# RELCERT_NO_CUT=1 all DECLINE. Widening test: every left bound passes; the right
# attitude caps psi <= 0.15, theta_p <= 0.15 are load-bearing and FORWARD-INVARIANT
# (the reference attitude is psi' = -psi, theta_p' = -theta_p, a contraction toward 0:
# on psi = 0.15 the field points inward, so no right trajectory leaves the box).
# Dynamics, rows and every other bound are unchanged.
#
# STORY 3 LADDER: rung_b (attitude order-raise)
# L = direct_L: attitude 2nd-order AND rollover 2nd-order (full model)
# R = IM (Intermediate Model): attitude 1st-order, rollover 2nd-order
#
# Rollover is MATCHED on both sides (both 2nd-order), so NO rollover product needed.
# Invariant: D_psi + D_theta (Lyapunov energy on attitude gap) -- Story 1 pattern.
# SIMPLER than the direct certification which needs v*r<=1.0 (bilinear product).
#
# The intermediate model (IM = rung_a's L) connects the two rungs:
#   rung_a L == rung_b R (both are IM: rollover 2nd-order, attitude 1st-order)
# Composition: rung_a + rung_b imply the direct story3_rollover_base invariant.
