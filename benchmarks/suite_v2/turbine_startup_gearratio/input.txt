# turbine_startup_gearratio: the start-up of a pitch-regulated wind turbine whose controller
# computes rotor speed with a stale gearbox ratio, against the same start-up with the correct ratio.
# scenario: degraded-controller (configuration error after a gearbox exchange)
# mechanisms: R P I (right-only repositioning; non-connection pruning of the parking edges,
#   RELCERT_NO_PRUNE=1 declines; checked cuts, RELCERT_NO_CUT=1 declines; matrix codes M4 M6 M6+).
#   R, P and I are properties of the ONE-SIDED claim, not of the gear error: they are present at
#   g = 1.00 (identical systems) with the claim w_L <= w_R (see "Where the letters come from").
#
# Round A (2026-10-26): model and claim unchanged; the header no longer presents the letters as
# effects of the cause. Two-sided claims were tried and do not certify with a meaningful lower
# tolerance (below).
# Round B (2026-10-29): physics-corrected model installed. The deployed's loop gains are the
# reference's divided by 1.05 and the evolve domains were the start-up's reachable speeds (left
# w <= 12.705, right w <= 12.1). Claim, verdicts, letters and cover unchanged by that step.
# Domain audit (2026-10-29): the evolve domains are now the overspeed trips, the physical end of
# the model (right w <= 13.31, the control system's 110 % overspeed limit; left w <= 13.9755 =
# 1.05 x 13.31, the same limit applied by the controller to its 5 %-low reading). Above rated the
# deployed's regulation is the slower one in true-speed coordinates, so the exact row alone fails
# on overspeed starts; the audit gave GEN a tolerance of 0.061 rpm (letters R P I D).
# Review round 6 (2026-10-30): no run reaches a state above rated (every phase flows toward a
# target at or below rated; simulated from 2 x 10^4 random starts below rated with random
# decisions: left max 12.705, right max 12.1), so the GEN tolerance and its D rested on admitted
# overspeed starts only. The claim states the start-up ceiling w_L <= 12.705 instead (Property);
# rows uniform, letters R P I D -> R P I. Numbers below are measured on this model unless marked
# as earlier.
#
# System. Rotor speed w in rpm, time in s. Numbers of the NREL 5-MW reference turbine (Jonkman et
# al., NREL/TP-500-38060, 2009): rated rotor speed 12.1 rpm, cut-in rotor speed 6.9 rpm, gearbox
# 97:1. The start-up at rated wind is a sequence of first-order phases (rotor inertia against the
# aerodynamic torque of each pitch setting), decided every 1 s:
#   SPINUP  2.0 <= w < 5.0   blades at the start-up pitch, generator off: the rotor free-spins
#                            toward 9 rpm, w' = 0.03 (9 - w)   (an aerodynamic balance, not a set point)
#   RAMP    5.0 <= w < 6.9   the pitch loop holds the rotor toward the synchronization speed
#                            7.5 rpm, w' = 0.04 (7.5 - w)
#   GEN     w >= 6.9         generator connected at cut-in; speed regulated to rated,
#                            w' = 0.05 (12.1 - w)
#   STOP    w < 2.0          parked: the brake decelerates the rotor, w' = -0.1 w (latched)
# SPINUP and RAMP declare STOP (the controller parks the rotor if the speed falls below 2 rpm).
#
# Right (reference): the start-up with the correct gearbox ratio (the numbers above).
# Left (deployed): the replacement gearbox has ratio 92.4:1, but the controller still divides the
# generator speed by 97, so it reads the rotor speed 5 % low (97 / 92.4 = 1.05). One cause: every
# speed the controller acts on is 1.05 times higher in true rotor speed: thresholds 2.1, 5.25,
# 7.245 rpm, synchronization target 7.875 rpm, rated target 12.705 rpm, and the RAMP and GEN loop
# gains are the reference's divided by 1.05: 0.04 / 1.05 = 0.0380952 and 0.05 / 1.05 = 0.047619.
# The controller commands a proportional torque on the measured error, w' = k (target - w / 1.05)
# = (k / 1.05) (1.05 target - w) (the reading of train_ato_odometry). The free-spin speed of
# SPINUP (9 rpm) and the brake are physics, not set points, and are unchanged. (Rounds 1 to A kept
# the stock gains 0.04 and 0.05, reading each phase as a closed loop in the measured coordinate;
# the verdicts and letters are the same on both models.)
#
# Property (uniform). w_L <= 1.05 w_R and w_L <= 12.705 in every phase (rpm; relational, up to
# the reference's re-timing): the deployed rotor never turns faster than 1.05 times a reference
# start-up, and never faster than its own rated target 12.705 = 1.05 x 12.1, the speed the stale
# ratio makes it regulate to. The claim is one-sided against an existential reference (the
# reference may be in a later phase and run ahead alone); a two-sided form does not certify
# (below). Requirement: the control system's overspeed limit, 110 % of rated (13.31 rpm); the claim
# bounds the deployed by 12.705 rpm < 13.31 rpm. It is a claim about start-ups (from rest or any
# state at or below rated), not about recovery from an overspeed: above rated the deployed's
# regulation is the slower one in true-speed coordinates (on the face w_L = 1.05 w_R,
# d/dt (1.05 w_R - w_L) = 0.03025 - 0.0025 w_R, negative above rated), and such states are
# reached by no run, only by an admitted start. Tight: the ceiling is exactly 12.705 (12.70 and
# 12.71 decline: below, the GEN flow rises to it; above, it admits a face pair above rated); the
# factor exactly 1.05 (1.049 and 1.051 decline). Without the ceiling the uniform exact row
# DECLINES (the GEN_L x GEN_R segment above rated). The bound moves with the cause: for a gearbox
# error g the claim w_L <= g w_R certifies at g = 1.00 (no error), 1.01, 1.02, 1.05, 1.10, 1.20
# (measured in round 2; re-measured 2026-10-29 on the round-B domains with the thresholds and
# targets times g, the gains divided by g and the left domain w <= 12.1 g); an error g > 1.1
# breaks the overspeed limit. Not implied by the domains.
#
# Where the letters come from (measured 2026-10-26, re-measured 2026-10-29 on the round-B model).
# The one-sided claim admits a reference that
# is already in a later phase. From a deployed SPINUP window the reference may start in RAMP; its
# pitch loop holds it at 7.5 rpm while the deployed free-spins toward 9 rpm, so the joint segment
# fails at every stretch and the reference first runs alone (left frozen) out of RAMP into GEN
# (R). RAMP and SPINUP declare STOP; the non-connection certificate (their flows rise at 2 rpm)
# prunes RAMP -> STOP and SPINUP -> STOP, so no run enters STOP: STOP_L is a start only (a rotor
# already parked); under RELCERT_NO_PRUNE=1 the repositioning step must
# also cover STOP (a parked reference against a spinning deployed) and the existential choice
# cannot replace it: DECLINED (P). The implied contraction atoms (w <= 9 in SPINUP, w <= 7.875 /
# 7.5 in RAMP) are load-bearing: DECLINED with RELCERT_NO_CUT=1 and without RELCERT_IMPLIED_CUT
# (I). At g = 1.00 (left = right) the claim w_L <= w_R shows the same three letters (RELCERT_SYNC=1,
# RELCERT_NO_PRUNE=1 and RELCERT_NO_CUT=1 all DECLINE), while the exact two-sided claim w_L = w_R
# certifies under all of them with no letter. So R, P and I witness the one-sided form of the
# claim (an existential reference that may be ahead), not the stale ratio; the cause sets the
# factor 1.05.
# Two-sided claims tried (to make the claim pin the cause from both sides; all measured on the
# round-B model 2026-10-29, where the speed range is 12.1 rpm; round-A values, with the stock
# gains on [0, 16], in parentheses):
#   w_R - d <= w_L <= 1.05 w_R in SPINUP, RAMP, GEN (STOP with the upper row only): DECLINED at
#     every d tried (0, 1, 5, 10, 12.705, 16; round A also 0.25, 0.5, 2 to 9, 12, 13); at
#     g = 1.00 (w_R - d <= w_L <= w_R) the same grid certifies only d = 0 (0.25 declines).
#     The (SPINUP_L, RAMP_R) segment fails at every stretch, and once a lower row binds the
#     reference's solo run the right-only repositioning that rescues the one-sided claim is not
#     found ([repo-dyn-pre] empty).
#   lower row only in RAMP and GEN: tightest d = 6.85 rpm (g = 1.05; round A 10.75) and 7.10
#     (g = 1.00; round A 11.00); only in GEN: 4.86 (round A 8.76) and 5.20 (round A 9.10): more
#     than a third of the 12.1 rpm range, near-vacuous, and the same without the cause.
#   Same-phase two-sided rows: the exact w_L = 1.05 w_R in RAMP and GEN (lambda 1) DECLINES at
#     the SPINUP -> RAMP handoff (7/8 unsat, countermodel w_L = w_R = 6: the free-spin phase is
#     not a scaled copy of the reference's, so the identity cannot be established at the RAMP
#     entry); 1.05 w_R - d <= w_L <= 1.05 w_R in RAMP and GEN certifies only from d = 7.46 rpm
#     (round A 11.55 of 16; the scaled gains on [0, 16] DECLINE at d = 16 at the stretch 1.05 and
#     at 1 / 1.05).
# Window: R and P hold for every gear error g < 1.2 (the free-spin speed 9 rpm exceeds the
# deployed's synchronization target 7.5 g); at g = 1.2 the joint segment passes and
# RELCERT_NO_PRUNE=1, RELCERT_SYNC=1 certify (round 2).
#
# Domains (one physical domain, written in true rotor-speed coordinates on both sides; owner's rule
# of 2026-10-29). The state w is the TRUE rotor speed on both sides. From rest (0) to the overspeed
# trip, where the control system shuts the turbine down and the model ends: ONE trip setting,
# 13.31 rpm = 110 % of rated on the controller's rotor-speed READING. The reference reads w, so it
# trips at w = 13.31; the deployed computes the rotor speed from the generator speed with the stale
# gearbox ratio and reads w / 1.05, so the same setting trips at a true w = 1.05 x 13.31 = 13.9755
# rpm (the stale ratio also delays the protection). One limit in two reading scales, not two limits:
# Domain conversion (kind iii): left 13.9755 = 1.05 x 13.31 (the same overspeed trip setting, 13.31 rpm on the rotor-speed reading; the deployed reads 1/1.05 of the true speed), right 13.31 = 13.31 x 1.
# (scripts/check_one_domain.py admits this file by that line.) Measured 2026-10-29: either single
# true-speed box (13.31 or 13.9755 on both sides) also CERTIFIES; the stated form keeps each model up
# to its own trip. Both are limits of the hardware's protection, not reachable-set estimates (the
# domain audit of 2026-10-29 replaced the round-B domains 12.705 / 12.1, the rated targets, which
# the exact GEN row stood on). Forward invariant in every mode (every target is below the trip and
# every flow is >= 0 at 0). Not load-bearing: the ceiling conjunct keeps the deployed at or below
# its rated target 12.705, below either trip. The right guards partition [0, 13.31] (no coverage
# gap); every left mode has a satisfiable start (w_R = w_L / 1.05 lies in the same reference
# phase).
#
# Stretch pinned (2026-10-27, final audit): lambda_max 6 -> 1. Every cover was already at lambda 1
# and the requirement is a real-time one, so the unused range [1, 6] is gone; verdicts and letters
# unchanged (measured 2026-10-27).
# Verdicts (RELCERT_IMPLIED_CUT=1 unless stated, measured 2026-10-30 on the trip domains with the
# ceiling row): CERTIFIED (about 0.6 s); CERTIFIED under RELCERT_NO_CHOICE=1,
# RELCERT_NO_PAIR_STRETCH=1, RELCERT_WELLFORMED_STRICT=1 and RELCERT_OPREGION=1; DECLINED under
# RELCERT_SYNC=1 (no right-only steps; every cover is at lambda 1, so no S), RELCERT_NO_PRUNE=1,
# RELCERT_NO_REPO=1, RELCERT_NO_CUT=1, RELCERT_NO_IMPLIED_CUT=1 and without RELCERT_IMPLIED_CUT.
# Cover: lambda 1, budget 1 in every left mode; SPINUP_L admissible [SPINUP, RAMP, GEN] with a
# right-only step; RAMP_L [RAMP, GEN]; GEN_L [GEN]; STOP_L all four. Pruned SPINUP->STOP,
# RAMP->STOP. relcert --wellformed: SPINUP ok (exit->RAMP), RAMP ok (exit->GEN), GEN ok
# (invariant), STOP ok (invariant), 0 UNKNOWN. Assumption 1 proof:
# WellFormed/TurbineStartupGearratio.lean (the right model on the trip domain).
[problem]
name = turbine_startup_gearratio
max_depth = 8
lambda_min = 1.0
lambda_max = 1.0
bound_T = 60.0

[Lsys]
state_vars = [w]
epsilon = 1.0

[Lsys.mode.SPINUP]
ode = w' = smt2:(* 0.03 (- 9 w));
guard = w >= 2.1 and w < 5.25
evolve = w >= 0.0 and w <= 13.9755
next = [SPINUP, RAMP, STOP]

[Lsys.mode.RAMP]
ode = w' = smt2:(* 0.0380952 (- 7.875 w));
guard = w >= 5.25 and w < 7.245
evolve = w >= 0.0 and w <= 13.9755
next = [RAMP, GEN, STOP]

[Lsys.mode.GEN]
ode = w' = smt2:(* 0.047619 (- 12.705 w));
guard = w >= 7.245
evolve = w >= 0.0 and w <= 13.9755
next = [GEN]

[Lsys.mode.STOP]
ode = w' = smt2:(* (- 0.1) w);
guard = w < 2.1
evolve = w >= 0.0 and w <= 13.9755
next = [STOP]

[Rsys]
state_vars = [w]
epsilon = 1.0

[Rsys.mode.SPINUP]
ode = w' = smt2:(* 0.03 (- 9 w));
guard = w >= 2.0 and w < 5.0
evolve = w >= 0.0 and w <= 13.31
next = [SPINUP, RAMP, STOP]

[Rsys.mode.RAMP]
ode = w' = smt2:(* 0.04 (- 7.5 w));
guard = w >= 5.0 and w < 6.9
evolve = w >= 0.0 and w <= 13.31
next = [RAMP, GEN, STOP]

[Rsys.mode.GEN]
ode = w' = smt2:(* 0.05 (- 12.1 w));
guard = w >= 6.9
evolve = w >= 0.0 and w <= 13.31
next = [GEN]

[Rsys.mode.STOP]
ode = w' = smt2:(* (- 0.1) w);
guard = w < 2.0
evolve = w >= 0.0 and w <= 13.31
next = [STOP]

[relational_invariant]
SPINUP = smt2:(and (<= L_w (* 1.05 R_w)) (<= L_w 12.705))
RAMP = smt2:(and (<= L_w (* 1.05 R_w)) (<= L_w 12.705))
GEN = smt2:(and (<= L_w (* 1.05 R_w)) (<= L_w 12.705))
STOP = smt2:(and (<= L_w (* 1.05 R_w)) (<= L_w 12.705))
