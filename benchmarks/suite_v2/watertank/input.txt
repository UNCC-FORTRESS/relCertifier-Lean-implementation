# watertank: set-point level controller under a sensor offset and a tampered fill pump (the
# paper's running example).
# scenario: sensor-attack
# mechanisms: S M B (time stretch lambda = 2 in Low and Mid, RELCERT_SYNC=1 declines; two right
#   segments per left window; a joint step from the reference's Low retains both Mid profiles;
#   matrix codes M1 M2 M3)
#
# THE PLANT. A tank of capacity 25 (level x in dm, so a 2.5 m tank; time in minutes).
# Every mode is a proportional pump controller that drives the level toward a set point c,
#   x' = k (c - x),   k = 1.0 /min   (a first-order relaxation, time constant 1 min).
# NOMINAL controller (right, the reference design):
#   PumpOff  x < 2           x' = 0               dry-run interlock: below the 2 dm intake
#                                                  the pump is switched off and latched
#                                                  (a sink, PumpOff -> PumpOff only)
#   Low      2 <= x < 10     x' = 1.0 (12.5 - x)  fill toward 12.5
#   Mid      10 <= x < 17    toward 17, in two selectable pump profiles chosen on entry:
#              MidEco          x' = 0.5 (17 - x)    half gain k/2 (energy-saving)
#              MidBoost        x' = 1.0 (17 - x)    full gain k
#   High     x >= 17         x' = 1.0 (17 - x)    regulate (drain) down to 17
# The nominal controller may move between MidEco and MidBoost at any time while in Mid,
# and returns from High into either profile. The right guards partition [0, 25] (no gap).
#
# THE ATTACK (left, the deployed controller; one adversary acting on two channels):
#   1. Sensor offset: the level sensor reads 3 dm LOW (x_measured = x - 3), so every
#      threshold and every set point the controller acts on is 3 dm higher in true level:
#        Low  5 <= x < 13   toward 15.5 (= 12.5 + 3)
#        Mid  13 <= x < 20  toward 20   (= 17 + 3)
#        High x >= 20       regulate down to 20
#   2. Actuation attack: the attack makes the pump aggressive: it doubles the low-fill
#      gain to 2.0, x' = 2.0 (15.5 - x), and locks mid-fill to the boost profile
#      (gain 1.0; the deployed controller has a single Mid profile).
#   Levels whose reading is below the interlock threshold (x_L < 5, i.e. a reading below
#   2) are outside the model: the deployed controller has no dry-run mode, and its Low
#   floor 5 = 2 + 3 is the nominal interlock threshold shifted by the offset. Every left
#   mode has a satisfiable start (x_R = x_L - 3 is in the right's Low, Mid or High guard).
#
# CLAIM (two rows per mode): |x_L - x_R| <= 3, i.e. x_L <= x_R + 3 and x_R <= x_L + 3 in
# every left mode: the true levels of the deployed and the reference tank never differ
# by more than the sensor offset. Requirement: the attack may not move the true level by more
# than the offset the operator already tolerates in the sensor. The tolerance 3 IS the offset,
# and the first row is tight: with x_L <= x_R + c the benchmark certifies down to c = 3.00
# (2.99 declines; bisection, both rows or the first alone). Why (derived from the model): on
# the boundary x_L = x_R + 3 the deployed Low field is 2.0 (15.5 - x_L) = 2.0 (12.5 - x_R),
# exactly the nominal Low field run at speed ratio 2, so the gap is neutral there (zero Lie
# derivative), not contracting; the same holds for Mid against MidEco at ratio 2 and against
# MidBoost at ratio 1. The second row is slack: alone it certifies down to x_R <= x_L + 1.50
# (1.49 declines); the claim keeps the symmetric offset band. Not implied by the domains.
#
# DOMAIN: the tank capacity, 0 <= x <= 25, identical in every mode on both sides. No
# certificate stands on it: widened to x <= 60 (and to -60 <= x <= 60) the benchmark
# still CERTIFIES (measured).
#
# Why stretching (S). The tampered Low pump runs at twice the nominal Low gain and the deployed
# Mid at twice MidEco's: only lambda = 2 matches them (RELCERT_SYNC=1: DECLINED).
# Branching (B). A joint step from the nominal Low retains BOTH MidEco and MidBoost, and both
# cover: MidEco passes only at lambda = 2, MidBoost at every grid point from 1 (the per-lambda
# segment rows of RELCERT_DEBUG=1 for the deployed Mid).
# Pruning (not load-bearing). Low -> PumpOff is pruned (the nominal Low flow from its entry
# x >= 2 never reaches x < 2). RELCERT_NO_PRUNE=1 alone CERTIFIES: the existential choice closes
# the same fallback (the reference commits to the successor that covers); only with
# RELCERT_NO_PRUNE=1 and RELCERT_NO_CHOICE=1 together is it DECLINED (the deployed Low window
# cannot cover a reference latched in PumpOff). The deployed floor 5 = 2 + 3 keeps PumpOff out
# of the admissible starts for the deployed Low.
# Cuts (not load-bearing). The set-point atoms x <= c are kept as cuts (deployed Low x <= 15.5,
# an implied contraction atom; deployed Mid x <= 20, nominal MidEco / MidBoost x <= 17, the
# closures of the strict guard caps; nominal Low x <= 12.5, implied), but RELCERT_NO_CUT=1,
# RELCERT_NO_IMPLIED_CUT=1 and RELCERT_NO_LINEAR_CUT=1 all CERTIFY: the per-pairing stretch
# recovers what the cut-narrowed domains gave. The cuts are load-bearing in watertank_twospeed.
#
# Verdicts (RELCERT_IMPLIED_CUT=1 unless stated, measured 2026-10-26): CERTIFIED; CERTIFIED
# under RELCERT_NO_CHOICE=1, RELCERT_NO_PRUNE=1, RELCERT_NO_CUT=1, RELCERT_OPREGION=1 and
# without RELCERT_IMPLIED_CUT; DECLINED under RELCERT_SYNC=1, RELCERT_SYNC=1 RELCERT_NO_CHOICE=1
# and RELCERT_NO_PRUNE=1 RELCERT_NO_CHOICE=1. Cover (joint segments only, no reposition): Low
# and Mid at lambda 2, budget 2 (admissible starts Low, MidEco, MidBoost resp. MidEco, MidBoost,
# High); High at lambda 1, budget 1. Rows identical (--handoff vacuous, 6/6). relcert
# --wellformed: Low ok (exit), MidEco, MidBoost, High, PumpOff ok (invariant).
[problem]
name = watertank
max_depth = 8
lambda_min = 1.0
lambda_max = 6.0
bound_T = 40.0

[Lsys]
state_vars = [x]
epsilon = 1.0

[Lsys.mode.Low]
ode = x' = smt2:(* 2.0 (- 15.5 x));
guard = x >= 5.0 and x < 13.0
evolve = x >= 0.0 and x <= 25.0
next = [Low, Mid]

[Lsys.mode.Mid]
ode = x' = smt2:(* 1.0 (- 20.0 x));
guard = x >= 13.0 and x < 20.0
evolve = x >= 0.0 and x <= 25.0
next = [Mid, High]

[Lsys.mode.High]
ode = x' = smt2:(* 1.0 (- 20.0 x));
guard = x >= 20.0
evolve = x >= 0.0 and x <= 25.0
next = [High, Mid]

[Rsys]
state_vars = [x]
epsilon = 1.0

[Rsys.mode.Low]
ode = x' = smt2:(* 1.0 (- 12.5 x));
guard = x >= 2.0 and x < 10.0
evolve = x >= 0.0 and x <= 25.0
next = [Low, MidEco, MidBoost, PumpOff]

[Rsys.mode.MidEco]
ode = x' = smt2:(* 0.5 (- 17.0 x));
guard = x >= 10.0 and x < 17.0
evolve = x >= 0.0 and x <= 25.0
next = [MidEco, MidBoost, High]

[Rsys.mode.MidBoost]
ode = x' = smt2:(* 1.0 (- 17.0 x));
guard = x >= 10.0 and x < 17.0
evolve = x >= 0.0 and x <= 25.0
next = [MidBoost, MidEco, High]

[Rsys.mode.High]
ode = x' = smt2:(* 1.0 (- 17.0 x));
guard = x >= 17.0
evolve = x >= 0.0 and x <= 25.0
next = [High, MidEco, MidBoost]

[Rsys.mode.PumpOff]
ode = x' = smt2:0.0;
guard = x < 2.0
evolve = x >= 0.0 and x <= 25.0
next = [PumpOff]

[relational_invariant]
Low  = x[l] <= x[r] + 3 and x[r] <= x[l] + 3
Mid  = x[l] <= x[r] + 3 and x[r] <= x[l] + 3
High = x[l] <= x[r] + 3 and x[r] <= x[l] + 3
