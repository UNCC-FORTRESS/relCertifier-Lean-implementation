# watertank_twospeed: the running example's attacked tank against a nominal controller whose
# low-fill pump has two speeds.
# scenario: sensor-attack
# mechanisms: S M B P (per-pairing time stretch, RELCERT_SYNC=1 declines; two right segments
#   per deployed window; branching joint steps; pruned dry-run edge, RELCERT_NO_PRUNE=1
#   declines; matrix codes M1 M2 M3 M4)
#
# Round A (2026-10-26): the claim is now the same in every mode (x_L <= x_R + 3, x_R <= x_L + 2).
# The previous rows (+8 overflow margin in Mid and High) were looser than this uniform claim,
# which also certifies, so their mode dependence (D) was not load-bearing; with the tighter
# uniform rows the implied cuts are no longer needed either (I lost). Letters were S M B P D I.
#
# THE PLANT (both sides, as in watertank). A tank of capacity 25 (level x in dm, a 2.5 m tank;
# time in minutes); every mode is a proportional pump controller x' = k (c - x) toward a set
# point c.
# NOMINAL controller (right). The running example's reference with its low-fill pump staged in
# two speeds:
#   PumpOff  x < 2          x' = 0               dry-run interlock below the 2 dm intake, latched
#                                                 (a sink)
#   Fast     2 <= x < 7     x' = 2.0 (12.5 - x)  low fill at full speed
#   Slow     7 <= x < 10    x' = 1.0 (12.5 - x)  low fill at half speed near the set point (the
#                                                 running example's nominal Low)
#   MidEco   10 <= x < 17   x' = 0.5 (17 - x)    } mid fill, two selectable profiles, switchable
#   MidBoost 10 <= x < 17   x' = 1.0 (17 - x)    } at any time (as in watertank)
#   High     x >= 17        x' = 1.0 (17 - x)    regulate down to 17
# The right guards partition [0, 25] (no coverage gap). Successor sets are complete for one
# 1-min period: Fast can reach the mid band (from just below 7 it reaches 11.76), so its
# successors are Fast, Slow, MidEco, MidBoost and the interlock PumpOff; Slow: Slow, MidEco,
# MidBoost.
# DEPLOYED controller (left) = the running example's attacked controller, unchanged:
#   Low  5 <= x < 13   x' = 2.0 (15.5 - x)    Mid  13 <= x < 20  x' = 1.0 (20 - x)
#   High x >= 20       x' = 1.0 (20 - x)
# ONE CAUSE, the attack of the running example (one adversary on two channels): the level
# sensor reads s = 3 dm low (every threshold and set point is 3 dm higher in true level; the
# low-fill floor 5 is the nominal interlock 2 seen through the offset), and the pump is forced to
# its full speed for the whole low fill (gain 2.0 where the nominal drops to half speed) and to
# the boost profile in mid fill. Levels whose reading is below the interlock (x_L < 5) are
# outside the model (no deployed dry-run mode), as in watertank. Every left mode has a
# satisfiable start (x_R = x_L - 3 is in Fast/Slow, MidEco/MidBoost resp. High).
#
# CLAIM (every left mode): x_L <= x_R + 3 and x_R <= x_L + 2, each constant a margin of the tank:
#   3 = the sensor offset = the dry-run interlock margin of the low fill (deployed floor 5 minus
#     the interlock 2): a filling deployed tank is matched by a reference whose pump runs
#     (x_R >= x_L - 3 >= 2), never by one latched in PumpOff; and the overflow margin: every
#     reference run from x <= 22 stays at or below 22 (all set points <= 17), so the deployed
#     stays at or below the 25 dm lip.
#   2 = underflow margin, the reference's interlock level 2 above the tank floor: while the
#     reference runs (x_R >= 2), the deployed tank is not empty.
# Not implied by the domains. Rows identical in every mode (--handoff vacuous, 6/6).
# Tightest (bisection to 0.01, measured): upper exactly 3.00 (2.99 and 3.01 DECLINE: on the
# boundary x_L = x_R + 3 the deployed field 2.0 (12.5 - x_R) equals Fast's at lambda 1 and Slow's
# at lambda 2, neutral; above 3 a reference latched in PumpOff becomes admissible); lower 1.50
# (1.49 DECLINES): a reference already in mid fill (set point 17) against a deployed still in
# low fill (target 15.5), 17 - 15.5.
# Cause dependence (measured; sensor offset s with every deployed threshold and set point s higher,
# the forced full speed kept): the tightest pair is (upper, lower) = (s, 4.5 - s): s = 0: upper 0
# (0.01 declines), lower 4.50 (4.49 declines); s = 1: lower 3.50; s = 2: upper 2 (1.99 declines),
# lower 2.50; s = 3 (this file): 3, 1.50; s = 4: upper 4 (3.99 declines), lower 0.50 (0.49
# declines). The upper bound is the offset and the lower bound shrinks as the offset grows.
# An arbitrary left schedule (every left mode on the whole range [5, 25], every mode a successor of
# every other): DECLINED.
#
# Why per-pairing stretch (S). The deployed low fill pairs with Fast at lambda 1 (same gain),
# Slow at 2 (gain ratio), MidEco at 3/2, MidBoost and High at 1; no single stretch covers all and
# the deployed window needs Fast and Slow (a reference starting in Fast crosses 7 within it):
# RELCERT_SYNC=1 and RELCERT_NO_PAIR_STRETCH=1 DECLINE. The per-pairing fallback cuts each
# joint segment to eps_R / 2 of left time, budget 2 (M); a joint step from Fast retains Slow,
# MidEco and MidBoost (B, branching 3; branching 2 in Mid).
# Why pruning (P). Fast -> PumpOff is pruned (Fast flows up from its floor 2). Under
# RELCERT_NO_PRUNE=1 the PumpOff segment fails at every stretch (a latched reference against a
# filling deployed tank) and the existential choice does not replace it in the per-pairing
# cover: DECLINED. This is the running example's dead dry-run edge (the source mode's flow never
# reaches the sink).
#
# DOMAIN: the tank capacity, 0 <= x <= 25, identical in every mode on both sides.
#
# Verdicts (RELCERT_IMPLIED_CUT=1 unless stated, measured 2026-10-26 with the round-A binary):
# CERTIFIED (about 2 s); CERTIFIED under RELCERT_NO_CHOICE=1, RELCERT_NO_CUT=1,
# RELCERT_NO_IMPLIED_CUT=1, RELCERT_NO_LINEAR_CUT=1, without RELCERT_IMPLIED_CUT,
# RELCERT_WELLFORMED_STRICT=1 and RELCERT_OPREGION=1 (every admitted start in some right guard,
# all three left modes); DECLINED under RELCERT_SYNC=1, SYNC+NO_CHOICE, RELCERT_NO_PRUNE=1,
# NO_PRUNE+NO_CHOICE and RELCERT_NO_PAIR_STRETCH=1. Covers: Low per pairing (Fast 1, Slow 2,
# MidEco 3/2, MidBoost 1, High 1; reported lambda 2), budget 2, admissible Fast, Slow, MidEco,
# MidBoost; Mid lambda 2, budget 2, admissible MidEco, MidBoost, High; High lambda 1, budget 1,
# admissible High. Pruned Fast -> PumpOff. relcert --wellformed: Fast ok (exit), Slow ok (exit),
# MidEco, MidBoost, High, PumpOff ok (invariant), 0 UNKNOWN.
[problem]
name = watertank_twospeed
max_depth = 8
lambda_min = 1.0
lambda_max = 6.0
bound_T = 40.0

[Lsys]
state_vars = [x]
epsilon = 1.0

[Lsys.mode.Low]
ode = x' = smt2:(* 2.0 (- 15.5 x));
guard = x >= 5.0 and x < 13.0
evolve = x >= 0.0 and x <= 25.0
next = [Low, Mid]

[Lsys.mode.Mid]
ode = x' = smt2:(* 1.0 (- 20.0 x));
guard = x >= 13.0 and x < 20.0
evolve = x >= 0.0 and x <= 25.0
next = [Mid, High]

[Lsys.mode.High]
ode = x' = smt2:(* 1.0 (- 20.0 x));
guard = x >= 20.0
evolve = x >= 0.0 and x <= 25.0
next = [High, Mid]

[Rsys]
state_vars = [x]
epsilon = 1.0

[Rsys.mode.Fast]
ode = x' = smt2:(* 2.0 (- 12.5 x));
guard = x >= 2.0 and x < 7.0
evolve = x >= 0.0 and x <= 25.0
next = [Fast, Slow, MidEco, MidBoost, PumpOff]

[Rsys.mode.Slow]
ode = x' = smt2:(* 1.0 (- 12.5 x));
guard = x >= 7.0 and x < 10.0
evolve = x >= 0.0 and x <= 25.0
next = [Slow, MidEco, MidBoost]

[Rsys.mode.MidEco]
ode = x' = smt2:(* 0.5 (- 17.0 x));
guard = x >= 10.0 and x < 17.0
evolve = x >= 0.0 and x <= 25.0
next = [MidEco, MidBoost, High]

[Rsys.mode.MidBoost]
ode = x' = smt2:(* 1.0 (- 17.0 x));
guard = x >= 10.0 and x < 17.0
evolve = x >= 0.0 and x <= 25.0
next = [MidBoost, MidEco, High]

[Rsys.mode.High]
ode = x' = smt2:(* 1.0 (- 17.0 x));
guard = x >= 17.0
evolve = x >= 0.0 and x <= 25.0
next = [High, MidEco, MidBoost]

[Rsys.mode.PumpOff]
ode = x' = smt2:0.0;
guard = x < 2.0
evolve = x >= 0.0 and x <= 25.0
next = [PumpOff]

[relational_invariant]
Low = x[l] <= x[r] + 3 and x[r] <= x[l] + 2
Mid = x[l] <= x[r] + 3 and x[r] <= x[l] + 2
High = x[l] <= x[r] + 3 and x[r] <= x[l] + 2
